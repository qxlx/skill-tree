# 樊登读书

# 企业进化论

### 8大方法论，破解企业成长难题

------

### 1. 整体适配论

- 政治：企业的动力源
  - 治理结构、利益机制，权力分配
- 经济：企业持续稳定增长的基石
  - 战略，商业模式，流程
- 文化：企业成长的土壤
  - 愿景和使命，价值观，行为规范

------

### 2. 因果链论

- 战略方程式：Y = f(x1, x2, x3…)
  - Y：目标
  - x：达成目标的关键成功要素
  - f：若干关键成功要素组合
  - 原则：从目标出发解构问题，区分真问题和伪问题

------

### 3. 战略推演论

- 取势：基于未来思考现在
  - 在众多趋势中，找到自己应该做的和不应该做的
- 明道：让知与行更加统一
  - 找到具体的路径，找到达成目标的关键成功要素和目标之间的连接
- 优术：搭起战略与执行的桥梁
  - 不断优化战略，明确关键绩效指标

------

### 4. 经营循环论

- PDCA循环
  - Plan（计划）：做好战略规划
  - Do（执行）：企业经营链条
  - Check（检查）：绩效回顾
  - Act（处理）：校正与纠偏
- 伟大的企业要做好五道题
  - 信仰题；哲学题；语文题；数学题；能力题

------

### 5. 管理循环论

- 四位一体的管理循环
  - 机制牵引，体制保证，文化导向，能力支撑
- 企业是一个有机体
  - 体制相当于人体的骨骼，机制相当于神经系统，文化相当于气血，能力相当于肌肉

------

### 6. 变革论

- “没有成功的企业，只有时代的企业”
- 变革是发展的必然，是永恒的主题，是不断向上跃迁的动力。只有持续不断地变革，企业才能在复杂多变的商业环境中一直活下去

------

### 7. 齿轮论

- 企业运作应该是小齿轮带动大齿轮
- 让员工当责的重要条件
  - 有员工当责的文化，激发员工的使命感
  - 有员工当责的文化，比如成立齿轮组
  - 优秀氛围的激励，比如表彰"齿轮"

------

### 8. 组织领导力论

- 领导力的基本原则
  - 集众人之智：集群体的智慧
  - 借众人之治：大家共同治理
  - 达众人之志：共享愿景，共享利益
