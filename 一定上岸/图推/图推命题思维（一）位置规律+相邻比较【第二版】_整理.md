## 一、了解"出题形式"

> 不同的出题形式，有不同的观察角度

### 图形推理的出题形式

| 出题形式 | 出题者喜好 |
|----------|-----------|
| **一组图** | 共同的特点，数量有关（恒定、等差、周期） |
| **两组图** | 共同的特点（左右可以分开看），数量有关（恒定、等差、运算） |
| **九宫格** | 共同的特点（每排或每列可以分开看），数量有关（恒定、等差、运算） |
| **分组分类** | ①两种规律（优先考虑）②有规律和没规律（新趋势-属性规律出现多） |
| **空间类** | 四面体、多面体、三视图、截面图、平面拼合、立体拼合等 |

### 数量中的数字规律

| 规律类型 | 说明 |
|----------|------|
| **等差** | 数字呈等差数列 |
| **恒定** | 数字保持不变 |
| **周期** | 数字呈周期性重复 |
| **运算** | 数字之间存在运算关系（较少） |

### 各出题形式出题者喜好汇总

| 出题形式 | 出题者喜好 |
|----------|-----------|
| **一组图（平移）** | 平移、相邻比较不出"分组分类" |
| **两组图** | 样式以"两组图""九宫格"为主 |
| **九宫格** | 喜欢"运算" |
| **空间类** | 较少出现 |
| **分组分类** | 较少出现 |

## 二、了解"作图特点"

> 作图特点，决定大方向

### 图推分类总览

| 分类 | 说明 |
|------|------|
| **有相同的图案** | 位置、样式、标记 |
| **无相同的图案** | 属性、数量、图形间位置 |

### "3+3"背诵版

**有一样的图案（3类）：**

| 类别 | 子分类 | 具体内容 |
|------|--------|---------|
| **完全一样** | 【1】位置 | 平移、旋转/翻转 |
| **部分一样** | 【2】样式（运算） | 黑白运算、加减同异 |
| | 【3】标记 | 标记 |

**没有一样的图案（3类）：**

| 类别 | 具体内容 |
|------|---------|
| **【1】属性** | 对称性、曲直性、开闭性 |
| **【2】数量** | 面（所有、大小、相同→框内面）、笔画、点（曲直交点、切点、框点）、线（曲直、横竖、框；平行线、贪吃蛇）、元素、直角 |
| **【3】图形间位置** | 图形间位置 |

> **注意**：**相邻比较**属于位置规律的延伸考点。

## 三、考点：位置规律

### 【理论速记】

> **理解为主，红色部分均为重点**

1. **命题者作图特点**：每幅图 **图案完全一样**。
2. **特殊情况**：**图案移动过程，在重合情况下**，图案数量会减少。
3. **考点**：（1）平移；（2）旋转、翻转。

---

## 四、考点一：平移

### 【理论速记】

1. 确定"平移"后，第一步先观察 **内部** 是否有规律。
2. 内部 **有规律**，考虑内外分开看。运动方向：**绕圈（顺/逆时针）**。
3. 内部 **无规律**，考虑常规平移。运动方向：**直线（上下、左右、斜对角线）**，且方向可变。
   - （1）"定方向"技巧：① **大面积图案**；② **数个数**。
   - （2）"走到头"后：① **循环走**；② **反弹**。
4. 运动步数：**恒定、递增** 为主。

### 【实战思维】

> **背诵为主，红色部分均为重点**

| 位置规律 | 子分类 | 要点 |
|----------|--------|------|
| **平移** | 内部有规律 | —— **内外分开看** |
| | 内部无规律 | —— **常规平移**：上下左右、斜着运动（方向可变）；技巧：① **特殊图案（大区域）** ② **数个数** |
| **旋转/翻转** | | 技巧：① **特殊图案（大区域）** ② **时针法、箭头法** |
| **相邻比较** | | ① **有黑块不动** ② **平移没规律** |

### 【答题思路】

① 确定"平移"后，第一步先观察内部是否有规律。

② 内部有规律，考虑内外分开看。运动方向：绕圈（顺/逆时针）。

③ 内部无规律，考虑常规平移。运动方向：直线（上下、左右、斜对角线），且方向可变。

### 如何确定移动的"方向"？

**（一）特殊图案（大区域）**

**（二）数个数**

- 横向黑块数量相同 → **横向运动**
- 纵向黑块数量相同 → **纵向运动**

### "走到头"出题者可以怎么出？

① **循环走**：从头开始

② **反弹走**：直接弹回

### 破解出题者"小心思"——加密与解密

**加密：** 图形经过特殊处理（如宫格拆分、隐藏线条等）

**解密：** 拆分思维，就近假设

## 五、考点：平移（基础）

### 实战例题思路

**例题1（25国考-88%）**

- 思维：**就近原则**
- 圆形：**顺时针3步**
- 正方形：**逆时针3步**

**思维技巧：**

- **就近原则**：相邻图形之间找规律
- **跳着看**：隔一个图形看规律

### 破解出题者"小心思"——16宫格

**加密：** 16宫格中的图形被加密处理

**解密：** **"内外分开看"** 思维

- 16宫格 → **拆分2部分**

### 破解出题者"小心思"——蜂窝类

**加密：** 蜂窝状图形

**解密：** 同"16宫格" → **内外分开看**

- 横向
- 左斜
- 右斜

### 实战例题思路

**例题2（25广东-86%）**

- 思维：**内外分开看**
- 小球都在动
  - 2：**顺时针1步**
  - 3：**逆时针1步**

### "走到头"的两种运动方式

① **循环走**：从头开始

② **反弹走**：直接弹回

### 平移基础小结

- **思维：就近原则**
- **思维：跳着看**
- **思维：内外分开看**
- **思维：个数定方向**
- **思维：循环走**
- **思维：特殊图案（大区域）**
- **思维：方向可变**

## 九、考点：旋转、翻转（基础）

### 【理论速记】

**考点二：旋转**

1. **方向**：① **顺时针** ② **逆时针**
2. **步数（角度）**：**30°、45°、60°、90°、180°**（高频）

### 如何区分旋转、翻转？

| 类型 | 变化特点 |
|------|---------|
| **180°旋转** | 上、下、左、右 **都变** |
| **左右翻转** | 只变 **左右** |
| **上下翻转** | 只变 **上下** |

> **口诀：怎么变，怎么翻，全变就是180°**

### 实战例题思路

**例题13（25山东事业-96%）**

- 外圈缺口：**顺时针90°**
- 内圈缺口：**左右翻转**

**例题14（25联考-84%）**

- 思维：**4个都动 → 对比选项**

**例题15（24江苏-62%）**

- 思维：**特殊图案（尖角）**
- 思维：**学会"偷懒"**

**例题16（23联考事业-60%）**

- 思维：**箭头法（找唯一，定方向）**
- 思维：**时针法（同一起点，同一路径，同一终点）**
- 思维：**黑球不好看 → 看白色**

### 旋转、翻转小结

- **思维：特殊图案**
- **思维：旋转、翻转**
- **思维：对比选项**
- **思维：时针法、箭头法**

## 十、位置规律·总结

### 【位置规律】

① 命题者作图特点：**每幅图图案完全一样**。

② 特殊情况：图案移动过程，在重合情况下，**图案数量会减少**。

③ 考点：**1.平移 2.旋转、翻转**

### 【平移】

① 确定"平移"后，第一步先观察内部是否有规律。

② 内部有规律，考虑 **内外分开看**。运动方向：**绕圈（顺/逆时针）**。

③ 内部无规律，考虑 **常规平移**。运动方向：**直线（上下、左右、斜对角线）**，且方向可变。

- （一）"定方向"技巧：1.**大面积图案** 2.**数个数**
- （二）"走到头"后：1.**循环走** 2.**反弹走**

④ 运动步数：**恒定、递增** 为主。

### 【旋转、翻转】

① 旋转：
- 方向：**顺时针、逆时针**
- 角度：**30°、45°、60°、90°、180°** 等常见角度

② 翻转：
- 左右翻转：图形沿竖轴对称
- 上下翻转：图形沿横轴对称

③ 技巧：1.**特殊图案（大区域）** 2.**时针法、箭头法**

### 【相邻比较】

命题者作图特点：

1. **有黑块不动**
2. **平移没规律**
