## 二、传统节日

### （一）中国四大传统节日

#### 1. 春节（元日、元旦）

- **时间**：农历正月初一
- **习俗**：拜年、放爆竹、贴年红、舞龙舞狮、祭祀、走亲访友等。
- **其他相关**：
  - **腊八**：农历腊月初八，习俗是喝腊八粥。
  - **小年**：农历腊月二十三，在民间是祭祀灶神的日子，习俗有祭灶、吃灶糖。
  - **除夕**：岁末最后一天晚上，习俗有吃团圆饭、守岁、祭祖等。

#### 2. 清明节（踏青节）

- **时间**：4月5日前后
- **习俗**：禁火寒食、扫墓踏青、插柳带花、荡秋千、蹴鞠、放风筝、拔河、打马球等。
- **其他相关**：
  - 是我国**第一个转变为节日的节气**（第二个为2018年设定的中国农民丰收节）。
  - 其中**禁火寒食**源于寒食节，因两节日临近，习俗也逐渐合二为一。
  - **寒食**：一般在冬至后的105天或106天，清明前一、二日，相传是为了纪念**介子推**。

#### 3. 端午节

- **时间**：农历五月初五
- **习俗**：悬钟馗像，挂艾叶、菖蒲，斗百草、驱五毒，赛龙舟，吃粽子，饮雄黄酒，佩香囊。
- **其他相关**：
  - **中国首个入选世界非物质文化遗产的传统节日**。
  - 一般认为，端午是为了纪念**屈原**。

#### 4. 中秋节（仲秋节、团圆节）

- **时间**：农历八月十五
- **习俗**：燃灯、吃月饼、观潮、赏桂花、设宴、祭月等。
- **其他相关**：
  - **月饼**最早是用来祭月的祭品，最初起源于**唐朝军队祝捷食品**。
  - "月饼"一词最早见于南宋吴自牧《梦梁录》中。
  - 有一种说法是，中秋吃月饼与**朱元璋反抗元朝**有关。

### （二）中国其他传统节日

- **元宵节**：农历正月十五，古时又名"元夕""上元""灯节""元夜"等。主要习俗有赏花灯、闹年鼓、迎厕神、猜灯谜等。**元宵节吃元宵的最早记载见于宋代**。

- **重阳节**：农历九月九日，又名"**老人节**"。主要习俗有登高、插茱萸、饮菊花酒、吃重阳糕、观赏菊花等。

- **中和节**：农历二月二，俗称"**龙抬头**"，主要习俗有熏虫儿、剃头、引龙回、吃龙耳（水饺）、吃龙鳞（春饼）、吃龙须（面条）、不动针线、以蜡烛照房子墙壁。

- **乞巧节**：农历七月初七夜，又称七巧节、七姐节、女儿节、七娘会、七夕祭、巧夕等，是传说中**牛郎织女每年相会**的日子。主要习俗有拜七姐、祈福许愿、乞求巧艺、看牵牛织女星、祈祷姻缘、储七夕水等。

- **中元节**：农历七月十五，是传说中**地官的生日**，所以又称"**鬼节**"。佛教徒这天要设"盂兰盆"，施斋供僧，举行诵经法会、放河灯等宗教活动。

### 传统节日诗词

- **春节**：桃符呵笔写，椒酒过花斜；风吹旷野纸钱飞，古墓垒垒春草绿。
- **中秋节**：未必素娥无怅恨，玉蟾清冷桂花孤。
- **元宵节**：东风夜放花千树；蓦然回首，那人却在灯火阑珊处。
- **七夕节**：天阶夜色凉如水，坐看牵牛织女星。
- **元宵节**：火树银花合，星桥铁锁开，金吾不禁夜，玉漏莫相催。
- **中秋节**：暮云收尽溢清寒，银汉无声转玉盘。
- **寒食节**：雨中禁火空斋冷，江上流莺独坐听。
- **端午节**：莫唱江南古调，怨抑难招，楚江沉魄。
- **上巳节**：三月三日天气新，长安水边多丽人。

## 三、礼俗

### 三礼

包括《周礼》《仪礼》《礼记》，标志着**礼仪发展的成熟阶段**。

### 五礼

**吉礼、嘉礼、宾礼、军礼、凶礼**。

### 太牢

古代帝王祭祀社稷时，牛、羊、豕(shǐ)（猪）三牲全备为"**太牢**"。

### 少牢

古代诸侯、卿大夫祭祀宗庙时，烹用羊、豕，叫作"**少牢**"。

### 成人礼

**男子二十而冠，女子十五而笄**。

### 丧礼等级

**天子死曰崩，诸侯曰薨，大夫曰卒，士曰不禄，庶人曰死**。

## 四、饮食

### 烹饪方式

- **焗**：利用蒸汽使密闭容器中的食物变熟。
- **烩**：把饭和各种菜混合在一起烹煮。
- **五香**通常指**茴香、花椒、八角、桂皮、丁香**。
- **五味**《礼记》中的"五味"是指"**酸、苦、辛、咸、甘**"。

### 菜系

- **四大菜系**：**鲁菜、川菜、粤菜、淮扬菜（苏菜）**。
- **八大菜系**：**鲁菜、川菜、粤菜、苏菜、浙菜、闽菜、湘菜、徽菜**。

| 菜系 | 代表菜品 |
|------|----------|
| **鲁菜代表** | 九转大肠、清汤燕窝、烤大虾、阳关三叠、一品豆腐、拔丝山药、葱烧海参 |
| **川菜代表** | 鱼香肉丝、宫保鸡丁、夫妻肺片、麻婆豆腐、回锅肉、东坡肘子 |
| **粤菜代表** | 白切鸡、蜜汁叉烧、烤乳猪、盐焗鸡、烧鹅、梅菜扣肉 |
| **淮扬菜代表** | 松鼠桂鱼、三套鸭、清炖蟹粉狮子头 |
| **闽菜代表** | 佛跳墙、荔枝肉 |
| **湘菜代表** | 剁椒鱼头 |
| **京菜代表** | 涮羊肉、烤鸭 |
| **东北菜代表** | 小鸡炖蘑菇、锅包肉、熘肉段 |

### 茶

- **起源**：**世界饮茶发源于中国**，三国以后，饮茶之风开始盛行。
- **陆羽**：唐代陆羽被称为**茶圣、茶仙**，他所著《茶经》是我国**最早的茶叶专著**。

#### 茶的种类

| 茶类 | 发酵类型 | 代表 |
|------|----------|------|
| **绿茶** | 不发酵 | 黄山毛峰（安徽）、六安瓜片（安徽）、龙井茶（浙江）、碧螺春（江苏） |
| **红茶** | 全发酵 | 祁门红茶（安徽）、正山小种 |
| **白茶** | 轻度发酵 | 白毫银针、白牡丹、寿眉 |
| **黄茶** | 微发酵 | 君山银针（湖南）、蒙顶黄芽（四川） |
| **青茶（乌龙茶）** | 半发酵 | 铁观音（福建）、大红袍（福建） |
| **黑茶** | 后发酵 | 普洱茶（云南） |

### 酒

- **世界三大蒸馏酒**：**法国的科涅克白兰地、英国的苏格兰威士忌、中国贵州的茅台**。
- **杜康**：杜康是中国古代传说中的"**酿酒始祖**"，被誉为"**酒圣**"。因杜康善酿酒，后世将杜康尊为**酒神**，制酒业则奉杜康为**祖师爷**。后世多以"**杜康**"借指酒。
- **饮中八仙**：**贺知章、李琎(jīn)、李适之、崔宗之、苏晋、李白、张旭、焦遂**。

> 知章骑马似乘船，眼花落井水底眠。
> 宗之潇洒美少年，举觞白眼望青天，皎如玉树临风前。
> 天子呼来不上船，自称臣是酒中仙。

## 五、建筑

### 1. 典型建筑风格

| 建筑风格 | 特点 | 代表建筑 |
|----------|------|----------|
| **宫殿建筑** | 一般建筑采取中轴对称的布局方式，由台基、柱框与墙身、屋顶三大部分组成。宫殿建筑多以庑殿顶、歇山顶为主。 | 北京故宫、曲阜孔庙大成殿、泰山岱庙、布达拉宫（政教合一） |
| **民居建筑** | 中国疆域辽阔、各地民居建筑形式多种多样。 | 北京四合院、西北窑洞、闽南红砖厝、客家土楼、湘西吊脚楼、广东碉楼 |
| **园林建筑** | 园林中供人们游憩或观赏用的建筑，分为私家园林、皇家园林、寺庙园林等。 | 颐和园、圆明园、避暑山庄、留园、拙政园 |
| **陵墓建筑** | 中国古代建筑的重要组成部分。 | 秦始皇陵、明十三陵、霸陵 |
| **宗教建筑** | 主要包括佛教、喇嘛教、伊斯兰教、道教等。 | 洛阳白马寺、四大石窟、清真寺、太清宫、上清宫 |
| **设施建筑** | 按照功能不同，可分为军事防御设施、水利设施和交通水运设施等。 | 长城、嘉峪关、山海关、都江堰、赵州桥、大运河、卢沟桥 |

### 2. 著名建筑

#### 北京故宫

位于北京市中心，又称**紫禁城**，明、清两代皇宫，是**世界上现存规模最大、最完整的古代木构建筑群**，被誉为**世界五大宫之首**。故宫于明成祖永乐四年（1406年）开始建设，以南京故宫为蓝本营建，紫禁城内的建筑分为**外朝**和**内廷**两部分。**外朝**的中心为**太和殿、中和殿、保和殿**，统称**三大殿**。**内廷**的中心是**乾清宫、交泰殿、坤宁宫**，统称**后三宫**。

#### 秦始皇陵

位于陕西省西安市临潼区城东骊山北麓，是我国**第一位封建王朝皇帝嬴政**的陵墓，建于秦王政元年（前247年）至秦二世二年（前208年），历时39年，是我国**历史上第一座规模庞大、设计完善的帝王陵寝**。

#### 布达拉宫

位于西藏自治区首府拉萨市区西北玛布日山上，是**藏王松赞干布为文成公主而建**，是**世界上海拔最高**，集宫殿、城堡、寺院于一体的宏伟建筑，也是**西藏最庞大、最完整的古代宫堡建筑群**。

#### 中国四大名园

**江苏苏州拙政园、北京颐和园、河北承德避暑山庄（世界现存最大的皇家园林）、江苏苏州留园**。

- **圆明园**：位于北京西北郊，清代一座大型皇家宫苑，有"**万园之园**"之称。
- **颐和园**：位于北京西郊，前身为清漪园，是我国**现今保存最完整的一座皇家行宫御苑**，被誉为"**皇家园林博物馆**"。
  - 颐和园是以昆明湖、万寿山为基址，以杭州西湖风景为蓝本，以佛香阁为构图中心，汲取江南园林的某些设计手法和意境而建成的一座大型天然山水园。
- **留园**：全园分为四个部分，同一个园林中能分别领略到山水、田园、山林、庭园四种不同景色：中部以水景见长，是全园的精华所在；东部以曲院回廊的建筑取胜；北部具农村风光，并有新辟盆景园；西区则是全园最高处，有野趣，以假山为奇，土石相间，堆砌自然。**全园最大的特色就是在有限的空间里面，营造出多种多样、层次丰富的意境**。
- **拙政园(中园)**：中园是拙政园的主景区，面积约8.5亩。它以水池为中心，亭台楼榭皆临水而建，有的亭榭则直出水中，具有江南水乡的特色。总的格局也依然保持着明代园林浑厚、质朴、疏朗的艺术风格。
- **承德避暑山庄**：它始建于1703年，历经清朝三代皇帝——康熙、雍正、乾隆耗时八十九年建成。拥有殿、堂、楼、馆、亭、榭、阁、轩、斋、寺等建筑一百余处。**它的最大特色是山中有园，园中有山**。与北京紫禁城相比，避暑山庄以朴素淡雅的山村野趣为格调，取自然山水之本色，吸收江南塞北之风光，成为**中国现存占地最大的古代帝王宫苑**。

#### 四大名窟

**敦煌莫高石窟、大同云冈石窟、洛阳龙门石窟、天水麦积山石窟**。

- **敦煌莫高石窟**——位于河西走廊西端的甘肃敦煌，俗称千佛洞，是**世界上现存规模最宏大、历史最长久、内容最丰富、保存最完好的佛教石窟艺术宝库**，被誉为"**东方艺术明珠**"。
- **洛阳龙门石窟**——位于河南洛阳市洛龙区伊河两岸的龙门山与香山上，佛教圣地，是我国**石刻艺术宝库之一**。

#### 中国佛教四大名山

**山西五台山、浙江普陀山、四川峨眉山、安徽九华山**，分别是**文殊菩萨、观世音菩萨、普贤菩萨、地藏菩萨**的道场。

#### 洛阳白马寺

位于河南省洛阳市老城以东，创建于东汉永平十一年（公元68年），是**佛教传入中国后兴建的第一座官办寺院**，有中国佛教的"**祖庭**""释源**"之称。

#### 中国古代四大书院

**应天书院**（河南商丘）、**岳麓书院**（湖南长沙）、**白鹿洞书院**（江西庐山）、**嵩阳书院**（河南登封）。
