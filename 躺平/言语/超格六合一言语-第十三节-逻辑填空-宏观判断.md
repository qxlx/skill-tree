# 第十三节 逻辑填空——宏观判断

> 来源：超格六合一言语-第十三节-逻辑填空-宏观判断.pdf ｜ 言语理解专项

主讲老师：超格老于

第五章 逻辑填空 03 宏观判断。

微观判断看**一个空内部**（解释关系、词语辨析），宏观判断看**空与空、句与句之间**的关系。本节按"空与空怎么联动"归为八类：

| 类型 | 核心动作 | 一句话判定 |
| --- | --- | --- |
| 首句原则 | 首句定主体、定基调 | 后文都是对首句的展开 |
| 双空对应 | 两空语义互相规定 | 一空定另一空，常构成正反、古今、因果对照 |
| 交叉并列 | 两空分别"管"一半，合起来才是答案 | ①＋②→第三义 |
| 句内并列 | 分号、顿号前后结构对称 | 位置对应、词性对应、语义相反或相承 |
| 行文并列 | 前后分句各自给一个义项 | ①＋② 合成一个成语 |
| 核心话题 | 全段只谈一件事 | 选项必须落在话题的词义范围内 |
| 承上启下 | 空格是前后文的接缝 | 上文收束＋下文领起 |
| 词义丰富 | 同一词兼有两层意思 | 字面义＋引申义同时成立 |

> **★重点**：宏观判断题**先看空的位置，再看空的关系**——两空之间是"对照""递进"还是"合成"，决定了答案的唯一性。

## 一、首句原则

> **★重点**：首句是**话题句**，它定了主体、定了态度、定了语体。后面所有空格都必须"顺着首句说"，**与首句的主体和基调保持一致**。

**例1**（2024省考）

> "精专"读书法，并不是让我们穿凿附会、______，那样只会"拘泥于章句而疏忽于会意，活脱书橱也"，而是提倡一种______、苦心孤诣的读书态度。读书就像品茗，虽然茶水的颜色和飘逸的茶香较易辨认，但茶中三味，却要细细品之才能体会得来。

依次填入画横线部分最恰当的一项是：

A. 咬文嚼字 去粗取精
B. 咬文嚼字 去伪存真
C. 雕章琢句 去粗取精
D. 雕章琢句 去伪存真

**破题**：首句定下"**读书方法**"这一话题，且用"并不是……而是……"作正反对照——第一空要与"**穿凿附会**""拘泥于章句""活脱书橱"同侧，是**死抠字眼**；第二空要与"苦心孤诣"同侧，是**细品之后取其精华**。

| 词语 | 侧重点 | 例句/搭配 |
| --- | --- | --- |
| 咬文嚼字 | 过分斟酌字句，**死抠字眼而不顾精神实质** | 与"穿凿附会""拘泥章句"同侧 |
| 雕章琢句 | 对文字**精心打磨使之华美**，多指写作 | 雕章琢句，辞藻华丽 |
| 去粗取精 | 除去杂质，**留取精华** | 与"茶中三味，细细品之"呼应 |
| 去伪存真 | 除掉虚假的，留下真实的 | 文段无"真伪"之别 |

> **⚠易错**："雕章琢句"是**褒义/中性**的写作功夫，与"穿凿附会"的贬义不同侧，不能并列。

**例2**（2024国考）

> 推进公交专用车道的开放共享，不等于废除公交专用通道，更不等于在城市交通治理中不再坚持"公交先行"的理念。理想状况下的公交专用通道共享，应该是在不影响公交通行效率的前提下，方便社会车辆的通行，从而在整体上提升道路交通的通行效率，而并非______。

填入画横线部分最恰当的一项是：

A. 厚此薄彼
B. 顾此失彼
C. 此消彼长
D. 不分彼此

**破题**：首句确立"**共享不等于废除**"的基调，尾句"**而并非**"与"在整体上提升"构成对照——理想状态是**两头都顾上**，反面就是**顾了一头丢了一头**。

| 词语 | 侧重点 | 例句/搭配 |
| --- | --- | --- |
| 顾此失彼 | 顾了这个丢了那个，**无法兼顾** | 与"整体上提升"直接相反 |
| 厚此薄彼 | 重视一方、轻视另一方，**待遇不公** | 对象多为人、地区 |
| 此消彼长 | 一个下降一个上升，**反相关** | 强调"总量不变" |
| 不分彼此 | 关系密切，不分你我 | 褒义，与语境相反 |

**例3**（2024国考）

> 许多老大难问题之所以长期无解，重要原因是调查研究流于形式，导致情况吃得不透、病根找得不准。有的是"盲人摸象"式调研，眼中只有一个个孤立的"盆景"，得出的结论往往是______；有的是"刻舟求剑"式调研，对新情况多凭主观判断下结论，导致出台的政策______不强。

依次填入画横线部分最恰当的一项是：

A. 一孔之见 时效性
B. 闭门造车 可行性
C. 老生常谈 科学性
D. 以偏概全 针对性

**破题**：首句点出病因"**情况吃不透、病根找不准**"，两个"有的是"分别对应两种病症——"盲人摸象""只有孤立的盆景"是**以局部代整体**；"刻舟求剑""凭主观判断"是**不针对新情况**。

| 词语 | 侧重点 | 与文段对应 |
| --- | --- | --- |
| 以偏概全 | 用**片面**看整体 | "盲人摸象""孤立的盆景" |
| 一孔之见 | 狭隘片面的见解（**名词性"见解"**） | 与"结论往往是"搭配尚可，但缺"以偏概全"的动作义 |
| 闭门造车 | 脱离实际、只凭主观 | 对应的是第二种调研，非第一种 |
| 老生常谈 | 听厌了的老话 | 与"盲人摸象"无关 |

| 词语 | 对应点 | 说明 |
| --- | --- | --- |
| 针对性 | **"对新情况"** | 政策不贴合新情况 |
| 时效性 | 时间上是否及时 | 文段谈的是"对不对症" |
| 可行性 | 能否落地 | 与"主观判断"关联弱 |
| 科学性 | 是否合乎科学 | 过于笼统 |

**例4**（2024国考）

> 全面从严治党和鼓励担当作为是内在统一的，不是彼此对立的。严并不是要把大家管死，使人瞻前顾后、畏首畏尾，搞成暮气沉沉、______的一潭死水，而是要通过明方向、______、正风气、强免疫，形成风清气正的党内政治生态，营造有利于干事创业的良好环境，进一步调动全党的积极性、主动性、创造性。

依次填入画横线部分最恰当的一项是：

A. 无所作为 立规矩
B. 无所事事 守底线
C. 浑浑噩噩 讲原则
D. 唯唯诺诺 严法纪

**破题**：首句给出"**严不是管死**"的总纲，第一空要与"暮气沉沉""一潭死水"同侧，是**不干事、没作为**；第二空与"明方向、正风气、强免疫"并列，同属**党的建设举措**，且"明方向"对"立规矩"最工整。

| 词语 | 侧重点 | 说明 |
| --- | --- | --- |
| 无所作为 | **没有做出成绩、没有贡献** | 与"一潭死水""不干事"呼应 |
| 无所事事 | 闲着什么都不做 | 重"闲"，与"管死"后"不敢为"略隔 |
| 浑浑噩噩 | 糊里糊涂、愚昧无知 | 重"糊涂" |
| 唯唯诺诺 | 一味顺从、无主见 | 与"瞻前顾后"重复 |

| 搭配 | 结构 | 说明 |
| --- | --- | --- |
| 明方向、**立规矩**、正风气、强免疫 | 动宾＋动宾，四字对举 | 均为"立"字类举措，句式最齐 |
| 守底线 | 偏"守"，与"明方向"不对仗 | 次优 |
| 讲原则／严法纪 | 前者偏"说"，后者偏"严" | 与"正风气"稍重 |

**例5**（2024国考）

> 应急情境下妥善治理谣言，考验的是应急处置能力的临场发挥，更是应急处置能力的建设。网络谣言治理主要有治标与治本两条路径，前者针对既成事实，______，即时奏效；后者侧重于"治未病"，______，久久为功，两条路径有机结合，方可有效遏制互联网谣言的生产与传播。

依次填入画横线部分最恰当的一项是：

A. 亡羊补牢 曲突徙薪
B. 双管齐下 未雨绸缪
C. 惩前毖后 深谋远虑
D. 补偏救弊 先发制人

**破题**：首句给出"**治标／治本**"两条路径的总纲——第一空对应"**针对既成事实……即时奏效**"，是**出了事再补救**；第二空对应"**治未病……久久为功**"，是**事前预防**。

| 词语 | 侧重点 | 对应 |
| --- | --- | --- |
| 亡羊补牢 | 出了问题**再补救** | 治标、即时奏效 |
| 曲突徙薪 | 把烟囱改弯、搬走柴草，**事先防患** | 治未病、久久为功 |
| 双管齐下 | 两方面同时进行 | 与"前者"单指一路不合 |
| 惩前毖后 | 批判过去的错误使人警惕 | 对象是"人"，非"事" |
| 补偏救弊 | 补救偏差漏洞 | 只含"救"，不含"防" |
| 未雨绸缪 | 事先做好准备 | 与"曲突徙薪"义近，但"曲突徙薪"更贴"治未病"的**隐患处置** |
| 先发制人 | 先下手争取主动 | 与"防"不同，重"抢" |

**例6**（2025超格模拟）

> 教学评价体系是"大思政课"建设效果的**探测器和矫正器**。凭借快速的计算能力、出色的存储技术和大数据分析能力，数字化技术能够______记录"教"与"学"的相关情况。以数字化技术科学评价教学过程与成果，不仅可以实现对思想政治理论课的"______"，还有助于实现知识评价、能力评价和价值评价的统一，为校正问题、提高水平提供依据。

依次填入画横线部分最恰当的一项是：

A. 客观 了如指掌
B. 真实 见微知著
C. 全面 对症下药
D. 动态 问诊把脉

**破题**：首句的喻体是"**探测器**"（发现问题）和"**矫正器**"（解决问题），第二空带引号，须与这一**医疗—诊断意象**同构，且要能同时覆盖"探测＋矫正"；第一空则对应"能够______记录……相关情况"，强调**全过程、随时**。

| 词语 | 侧重点 | 说明 |
| --- | --- | --- |
| 问诊把脉 | 中医术语，喻**调查研究、找出问题关键** | 与"探测器＋矫正器"双义相合 |
| 对症下药 | 针对病症用药 | 只对应"矫正器"，缺"探测"义 |
| 了如指掌 | 了解得非常清楚 | 只对应"清楚"，无"诊断"义 |
| 见微知著 | 见苗头即知趋势 | 只对应"探测器" |

| 词语 | 对应点 | 说明 |
| --- | --- | --- |
| 动态 | **"凭借快速计算、大数据分析"** | 强调持续、实时 |
| 客观／真实 | 与"主观"相对 | 文段强调"快、全、实时" |
| 全面 | 覆盖面广 | 与"大数据"呼应，但不如"动态"贴"快速" |

**例7**（2025四川）

> 可以说，于社会生活，路名是坐标、是方位；于文化建设，路名是记忆、是传承。城市的路名，是导航上______的回家之路，也是心灵中______的归乡之路，不仅能带着我们回到亮着灯光、飘着饭香的小家，也能带着我们回到历史之河、传统之脉的家园。路名______起空间与时间，对接着历史与生活，为城市生活增添了一份精神的底色。

依次填入画横线部分最恰当的一项是：

A. 山长水阔 朝思夜盼 交织
B. 翻山越岭 望眼欲穿 连通
C. 纵横交错 源远流长 串联
D. 落叶归根 魂牵梦萦 缝合

**破题**：首句给出**空间（坐标、方位）＋时间（记忆、传承）**双维度，三空依次对应：①"**导航上**"→ 地图上的路**纵横交错**；②"**历史之河、传统之脉**"→ **源远流长**；③"**起空间与时间**"→ 把两者**串联**起来。

| 词语 | 侧重点 | 说明 |
| --- | --- | --- |
| 纵横交错 | 道路、山脉、河流**交叉在一起** | 与"导航上"的画面感一致 |
| 山长水阔 | 山水阻隔、路途遥远 | 形容"远"，非"密" |
| 翻山越岭 | 旅途辛苦 | 与"导航上"不搭 |
| 落叶归根 | 客居他乡终归故里 | 与"导航"不搭 |

| 词语 | 侧重点 | 对应 |
| --- | --- | --- |
| 源远流长 | 源头远、水流长，喻**历史悠久** | 与"历史之河、传统之脉"呼应 |
| 朝思夜盼／望眼欲穿 | 盼望殷切（**未发生**） | 与"归乡"的既成感不合 |
| 魂牵梦萦 | 万分思念（**已发生**） | 可通，但与"历史"关联弱 |

> **★重点**：讲义特别提示——"朝思夜盼""望眼欲穿"侧重**尚未发生**的盼望，"源远流长""魂牵梦萦"侧重**已然发生**的积淀。**时态**也是判定点。

**例8**（2023事业单位）

> 每一天，太空垃圾和天体碎片都像**雨点**一样______地落在我们的行星表面。其中很大一部分岩石和金属块将化作一道肉眼可见的火焰撕裂大气层，只有极小一部分能够作为陨石抵达地表。事实上，大部分落在地表的天外来客都是亚毫米尺寸的尘埃粒子，被称为微小陨石，它们非常难以______和量化。

依次填入画横线部分最恰当的一项是：

A. 密集 研究
B. 持续 追踪
C. 杂乱 观察
D. 猛烈 发现

**破题**：首句的喻体是"**雨点**"，雨点的特征是**又多又密**，故第一空取"密集"；后文"亚毫米尺寸"决定了它们**极难被跟踪定位**。

| 词语 | 侧重点 | 说明 |
| --- | --- | --- |
| 密集 | 数量多而**集中** | 与"像雨点一样"直接对应 |
| 持续 | 时间上不间断 | "每一天"已表持续，空处应补"多" |
| 杂乱 | 无秩序 | 与"雨点"意象不合 |
| 猛烈 | 力量大、势头凶 | 与"尘埃粒子"不合 |

| 词语 | 侧重点 | 搭配 |
| --- | --- | --- |
| 追踪 | 按线索**跟踪寻找** | 与"量化"并列，科学观测常用 |
| 研究 | 探求规律 | 与"量化"并列时层次不齐 |
| 观察 | 用眼察看 | 亚毫米粒子难以"观察" |
| 发现 | 找出原先存在的事物 | 与"量化"并列不当 |

**例9**（2020事业单位）

> 守护儿童是一项专业性很强的社会工作。留守儿童不是一个______群体，而是无数鲜活个体。他们中，有的亟待物质救助，有的呼唤心理疏导；有安全教育的需要，也有权益维护的诉求。实现因人施策的"精准关爱"，有赖______力量的投入。对此，国家出台相关《意见》支持法律、心理咨询等各类专业人员，针对留守儿童的不同特点提供服务。

依次填入画横线部分最恰当的一项是：

A. 模糊 专业
B. 弱势 政策
C. 孤立 集体
D. 松散 公益

**破题**：首句定调"守护儿童是**专业性很强**的社会工作"，末句"支持法律、心理咨询等各类**专业人员**"直接回扣——第二空必为"专业"；第一空与"**无数鲜活个体**"对照，是**笼统、模糊**。

| 词语 | 侧重点 | 说明 |
| --- | --- | --- |
| 模糊 | 轮廓不清、**笼统** | 与"鲜活个体"形成对照 |
| 弱势 | 处于不利地位 | 与"而是无数鲜活个体"不对立 |
| 孤立 | 与外界隔绝 | 与"群体"搭配不当 |
| 松散 | 结构不紧密 | 与"个体"不对立 |

> **⚠易错**：首句与尾句**首尾呼应**是命题人最爱设的"回扣点"，本题第二空在尾句有原词复现（"专业人员"），属于送分。

**例10**（2018省考）

> 一项最新的研究成果表明，人类肤色的差异变大至少从90万年前就开始了。基于非洲地区人们皮肤色素沉着相关基因变异的分析发现，黑皮肤相对来说拥有比较______的遗传变异，这表明"白种人更先进"的种族主义观念存在______。

依次填入画横线部分最恰当的一项是：

A. 明显 偏见
B. 罕见 疑问
C. 快速 漏洞
D. 古老 缺陷

**破题**：首句给出时间坐标"**至少从90万年前**"，第一空须与之呼应，即**古老**；第二空要与前文的科学结论形成"证伪"关系——该观念存在**缺陷**。

| 词语 | 对应点 | 说明 |
| --- | --- | --- |
| 古老 | **"90万年前"** | 时间维度直接对应 |
| 明显 | 显著 | 与时间无关 |
| 罕见 | 稀少 | 与"差异变大"矛盾 |
| 快速 | 速度快 | 与"遗传变异"搭配不当 |

| 词语 | 侧重点 | 说明 |
| --- | --- | --- |
| 缺陷 | 不完善、有漏洞 | 与"科学证据"形成对撞 |
| 偏见 | 片面的看法 | "种族主义观念存在偏见"语义重复 |
| 疑问 | 怀疑 | 与"这表明"的确定语气不合 |
| 漏洞 | 破绽 | 可通，但"观念"更常配"缺陷" |

## 二、双空对应

> **★重点**：两个空**互为规定**——常见三种关系：**正反相对**（不是A，而是B）、**古今对照**（过去／现在）、**因果承接**（因为A，所以B）。先把两空的"关系"定下来，再去选项中找**成对**的那一组。

**例1**（2023浙江）

> 城市形象不是______的，它会随着一座城市的发展需要而产生相应的变化，因此，对于城市形象的研究也应当______。

依次填入画横线部分最恰当的一项是：

A. 千篇一律 兼收并蓄
B. 墨守成规 求同存异
C. 因循守旧 革故鼎新
D. 一成不变 与时俱进

**破题**：两空构成"**正反相对**"——第一空说"不会固定不变"，第二空说"研究要跟着变"，"因此"提示因果同向。

| 词语 | 侧重点 | 说明 |
| --- | --- | --- |
| 一成不变 | **一经形成就不再改变** | 与"随着发展而变化"正相反 |
| 千篇一律 | 形式单一、机械重复 | 强调"一个样"，非"不变" |
| 墨守成规 | 守着老规矩不肯改（**形容人**） | 主语是"城市形象"，对象不合 |
| 因循守旧 | 沿袭旧规、不思革新（**形容人**） | 同上 |

| 词语 | 侧重点 | 说明 |
| --- | --- | --- |
| 与时俱进 | 随时代发展而前进 | 与"相应变化"同向 |
| 兼收并蓄 | 把不同内容都吸收进来 | 讲"包容"，非"更新" |
| 求同存异 | 找共同点、保留分歧 | 讲"处理分歧" |
| 革故鼎新 | 除去旧的、建立新的 | 程度过重，非"研究态度" |

**破题**：引号内"**橘生淮南则为橘、生于淮北则为枳**"是判定标志——讲的是**不顾各地差异、生搬硬套**；对策自然是**因地制宜**，一"套"一"宜"，正反对应。

| 词语 | 侧重点 | 说明 |
| --- | --- | --- |
| 削足适履 | **不顾具体条件、生搬硬套** | 与"橘枳之变"直接对应 |
| 故步自封 | 守旧不求进步 | 与"差异"无关 |
| 纸上谈兵 | 空谈理论不解决实际问题 | 与"一套技术包打天下"稍隔 |
| 好高骛远 | 追求过高过远的目标 | 与"技术引用"不搭 |

| 词语 | 侧重点 | 说明 |
| --- | --- | --- |
| 因地制宜 | **根据各地具体情况制定办法** | 与"各地间情况差异较大"呼应 |
| 循序渐进 | 按步骤逐步深入 | 讲"顺序"，非"差异" |
| 实事求是 | 从实际出发 | 可通，但不如"因地制宜"贴"各地" |
| 脚踏实地 | 做事踏实 | 与"差异"无关 |

**例11**（2023国考）

> 地方政府要以民众利益、公共利益、国家利益为重，不能只追求短期利益，只追求政绩，而做出______的事情来。对官员的政绩考核、对政府的绩效评估，更要注重民生，注重社会的长远发展，这样才能从根本上避免破坏生态环境、破坏可持续发展大局、损害民众利益等"______"现象的继续发生。

依次填入画横线部分最恰当的一项是：

A. 扬汤止沸 移花接木
B. 竭泽而渔 杀鸡取卵
C. 本末倒置 抱薪救火
D. 饮鸩止渴 掩耳盗铃

**破题**：两空是"**行为—现象**"的**同义复现**：前空讲"只顾短期利益"的做法，后空是带引号的**同义成语**，且要与"破坏生态、破坏可持续发展"精准对应。

| 词语 | 侧重点 | 说明 |
| --- | --- | --- |
| 竭泽而渔 | 抽干水塘捕鱼，**只顾眼前、不顾长远** | 与"短期利益／长远发展"直接对应 |
| 杀鸡取卵 | 贪图眼前好处而不顾长远 | 与"竭泽而渔"同义，作引号现象最贴 |
| 扬汤止沸 | 办法不彻底，不能根本解决 | 讲"治标"，非"断根" |
| 本末倒置 | 主次颠倒 | 与"短期／长远"不对应 |
| 饮鸩止渴 | 用错误办法解眼前困难、不顾后果 | 可通，但"毒"的意象文段没有 |

> **★重点**：两空填**近义成语**是本题的"格式提示"——看到"做出……的事情"＋"'……'现象"，就要意识到两空说的是**同一件事**。

**例12**（2025国考）

> 各国正逐步形成以无人机、巡航导弹、弹道导弹、轰炸机等为主力的高效空袭体系，可以实现对目标空域的饱和袭击。这让只能命中单一目标的防空导弹陷入______的境地。面对复杂多样的战场威胁，防空导弹不再______，而是"攥指成拳"，朝着防空导弹系统升级转变。

B. 鞭长莫及 形单影只
C. 捉襟见肘 故步自封
D. 孤掌难鸣 单打独斗

**破题**：第二空是全题的"锁"——"**而是'攥指成拳'**"提示反面是**各自单干**，**单打独斗**；第一空"只能命中单一目标"对"饱和袭击"，正是**力量孤单、难以应对**。

| 词语 | 侧重点 | 说明 |
| --- | --- | --- |
| 孤掌难鸣 | **力量孤单、难以成事** | 与"只能命中单一目标"呼应 |
| 捉襟见肘 | 顾此失彼、穷于应付 | 也可，但第二空"故步自封"不合 |
| 腹背受敌 | 前后都受攻击 | 文段讲"饱和"，非"夹击" |
| 鞭长莫及 | 距离太远、力量达不到 | 讲"够不着" |

| 词语 | 侧重点 | 说明 |
| --- | --- | --- |
| 单打独斗 | **一个人单干、无配合** | 与"攥指成拳"正相反 |
| 各自为战 | 各自独立作战 | 与"攥指成拳"也相反，但"单打独斗"更贴"单一目标" |
| 形单影只 | 孤独、无同伴 | 形容人 |
| 故步自封 | 守旧不求进步 | 与"升级转变"相反，非"协作" |

**例13**（2024四川）

> 通常深度大于6000米的深海被称为深渊，科学家认为其有着______的科考和科研价值。下潜到1万米深度，相当于在1个手指甲大小的面积上承受约1吨的重量。气压、光照、盐度的逐级变化，造就了地球这个最深处的特殊性。在此开展科学研究，能够获取地球物理、地质构造等______的科学资料。

依次填入画横线部分最恰当的一项是：

A. 不可替代 独一无二
B. 无与伦比 不胜枚举
C. 难以估量 丰富多彩
D. 前所未有 错综复杂

**破题**：两空各管一段——第一空讲"**价值**"，深渊极端环境难以复制，价值**难以估量**；第二空讲"**资料**"，气压、光照、盐度逐级变化带来的是**多类型、多门类**的资料。

| 词语 | 侧重点 | 说明 |
| --- | --- | --- |
| 难以估量 | 很难估计，**数量大或程度重** | 与"价值"搭配自然 |
| 不可替代 | 独特、不可或缺 | 可通，但程度判断无依据 |
| 无与伦比 | 没有能比得上的 | 常作"美得无与伦比" |
| 前所未有 | 从来没有过 | 强调"开创性" |

| 词语 | 侧重点 | 说明 |
| --- | --- | --- |
| 丰富多彩 | 内容**丰富、门类多** | 与"地球物理、地质构造等"并列列举呼应 |
| 独一无二 | 唯一的 | 修饰"资料"不当 |
| 不胜枚举 | 数量多得举不完 | 与"资料"搭配偏书面堆砌 |
| 错综复杂 | 头绪繁多、相互纠结 | 含贬义色彩 |

**词语积累｜无与伦比**

> **★重点**：这个词在真题中高频出现，且几乎都是**正面极致评价**，注意其搭配对象。

| 例句 | 出处 | 用法要点 |
| --- | --- | --- |
| 中华文明正是凭借其自强不息的进取精神、革故鼎新的强大气魄，不断突破"山重水复"，屡屡迎来"柳暗花明"，从而具有了**无与伦比**的创造能力与创新意识。 | 2025学习时报《更好担负起新时代新的文化使命》 | 修饰"能力、意识" |
| 对中国古代青铜馆内的大克鼎、中国古代陶瓷馆内的彩色釉陶俑，他们印象尤其深刻，频频赞叹中国历史文化"**美得无与伦比**"。 | 2025新华每日电讯《金蛇贺岁 春满神州》 | 可作"美得无与伦比"的补语 |
| 中国产业链供应链的效率、成本优势和规模**无与伦比**，中国业务往往占跨国企业全球业务份额的15%到40%不等。 | 2025人民日报《"在高质量发展的中国把握机遇"》 | 修饰"优势、规模" |

**例14**（2021国考）

> 中国道路的成功开创不仅创造了中国奇迹，而且创造了中国经验。中国经验无疑是中国智慧的结晶，具有鲜明的______。但是，中国经验作为中国道路的积极成果，也是在遵循历史发展和现代化发展规律，吸收世界发展经验教训的基础上形成的，它是对人类文明发展进行探索的重要产物，反映了人类文明进步的规律，因而又具有一定的______。

依次填入画横线部分最恰当的一项是：

A. 地域性 国际性
B. 先进性 创新性
C. 实践性 理论性
D. 特殊性 普遍性

**破题**：两空由"**但是……因而……**"构成**正反递进**：前句讲"中国经验是**中国的**"→ 特殊；后句讲"反映人类文明进步的**规律**"→ 普遍。

| 词语 | 侧重点 | 说明 |
| --- | --- | --- |
| 特殊性 | 独有的、区别于他者的性质 | 与"中国经验""中国智慧"呼应 |
| 地域性 | 限于某一地区的属性 | 与"中国道路"的制度属性不符 |
| 先进性 | 水平领先 | 与"但是"后的转折不构成对照 |
| 实践性 | 来自实践 | 同上 |

| 词语 | 侧重点 | 说明 |
| --- | --- | --- |
| 普遍性 | 适用于**一般、共通**的规律 | 与"人类文明进步的规律"精准对应 |
| 国际性 | 跨国界的属性 | 偏"地理范围"，非"规律" |
| 理论性 | 系统化的属性 | 与"规律"关联弱 |
| 创新性 | 首创性 | 与转折不对应 |

> **⚠易错**：本题的判定点是**转折词"但是"＋因果词"因而"**——转折后必然转向另一面，而"特殊性↔普遍性"正是哲学上最标准的一对。

| 千姿百态 | 形态多样 | 对象是"物质构成"，不合 |

| 词语 | 侧重点 | 说明 |
| --- | --- | --- |
| 类似 | **大致相像** | 与"源源不断流入、混合"对应 |
| 共同 | 彼此共有 | 语义过强，且与"最初……大相径庭"衔接不顺 |
| 全新 | 完全新的 | 与"混合"逻辑相反 |
| 独特 | 独有的 | 同上 |

## 三、交叉并列

> **★重点**：文段把一件事拆成**两个并列的分句**，两个空格分别"管"其中一半，**合起来**才能覆盖全部信息。只对应一半的选项，是本题最典型的陷阱。

**例1**（2023四川）

> 宋词应该怎么读？传统的阅读，往往按词人生平和时代背景介绍、字词训诂、文意串讲、艺术赏析这样的程式进行，______，但读者跟文本、词人之间总有一层隔膜。如今也有不少创新性解读，加入各种大胆的演绎、戏说，能抓住读者的眼球，但往往偏离历史事实，消费古人，______。

依次填入画横线部分最恰当的一项是：

A. 按部就班 追名逐利
B. 分门别类 不伦不类
C. 一板一眼 夸大其词
D. 中规中矩 哗众取宠

**破题**：两空是**古今两种读法的对照**——传统读法"按程式进行"→ **中规中矩**（合规矩但刻板）；新解读"抓眼球、消费古人"→ **哗众取宠**（用浮夸言行迎合众人）。前后必须**一褒一贬、一守一放**。

| 词语 | 侧重点 | 说明 |
| --- | --- | --- |
| 中规中矩 | **合乎标准、法则**，平稳不出格 | 与"按……程式进行"对应 |
| 按部就班 | 按条理步骤去做 | 可通，但带"缺乏创新"的评价，与"但……隔膜"衔接稍硬 |
| 分门别类 | 按特征分类整理 | 文段是"按顺序讲"，非"分类" |
| 一板一眼 | 有条理、合规矩 | 偏口语，与文段书面语体稍隔 |

| 词语 | 侧重点 | 说明 |
| --- | --- | --- |
| 哗众取宠 | 用浮夸言行**迎合众人以博好感** | 与"抓眼球、消费古人"精准对应 |
| 追名逐利 | 追求名位利益 | 讲"动机"，文段讲"手法" |
| 不伦不类 | 不规范、不像样 | 程度偏轻，且不含"迎合"义 |
| 夸大其词 | 语言夸张超过事实 | 只对应"戏说"，缺"迎合观众" |

**例2**（2024国考）

| 返璞归真 | 恢复质朴本真 | 讲"回归"，非"守正" |

| 恢宏 | 宽阔、广大 | 多修饰"气势、规模"，与"神韵"搭配稍隔 |

## 四、句内并列

> **★重点**：句内出现**分号、顿号**时，前后分句**结构对称**，同一位置的词往往**词性相同、语义相反或相承**。做法：把对称位置"对齐"读一遍，答案自然浮现。

**例1**（2024国考）

> 史书是古人写就的，有些内容可能会因有人随意取舍、记忆有误或者心存故意而______历史事实。运用基因等高科技手段的考古研究是科学，它以客观而非主观的科学事实和科学数据得出结论。科学可以检验，可以用重复操作检验此前的研究成果是否准确、正确，从而______了人为造假的可能。

依次填入画横线部分最恰当的一项是：

A. 违背 化解
B. 虚构 杜绝
C. 掩盖 规避
D. 偏离 降低

**破题**：①"因……而______历史事实"——三种原因（随意取舍、记忆有误、心存故意）共同导致的是**偏离**，而非主动"违背"；②"从而______了人为造假的可能"——科学检验只能把可能性**降低**，不能彻底"杜绝"。

| 词语 | 程度/侧重点 | 说明 |
| --- | --- | --- |
| 偏离 | **离开原本的方向、轨道** | 三种原因都能导致"偏"，程度适中 |
| 违背 | 违反、背离（**主观性强**） | "记忆有误"不是主观违背 |
| 虚构 | 凭想象编造 | 只对应"心存故意" |
| 掩盖 | 遮盖使不显露 | 与"取舍、失误"不对应 |

| 词语 | 程度 | 说明 |
| --- | --- | --- |
| 降低 | **使程度减小** | 科学只能降低概率，表述准确 |
| 杜绝 | **彻底消除**（程度最重） | 与"可能"矛盾，过于绝对 |
| 化解 | 消除、解除 | 对象多为矛盾、风险 |
| 规避 | 设法避开 | 与"可能"搭配不当 |

> **⚠易错**：程度题看**绝对化表述**——"杜绝""彻底""完全"往往是陷阱，除非文段有对应铺垫。

**例2**（2020国考）

> 准确、权威的信息不及时传播，虚假、歪曲的信息就会搞乱人心；积极、正确的思想舆论不发展壮大，消极、错误的言论观点就会肆虐______。这方面，主流媒体守土有责，更要守土尽责，及时提供更多真实客观、观点鲜明的信息内容，牢牢______舆论场主动权和主导权。主流媒体要敢于引导、善于疏导，原则问题要旗帜鲜明、立场坚定，一点都不能______。

依次填入画横线部分最恰当的一项是：

A. 泛滥 掌握 含糊
B. 滋生 控制 迟疑
C. 蔓延 守护 犹豫
D. 扩散 占据 退缩

**破题**：①"**肆虐**______"——"肆虐"已含猛烈之势，后接**泛滥**最顺；②"牢牢______主动权和主导权"——"牢牢"与**掌握**固定搭配；③"一点都不能______"＋"旗帜鲜明、立场坚定"→ 态度不能**含糊**。

| 词语 | 侧重点 | 说明 |
| --- | --- | --- |
| 泛滥 | 坏事物**大量涌现、不受限制** | 与"肆虐"同侧，气势一致 |
| 滋生 | 繁殖产生 | 与"肆虐"不搭 |
| 蔓延 | 像蔓草一样向四周扩展 | 可通，但缺"成灾"义 |
| 扩散 | 向四周散开 | 中性，色彩偏弱 |

| 词语 | 搭配 | 说明 |
| --- | --- | --- |
| 掌握主动权 | **固定搭配** | "牢牢掌握"最稳 |
| 控制 | 控制局面 | 与"主动权"搭配弱 |
| 守护 | 守卫保护 | 与"主动权"不搭 |
| 占据 | 占住（位置、优势） | 与"牢牢"搭配稍隔 |

| 词语 | 侧重点 | 说明 |
| --- | --- | --- |
| 含糊 | **态度不明、不清晰** | 与"旗帜鲜明"正相反 |
| 迟疑 | 犹豫不决（**动作上**） | 与"立场坚定"对应弱 |
| 犹豫 | 拿不定主意 | 同上 |
| 退缩 | 后退畏缩 | 讲"敢不敢"，非"明不明" |

**例3**（2024山东）

> 从物质形态上看，广义的历史典籍版本包括甲骨文、金文、简帛、石刻、唐宋元明清及近代的手写本、印刷品等，可谓______。此外，还有大量的出土文物、地上地下遗址、文化遗存，以及祖祖辈辈______的历史传说、民风民俗、家风家训等，这些共同构成"广阔的文化空间"，也是一座巨大的、______的文化宝藏，蕴藏着中华文明生生不息的密码。

依次填入画横线部分最恰当的一项是：

A. 琳琅满目 一脉相承 独一无二
B. 汗牛充栋 口耳相传 无与伦比
C. 浩如烟海 倾囊相授 包罗万象
D. 卷帙浩繁 言传身教 价值连城

**破题**：①"甲骨文、金文、简帛、石刻……手写本、印刷品"全是**典籍**，取**汗牛充栋**（藏书极多）；②"历史传说、民风民俗、家风家训"是**民间口头流传**，取**口耳相传**；③"巨大的、______的文化宝藏"→ 内容包罗万象、无以伦比。

| 词语 | 侧重点 | 说明 |
| --- | --- | --- |
| 汗牛充栋 | **藏书极多**（运输时牛出汗、堆满屋栋） | 专用于书籍，最贴"典籍版本" |
| 卷帙浩繁 | 书籍多或一部书篇幅长 | 可通，但侧重"篇幅" |
| 浩如烟海 | 典籍、资料极丰富 | 也可，但下文只有"口耳相传"能锁死答案 |
| 琳琅满目 | 美好物品多（商品、工艺品） | 对象不合 |

| 词语 | 侧重点 | 说明 |
| --- | --- | --- |
| 口耳相传 | **口说耳听、代代相传** | 与"传说、民俗、家训"精准对应 |
| 一脉相承 | 思想、学说有继承关系 | 偏正式、严肃的思想文化 |
| 倾囊相授 | 把知识技能全部传授给学生 | 限于师生之间 |
| 言传身教 | 既讲道理又做示范 | 强调"以身作则" |

| 词语 | 侧重点 | 说明 |
| --- | --- | --- |
| 无与伦比 | 没有能比得上的 | 与前文"巨大""广阔"的气势相配 |
| 独一无二 | 唯一的 | 讲"唯一性"，非"丰富性" |
| 包罗万象 | 内容丰富、应有尽有 | 与"巨大"并列可通，但第二空已排除 C |
| 价值连城 | 物品极其贵重 | 偏"经济价值" |

## 五、行文并列

> **★重点**：这是宏观判断里最"机械"也最有效的一类——**前后两个分句各给一个义项，两个义项相加＝一个成语**。讲义把它画成箭头链：
>
> ```
> ①A 义项 → 词 X　②B 义项 → 词 Y　→　①＋② ⇨ 答案
> ```

**例1**（2023国考）

> 红树林的地下部分长期处于厌氧环境，减缓了根系和凋落物的分解速率，加速了碳埋藏速率。此外，红树林大多分布于沉积型海岸河口，由上游河流和海洋潮汐共同作用带来的大量外源性碳，被它们固定并快速沉积下来。这"______"的组合拳使得红树林成为海岸带蓝碳碳汇的主要贡献者。

填入画横线部分最恰当的一项是：

A. 标本兼治
B. 一举两得
C. 取长补短
D. 开源节流

**破题**：**两段各给一半**——①"减缓分解、加速埋藏"＝**节流**（少流失）；②"固定并快速沉积外源碳"＝**开源**（多进来）。①＋② 正是**开源节流**。

| 分句 | 义项 | 对应词素 |
| --- | --- | --- |
| 减缓分解速率、加速碳埋藏 | 减少碳的流失 | **节流** |
| 固定并快速沉积外源碳 | 增加碳的来源 | **开源** |

| 词语 | 侧重点 | 说明 |
| --- | --- | --- |
| 开源节流 | **增加来源＋减少流失** | ①＋② 完全覆盖 |
| 标本兼治 | 治标与治本同时进行 | 文段无"标／本"之分 |
| 一举两得 | 做一件事得两方面好处 | 只讲"得两头"，不指"开与节" |
| 取长补短 | 吸取长处弥补短处 | 无"长短"关系 |

**例2**（2023省考）

> 人们在传承传统春节精神的同时，能够以开放包容的态度接受当代新鲜事物和不同地域文化，使得年货消费展现出许多新特征。各地不尽相同的年味儿背后，是传统文化在不同层面的______呈现。年货消费趋势的转变，既是对传统文化的传承和发扬，更是人们在新时代主动选择的结果，展现了老传统与新文化______的发展趋势，承载了现代人对传统文化的全新阐释。春节传统民俗融入现代元素和地域特色，定将绽放出新的______色彩。

依次填入画横线部分最恰当的一项是：

A. 多元性 浑然一体 地域化
B. 差异性 水乳交融 时代化
C. 创新性 难分难解 现代化
D. 继承性 相得益彰 商业化

**破题**：①"**各地不尽相同**的年味儿"→ **差异性**；②"老传统与新文化______"→ 两者彼此融合，**水乳交融**；③末句是**合成空**：**现代元素 → 现代化**，**地域特色 → 地域化**，两者相加＝**时代化**。

| 分句 | 义项 | 对应词素 |
| --- | --- | --- |
| 融入现代元素 | 跟上当代 | **现代化** |
| 融入地域特色 | 带上地方色彩 | **地域化** |
| ①＋② | 兼具当代性与地方性 | **时代化** |

| 词语 | 侧重点 | 说明 |
| --- | --- | --- |
| 差异性 | 彼此**不同** | 与"各地不尽相同"直接对应 |
| 多元性 | 种类多、并存 | 可通，但下文"不尽相同"更贴"差异" |
| 创新性 | 有创造性 | 与"不同层面"不搭 |
| 继承性 | 有承袭 | 与"不尽相同"相反 |

| 词语 | 侧重点 | 说明 |
| --- | --- | --- |
| 水乳交融 | 像水和乳汁般**融合紧密** | 与"老传统＋新文化"对应 |
| 浑然一体 | 完整不可分割 | 讲"整体性"，非"两种融合" |
| 难分难解 | 相持不下或关系极亲密 | 多用于争斗、纠纷 |
| 相得益彰 | 互相配合，各自长处更显 | 讲"互相成就"，非"融合" |

**例3**（2024国考）

> 所谓环境影响评价，是指对规划和建设项目实施后可能造成的环境影响进行分析、预测和评估，提出预防或减轻不良环境影响的对策和措施，进行跟踪监测的方法与制度。可以说，环境影响评价是控制环境风险的"______"，也是在发展中守住绿水青山的第一道防线，对协同推进经济高质量发展和生态环境高水平保护发挥着重要作用。

填入画横线部分最恰当的一项是：

A. 预警机
B. 安全阀
C. 试金石
D. 缓冲器

**破题**：定义句里给了**两个动作**——"**预防**"和"**减轻**"。①预防 → 事前报警，对应**预警机**；②减轻 → 事后缓解，对应**缓冲器**。①＋② 合起来才是"**安全阀**"（既能报警又能泄压）。

| 分句 | 义项 | 对应选项 |
| --- | --- | --- |
| 提出**预防**对策 | 事前警示 | 预警机（只覆盖一半） |
| 提出**减轻**对策 | 事后缓解 | 缓冲器（只覆盖一半） |
| ①＋② | 全程控险 | **安全阀** |

| 词语 | 侧重点 | 说明 |
| --- | --- | --- |
| 安全阀 | 压力超限时**自动开启泄压**，兼具报警与调控 | 同时覆盖"预防＋减轻" |
| 预警机 | 危险未发生或刚露苗头时**预报警示** | 只对应"预防" |
| 缓冲器 | 起**过渡缓解**作用，减少冲击 | 只对应"减轻" |
| 试金石 | 比喻可靠的**检验方法** | 与"控制风险"无关 |

> **⚠易错**：本题三个干扰项**各自都对一半**——这正是"行文并列"的标志。凡是两个选项"分别对应一个分句"，就要立刻想到**合成答案**。

**例4**（2024省考）

> 许多自媒体采取"流量至上"的经营模式，为追求流量，可能并不会审查所推送的信息是否失真，但对于大量面临"信息茧房"障碍的读者来说，一般不会去思考和辨别言论的真伪，即便有疑虑也难以去辨别。所以，实践中______的情形较多。

填入画横线部分最恰当的一项是：

A. 偏听偏信
B. 亦步亦趋
C. 人云亦云
D. 盲从盲信

**破题**：读者这一侧给了**两个动作**——①"**不会去思考**"＝盲从（不动脑）；②"**不去辨别真伪**"＝盲信（不辨真伪）。①＋② 即为**盲从盲信**。

| 分句 | 义项 | 对应词素 |
| --- | --- | --- |
| 一般不会去思考 | 不独立思考 | **盲从** |
| 不会/难以辨别真伪 | 不辨真假 | **盲信** |

| 词语 | 侧重点 | 说明 |
| --- | --- | --- |
| 盲从盲信 | **既盲从又盲信**（双义） | ①＋② 全覆盖 |
| 人云亦云 | 别人说什么跟着说什么、无主见 | 只对应"不思考" |
| 偏听偏信 | 只听一面之词就信 | 只对应"不辨真伪" |
| 亦步亦趋 | 事事模仿、追随别人 | 讲"跟随"，非"信" |

**例5**（2021事业单位）

> 实际上雾霾形成的原因是多方面的，识别污染源是有效治理大气污染至关重要的环节。对京津冀区域而言，认清区域内的污染源的共性及差别，有助于区域内地区______地对污染源进行综合治理。

填入画横线部分最恰当的一项是：

A. 因地制宜
B. 正本清源
C. 齐心协力
D. 有的放矢

**破题**："**共性及差别**"是两个义项——①"差别"→ 各地不同，对应**因地制宜**；②"共性"→ 共同应对，对应**齐心协力**。①＋② 合起来才是"**有的放矢**"（目标明确、有针对性）。

| 分句 | 义项 | 对应选项 |
| --- | --- | --- |
| 认清**差别** | 按各地情况分别施策 | 因地制宜（一半） |
| 认清**共性** | 各方协同一致 | 齐心协力（一半） |
| ①＋② | 目标明确、精准施治 | **有的放矢** |

| 词语 | 侧重点 | 说明 |
| --- | --- | --- |
| 有的放矢 | 对准靶子射箭，**目标明确、有针对性** | 同时覆盖"分"与"合" |
| 因地制宜 | 按各地具体情况制定办法 | 只对应"差别" |
| 齐心协力 | 思想一致、共同努力 | 只对应"共性" |
| 正本清源 | 从根源上整顿清理 | 与"识别污染源"近，但缺"协同"义 |

## 六、核心话题

> **★重点**：全段只谈**一件事（核心话题）**，所有空格都必须落在该话题的**词义范围之内**。选项若"词义对但话题偏"，一票否决。

**例1**（2023国考）

> "报得准"是气象监测预报预警的生命力。天气预报准确率高，防灾减灾才能______，为有关部门正确决策提供科学客观的支撑，应急处置才能有力有效。

填入画横线部分最恰当的一项是：

A. 全力以赴
B. 万无一失
C. 有的放矢
D. 有条不紊

**破题**：核心话题是"**准确**"——预报准了，防灾措施才**有针对性**，与后文"提供科学客观的支撑"同向。

| 词语 | 侧重点 | 说明 |
| --- | --- | --- |
| 有的放矢 | **目标明确、有针对性** | 与"报得准""科学支撑"同侧 |
| 全力以赴 | 投入全部力量 | 讲"努力程度"，非"准确" |
| 万无一失 | 绝对不会出差错 | 程度绝对，与"有力有效"不匹配 |
| 有条不紊 | 有条理、不慌乱 | 讲"秩序"，非"精准" |

**例2**（2018省考）

> 跟其他射电望远镜一样，中国大射电望远镜最主要的两大科学目标是______的中性氢和观测脉冲星，前者是研究宇宙大尺度物理学，以______宇宙起源和演化，后者是研究极端状态下的物质结构与物理规律。

依次填入画横线部分最恰当的一项是：

A. 巡访 探寻
B. 巡视 探索
C. 巡查 探讨
D. 巡弋 探究

**破题**：核心话题是"**射电望远镜**"——它的动作是**大范围扫视天空**，故取"巡视"；它的目的是**探求宇宙规律**，故取"探索"。

| 词语 | 侧重点 | 说明 |
| --- | --- | --- |
| 巡视 | **巡回观察** | 与望远镜"扫天"的功能一致 |
| 巡访 | 巡回访问（**用于人**） | 对象不合 |
| 巡查 | 巡回检查（**用于治安、设施**） | 带"查错"义 |
| 巡弋 | 军舰巡逻（**用于舰船**） | 对象不合 |

| 词语 | 侧重点 | 说明 |
| --- | --- | --- |
| 探索 | 多方寻求答案、**探求未知** | 与"宇宙起源"搭配最稳 |
| 探寻 | 寻找、探求 | 对象多为"道路、真相" |
| 探讨 | 讨论研究（**需双方**） | 主语是"研究"，非"讨论" |
| 探究 | 探索追究 | 可通，但"探索"与"宇宙"更常见 |

**例3**（2022事业单位）

> 古代在一些交通不便、文化闭塞的地方，盐促进了当地的商品流通以及商业发展，并因此______出一条条盐道。在西南地区，隐藏着众多古时的盐道，这些道路因盐而兴起，也因盐而______。它们影响着巴蜀地区的社会与经济格局，间接催生了民族间文化与商业的______。虽然没有茶叶的芬芳，没有丝绸的华丽，但其历史意义却丝毫不亚于茶马古道和丝绸之路，因此被很多学者称为"中国西南的陆上大运河"。

依次填入画横线部分最恰当的一项是：

A. 开辟 湮灭 转换
B. 孕育 衰落 沟通
C. 衍生 繁盛 交融
D. 涌现 发达 互动

**破题**：核心话题是"**盐—盐道—文化**"的**生成与兴衰链**：①盐"促进流通"而**衍生**出盐道；②"因盐而兴起，也因盐而______"——与"兴起"相对，取由盛转**繁盛**（板书逻辑：兴起↔繁盛，同侧递进）；③"文化与商业的______"→ **交融**。

| 词语 | 侧重点 | 说明 |
| --- | --- | --- |
| 衍生 | 从母体**派生出**新事物 | 与"因盐而生"的因果链合 |
| 开辟 | 打通、开创 | 与"因此"的因果衔接稍硬 |
| 孕育 | 蓄养、酝酿 | 偏"长时间培育" |
| 涌现 | 大量突然出现 | 与"一条条"搭配可，但缺"派生"义 |

| 词语 | 侧重点 | 说明 |
| --- | --- | --- |
| 繁盛 | 繁荣兴盛 | 与"兴起"同侧，构成"兴—盛"递进 |
| 湮灭 | 埋没消失 | 与"隐藏着众多古时盐道"矛盾 |
| 衰落 | 由盛转衰 | 与后文"影响格局、催生交融"矛盾 |
| 发达 | 发展充分 | 多形容"交通、经济" |

| 词语 | 侧重点 | 说明 |
| --- | --- | --- |
| 交融 | 彼此**融合为一** | 与"文化与商业"并列关系合 |
| 转换 | 转变、更换 | 与"催生"不搭 |
| 沟通 | 使彼此相通 | 讲"联系"，程度偏轻 |
| 互动 | 相互作用 | 讲"往来"，非"融合" |

B. 告知 妄下雌黄

D. 启迪 评头论足

**例5**（2023国考）

> 补齐公共服务短板，首先要善于发现深层次问题。要深入调研、综合分析、精准掌握，弄清问题的本质和关键，做到______。同时，补齐公共服务短板不是简单地打打补丁，也不会______。有一些短板和弱项，是随着时代发展而凸显的系统性问题，只有通过推动经济社会高质量发展才能从根本上解决。

| 词语 | 侧重点 | 说明 |
| --- | --- | --- |

| 细致入微 | 观察思考细致全面 | 与"关键"不对应 |
| 循序渐进 | 按步骤逐渐深入 | 与"精准掌握"不同侧 |

| 词语 | 侧重点 | 说明 |
| --- | --- | --- |
| 一劳永逸 | 辛苦一次，**以后不再费事** | 与"从根本上解决需要长期推动"对照 |
| 完美无缺 | 没有缺点 | 与"打补丁"不对应 |
| 水到渠成 | 条件成熟，事情自然成功 | 与"不会"搭配不当 |
| 一成不变 | 一经形成不再改变 | 与"补齐短板"无关 |

## 七、承上启下

> **★重点**：空格位于**段中**时，它要同时"**接住上文**"和"**领起下文**"。判定动作：把空格前后的关键词各圈一个，看哪个选项能**同时装下两个**。

**例1**（2024国考）

> 世界航天大国都在积极开展空间碎片清除技术研究，提出了各自的清除方案。总的来看有两大类：一类是接触式，如机械臂抓捕、安装离轨装置等；第二类是非接触式，如用激光或离子束等进行推移。两类清除方式______，都是要让碎片离开当前轨道，进入大气层烧毁。

填入画横线部分最恰当的一项是：

A. 各有千秋
B. 如出一辙
C. 双管齐下
D. 殊途同归

**破题**：上文给"**两类……方式不同**"，下文给"**都是要……**（结果相同）"——承上启下，正是"**途径不同、结果相同**"。

| 词语 | 侧重点 | 说明 |
| --- | --- | --- |
| 殊途同归 | **途径不同，结果相同** | 上承"两类"，下接"都是要" |
| 各有千秋 | 各有长处 | 下文未讲"优劣" |
| 如出一辙 | 两件事非常相似 | 与"两大类"的差异矛盾 |
| 双管齐下 | 两种方法同时使用 | 下文未讲"同时" |

**例2**（2023山东）

> 楚文化是长江流域的文化，中原文化是黄河流域的文化，二者如______，却又联系紧密。楚国的发祥地在中原，楚文化也______于中原地区，楚文化与中原文化交汇融合，______，都是光辉灿烂的中国传统优秀文化的组成部分。

依次填入画横线部分最恰当的一项是：

A. 并驾齐驱 起始 不谋而合
B. 齐头并进 发源 不约而同
C. 双峰对峙 滥觞 殊途同归
D. 比翼齐飞 发轫 异曲同工

**破题**：①"二者如______，**却又联系紧密**"——"却"提示前文应是**并立、对峙**，取"双峰对峙"；②"楚文化也______于中原地区"——"滥觞"即发源；③"交汇融合，______，都是……组成部分"——**路径不同、归宿相同**，取"殊途同归"。

| 词语 | 侧重点 | 说明 |
| --- | --- | --- |
| 双峰对峙 | 两座山峰相对耸立，**并立而各自独立** | 与"却又联系紧密"形成转折 |
| 并驾齐驱 | 力量、才能不分高下 | 讲"水平相当"，非"并立" |
| 齐头并进 | 多方面同时前进 | 讲"同步进行" |
| 比翼齐飞 | 夫妻情投意合、并肩前进 | 对象不合 |

| 词语 | 侧重点 | 说明 |
| --- | --- | --- |
| 滥觞 | **江河发源处**，喻事物的起源 | 与"发祥地"呼应，书面雅致 |
| 起始 | 开始 | 与"于"搭配生硬 |
| 发源 | 起源（河流） | 可通，但缺文言色彩 |
| 发轫 | 拿开止住车轮的木头，喻开端 | 多用于"事业"，不接"于" |

| 词语 | 侧重点 | 说明 |
| --- | --- | --- |
| 殊途同归 | 途径不同、结果相同 | 与"交汇融合""都是组成部分"呼应 |
| 不谋而合 | 事先没商量而意见一致 | 主语须是"人／方面" |
| 不约而同 | 没有约定而行动一致 | 同上 |
| 异曲同工 | 做法不同、效果同样好 | 讲"效果"，非"归宿" |

| 睹物思情 | **看到某物而想起相关的情感、往事** | 与"旧照""泣不成声"精准对应 |

## 八、词义丰富

> **★重点**：某个词**兼有两层含义**（字面义＋引申义，或"实"＋"虚"），文段又恰好**两层都用到**时，该词就是最优解。这是"多义优先"的另一种考法。

**例1**（2019省考）

> 我们党领导人民干革命、搞建设、抓改革，从来都是为了解决中国的现实问题。如果对矛盾______，甚至回避、掩饰矛盾，在矛盾面前畏缩不前，坐看矛盾恶性转化，那就会______，最后势必造成无法弥补的损失。

依次填入画横线部分最恰当的一项是：

A. 置若罔闻 亡羊补牢
B. 视而不见 尾大不掉
C. 闭目塞听 覆水难收
D. 熟视无睹 积重难返

**破题**：①"对矛盾______，**甚至回避、掩饰**"——递进提示前空程度**轻于**"回避掩饰"，即只是"看见了当没看见"，取"熟视无睹"；②"坐看矛盾**恶性转化**"→ 问题越积越重，取"积重难返"。

| 词语 | 程度/侧重点 | 说明 |
| --- | --- | --- |
| 熟视无睹 | **看惯了如同没看见**，不重视 | 程度轻于"回避、掩饰"，递进成立 |
| 视而不见 | 睁眼却看不见，不注意 | 与"熟视无睹"近，但缺"长期看惯"义 |
| 置若罔闻 | 放在一边不管，好像没听见 | 偏"听"，对象多为意见、呼声 |
| 闭目塞听 | 闭眼堵耳，对外界不闻不问 | 程度过重，与"甚至"后的递进冲突 |

| 词语 | 侧重点 | 说明 |
| --- | --- | --- |
| 积重难返 | **长期积累的问题不易解决** | 与"恶性转化""无法弥补"对应 |
| 亡羊补牢 | 出事后补救 | 与"损失"矛盾（已补救则不致无法弥补） |
| 尾大不掉 | 机构庞大、指挥不灵 | 与"矛盾"不搭 |
| 覆水难收 | 事已成定局、难以挽回 | 讲"结果不可逆"，与"恶性转化"的过程义稍隔 |

**例2**（2023山东）

> 自"安史之乱"之后，盛极一时的唐王朝______。当时的衣冠贵胄目睹国运的______衰退，在政治上无法施展抱负，只能够在文化领域当中寻找实现的机会，许多文人为了逃避现实又像魏晋时期的"竹林七贤"一样，从酒、音乐、文学、宗教、哲学中寻求解脱。但与"竹林七贤"不同的是，他们可以用绘画来表达个人的情感和意念。

依次填入画横线部分最恰当的一项是：

A. 轰然崩塌 日渐
B. 风光不再 逐步
C. 一蹶不振 日益
D. 大厦将倾 逐渐

**破题**：①"**盛极一时**的唐王朝______"——由盛转衰，取"一蹶不振"（受重挫后再难振作）；②"国运的______**衰退**"——与"衰退"搭配，"日益"最稳（讲义专列"日益"的三个官媒例句，正指向本空）。

| 词语 | 侧重点 | 说明 |
| --- | --- | --- |
| 一蹶不振 | 受一次挫折后**再也振作不起来** | 与"盛极一时"形成落差 |
| 风光不再 | 从前的好形势结束、走下坡路 | 可通，但"逐步"与"衰退"搭配较弱 |
| 轰然崩塌 | 突然猛烈倒塌 | 程度过重，唐王朝此后仍延续百余年 |
| 大厦将倾 | 眼看就要倒塌，形势危急 | 只指"将倾"，非"已衰" |

| 词语 | 侧重点 | 搭配 |
| --- | --- | --- |
| 日益 | 一天比一天更加（**书面、时政高频**） | 日益突出、日益增多、日益衰退 |
| 日渐 | 一天天逐渐 | 日渐消瘦、日渐衰落 |
| 逐步 | 一步一步地（**人为推进**） | 逐步推进、逐步完善 |
| 逐渐 | 渐渐（**自然变化**） | 逐渐消失 |

**词语积累｜日益**

| 例句 | 出处 |
| --- | --- |
| 全球保护主义**日益**抬头的时代。 | 2024人民日报《更好促进中国东盟互利共赢》 |
| 在融合过程中难统筹、难融合、不协同、不平衡等发展问题**日益**突出。 | 2024人民日报《推动新型信息基础设施协调发展》 |
| 国际形势动荡不安，全球风险挑战**日益**增多…… | 2024人民日报《国际人士热切期待习近平主席出席金砖国家领导人会晤》 |

**例3**（2024山东）

> 稳步推进个人所得税改革，______收入分配秩序，提高居民收入水平和消费购买力。近年来，我国个人所得税改革______，通过提高基本减除费用标准、设立专项附加扣除、优化调整税率结构等一系列组合拳，上亿自然人纳税人税收负担明显减轻，综合所得年收入10万元以下的自然人纳税人，大部分不用再缴纳个人所得税。

依次填入画横线部分最恰当的一项是：

A. 规范 蹄疾步稳
B. 强化 循序渐进
C. 调整 筚路蓝缕
D. 完善 披荆斩棘

**破题**：①"______收入分配**秩序**"——"秩序"的固定搭配是"**规范**"；②"**稳步推进**"是首句给的基调，改革既快又稳，取"蹄疾步稳"（"蹄疾"呼应"快"，"步稳"呼应"稳"，一词双义）。

| 词语 | 搭配 | 说明 |
| --- | --- | --- |
| 规范秩序 | **固定搭配** | 规范市场秩序、规范收入分配秩序 |
| 强化 | 加强（力度） | 与"秩序"搭配弱 |
| 调整 | 改变（结构、政策） | 与"秩序"搭配不当 |
| 完善 | 使之完备（制度、体系） | 可通，但不如"规范秩序"稳定 |
