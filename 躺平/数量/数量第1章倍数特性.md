## 一、整除型

### 核心结论

> **★重点**：若 `A = B × C`（B、C 均为整数），那么 A 能被 B 整除，且 A 能被 C 整除。

### 整除判定方法

**（1）口诀法（常用于 3、4、5、9）**

| 判定 | 方法 | 示例 |
| --- | --- | --- |
| 3 / 9 | 看各位数字之和能否被 3/9 整除（巧用弃 3 法、弃 9 法） | 12345 |
| 2 / 5 | 看数字末一位能否被 2/5 整除 | 12125 |
| 4 / 25 | 看数字末两位能否被 4/25 整除 | 12124 |
| 8 / 125 | 看数字末三位能否被 8/125 整除 | 12164 |

**（2）拆分法（没口诀的数，常用于 7、11、13）**

一个数 = 接近且明显能被整除的数 ± 零头，只看零头。
例：判断 623 ÷ 7，把 623 拆成 7 的倍数 ± 零头，只看零头能否被 7 整除。

**（3）因式分解（复杂倍数，常用于 6、12、18、24 等）**

> **⚠易错**：因式分解必须分解成两个**互质**的数（互质指两数没有公约数），同时满足能被这两个数整除。例：`24 = 3 × 8`（不能用 4 × 6）。

### 例题

**例1**（2025联考）某绿色有机农场把61600平方米耕地划分为玉米、大豆、稻谷三个作物区，玉米和大豆的面积比是7:2，大豆和稻谷的面积比是6:1，则玉米的面积是多少平方米？
A. 46200
B. 47200
C. 48200
D. 49200

**破题**：两个比例统一化 → 玉米:大豆:稻谷，答案必是"玉米份数"的倍数，先用倍数排除。

**解析**：玉米:大豆 = 7:2，大豆:稻谷 = 6:1，统一大豆为 6 份，得三区之比 `21 : 6 : 1`，共 28 份。
`61600 ÷ 28 = 2200`（平方米/份），玉米 = `21 × 2200 = 46200`。
（验证：大豆 = 13200，稻谷 = 2200，46200 + 13200 + 2200 = 61600 ✓）

**答案：A**

**例2**（2025联考）某购物平台推出每消费600元立减50元的活动，钟先生在该平台准备购买单价为500元的某款商品不超过10件，问他购买几件时平均每件的购买成本最低？
A. 5
B. 6
C. 8
D. 9

**破题**：每满 600 减 50 → 500n 元里含多少个 600，用 `500n ÷ 600 = 5n/6` 判断，逐项代入算均价。

**解析**：购买 n 件，总价 500n，立减 `50 × ⌊5n/6⌋`：

| n | 总价 | 立减次数 | 立减金额 | 平均每件 |
| --- | --- | --- | --- | --- |
| 5 | 2500 | 4 | 200 | 460 |
| 6 | 3000 | 5 | 250 | 约458.3 |
| 8 | 4000 | 6 | 300 | 462.5 |
| 9 | 4500 | 7 | 350 | 约461.1 |

买 6 件平均成本最低（约458.3元）。

**答案：B**

**例3**（2025江苏）某5A级景区门票90元/人，教师免票、大学生半票，乘坐索道另付70元/人。某校教师和大学生共110人到该景区研学，若支付的门票和索道费共11750元，则参与研学的教师有（）。
A. 6人
B. 10人或20人
C. 10人
D. 6人或20人

**破题**：门票费 = 45 × 大学生数，必是 45 的倍数；索道费 70 × 110 先扣除，余数用整除性验证。

**解析**：设大学生 s 人、教师 t 人，s + t = 110。110 人乘索道共 `70 × 110 = 7700` 元，门票共 `11750 - 7700 = 4050` 元。
大学生半票 45 元/人：`4050 ÷ 45 = 90` 人 → 教师 = `110 - 90 = 20` 人。

> **★重点**：注：选项是"数量最大"的技巧——此类多解/复合条件题，优先锁定含大数值的选项。

**答案：D**

## 二、余数型

### 核心结论

> **★重点**：余数型（公务员思想：均分思想、多退少补）。题型特征：均分、多几个、少几个。
> 若 `总数 = ax + b`，则（总数 - b）能被 a 整除（a、x 均为整数）。

**补例1** 一堆苹果分给一些人，平均每人分3个……问这堆苹果有多少个？
（总数是 3 的倍数）

**补例2** 一堆苹果分给一些人，平均每人分10个，还剩3个……问这堆苹果有多少个？
A. 117　B. 120　C. 123　D. 126
（总数 - 3 是 10 的倍数 → 选 C.123）

**补例3** 一堆苹果分给一些人，平均每人分10个，还缺3个……问这堆苹果有多少个？
A. 117　B. 120　C. 123　D. 126
（总数 + 3 是 10 的倍数 → 选 A.117）

**例4**（2025全国事业单位）某厂购进一批染料，分别为红色和蓝色，该厂每天消耗红色染料3桶，蓝色染料2桶，7天后检查发现剩余染料中红色是蓝色的3倍。问该厂共购进至少多少桶染料？（）
A. 36
B. 37
C. 39
D. 43

**破题**：已消耗量确定（红 21、蓝 14），设剩余蓝色 b 桶，总数 = 已消耗 + 剩余，用"至少"从小代入。

**解析**：7 天已消耗红 `3 × 7 = 21` 桶、蓝 `2 × 7 = 14` 桶。设剩蓝色 b 桶，则剩红色 3b 桶。
`总数 = 21 + 14 + b + 3b = 35 + 4b`，即总数减 35 是 4 的倍数（或总数 ÷ 4 余 3）。
选项中 36 ÷ 4 余 0、37 余 1、`39 = 35 + 4`（b = 1，剩红 3 桶、剩蓝 1 桶，符合）、43 余 3 但更大。
至少为 39 桶。

**答案：C**

**例5**（2025山东事业单位）某网站有会员2025人，该网站拟面向会员举办礼品派发活动，让会员从1~2025中抓阄抓取自己的编号，规定编号能被3除余1，且被5除余1的会员可以获得一份礼品。那么可以获得礼品的会员有多少人？
A. 135
B. 134
C. 136
D. 137

**破题**：被 3 除余 1 且被 5 除余 1 → 被 15 除余 1，数等差数列的项数。

**解析**：编号满足 `15k + 1 ≤ 2025`（k = 0, 1, 2, …），即 `k ≤ 2024 ÷ 15 = 134.…`，k 最大取 134。
人数 = `134 - 0 + 1 = 135` 人。

**答案：A**

## 三、比例型

### 表达方式与适用条件

比例的四种表达（以"男员工是女员工的 3/5"为例）：

1. 分数：男员工是女员工的 3/5；
2. 比例：男员工与女员工之比 3:5；
3. 百分数：男员工是女员工的 60%；
4. 倍数：男员工是女员工的 0.6 倍。

> **★重点**：比例型适用条件——①题干特征：出现分数、比例、百分数、倍数；②对象特征：描述对象为不可分割的整体，整数才有意义（人、车、年龄等）。

### 四个考法

核心：**问题和分子、分母的关系**。设男:女 = m:n（最简分数）：

| 问题 | 结论 |
| --- | --- |
| ① 男生人数 | 是 m 的倍数 |
| ② 女生人数 | 是 n 的倍数 |
| ③ 全班人数 | 是 m+n 的倍数 |
| ④ 男女生人数差 | 是 m-n 的倍数 |

考法三（A 与非 A 思想）：把"其他/剩余部分"作为一个整体与目标对象作比。

### 例题

**例6**（2024联考）某单位为解决职工暑期"带娃难"的问题，开设了暑托班。开班时男孩与女孩的比例为3:4，后来有2个男孩、1个女孩退出暑托班，此时男孩与女孩的比例为2:3。那么开班时女孩有多少人？
A. 10
B. 12
C. 14
D. 16

**破题**：比例发生变化且有具体增减人数 → 设份数列方程。

**解析**：设开班时男孩 3x 人、女孩 4x 人。
`(3x - 2) : (4x - 1) = 2 : 3` → `3(3x - 2) = 2(4x - 1)` → `9x - 6 = 8x - 2` → `x = 4`。
女孩 = `4 × 4 = 16` 人。

**答案：D**

**例7**（2025国考）甲、乙、丙、丁四个部门共有210名员工，且甲部门员工数比丁部门多10人。现乙部门调动20名员工到丙部门且其剩余员工并入丁部门后，甲、丙、丁三个部门的员工数之比为3:3:4。问原乙部门有多少名员工？
A. 41
B. 46
C. 51
D. 56

**破题**：乙部门人员全部调出 → 总人数 210 不变，最终只有甲、丙、丁，按 3:3:4 拆分倒推。

**解析**：`210 × 3/10 = 63`（甲）、`63`（丙）、`210 × 4/10 = 84`（丁）。
甲 = 丁原 + 10 → 丁原 = 63 - 10 = 53。
丁终 84 = 丁原 53 + 乙剩余 → 乙剩余 = 31。
乙原 = 调走 20 + 剩余 31 = `51` 名。

**答案：C**

## 四、倍数特性之增长率型（用资料解决数量）

充分利用已学过的资料分析来解决数量问题：

1. 分析关系：基期、现期、增长量、增长率；
2. 结合选项，做"猜+结合"。

**例8**（2025国考）某企业今年3月节电量是1月的1.2倍、2月的1.5倍，已知2月节电量比1月少4万度，问今年一季度企业节电量为多少万度？
A. 48
B. 52
C. 56
D. 60

**破题**：3 月分别是 1 月的 1.2 倍、2 月的 1.5 倍 → 化为整数比设份数。

**解析**：`3月 = 1.2 × 1月 = 2月的1.5倍`。取 3 月 = 6k，则 1 月 = `6k ÷ 1.2 = 5k`，2 月 = `6k ÷ 1.5 = 4k`。
1月 - 2月 = k = 4 → 1月 20、2月 16、3月 24。
一季度总量 = `20 + 16 + 24 = 60` 万度。

**答案：D**

**例9**（2025江苏）某市正在深入推进"智改数转网联"升级行动计划，力争实现全市规模以上企业全覆盖。目前，全市规模以上企业2080家，其中未完成升级的规模以上企业比已完成升级的多0.6倍，那么已完成升级的规模以上企业有（）。
A. 780家
B. 800家
C. 1280家
D. 1300家

**破题**："多 0.6 倍" → 未完成 : 已完成 = 1.6 : 1 = 8 : 5，总数是 13 的倍数。

**解析**：设已完成 x 家，未完成 = 1.6x。
`x + 1.6x = 2.6x = 2080` → `x = 2080 ÷ 2.6 = 800` 家。

**答案：B**

**例10**（2025广东）某助农电商企业销售柠檬、蜜柚两种水果，由于季节变化，这个月蜜柚的销量比上月增加了40%，而柠檬的销量降低了20%，最终当月这两种水果的总销量比上个月增加4%，则蜜柚上月销量占这两种水果上月销量的（）。
A. 60%
B. 50%
C. 40%
D. 30%

**破题**：混合增长率 → 十字交叉或设上月销量列方程。

**解析**：设上月蜜柚 a、柠檬 b。
`1.4a + 0.8b = 1.04(a + b)` → `0.36a = 0.24b` → `a : b = 2 : 3`。
蜜柚上月占比 = `2 ÷ (2 + 3) = 40%`。

**答案：C**

**例11**（2025山东事业单位）某村计划建设一座面积为960m²的文化广场，应广大村民的合理诉求，建筑面积需增加40m²，问在不增加预算的情况下每平方米成本需要降低百分之几？
A. 3%
B. 6%
C. 5%
D. 4%

**破题**：预算不变 → 总成本不变，单价与面积成反比。

**解析**：新面积 = `960 + 40 = 1000` m²。
单价之比 = 面积反比 = `1000 : 960 = 25 : 24`，即新单价为原单价的 24/25。
降低 = `1 - 24/25 = 1/25 = 4%`。

**答案：D**

## 五、倍数特性之 A=B×C（用资料解决数量）

形式：A = B × C，给单个量。方法：**赋值**（总量设为各数量的公倍数）。
公倍数求法：短除法。练习：求 18、30 的公倍数（90）；18、30、50 的公倍数（450）。

**例12**（2025联考）某小区组织"情满金秋"柑橘采摘活动，参加人员按年龄分成老、中、青三组，老年组、中年组的人数之比为5:2，中年组、青年组的人数之比为3:4。老年组、中年组、青年组平均每人采摘速度之比为1:2:3。已知青年组共采摘80斤柑橘，那么三组人员一共采摘柑橘：
A. 170斤
B. 212斤
C. 255斤
D. 298斤

**破题**：采摘总量 = 人数 × 速度，两组比例统一后"人数比 × 速度比"得总量比。

**解析**：老:中 = 5:2，中:青 = 3:4 → 统一中年为 6 → 老:中:青 = `15 : 6 : 8`。
采摘量比 = 人数比 × 速度比 = `(15×1) : (6×2) : (8×3) = 15 : 12 : 24`。
青年组 24 份 = 80 斤 → 1 份 = 10/3 斤。
总量 = `15 + 12 + 24 = 51` 份 = `51 × 10/3 = 170` 斤。

**答案：A**

**例13**（2025天津）某水产养殖公司拥有若干幼体培育车间、育苗车间和藻类池。已知幼体培育车间的水体与育苗车间的水体之比为1:4，藻类池的水体是幼体培育车间水体的50%。若每200m³水体需配备1名管理人员，则幼体培育车间需要的管理人员比育苗车间少12人。问该公司共配备了多少名管理人员？
A. 25
B. 24
C. 23
D. 22

**破题**：人数比 = 水体比，设幼体水体为 x，表示三个水体。

**解析**：设幼体车间水体 x m³，则育苗 = 4x，藻类池 = 0.5x。
管理人员：幼体 `x/200` 人，育苗 `4x/200` 人，差 `3x/200 = 12` → `x = 800`。
幼体 4 人、育苗 16 人、藻类池 `0.5 × 800 ÷ 200 = 2` 人。
共 `4 + 16 + 2 = 22` 名。

**答案：D**

**例14**（2024江苏）小王去超市买办公用品，经费恰好可以买18个计算器或者买30个订书机或者50个档案盒，若购买了6个计算器、8个订书机后，剩下的经费全部购买了档案盒，则他购买档案盒的个数是（）
A. 10
B. 14
C. 20
D. 26

**破题**：同一经费买三种商品 → 赋值总经费为 18、30、50 的公倍数 450。

**解析**：设总经费 450 元 → 计算器单价 25 元、订书机 15 元、档案盒 9 元。
已花：`6 × 25 + 8 × 15 = 150 + 120 = 270` 元。
剩 `450 - 270 = 180` 元 → 档案盒 `180 ÷ 9 = 20` 个。

**答案：C**

## 专项拔高练习一

**练习1**（2025联考）某工程项目要招聘100名甲乙两个岗位的工人，月工资分别为3000元和4000元，且招聘的乙岗位工人数不少于甲岗位的2倍。为使月付工资最少，则甲乙两个岗位招聘工人数分别为：
A. 31人，69人
B. 32人，68人
C. 33人，67人
D. 34人，66人

**破题**：甲岗位工资低 → 甲越多越省；约束"乙 ≥ 2甲"给出甲的上限。

**解析**：乙 ≥ 2甲 且 甲 + 乙 = 100 → 3甲 ≤ 100 → 甲 ≤ 33.3，甲最大取 33。
甲 33 人、乙 67 人时工资最少。

**答案：C**

**练习2**（2023山东）某科研团队中男性占比高于50%，低于60%，问这一团队最少有几人？
A. 5
B. 6
C. 7
D. 8

**破题**：男性人数为整数，找最小的 n 使存在整数 m 满足 `n/2 < m < 0.6n`。

**解析**：n = 5：男性只能为 3（3/5 = 60%，不满足"低于"）；n = 6：3/6 = 50%、4/6 ≈ 67%，都不行；
n = 7：`4/7 ≈ 57.1%`，高于 50% 且低于 60% ✓。最少 7 人。

**答案：C**

**练习3**（2025山东事业单位）选举规定，候选人需要获得超过总票数的 5/6 才能当选，在统计了 4/5 的选票后，候选人甲获得了当选所需票数的 4/5，问甲还需要获得剩余选票的几分之几以上才能成功当选？
A. 5/6
B. 4/5
C. 3/4
D. 2/3

> 注：题干中三个分数在 OCR 稿中缺失，已按 2025 山东事业单位真题（PDF 第 36 页）核实为 5/6、4/5、4/5。

**破题**：总票数含分母 6 和 5 → 赋值总票数为 30 的倍数。

**解析**：设总票数 30k。当选需 > `30k × 5/6 = 25k` 票；已统计 `30k × 4/5 = 24k` 票。
甲已得 `25k × 4/5 = 20k` 票。剩余选票 `30k - 24k = 6k` 张。
还需 > `25k - 20k = 5k` 票 → 需获得剩余选票的 `5k/6k = 5/6` 以上。

**答案：A**

**练习4**（2024广东）档案室需要整理300份档案，要求每天整理的档案数量相同，且规定了完成的期限。如果要提前一天完成，那么每天需要多整理10份档案。则规定的期限为（）天。
A. 6
B. 7
C. 8
D. 9

**破题**：总量 300 不变，天数与每天工作量成反比，列分式方程。

**解析**：设期限 x 天，则原来每天 `300/x` 份，提前一天每天 `300/(x-1)` 份。
`300/(x-1) - 300/x = 10` → `300 ÷ [x(x-1)] = 10` → `x(x - 1) = 30` → `x = 6`。
（验证：6 天每天 50 份；5 天每天 60 份，多 10 份 ✓）

**答案：A**

**练习5**（2025联考）某公司搬家需打包运走电脑主机和显示器各n台。有两种打包方式：一种是一箱装入6台主机和4台显示器，另一种是一箱装入3台主机和8台显示器。已知公司所有的电脑主机和显示器正好装满若干箱，问n可能的最小值为：
A. 18
B. 24
C. 30
D. 36

**破题**：设两种箱各 x、y 箱，主机数 = 显示器数 = n，消去 n 找 x:y 的关系。

**解析**：`6x + 3y = 4x + 8y` → `2x = 5y` → x : y = 5 : 2（x = 5k，y = 2k）。
`n = 6 × 5k + 3 × 2k = 36k`，最小 k = 1 → n = 36。

**答案：D**

**练习6**（2021北京）为响应国家"做好重点群体就业工作"的号召，某企业扩大招聘规模，计划在年内招聘高校毕业生240名，但实际招聘的高校毕业生数量多于计划招聘的数量。已知企业将招聘到的高校毕业生平均分配到7个部门培训，并在培训结束后将他们平均分配到9个分公司工作。问该企业实际招聘的高校毕业生至少比计划招聘数多多少人？
A. 6
B. 12
C. 14
D. 28

**破题**：实际人数能被 7 和 9 整除 → 是 63 的倍数，找大于 240 的最小值。

**解析**：63 的倍数中大于 240 的最小值为 `63 × 4 = 252`。
`252 - 240 = 12` 人。

**答案：B**

**练习7**（2024全国事业单位联考）企业招聘了100多名应届毕业生，其中13人被分配到总部工作，剩下的人正好被平均分配到7个分公司，也能被平均分配到9个分公司工作。问企业招聘了多少名应届毕业生？（）
A. 126
B. 139
C. 176
D. 189

**破题**：n - 13 是 7 和 9 的公倍数（63 的倍数），n 在 100~200 之间。

**解析**：`n = 63k + 13`。k = 2 → `126 + 13 = 139`，在 100 多范围内 ✓。

**答案：B**

**练习8**（2024广东）某社区计划组织志愿者为社区内的独居老人提供服务。按已有志愿者的数量，如果每位志愿者服务10位老人，则有5位老人无人提供服务；如果增加2位志愿者，则每位志愿者最多服务8位老人就能为所有老人提供服务。那么该社区最多有（）位独居老人。
A. 50
B. 55
C. 60
D. 65

**破题**：老人数 = 10×志愿者 + 5，是"10 的倍数 + 5"型；再结合"8×(志愿者+2) ≥ 老人数"求最值。

**解析**：设志愿者 v 人，老人 = `10v + 5` 位。
`10v + 5 ≤ 8(v + 2)` → `10v + 5 ≤ 8v + 16` → `v ≤ 5.5` → v 最大取 5。
老人最多 = `10 × 5 + 5 = 55` 位。

**答案：B**

**练习9**（2022天津）某地组织大型公益演出，临时抽调一支一百多人的志愿服务队。其中，20至30岁（不含30岁）的人数占总人数的68%，30岁及以上的人数是不到20岁人数的7倍。已知30岁以下的人数比30岁及以上的人数多66人，问这支服务队共多少人？
A. 90
B. 120
C. 150
D. 180

**破题**：68% = 17/25 → 总人数是 25 的倍数；用"不到20岁"把三段人数统一。

**解析**：设总人数 T，不到 20 岁 a 人，则 30 岁及以上 7a 人。
`a + 7a = 32% × T` → `8a = 0.32T` → `a = 0.04T`，30 岁及以上 = `0.28T`。
30 岁以下（20~30 岁 68% + 不到 20 岁 4% = 72%）比 30 岁及以上（28%）多 44%T = 66 → `T = 150`。
（验证：20~30 岁 102 人、不到 20 岁 6 人、30 岁及以上 42 人，108 - 42 = 66 ✓，且为一百多人 ✓）

**答案：C**

**练习10**（2024联考）大学生创业主要集中在高科技、智力服务、连锁加盟和自媒体运营四个领域。某学院今年选择创业的大学毕业生不到50人，其中选择智力服务领域、连锁加盟领域和自媒体运营领域的分别占 1/7、1/2 和 1/3。那么该学院今年选择高科技领域创业的大学毕业生有多少人？
A. 1
B. 3
C. 5
D. 7

> 注：题干中三个分数在 OCR 稿中缺失，已按 2024 联考真题（PDF 第 43 页）核实为 1/7、1/2、1/3。

**破题**：总人数是 7、2、3 的公倍数，结合"不到 50 人"锁定总人数。

**解析**：`LCM(7, 2, 3) = 42`，不到 50 人 → 总人数 42。
智力服务 `42 × 1/7 = 6` 人、连锁加盟 `42 × 1/2 = 21` 人、自媒体 `42 × 1/3 = 14` 人。
高科技 = `42 - 6 - 21 - 14 = 1` 人。

**答案：A**

**练习11**（2024江苏）某居民楼居住人数介于90和110之间，其中50岁及以上居民占 1/12，女性占 7/16。若该居民楼30岁及以上居民比30岁以下居民多20人，则30岁以下居民比50岁及以上居民多：
A. 30人
B. 27人
C. 23人
D. 20人

> 注：题干中两个分数在 OCR 稿中缺失，已按 2024 江苏真题（PDF 第 44 页）核实为 1/12、7/16。

**破题**：总人数是 12 和 16 的公倍数，结合"90~110"锁定总人数。

**解析**：`LCM(12, 16) = 48`，90~110 之间的倍数为 96 → 总人数 96。
50 岁及以上 = `96 × 1/12 = 8` 人。
设 30 岁以下 x 人，则 30 岁及以上 `x + 20` 人，`x + x + 20 = 96` → `x = 38`。
30 岁以下比 50 岁及以上多 `38 - 8 = 30` 人。

**答案：A**

**练习12**（2023联考）某高校今年共有231名本科毕业生被录取为硕士研究生。其中推荐录取人数比上年度减少 1/6，而考试录取人数比上年度增加 31/150，总体录取人数比上年度高10%，那么，这所高校今年推荐录取的研究生人数为：
A. 40人
B. 45人
C. 50人
D. 55人

> 注：题干中两个分数在 OCR 稿中缺失，已按 2023 联考真题（PDF 第 45 页）核实为 1/6、31/150。

**破题**：今年考试录取 = 去年的 `1 + 31/150 = 181/150` → 今年考试录取是 181 的倍数，结合总数 231 锁定。

**解析**：今年考试录取人数是 181 的倍数，且 `今年考试 + 今年推荐 = 231`，故今年考试录取只能是 181。
今年推荐 = `231 - 181 = 50` 人。
（验证：今年推荐 = 去年推荐 × 5/6 → 去年推荐 = 60；去年考试 = 181 × 150/181 = 150；去年总数 210，今年 231 比 210 高 10% ✓）

**答案：C**

**练习13**（2024国考）甲、乙、丙三个研发团队共有研发人员300多人，其中甲的人数比乙多26%。现丙调3人去乙后，两个团队人数相同。问此时甲至少调多少人去丙后，才能保证丙的人数是甲的2倍以上？
A. 49
B. 35
C. 50
D. 40

**破题**："多 26%" → 甲 : 乙 = 63 : 50；"丙调 3 人去乙后两队相同" → 丙 = 乙 + 6，设乙 50k 列总人数。

**解析**：甲 = 63k，乙 = 50k，丙 = 50k + 6。
`63k + 50k + 50k + 6 = 163k + 6` 为 300 多 → k = 2，总人数 332。
甲 = 126，乙 = 100，丙 = 106。丙调 3 人去乙后：乙 = 丙 = 103。
设甲调 x 人去丙：`103 + x > 2(126 - x)` → `3x > 149` → `x > 49.67` → 至少 50 人。

**答案：C**

**练习14**（2024全国事业单位联考）甲、乙和丙三个单位共有职工240人，其中乙单位人数比甲单位多，甲单位女性职工正好比男性多14%。问丙单位最多有多少名职工？
A. 25
B. 27
C. 29
D. 31

**破题**：女 = 男 × 1.14 = 男 × 57/50 → 甲单位总人数是 107 的倍数；问丙最多 → 甲、乙尽量少。

**解析**：甲单位男 : 女 = 50 : 57 → 甲单位人数是 107 的倍数，最少 107 人。
乙比甲多且要尽量少 → 乙最少 = 108 人。
丙最多 = `240 - 107 - 108 = 25` 人。

**答案：A**

**练习15**（2020江苏）某企业预计今年营业收入增长15%，营业支出增长10%，营业利润增加600万元。已知该企业去年的营业利润为1000万元，则其今年的预计营业支出是
A. 9000万元
B. 9900万元
C. 10800万元
D. 11500万元

**破题**：收入 - 支出 = 利润，今年利润 1600 万，设去年收入、支出列方程。

**解析**：今年利润 = `1000 + 600 = 1600` 万元。设去年收入 R、支出 E，`R - E = 1000`。
`1.15R - 1.10E = 1600` → `0.15R - 0.10E = 600` → `15R - 10E = 60000`。
代入 `R = 1000 + E`：`15000 + 15E - 10E = 60000` → `5E = 45000` → `E = 9000`。
今年支出 = `9000 × 1.1 = 9900` 万元。

**答案：B**

**练习16**（2021联考）某果蔬专业博士生一行8人，深入某贫困山区，为当地3个村的村民传授果树的种植技术，当年3个村的水果产量之比为3:2:5，第2年3个村的水果产量都有不低于20%的增加，且3村水果总产量增加50%，问3个村水果产量的最大增幅可能是多少？
A. 80%
B. 120%
C. 150%
D. 170%

**破题**：设今年产量 3k、2k、5k，总量 10k，增量共 5k；每村增量 ≥ 各自产量的 20%，求某村增幅上限。

**解析**：村1 增量 ≥ 0.6k，村2 增量 ≥ 0.4k。
要使某村（如村3）增幅最大，其余两村增量取最小：村3 增量 = `5k - 0.6k - 0.4k = 4k`。
增幅 = `4k ÷ 5k = 80%`。

**答案：A**

**练习17**（2024联考）某人买了甲、乙两种金融产品，期限结束后，甲、乙两种金融产品收益率分别是5%和3%，最终收益率为3.5%，那么购买甲、乙两种金融产品的金额比例为：
A. 1:1
B. 1:2
C. 1:3
D. 1:4

**破题**：混合收益率 → 十字交叉。

**解析**：`5a + 3b = 3.5(a + b)` → `1.5a = 0.5b` → `a : b = 1 : 3`。

**答案：C**

## 小结

> **★重点**：倍数特性解题思维：利用选项结合倍数关系，先排除，排除不完再代入算。

| 类型 | 核心要点 |
| --- | --- |
| 整除型 | `A = B × C`（B、C 为整数）→ A 能被 B、C 整除；3/9 看数字和（巧用弃 3 法、弃 9 法），2/5 末一位，4/25 末两位，8/125 末三位；拆分法用于 7、11、13；因式分解用于 6、12、18、24（须互质） |
| 余数型 | 均分思想：若 `总数 = ax + b`，则（总数 - b）能被 a 整除（a、x 均为整数） |
| 比例型 | 题干特征：分数、比例、百分数、倍数；核心：问题和分子、分母的关系；男生是 m 的倍数、女生是 n 的倍数、全班是 m+n 的倍数、差是 m-n 的倍数；另有 A 与非 A 思想 |
| 增长率型 | ①分析关系：基期、现期、增长量、增长率；②结合选项，做"猜+结合" |
