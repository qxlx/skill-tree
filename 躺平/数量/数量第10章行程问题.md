## 一、基础行程

### 1. 普通行程

```
路程 = 速度 × 时间
S = V × T
```

注：

1. 单位换算：`1米/秒 = 3.6千米/时`。
2. 只给时间或者给定速度比例可赋值（类似工程问题给定时间型和给定效率比例型）。

**例1**（2025国考）张某 8:00 开车从 A 地出发，在 A、B 两地之间往返行驶。8:30 第一次到达 A、B 之间的 C 点时加速 30% 继续行驶，并于 9:00 第二次到达 C 点。问 AC 距离是 BC 距离的多少倍？（选项 OCR 缺失，建议核对 PDF 第 5 页）

**破题**：往返 + 中途加速 → 画图分段："A→C"一段，"C→B→C"一段；同样半小时内走的路程与速度成正比。

**解析**：设 AC = x、CB = y、原速为 v。

第 1 段（8:00~8:30，30 分钟）：x = 0.5v。
第 2 段（8:30~9:00，30 分钟）：速度变为 1.3v，走 C→B→C 共 2y，故 2y = 0.5×1.3v = 0.65v，y = 0.325v。

AC ÷ BC = 0.5v ÷ 0.325v = 20/13 ≈ 1.54 倍。（选项 OCR 缺失，建议核对 PDF 第 5 页）

**例2**（2025天津）一条长方形跑道 ABCD 中，AB 长度是 AD 的 1.5 倍。小张从 A 点出发以 9 千米/小时的速度向 B 点方向匀速慢跑，40 秒后尚未到达 B 点，距离 B 点还有 35 米。如他继续沿跑道匀速慢跑，再过 1 分钟后，他与 A 点的直线距离在以下哪个范围内？

A. 不到135米
B. 135~140米之间
C. 140~145米之间
D. 超过145米

**破题**：给速度给时间 → 先把"还剩 35 米"还原成长方形长宽，再按折线跑位算直线距离（构造直角三角形）。

**解析**：9 千米/小时 = 2.5 米/秒。

40 秒跑 2.5×40 = 100 米，距 B 还剩 35 米 → AB = 135 米；AB = 1.5AD → AD = 90 米。

再过 60 秒跑 150 米，累计 250 米。AB+BC = 135+90 = 225 米，故此时他在 CD 上、距 C 点 25 米处。

以 A 为原点、AB 为横轴：C 点坐标 (135, 90)，该点坐标 (110, 90)，与 A 的直线距离 = √(110²+90²) = √20200 ≈ 142.1 米。

**答案**：C

### 2. 火车过桥

火车过桥（从开始进入隧道/桥到车身完全驶出）：

```
S路 = S桥 + S车
总路程 = 桥长 + 火车车身长度 = 火车速度 × 过桥时间
```

火车完全在桥上（车尾进入到车头未露出）：

```
S路 = S桥 - S车
总路程 = 桥长 - 火车车身长度 = 火车速度 × 过桥时间
```

**例3**（2025江苏）引导车引导运输车队前往某地，途经一座桥梁和一个隧道，引导车与运输车队速度一致，引导车的长度忽略不计。匀速通过 800 米长的桥梁，引导车需 36 秒，运输车队需 45 秒。通过隧道时车速比通过桥梁时下降 25%，若引导车需 60 秒，则运输车队需：

A. 69秒
B. 70秒
C. 72秒
D. 75秒

**破题**：无长度的引导车与有长度的车队过同一座桥 → 两者用时之差就是"车身通过"的时间，先定速度再定车长。

**解析**：引导车过桥：v = 800÷36 = 200/9 米/秒。

车队过桥（桥长+车长）：(800+L)÷(200/9) = 45 → 800+L = 1000 → L = 200 米。

隧道内车速降 25%：v' = (200/9)×0.75 = 50/3 米/秒。引导车 60 秒 → 隧道长 = (50/3)×60 = 1000 米。

车队过隧道：(1000+200)÷(50/3) = 1200×3/50 = 72 秒。

**答案**：C

### 3. 匀加速（新型热门考法）

识别：匀减速、匀加速。

```
匀变速运动的平均速度：V = (V初速度 + V末速度) / 2
```

**例4**（2025联考）甲乙两辆车相距 200 米，同向同时沿直线出发。乙保持 5 米/秒的速度匀速前行，甲从速度为零起步做匀加速运动追赶乙，10 秒后恰好追上乙。则甲在追上乙时的速度为：

A. 10米/秒
B. 30米/秒
C. 50米/秒
D. 70米/秒

**破题**：匀加速 + 追及 → 追上时间已知，用"平均速度 = (V初+V末)/2"把匀加速当平均速算。

**解析**：10 秒追上，甲比乙多跑 200 米，故甲 10 秒共跑 200+5×10 = 250 米。

平均速度 = 250÷10 = 25 米/秒。

25 = (0+V末)÷2 → V末 = 50 米/秒。

**答案**：C

**例5**（2025联考）小张和小赵分别从甲、乙两地同时出发前往对方的出发地。小张出发时的速度是小赵的一半，两人匀速行进 1 小时后迎面相遇。此后小张开始均匀加速，最终比小赵晚到达 1 小时。问小张到达时的速度是小赵到达时速度的多少倍？（选项 OCR 缺失，建议核对 PDF 第 11 页）

**破题**：相遇点把全程切成两段，两人剩余路程正好互换 → 先用"小张 1 小时的路 = 小赵的剩余路"定时间，再用平均速度反推加速末速。

**解析**：设小赵速度 v、小张 v/2。1 小时相遇 → 全程 = (v+v/2)×1 = 1.5v；相遇点距甲 = v/2（小张已走），距乙 = v。

相遇后小赵到甲还需 (v/2)÷v = 0.5 小时，小赵全程用 1.5 小时。

小张比小赵晚 1 小时到 → 小张全程 2.5 小时，加速段用 1.5 小时走完剩下的 v。

加速段平均速度 = v÷1.5 = 2v/3 = (v/2+V末)÷2 → V末 = 4v/3-v/2 = 5v/6。

小张到达时速度 ÷ 小赵到达时速度 = (5v/6)÷v = 5/6。（选项 OCR 缺失，建议核对 PDF 第 11 页）

### 4. 等距离平均速度

判定：等距离。

```
等距离平均速度公式：V = 2V₁V₂ / (V₁+V₂)
```

> **★重点**：常适用于"等距离 + 多个不同速度"：（1）直线等距离；（2）直线往返；（3）上下坡往返。

**例6**（2023广东）某地举办了"铁人三项"体育活动，先进行蛙跳，后游泳，最后竞走到达终点。一位选手在上午 7 点出发，9 点到达了终点，全程未休息，其蛙跳、游泳和竞走的速度分别为每小时 2 千米、3 千米和 6 千米。如果蛙跳和竞走的路程相同，则所有项目的总路程是（　）。

A. 无法计算
B. 6千米
C. 8千米
D. 12千米

**破题**：三项运动、只给总时间，且"两项路程相同"→ 设路程列时间方程，所求总路程恰好是方程里的整体。

**解析**：设蛙跳、竞走各 x 千米，游泳 y 千米。总时 7:00~9:00 共 2 小时：

x/2 + y/3 + x/6 = 2

x/2+x/6 = 2x/3，故 2x/3 + y/3 = 2 → 2x+y = 6。

总路程 = 2x+y = 6 千米（无需分别求出 x、y，整体即答案）。

**答案**：B

**例7**（2023国考）一辆汽车从甲地开往乙地，先以 40 千米/小时的速度匀速行驶一半的路程，然后均匀加速；行驶完剩下路程的一半时，速度达到 80 千米/小时；此后均匀减速，到达乙地时的速度正好降为 0。问其全程的平均速度在以下哪个范围内？

A. 不到44千米/小时
B. 在44~45千米/小时之间
C. 在45~46千米/小时之间
D. 超过46千米/小时

**破题**：三段"匀速 + 匀加速 + 匀减速"，每段都给了起止速度 → 逐段用平均速度求时间，再合成总时间。

**解析**：设全程为 S。

第一段（S/2，40 千米/小时匀速）：时间 = S/80。
第二段（S/4，40→80 匀加速，平均 60）：时间 = (S/4)÷60 = S/240。
第三段（S/4，80→0 匀减速，平均 40）：时间 = (S/4)÷40 = S/160。

总时间 = S/80+S/240+S/160 = (6S+2S+3S)/480 = 11S/480。

全程平均速度 = S÷(11S/480) = 480/11 ≈ 43.6 千米/小时，不到 44。

**答案**：A

## 二、相对行程

目录：（1）相遇和追及　（2）环形相遇和追及　（3）多次相遇　（4）流水行船。

### 1. 相遇和追及

**直线相遇**（同时相向而行）：

```
S相遇 = (V₁ + V₂) × t = V和 × t
```

S相遇：就是两人走的路程之和。

**直线追及**（同时同向而行）：

```
S追及 = S差 = (V₁ - V₂) × t = V差 × t
```

S追及：追及刚开始时两人相差的距离（多跑的距离）。

**例8**（2025四川）甲、乙两地相距 150 千米。小张、小李分别于 8:00 和 9:00 开车从甲地匀速前往乙地。小张开了 135 千米被小李追上，且于 10:30 到达乙地。问小李的速度为多少千米/小时？

A. 75
B. 90
C. 108
D. 120

**破题**：同一条路、同一方向、出发时间不同 → 先由"到乙的时间"定小张速度，再用被追上的地点定小李速度。

**解析**：小张 8:00 出发、10:30 到乙：150÷2.5 = 60 千米/小时。

被追上时小张走了 135 千米，用时 135÷60 = 2.25 小时，即 10:15 被追上。

小李 9:00 出发，到 10:15 共 1.25 小时走 135 千米 → 135÷1.25 = 108 千米/小时。

**答案**：C

### 2. 环形相遇和追及

**环形相遇**（同点相向出发）：

```
S和 = V和 × T遇
相遇1次，S和 = 1圈；……；相遇N次，S和 = N圈
```

本质：每一次相遇到下一次相遇期间，两人走的路程和是一圈。

**环形追及**（同点同向出发）：

```
S差 = V差 × T追
追上1次，S差 = 1圈；追上N次，S差 = N圈
```

本质：每一次追上到下一次追上期间，两人走的路程差是一圈（套了一圈）。

**例9**（2025国考）甲和乙从环形跑道的同一点出发，向相反方向匀速慢跑，乙的速度是甲的一半。两人 3 分钟后第一次相遇，此后乙加速又跑了正好半圈后和甲第二次相遇。问两人第一次到第二次相遇间隔了多长时间？

A. 2分10秒
B. 2分15秒
C. 2分20秒
D. 2分30秒

**破题**：环形反向跑 → 第一次相遇两人合走一圈（定出圈长），第二次相遇再合走一圈，看这一圈如何分配。

**解析**：设甲速 2u、乙速 u（乙是甲的一半），3 分钟第一次相遇 → 一圈 = (2u+u)×3 = 9u。

第二次相遇时两人又合走一圈 9u。题干说乙跑了正好半圈 = 4.5u，故甲也跑 4.5u。

甲速 2u → 用时 4.5u÷2u = 2.25 分钟 = 2 分 15 秒。（校验：乙加速后速度 = 4.5u÷2.25 = 2u，与"加速后半圈相遇"自洽）

**答案**：B

**例10**（2020山东）甲、乙两人在一条 400 米的环形跑道上从相距 200 米的位置出发，同向匀速跑步。当甲第三次追上乙的时候，乙跑了 2000 米。问甲的速度是乙的多少倍？

A. 1.2
B. 1.5
C. 1.6
D. 2.0

**破题**："同向 + 相距 200 米 + 追上 3 次"→ 甲多跑的路程 = 初始间距 + 2 圈，别漏掉起点的 200 米。

**解析**：第 1 次追上多跑 200 米，此后每追上一次多跑一圈 400 米，第 3 次追上共多跑 200+2×400 = 1000 米。

乙跑 2000 米 → 甲跑 2000+1000 = 3000 米。

甲速:乙速 = 3000:2000 = 1.5。

**答案**：B

### 3. 多次相遇

> **★重点**：需区分"两端出发"与"同端出发"两类多次往返迎面相遇。

**两端出发**（直线两端出发多次往返迎面相遇）：

```
第1次迎面相遇，共走 1S
第2次迎面相遇，共走 3S
第3次迎面相遇，共走 5S
……
第n次迎面相遇，共走 S和 = (2n-1)S = (V₁+V₂) × t
```

**同端出发**：

```
第1次相遇，共走 2S
第2次相遇，共走 4S
……
第n次相遇，共走 2nS = (V₁+V₂) × t
```

**例11**（2020联考）小王在甲医院，小赵在乙医院。两人从所在医院同时骑车出发，来回往返于两个医院之间。已知小王骑车速度为 205 米/分钟，小赵骑车速度为 225 米/分钟，且经过 12 分钟后两人第二次相遇。问两家医院相距多少米？

A. 1290
B. 1720
C. 2150
D. 2580

**破题**："两端出发、第二次迎面相遇"→ 直接套第 n 次相遇共走 (2n-1)S，此处 3S = V和 × t。

**解析**：第 2 次相遇共走 3S（S 为两院距离）：

3S = (205+225)×12 = 430×12 = 5160

S = 5160÷3 = 1720 米。

**答案**：B

**例12**（2025广东）父子两人在百米赛道上匀速跑步，两人从赛道起点同时出发。父亲跑到终点时，儿子距离终点还有 40 米。若父亲立即折返跑向赛道起点，则两人相遇时，儿子距离终点还有（　）米。

A. 35
B. 30
C. 25
D. 15

**破题**：同点同时同向出发、父到终点折返 → 先用"同时间路程比 = 速度比"，折返后即变成"相距 40 米的相遇问题"。

**解析**：父亲跑完 100 米时，儿子跑了 100-40 = 60 米 → V父:V儿 = 100:60 = 5:3。

此时两人相距 40 米、相向而行，相遇时儿子再跑 40×3/(5+3) = 15 米。

儿子共跑 60+15 = 75 米，距终点 100-75 = 25 米。

**答案**：C

### 4. 流水行船

```
V顺 = V船 + V水
V逆 = V船 - V水
```

（1）在静水中的速度为 V船；（2）漂流速度为 V水。

> **★重点**：`V船 = (V顺 + V逆)/2`，`V水 = (V顺 - V逆)/2`。

**例13**（2020联考）一艘轮船顺流而行，从甲地到乙地需要 6 天；逆流而行，从乙地到甲地需要 8 天。若不考虑其他因素，一个漂流瓶从甲地到乙地需要多少天？

A. 24
B. 36
C. 48
D. 56

**破题**：只给顺、逆流时间 → 设路程为特值（1），先求 V水，漂流时间 = 路程 ÷ V水。

**解析**：设甲乙距离为 1。V顺 = 1/6，V逆 = 1/8。

V水 = (V顺-V逆)÷2 = (1/6-1/8)÷2 = (1/24)÷2 = 1/48。

漂流瓶被水冲走，速度即 V水：时间 = 1÷(1/48) = 48 天。

**答案**：C

## 三、比例行程

> **★重点**：S=VT，找相等的量，看比例，找份数（类比资料分析的比例思想）。

| 条件 | 结论 |
| --- | --- |
| S 相等 | V、T 成反比 |
| V 相等 | S、T 成正比 |
| T 相等 | S、V 成正比 |

常考：路程相同、时间相同。

**例14**（2025上海）一辆货车 8:00 从 A 地出发，在 A、B 两地之间往返行驶，出发时速度为 n 千米/小时，每次回到 A 地后，速度都增加 0.5n 千米/小时。已知该货车前两次到达 A、B 之间 C 地的时间分别为 8:30 和 9:15，则其第四次到达 C 地的时间是：

A. 10:30
B. 10:35
C. 10:40
D. 10:45

**破题**：往返 + 每次回到 A 提速 → 前两次到 C 可定出 AC、BC 与初速的关系，再一轮一轮往后推时刻。

**解析**：设 AC = x、BC = y、初速 n。

第一次到 C（8:00→8:30，0.5 小时）：x = 0.5n。
8:30 后继续到 B 再折回 C，共 2y，用时 45 分钟（8:30→9:15）：2y = 0.75n → y = 0.375n。

9:15 从 C 回 A：0.5n÷n = 0.5 小时 → 9:45 回到 A，速度升为 1.5n。

第三次到 C：0.5n÷1.5n = 1/3 小时 = 20 分钟 → 10:05。
继续到 B 再折回 C：2×0.375n÷1.5n = 0.5 小时 = 30 分钟 → 10:35。

**答案**：B

## 本章梳理

| 模块 | 核心公式/要点 |
| --- | --- |
| 普通行程 | S=V×T；1 m/s = 3.6 km/h |
| 火车过桥 | 完全通过：桥长+车长=VT；完全在桥上：桥长−车长=VT |
| 匀加速 | 平均速度 = (V初速度+V末速度)/2 |
| 等距离平均速度 | V = 2V₁V₂/(V₁+V₂)；直线等距离、直线往返、上下坡往返 |
| 相遇 | 同时相向：S相遇 = (V₁+V₂)×t |
| 追及 | 同时同向：S追及 = (V₁−V₂)×t |
| 环形 | 同点相向（相遇）/同点同向（追及）；N 次共走 N 圈 |
| 多次相遇 | 两端出发第 n 次共走 (2n−1)S；同端出发第 n 次共走 2nS |
| 流水行船 | V顺=V船+V水，V逆=V船−V水；V船=(V顺+V逆)/2 |

## 专项拔高练习十

**练习1**（2025天津）从甲地到乙地为下坡路，从乙地到丙地为上坡路。小张从甲地开车经过乙地前往丙地，此后原路返回。其上坡速度是下坡的 60%。已知他从甲地到乙地用时正好是去程全程用时的一半，则他返程全程用时比去程全程用时：

A. 少不到10%
B. 少10%以上
C. 多不到10%
D. 多10%以上

**破题**：往返上下坡，去程"下+上"、返程"上+下" → 用"甲到乙用时是全程一半"定两段路程之比，再比总时间。

**解析**：设甲乙 = a（去程下坡）、乙丙 = b（去程上坡），下坡速 v、上坡 0.6v。

去程时间 = a/v + b/(0.6v) = a/v + 5b/(3v)；已知 a/v 占去程一半 → a/v = 5b/(3v) → a = 5b/3。

返程 = 丙→乙下坡 b/v + 乙→甲上坡 a/(0.6v) = b/v + 5a/(3v) = b/v + 25b/(9v) = 34b/(9v)。
去程 = 5b/(3v) + 5b/(3v) = 10b/(3v)。

返程÷去程 = (34/9)÷(10/3) = 17/15 ≈ 1.133，即多约 13.3%。

**答案**：D

**练习2**（2022北京）一辆车每天都比前一天多开 15 千米，第三天开的距离正好是第一天的 2 倍。则前三天一共开了多少千米？

A. 225
B. 190
C. 135
D. 130

**破题**："每天多 15、第三天是第一天 2 倍"→ 等差三项设 a、a+15、a+30，一倍关系直接定 a。

**解析**：a+30 = 2a → a = 30。

三天共 30+45+60 = 135 千米。（也可用中项：中间项 45 为平均数，3×45 = 135）

**答案**：C

**练习3**（2023山东）甲、乙、丙在 400 米标准跑道上跑步，甲跑一圈用 2 分钟，乙用 1.5 分钟，丙用 2.5 分钟。若甲、乙、丙按顺序轮流每人半圈接力跑，共跑 1600 米，问乙一共跑了多少分钟？

A. 2
B. 2.25
C. 3
D. 3.25

**破题**：轮流接力 + 每人固定半圈 → 先算三人速度，再数 1600 米里乙跑了几棒。

**解析**：甲 400÷2 = 200 米/分；乙 400÷1.5 = 800/3 米/分；丙 400÷2.5 = 160 米/分。

1600 米 = 4 圈 = 8 个半圈，顺序为 甲、乙、丙、甲、乙、丙、甲、乙 → 乙跑第 2、5、8 棒。

乙共跑 3×200 = 600 米，用时 600÷(800/3) = 2.25 分钟。

**答案**：B

**练习4**（2023联考）某公路隧道长 1500 米，一辆公共汽车匀速从隧道通过，测得公共汽车从开始进入隧道到车身完全驶出隧道用时 151 秒，整辆公共汽车完全在隧道里的时间为 149 秒。则公共汽车的车身长度和行驶速度分别为：

A. 8米；5米/秒
B. 10米；10米/秒
C. 10米；15米/秒
D. 12米；20米/秒

**破题**："完全通过"= 隧道长+车长，"完全在隧道内"= 隧道长-车长 → 两式相减可同时消去隧道长、直接得车长与速度的关系。

**解析**：设车长 L、速度 v：

(1500+L)÷v = 151
(1500-L)÷v = 149

两式相减：2L÷v = 2 → L = v。代入第一式：1500+v = 151v → v = 10 米/秒，L = 10 米。

**答案**：B

**练习5**（2020天津选调）某铁路桥长 1440 米，一列动车从桥上通过，测得动车从开始上桥到完全下桥用了 21 秒，动车的速度为 288 km/h，则整列动车完全在桥上的时间为（　）秒。

A. 18
B. 16
C. 15
D. 12

**破题**：先做单位换算（km/h → m/s），再用"完全通过"求车长，最后用"完全在桥上"求时间。

**解析**：288 千米/小时 = 288÷3.6 = 80 米/秒。

完全通过：(1440+L)÷80 = 21 → 1440+L = 1680 → L = 240 米。

完全在桥上：(1440-240)÷80 = 1200÷80 = 15 秒。

**答案**：C

**练习6**（2023山东）一辆车从甲地行驶到乙地共 20 千米，用时 20 分钟。已知该车在匀加速到最大速度后开始匀减速，到乙地时速度恰好为 0。问该车行驶的最大速度是多少千米/小时？

A. 100
B. 108
C. 116
D. 120

**破题**："从 0 加速到最大速度再减到 0"，只给总路程、总时间 → 全程平均速度 = 最大速度的一半。

**解析**：20 分钟 = 1/3 小时，平均速度 = 20÷(1/3) = 60 千米/小时。

加速段平均 = (0+Vmax)÷2，减速段平均 = (Vmax+0)÷2，两段平均相同 → 全程平均 = Vmax÷2。

Vmax÷2 = 60 → Vmax = 120 千米/小时。

**答案**：D

**练习7**（2025浙江）小李开车从静止开始匀加速行驶 10 分钟后，再匀速行驶 20 分钟，然后开始第二次匀加速行驶 13.5 千米。已知两次匀加速行驶总距离与匀速行驶距离相等，那么匀速行驶的速度是多少千米/小时？

A. 54
B. 63
C. 72
D. 81

**破题**：两段匀加速都从同一速度起止 + 一段匀速 → 匀加速段位移 = 平均速度×时间，把已知条件全换成 v 的倍数。

**解析**：设匀速速度为 v（千米/小时）。

匀速段 20 分钟 = 1/3 小时 → 距离 = v/3。
第一次加速 10 分钟 = 1/6 小时，从 0 加到 v → 距离 = (0+v)÷2×1/6 = v/12。
第二次加速距离 = 13.5 千米。

由"两次加速总距离 = 匀速距离"：v/12 + 13.5 = v/3 → v/3-v/12 = v/4 = 13.5 → v = 54 千米/小时。

**答案**：A

**练习8**（2024全国事业单位联考）甲、乙两辆车同时从 A 地出发驶向 B。甲车匀速行驶，乙车出发时的速度与甲车相同且均匀加速，1 小时后其行驶的距离是甲车的 1.5 倍。此后乙车均匀减速，又过了 1 小时到达 B 地时，其速度是从 A 地出发时的 0.5 倍。问甲车还要多长时间到达 B 地？

A. 30分钟
B. 40分钟
C. 45分钟
D. 60分钟

**破题**：两车同地同时出发，乙"先加速后减速"、甲匀速 → 用平均速度把乙两段位移都化成 v 的倍数，再扣掉甲已走的部分。

**解析**：设甲速 v。

第 1 小时乙匀加速、位移是甲的 1.5 倍 = 1.5v → 乙 1 小时末速度 = 2v（因平均 = (v+2v)÷2 = 1.5v）。
第 2 小时乙从 2v 匀减速到 0.5v → 位移 = (2v+0.5v)÷2×1 = 1.25v。

全程 AB = 1.5v+1.25v = 2.75v；甲 2 小时只走了 2v。

甲还需 0.75v，即 0.75 小时 = 45 分钟。

**答案**：C

**练习9**（2020联考）小明每天从家中出发骑自行车经过一段平路，再经过一道斜坡后到达学校上课。某天早上，小明从家中骑车出发，一到校门口就发现忘带课本，马上返回，从离家到赶回家中共用了 1 个小时。假设小明当天平路骑行速度为 9 千米/小时，上坡速度为 6 千米/小时，下坡速度为 18 千米/小时，那么小明的家距离学校多远？

A. 3.5千米
B. 4.5千米
C. 5.5千米
D. 6.5千米

**破题**：去回各走一遍平路和坡路，坡去时上坡、回时下坡 → 平路时间加倍，坡路时间 = s/6+s/18，多数可约掉。

**解析**：设平路 p 千米、坡路 s 千米（去时上坡）。

去程：p/9+s/6；返程：p/9+s/18。

总时 = 2p/9 + s/6 + s/18 = 2p/9 + (3s+s)/18 = 2p/9 + 2s/9 = 2(p+s)/9 = 1

→ p+s = 4.5 千米，即家到学校的距离。

**答案**：B

**练习10**（2020联考）甲乙两人在相距 1200 米的直线道路上相向而行，一条狗与甲同时出发跑向乙，遇到乙后立即调头跑向甲，遇到甲后再跑向乙，如此反复。已知甲的速度为 40 米/分钟，乙为 60 米/分钟，狗为 80 米/分钟。不考虑狗调头所耗时间，当甲乙相距 100 米时狗跑了多少米？

A. 1100
B. 1000
C. 960
D. 880

**破题**：狗来回折返、速度始终不变 → 不必管折返次数，只要求"狗跑了多久"，即甲乙从相距 1200 米缩到 100 米的时间。

**解析**：甲乙靠近速度 = 40+60 = 100 米/分钟，需靠近 1200-100 = 1100 米。

时间 = 1100÷100 = 11 分钟。

狗跑 80×11 = 880 米。

**答案**：D

**练习11**（2023北京）从 A 地到 B 地是下坡路，一辆车从 A 地开往 B 地需要三小时，从 B 地开往 A 地需要四小时。已知这辆车下坡速度比上坡速度快 15 千米/小时，则 A、B 两地之间的距离是多少千米？

A. 120
B. 180
C. 240
D. 300

**破题**：同一条路、两个方向，只给时间与速度差 → 用两个时间分别表示"下坡速、上坡速"，再作差。

**解析**：设 AB = d。A→B 为下坡：V下 = d/3；B→A 为上坡：V上 = d/4。

d/3-d/4 = 15 → d/12 = 15 → d = 180 千米。（校验：60-45 = 15 ✓）

**答案**：B

**练习12**（2022江苏）某人以每小时 10 公里的速度从甲地骑车前往乙地，中午 12:30 到达。若以每小时 15 公里的速度行驶，上午 11:00 到达，则他出发的时间是：

A. 上午7:15
B. 上午7:30
C. 上午7:45
D. 上午8:00

**破题**：同一路程、两种速度、两到达时刻 → 时间差 = 路程×(1/10-1/15)，先求路程再倒推出发时刻。

**解析**：12:30 与 11:00 相差 1.5 小时：d/10-d/15 = 1.5 → d/30 = 1.5 → d = 45 千米。

10 千米/小时需 45÷10 = 4.5 小时 → 出发时刻 = 12:30-4小时30分 = 8:00。（校验：15 千米/小时需 3 小时，8:00+3 = 11:00 ✓）

**答案**：D

**练习13**（2024联考）A、B 两地相距 100 米，甲、乙两人分别从 A、B 两地同时出发，匀速相向而行。相遇后，甲原路返回 A 地，乙继续向 A 前行，当甲、乙均到 A 地结束。已知乙的用时是甲的三倍，那么甲的速度是乙的：

A. 2倍
B. 3倍
C. 4倍
D. 5倍

**破题**：相遇后甲折返、乙继续 → 用相遇点把两人的总时间分别写出来，再套"乙用时是甲 3 倍"。

**解析**：设甲速 v₁、乙速 v₂，相遇点距 A 为 d。

相遇时同时出发：d/v₁ = (100-d)/v₂ → d = 100v₁/(v₁+v₂)。

甲总时 = 2d/v₁（到相遇点再折回 A）；乙总时 = 100/v₂（一直向 A 走完 100 米）。

由 100/v₂ = 3×2d/v₁ = 6d/v₁ → d = 100v₁/(6v₂)。

联立两式（d、100v₁ 均不为 0）：1/(v₁+v₂) = 1/(6v₂) → v₁+v₂ = 6v₂ → v₁ = 5v₂。

**答案**：D
