## 一、年龄问题知识点

| 序号 | 特性 | 用法 |
| --- | --- | --- |
| 1 | 每过 N 年都长 N 岁 | 同一时间轴上"人人同步 +N" |
| 2 | 年龄差不变 | 任何年份的差都是同一个数 |
| 3 | 年龄倍数越来越小 | 倍数随年份递减，趋近于 1 |

```
每过 N 年，每人都长 N 岁
任意两年份：甲、乙年龄差恒定
年份越往后，"大年龄 ÷ 小年龄"的倍数越小
```

注：

1. **年龄为周岁，且为整数**（这是不定方程、整除判定的前提）。
2. **年龄差不变**，问年龄差时结合选项的倍数特性解题。
3. 宝宝出生当年（**按 0 岁计算**）母亲 25 岁。
4. 考出生不考死亡，**年龄为负数代表尚未出生**。

> **⚠易错**：题目说"10 年前祖父的年龄是小田的 6 倍"，10 年前小田可能还没出生，此时年龄为负数，"6 倍"关系仍然成立——不要因为"没出生"就直接排除。

## 二、解题方法：列表法

把"人物 × 时间"画成表格，每个格子填"当年年龄"，再横向作差、纵向找倍数。

| 方法 | 适用条件 | 操作 |
| --- | --- | --- |
| 代入选项 | 条件清晰、信息充分 | 把选项年龄代回题干验倍数 |
| 设未知数列方程 | 不便代入 | **设小不设大**，减少分数 |
| 常识思维 | 生活类题目 | 做猜结合，先排除明显不合理的年龄 |

```
列表：行 = 人物（甲/乙/丙），列 = 年份（10年前 | 今年 | 5年后）
列式：同一年龄差恒定 → 用"差"串起两个年份
```

> **★重点**：年龄问题方程法口诀——**设小不设大**。设年龄小的为 x，另一个用"x + 年龄差"表示，全程不出现分数。

### 例题（例1—例9）

**例1**（2025联考）5 年后小田父亲的年龄将是小田年龄的 2 倍，10 年前小田祖父的年龄是小田年龄的 6 倍。已知小田祖父比小田父亲大 25 岁，问小田今年多少岁？

A. 20
B. 22
C. 25
D. 26

**解析**：

**破题**：三个时间点、三个人 → 列表，全部用"小田今年 x 岁"表示。

设小田今年 x 岁：

```
父亲今年 = 2(x + 5) - 5 = 2x + 5
祖父今年 = 6(x - 10) + 10 = 6x - 50
祖父 - 父亲 = (6x - 50) - (2x + 5) = 4x - 55 = 25
4x = 80 → x = 20
```

代回验证：父亲 45 岁、祖父 70 岁，差 25 岁；5 年后小田 25、父亲 50（2 倍）；10 年前小田 10、祖父 60（6 倍），全部自洽。

**答案：A**

**例2**（2021重庆选调）不到 30 岁的哥哥今年的年龄正好是弟弟年龄的 5 倍，若干年后哥哥的年龄就是弟弟的 4 倍，又过了若干年，哥哥的年龄将是弟弟的 3 倍，则今年两兄弟的年龄差是（ ）岁。

A. 12
B. 13
C. 14
D. 15

**解析**：

**破题**：倍数从 5 → 4 → 3，年龄差不变 → 用"差"的整除性筛选项。

设年龄差为 d。当"哥哥 = k × 弟弟"时：`哥哥 = k·d/(k-1)`、`弟弟 = d/(k-1)`，两者都必须是整数。

```
k = 5 → 弟弟 = d/4 → d 是 4 的倍数
k = 4 → 弟弟 = d/3 → d 是 3 的倍数
k = 3 → 弟弟 = d/2 → d 是 2 的倍数
```

d 同时是 4 与 3 的倍数 → **d 是 12 的倍数**，选项中只有 12 满足。

验证 d = 12：今年弟弟 3 岁、哥哥 15 岁（< 30 ✓）；1 年后 16 = 4 × 4；3 年后 18 = 3 × 6，全部成立。

> **★重点**：年龄倍数题不必逐年倒推——"差是 (k-1) 的倍数"这一条就能直接筛选项。

**答案：A**

**例3**（2025联考）今年甲和乙的年龄和为 26 岁，5 年后甲的年龄是乙的 3 倍。若干年后，甲的年龄是乙的 2 倍，则此时乙的年龄为（ ）。

A. 12岁
B. 16岁
C. 18岁
D. 20岁

**解析**：

**破题**：已知"和"与"倍数"，先解出今年两人年龄，再用**年龄差不变**求目标年份。

```
甲 + 乙 = 26；甲 + 5 = 3(乙 + 5)
(26 - 乙) + 5 = 3乙 + 15 → 31 - 乙 = 3乙 + 15 → 16 = 4乙 → 乙 = 4，甲 = 22
年龄差 = 22 - 4 = 18
目标年：甲' = 2乙'，且甲' - 乙' = 18 → 乙' = 18
```

**答案：C**

**例4**（2025国考）2024 年甲、乙、丙三人的年龄之和与 2034 年甲的年龄相同，且甲、乙的年龄之差大于乙、丙的年龄之差。已知乙的年龄小于甲但大于丙，问 2024 年甲的年龄最小可能为多少岁？

A. 13
B. 11
C. 10
D. 9

**解析**：

**破题**：出现"三人和 = 某人十年后年龄"→ 先消元，再按不等式取最小整数。

```
甲 + 乙 + 丙 = 甲 + 10 → 乙 + 丙 = 10
乙 > 丙 → 乙 > 5
甲 - 乙 > 乙 - 丙 = 乙 - (10 - 乙) = 2乙 - 10
∴ 甲 > 3乙 - 10
```

取乙 = 6（最小可行值）→ 丙 = 4，甲 > 8，且甲 > 乙 = 6，故甲最小取 **9**。

验证：9 + 6 + 4 = 19，2034 年甲 = 9 + 10 = 19 ✓；甲乙差 3 > 乙丙差 2 ✓。

**答案：D**

**例5**（2023联考）美术培训班有 3 名学员，他们的年龄满足以下条件：他们的年龄都是正整数；2 号学员的年龄是 1 号学员年龄的一半；3 号学员比 2 号学员大 7 岁；3 名学员的年龄之和是不超过 70 的素数，且该素数的各位数字之和为 13，那么这 3 位学员的年龄分别是多少岁？

A. 12；6；13
B. 20；10；17
C. 24；12；19
D. 30；15；22

**解析**：

**破题**：条件全是整数 + 素数 + 数位和 → 直接**代选项验证**最快。

设 1 号 = 2a、2 号 = a、3 号 = a + 7，和 = 4a + 7（≤ 70 → a ≤ 15）。

| 选项 | 年龄 | 和 | 是否素数 | 数位和 |
| --- | --- | --- | --- | --- |
| A | 12；6；13 | 31 | 是 | 3+1=4 ✗ |
| B | 20；10；17 | 47 | 是 | 4+7=11 ✗ |
| C | 24；12；19 | 55 | 否 ✗ | — |
| D | 30；15；22 | 67 | 是 | 6+7=13 ✓ |

只有 D 同时满足"和为素数"且"数位和 13"。

**答案：D**

**例6**（2025广东）小王参加工作时的年龄，和他弟弟现在的年龄相同，小王工作两年后，弟弟也正式参加工作，现在兄弟俩的年龄之和，正好是他们工龄之和的 8 倍。如果弟弟 20 岁正式参加工作，则小王比弟弟大（ ）岁。

A. 3
B. 4
C. 5
D. 6

**解析**：

**破题**："参加工作年龄 / 工龄 / 现在年龄"三线交叉 → 设小王已工作 t 年作中介。

设小王已工作 t 年，弟弟参加工作 20 岁，比小王晚 2 年：

```
弟弟现在年龄 = 20 + (t - 2) = t + 18
小王参加工作时的年龄 = 弟弟现在年龄 = t + 18
小王现在年龄 = (t + 18) + t = 2t + 18
年龄和 = (2t + 18) + (t + 18) = 3t + 36
工龄和 = t + (t - 2) = 2t - 2
3t + 36 = 8(2t - 2) = 16t - 16 → 52 = 13t → t = 4
```

小王参加工作 22 岁，弟弟当时 18 岁 → 小王比弟弟大 **4** 岁。

**答案：B**

**例7**（2024国考）甲、乙、丙三人的年龄之比为 3:4:5。8 年之后，甲、乙的年龄之和是丙的 1.5 倍，且这一年甲、乙、丙、丁四人的平均年龄为 43 岁。问再过 15 年，甲、乙、丙、丁中有几人将超过 60 岁？

A. 4
B. 3
C. 2
D. 1

**解析**：

**破题**：比例 → 设 3x、4x、5x；四人平均年龄用来"补"出丁。

```
8 年后：甲 + 乙 = 3x + 4x + 16 = 7x + 16；丙 = 5x + 8
7x + 16 = 1.5(5x + 8) = 7.5x + 12 → 4 = 0.5x → x = 8
今年：甲 24、乙 32、丙 40
8 年后四人和 = 43 × 4 = 172；甲乙丙 8 年后 = 32 + 40 + 48 = 120
丁（8 年后）= 52 → 丁今年 44
再过 15 年（即从今年起 23 年）：甲 47、乙 55、丙 63、丁 67
```

超过 60 岁的有丙、丁 **2 人**。

**答案：C**

**例8**（2021联考）2020 年老张的年龄是小王年龄的 4 倍，2021 年老李的年龄是小王年龄的 3 倍，已知老张比老李大 12 岁，问哪一年三人的年龄之和第一次超过 140 岁？

A. 2020
B. 2023
C. 2026
D. 2029

**解析**：

**破题**：两个年份、三次"倍数"→ 统一到同一年列表，再用"差 12 岁"定参数。

```
设 2020 年小王 = w，则 2020 年老张 = 4w
2021 年：小王 = w + 1，老李 = 3(w + 1)，老张 = 4w + 1
(4w + 1) - 3(w + 1) = 12 → w = 14
2020 年：小王 14、老张 56；老李 2021 年 45 → 2020 年 44
2020 年和 = 14 + 56 + 44 = 114
114 + 3n > 140 → n > 8.67 → n = 9 → 2029 年
```

**答案：D**

**例9**（2024考）2023 年王的年龄比张的年龄的 2 倍小 2 岁，2025 年张的年龄是李的年龄的 1.5 倍，2030 年张和李的年龄之和与王的年龄相同。问 3 人的年龄之和在哪一年第一次超过 120 岁？

A. 2037年
B. 2036年
C. 2035年
D. 2034年

**解析**：

**破题**：三个年份、三个人 → 以 2023 年为基准年，全部用"张 2023 年 = z"表示。

```
王(2023) = 2z - 2
2025 年：张 = z + 2，李 = (z + 2) ÷ 1.5
2030 年：张 = z + 7，李 = (z + 2) ÷ 1.5 + 5，王 = 2z + 5
z + 7 + (z + 2) ÷ 1.5 + 5 = 2z + 5 → (z + 2) ÷ 1.5 = z - 7
z + 2 = 1.5z - 10.5 → 12.5 = 0.5z → z = 25
2023 年：张 25、王 48、李 16，和 = 89
89 + 3n > 120 → n > 10.33 → n = 11 → 2034 年
```

**答案：D**

> **⚠易错**：例9 求的是"**第一次超过**"，n 取最小整数即 11 年；若误算成"等于或超过"会漏一年。

## 三、年龄和不定方程结合

**年龄和日期均为整数，利用不定方程特性求解。**

```
年龄、年份、月份、日期 → 全部是整数
列方程后用整除性（倍数特性）缩小范围，再代选项
```

### 例题（例10—例11）

**例10**（2025全国事业单位）今年，甲与乙的年龄和等于丙的年龄，三人年龄均小于 30 岁且平均年龄小于 20 岁。5 年后，乙年龄的 2 倍比甲和丙年龄之和少 10 岁。问今年三人年龄之和可能的最大值为（ ）。

A. 46
B. 52
C. 58
D. 64

**解析**：

**破题**：条件全是"整数 + 范围"→ 消元成单变量，再取上限。

```
丙 = 甲 + 乙
5 年后：2(乙 + 5) = (甲 + 5) + (丙 + 5) - 10 → 2乙 + 10 = 甲 + 丙
代入 丙 = 甲 + 乙：2乙 + 10 = 2甲 + 乙 → 乙 = 2甲 - 10
丙 = 3甲 - 10，三人和 = 6甲 - 20
约束：丙 < 30 → 3甲 - 10 < 30 → 甲 < 13.33；平均 < 20 → 和 < 60
甲 = 13 → 乙 = 16、丙 = 29，和 = 58（< 60 ✓）
```

**答案：C**

**例11**（2025浙江）甲处室有 6 人，乙处室有 4 人，甲处室平均年龄比乙处室大 1.5 岁。甲处室新进了小张，乙处室新进了老张，老张比小张大 20 岁，他们来了之后甲处室平均年龄比乙处室小 2 岁。问老张比乙处室原来的平均年龄大多少岁？

A. 5
B. 7.5
C. 12.5
D. 15

**解析**：

**破题**：两次"平均数"对比 → 用"总量 = 平均数 × 人数"，列一个方程即可，不必求出具体年龄。

设乙处室原平均年龄 b，则甲为 b + 1.5；设小张 u 岁，则老张 u + 20。

```
(6(b + 1.5) + u) ÷ 7 = (4b + u + 20) ÷ 5 - 2
两边乘 35：5(6b + 9 + u) = 7(4b + u + 20) - 70
30b + 45 + 5u = 28b + 7u + 70 → 2b - 25 = 2u → u = b - 12.5
老张 = u + 20 = b + 7.5
```

老张比乙处室原平均年龄大 **7.5 岁**。

**答案：B**

## 四、年龄和年龄的平方

这是**送分题**，识别特征是"某年年龄的平方 = 那一年的年份"。

### 1. 世纪和年代

| 写法 | 含义 |
| --- | --- |
| 198？ | 20 世纪八十年代 |
| 199？ | 20 世纪九十年代 |
| 202？ | 21 世纪 |

### 2. 识别

**平方数等于那一年的年份**。例：有一个 20 世纪八九十年代出生的人，在 21 世纪恰好有一年，他年龄的平方数等于那一年的年份。

### 3. 方法

```
出生年份 + 年龄 = 当年年份 = 平方数
```

```
1892 + 44 = 1936 = 44²
1980 + 45 = 2025 = 45²
2070 + 46 = 2116 = 46²
```

> **★重点**：只要记住 **44² = 1936、45² = 2025、46² = 2116** 三个"人 × 年份"配对，年龄平方题（含属相题）全部秒杀——三个式子都满足"出生年 + 年龄 = 平方数"。

> **⚠易错**："在 21 世纪"是硬约束：1936 属 20 世纪，所以 1892 年出生这一组不能用于 21 世纪的题目。

**例12**（2022联考）有一个 20 世纪八九十年代出生的人，在 21 世纪，恰好有一年，他年龄的平方数等于那一年的年份。这个人是哪年出生的？

A. 1995
B. 1990
C. 1985
D. 1980

**解析**：

**破题**：年份 = 年龄²，且年份在 2000—2099 之间 → 只有 45² = 2025 落在 21 世纪。

```
出生年 = 2025 - 45 = 1980（属 20 世纪八十年代 ✓）
```

其余：44² = 1936 属 20 世纪，不符合"在 21 世纪"。

**答案：D**

## 五、属相和本命年

十二生肖：

```
子鼠、丑牛、寅虎、卯兔、辰龙、巳蛇、午马、未羊、申猴、酉鸡、戌狗、亥猪
```

注：

1. **本命年以 12 为周期**（12 岁、24 岁、36 岁……）。
2. **属相相同 → 年龄差为 12 的倍数**。

**例13**（2018吉林）某业务处长和科员两人属相相同，科员在第一个本命年时处长是第三个本命年。科员今年 20 岁，当处长年龄是科员年龄的 2 倍时，需要经过的时间是：

A. 7年
B. 4年
C. 5年
D. 6年

**解析**：

**破题**："第一个本命年 / 第三个本命年"→ 12 岁与 36 岁，年龄差 24 岁。

```
年龄差 = 36 - 12 = 24（亦是 12 的倍数，符合属相相同）
处长今年 = 20 + 24 = 44
设经过 t 年：44 + t = 2(20 + t) → 44 + t = 40 + 2t → t = 4
```

**答案：B**

**例14**（2017陕西）今年是鸡年，公历年数为 2017。小王发现，在未来十年内的某一年，他年龄的平方数正好是那年的公历年数，则小王的属相为（ ）

A. 牛
B. 虎
C. 兔
D. 龙
E. 蛇
F. 马
G. 羊
H. 猴

**解析**：

**破题**：2017 起十年内 → 年份只能是 2017—2027，其间唯一的平方数是 2025 = 45²。

```
2025 - 45 = 1980 年出生
1980 年为庚申年 → 属猴
```

验证：2017 年为丁酉鸡年，1980 年与 2017 年相差 37 年，37 ÷ 12 余 1 → 属相比鸡早一位，即猴 ✓

**答案：H**

## 七、专项拔高练习十三

**练习1**（2024全国事业单位联考）2024 年，某家庭大女儿的年龄是小女儿年龄的 2 倍。2028 年，小女儿的年龄是 2024 年时的 2 倍。2029 年，两个女儿的年龄之和是母亲年龄的一半。问母亲比大女儿大几岁？（ ）

A. 29
B. 30
C. 31
D. 32

**解析**：

**破题**："2028 年小女儿 = 2024 年的 2 倍"→ 4 年增长一倍，可直接定出小女儿年龄。

```
设 2024 年小女儿 x 岁：x + 4 = 2x → x = 4，大女儿 8
2029 年：大女儿 13、小女儿 9，和 = 22 = 母亲 ÷ 2 → 母亲 = 44
2024 年母亲 = 39 → 39 - 8 = 31
```

**答案：C**

**练习2**（2024浙江）小张和小王的年龄之和为 45 岁。5 年之后小李的年龄比小张的 3 倍少 16 岁。已知小张的年龄比小王小，那么再过 5 年，3 人的平均年龄最大可能为多少岁？

A. 45
B. 48
C. 50
D. 54

**解析**：

**破题**：求"平均年龄最大"→ 让小张尽量大，受"小张 < 小王"约束。

```
小李（5 年后）= 3(张 + 5) - 16 = 3张 - 1 → 今年李 = 3张 - 6
三人今年和 = 张 + 王 + 李 = 45 + (3张 - 6) = 39 + 3张
小张 < 小王 且 张 + 王 = 45 → 张 ≤ 22（取等时王 23）
张 = 22 → 今年和 = 39 + 66 = 105
再过 5 年（自"5 年之后"再推 5 年，即从今年起 10 年）：和 = 105 + 30 = 135
平均 = 135 ÷ 3 = 45
```

> **⚠易错**："再过 5 年"是在"5 年之后"这个时间点上再推 5 年，三人和要加 30 而不是 15；只加 15 会得到 40 岁，选项中没有，正是这个坑。

**答案：A**

**练习3**（2019江西法检）王老师一家有 5 人，父亲、母亲、妻子、女儿和他本人，今年母亲、王老师和女儿年龄之和为 135 岁，而且他们三人的年龄正好构成等差数列，那么今年王老师多少岁？

A. 42
B. 45
C. 48
D. 50

**解析**：

**破题**：三人成等差数列 → 中间项 = 总和 ÷ 3；王老师居中（母亲 > 王老师 > 女儿）。

```
135 ÷ 3 = 45
```

**答案：B**

**练习4**（2018福建选调）有一个 00 后的孩子，其今年年龄的 20 倍加上 18，然后乘以 5，再加 365，减去其出生的月份后得到的数字是 1646，那么，这个孩子的出生日期是多少？

A. 2006年9月
B. 2007年8月
C. 2008年7月
D. 2009年6月

**解析**：

**破题**：整串运算逆推成一个不定方程，年龄与月份都是整数。

```
(20a + 18) × 5 + 365 - m = 1646
100a + 90 + 365 - m = 1646 → 100a - m = 1191
m 为 1—12 的整数 → 100a ∈ (1191, 1203] → a = 12，m = 9
```

年龄 12 岁、9 月出生，00 后 → 2006 年 9 月（2018 年 9 月后满 12 岁）。

**答案：A**

**练习5**（2023湖北选调）已知大明小丽俩夫妻有一个儿子，大明和儿子的年龄之积加上小丽的年龄等于 85，小丽和儿子年龄之积加上大明的年龄等于 86。问大明和小丽年龄之积加上儿子的年龄为多少？

A. 704
B. 814
C. 870
D. 872

**解析**：

**破题**：两式相减 → 因式分解出"儿子年龄 - 1"，整数解唯一。

```
大明×儿子 + 小丽 = 85 …①
小丽×儿子 + 大明 = 86 …②
② - ①：(儿子 - 1)(小丽 - 大明) = 1 → 儿子 = 2，小丽 = 大明 + 1
代回①：2×大明 + 大明 + 1 = 85 → 大明 = 28，小丽 = 29
所求 = 28 × 29 + 2 = 812 + 2 = 814
```

**答案：B**

**练习6**（2023浙江事业单位）A、B 两个小组分别有 4 人和 6 人，调换前两组平均年龄相同。在 A 组的甲调入 B 组、B 组的乙调入 A 组后，A 组平均年龄比 B 组大 5 岁。那么甲的年龄比乙（ ）。

A. 大24岁
B. 大12岁
C. 小12岁
D. 小24岁

**解析**：

**破题**：调换前后"总量不变"，只用平均数差一个方程即可。

设原平均年龄 a，甲 x 岁、乙 y 岁：

```
(4a - x + y) ÷ 4 - (6a - y + x) ÷ 6 = 5
两边乘 12：3(4a - x + y) - 2(6a - y + x) = 60
12a - 3x + 3y - 12a + 2y - 2x = 60 → 5(y - x) = 60 → y - x = 12
```

即甲比乙**小 12 岁**。

**答案：C**

**练习7**（2019深圳）某家庭有爸爸、妈妈、女儿 3 人，今年每 2 人的平均年龄加上余下 1 人的年龄之和，分别为 39、52、53，则 3 人中最大年龄与最小年龄之差为（ ）。

A. 22
B. 24
C. 26
D. 28

**解析**：

**破题**：三个"两人平均 + 第三人"式相加 → 左边正好是 2 倍总年龄。

```
设三人年龄 a、b、c：
(39 + 52 + 53) = 144 = 2(a + b + c) → 总和 = 72
(72 - c) ÷ 2 + c = 39 → 36 + c/2 = 39 → c = 6
(72 - b) ÷ 2 + b = 52 → b = 32
(72 - a) ÷ 2 + a = 53 → a = 34
最大 - 最小 = 34 - 6 = 28
```

**答案：D**

**练习8**（2023联考）一家三口年龄各不相同，今年爸爸与妈妈年龄之和是孩子年龄的 8 倍，而 10 年后，爸爸与妈妈年龄之和为孩子年龄的 5 倍。今年爸爸、妈妈的年龄在各种可能组合中乘积最大，问今年妈妈的年龄可能是多少岁？

A. 39
B. 40
C. 50
D. 51

**解析**：

**破题**：先解孩子年龄，再用"和一定、差最小积最大"求父母年龄。

```
父 + 母 = 8子；10 年后 父 + 母 + 20 = 5(子 + 10) = 5子 + 50
8子 + 20 = 5子 + 50 → 子 = 10 → 父 + 母 = 80
和 80 固定，乘积最大要求两人尽量接近：40 + 40，但"年龄各不相同"→ 39 + 41
妈妈可能为 39 岁（或 41 岁，选项中只有 39）
```

**答案：A**

**练习9**（2012浙江）有一个上世纪 80 年代出生的人，如果他能活到 80 岁，那么有一年他的年龄的平方数正好等于那一年的年份。问此人生于哪一年：

A. 1980年
B. 1983年
C. 1986年
D. 1989年

**解析**：

**破题**："活到 80 岁"意味着平方数年份 ≤ 出生年 + 80，用来排除过大的平方数。

```
1980 年生 → 45² = 2025 年时 45 岁（≤ 80 ✓），出生 1980 落在 80 年代 ✓
1983 年生 → 需 1983 + n = n²，n² - n = 1983 无整数解
```

**答案：A**

**练习10**（2017江西）有一个 20 世纪 80 年代出生的人，如果他能活到 80 岁，那么有一年他的年龄的平方数正好等于那一年的年份。此人生于：

A. 1985年
B. 1984年
C. 1983年
D. 1980年

**解析**：

**破题**：与练习9 同构，仍是 45² = 2025 这一组。

```
出生年 = 2025 - 45 = 1980
```

**答案：D**
