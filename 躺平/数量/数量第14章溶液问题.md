# 第十四章 溶液问题

> 来源：数量第14章溶液问题.pdf ｜ 数量关系专项
> 主讲老师：高照

## 一、基本公式

```
溶液 = 溶质 + 溶剂
浓度 = 溶质 ÷ 溶液
溶质 = 溶液 × 浓度
```

| 量 | 公式 | 备注 |
| --- | --- | --- |
| 溶液 | 溶质 + 溶剂 | 加水只增溶液，加盐只增溶质 |
| 浓度 | 溶质 ÷ 溶液 | 溶质不变时，浓度与溶液成反比 |
| 溶质 | 溶液 × 浓度 | 混合前后"溶质守恒" |

> **★重点**：溶液题的一切等式都来自**溶质守恒**——混合前的溶质之和 = 混合后的溶质。蒸发、稀释时溶质不变，只有反复"倒出—加满"才需要连乘。

## 二、线段法

1. 部分写两边，整体写中间。
2. **距离和量成反比**（两部分的"距离"之比 = 两部分的量之反比）。

```
        a% ──────── 混合浓度 ──────── b%
        ← 距离 d₁ →        ← 距离 d₂ →
        d₁ : d₂ = m₂ : m₁   （m 为该侧溶液的"量"）
```

技巧：

1. **等量溶液混合，浓度居中**（即两浓度的平均值）。
2. **等浓度的溶液混合，浓度不变**。

> **⚠易错**：线段法的"距离"是浓度差，不是溶液质量；比值方向是**反比**，写反了整题全错。

## 三、溶液公式的应用

原文归纳为两类：**（1）两类混合；（2）多者混合**。多者混合的处理方式是**两两混合**，逐步消元。

### 例题（例1—例8）

**例1**（2025联考）实验室只有盐和浓度为 40% 的盐水，为制备 120 克浓度为 50% 的盐水，则需要浓度为 40% 的盐水量是：

A. 60克
B. 80克
C. 100克
D. 110克

**解析**：

**破题**：只有"盐"和"40% 盐水"两种原料 → 两类混合，用溶质守恒。

设需 40% 盐水 m 克，则加纯盐 120 - m 克：

```
40% × m + (120 - m) = 120 × 50%
0.4m + 120 - m = 60 → 0.6m = 60 → m = 100
```

**答案：C**

**例2**（2024联考）一次化学实验中，稀释一定量的盐水，在此盐水中加入 100g 水后，其浓度变为原来的 80%，则原盐水质量为：

A. 200g
B. 300g
C. 400g
D. 500g

**解析**：

**破题**：加水 → 溶质不变 → 浓度与溶液成反比。

设原溶液 m 克：

```
m ÷ (m + 100) = 80% → m = 0.8(m + 100) → 0.2m = 80 → m = 400
```

**答案：C**

> **小技巧**：两种溶液浓度相同 —— 目的是**快速消掉两边的未知数**，原理是**分数比例不变思维**。

```
A ÷ C = (A - C) ÷ (B - D) 型比例关系：浓度相同时，两部分之比保持不变
```

**例3**（2025江苏）甲、乙两瓶质量和浓度均相同的酒精溶液，在甲瓶中加入 20 克水、乙瓶中加入 50 克浓度为 30% 的酒精溶液后，浓度仍然相等。若继续在甲瓶中加入 30 克纯酒精，溶液又恢复到最初浓度，则乙瓶酒精溶液最初的质量是（ ）。

A. 100克
B. 110克
C. 120克
D. 150克

**解析**：

**破题**："浓度仍相等"+"加回纯酒精又复原"→ 先用复原条件定浓度，再回代求质量。

设原质量 m 克、原浓度 c：

```
甲加 30 克纯酒精后复原：(mc + 30) ÷ (m + 50) = c
mc + 30 = mc + 50c → c = 60%
```

（注意甲瓶此时溶液为 m + 20 + 30 = m + 50。）

```
浓度相等：(0.6m) ÷ (m + 20) = (0.6m + 15) ÷ (m + 50)
0.6m(m + 50) = (0.6m + 15)(m + 20)
0.6m² + 30m = 0.6m² + 12m + 15m + 300 → 3m = 300 → m = 100
```

**答案：A**

**例4**（2020广东）现有浓度为 4% 的食盐水 250 克，若向该食盐水添加 10 克食盐，再蒸发掉 160 克水，则新获得的食盐水的浓度为：

A. 10%
B. 15%
C. 20%
D. 25%

**解析**：

**破题**：加溶质 + 蒸发溶剂，两步都只改"一边"，逐项调整即可。

```
原溶质 = 250 × 4% = 10
加盐后溶质 = 10 + 10 = 20，溶液 = 260
蒸发 160 克水：溶液 = 260 - 160 = 100
浓度 = 20 ÷ 100 = 20%
```

**答案：C**

**例5**（2022江苏）某种杀虫剂每桶 5 公斤，浓度为 40%，使用时需将浓度稀释到 5%，每亩地喷洒 60 公斤。若某农户家中有 4 亩地，则至少需要该杀虫剂：

A. 3桶
B. 4桶
C. 5桶
D. 6桶

**解析**：

**破题**：先算"一桶能兑出多少喷洒液"，再算总需求量。

```
每桶有效成分 = 5 × 40% = 2 公斤
稀释到 5% → 可兑药液 = 2 ÷ 5% = 40 公斤
4 亩需药液 = 4 × 60 = 240 公斤
240 ÷ 40 = 6 桶
```

**答案：D**

**例6**（2020浙江选调）实验室内有浓度分别为 10% 和 25% 的盐酸各 500 毫升，从两种溶液中分别倒出一部分配成浓度为 15% 的盐酸 600 毫升。如果将剩余的盐酸混合，则该溶液的浓度为：

A. 16.5%
B. 18.6%
C. 20%
D. 21.25%

**解析**：

**破题**：先按"15%、600 毫升"求出各倒出多少，剩余部分自然得出。

```
设取 10% 的 a 毫升、25% 的 b 毫升：
a + b = 600；0.1a + 0.25b = 600 × 15% = 90
0.1a + 0.25(600 - a) = 90 → 150 - 0.15a = 90 → a = 400，b = 200
剩余：10% 的 100 毫升（溶质 10）、25% 的 300 毫升（溶质 75）
浓度 = (10 + 75) ÷ (100 + 300) = 85 ÷ 400 = 21.25%
```

**答案：D**

**例7**（2020上海）有甲、乙两个瓶子，甲瓶里装了 200 毫升清水，乙瓶里装了 200 毫升纯酒精。第一次把 20 毫升纯酒精由乙瓶倒入甲瓶，第二次把甲瓶中 20 毫升溶液倒回乙瓶，此时甲瓶里含有纯酒精的量（ ）乙瓶里含水的量。

A. 大于
B. 小于
C. 等于
D. 不能确定

**解析**：

**破题**："倒来倒去、有来有回"——总量守恒，直接算两瓶的交换量。

```
第一次后：甲 = 200 水 + 20 酒精，共 220 毫升
倒回乙的 20 毫升中：酒精 20 × 20/220 = 20/11 毫升，水 20 × 200/220 = 200/11 毫升
甲瓶最终酒精 = 20 - 20/11 = 200/11 毫升
乙瓶最终含水 = 200/11 毫升
两者相等
```

**答案：C**

> **★重点**：两瓶互相倒且**总量不变**时，甲瓶里的酒精量必然等于乙瓶里的水量——因为甲瓶里"少掉的水"全部去了乙瓶，而甲瓶"多出的酒精"全部来自乙瓶。

**例8**（2023江苏）浓度分别为 68%、72%、78% 的三种酒精溶液的总质量为 240 克。若将它们全部混合，则可得浓度为 74% 的酒精溶液；若只将浓度为 72% 和 78% 的酒精溶液混合，则得浓度为 76% 的酒精溶液。这三种酒精溶液中，浓度为 72% 的酒精溶液质量为（ ）

A. 30克
B. 40克
C. 48克
D. 60克

**解析**：

**破题**：三者混合 → **两两混合**降维：先用 72% 与 78% 的混合得质量比。

```
设 68%、72%、78% 的质量分别为 a、b、c
72% 与 78% 混合成 76%：72b + 78c = 76(b + c) → 2c = 4b → c = 2b
三者和：a + b + c = a + 3b = 240 → a = 240 - 3b
溶质守恒：68a + 72b + 78c = 240 × 74% = 17760
68(240 - 3b) + 72b + 156b = 17760
16320 - 204b + 228b = 17760 → 24b = 1440 → b = 60
```

即 72% 的溶液 60 克（此时 a = 60 克、c = 120 克）。

**答案：D**

## 四、等量变化：蒸发稀释类

识别：**溶质不变**。

1. 溶液 …… n%，加一定量的水，浓度变为 m%，**再加入等量的水**；
2. 溶液 …… n%，蒸发一定量的水，浓度变为 m%，**再蒸发等量的水**。

方法：

1. 列表（溶质 = 溶液 × 浓度）；
2. **赋值溶质**（取浓度的公倍数即可）；
3. 求加入 / 蒸发水的量。

> **★重点**：等量加水（或等量蒸发）题，把**溶质赋值为两浓度的最小公倍数**，则两次的"溶液量"都是整数，水量差 = 每次加入量，一步出答案。

**例9**（2023福建事业单位）有一杯盐水，第一次往杯内加入一些水后浓度变为 12%，第二次再加入同样多的水后浓度变为 8%，第三次再加入同样多的水后浓度变为（ ）。

A. 7%
B. 6%
C. 5%
D. 4%

**解析**：

**破题**：三次"加同样多的水" → 赋值溶质，把每次加水量算成同一个数。

```
赋溶质 = 24（12 与 8 的公倍数）
第一次后溶液 = 24 ÷ 12% = 200，第二次后 = 24 ÷ 8% = 300 → 每次加水 100
第三次后溶液 = 300 + 100 = 400 → 浓度 = 24 ÷ 400 = 6%
```

**答案：B**

**例10**（2022黑龙江公检法）一杯浓度为 50% 的糖水，加入一定量的水后浓度变为 40%，再加入与上一次等量的水后，糖水变为 60 克，问糖水中的糖有多少克？

A. 18
B. 20
C. 24
D. 30

**解析**：

**破题**：两次等量加水 + 最终总量已知 → 设原溶液 m，把加水量用 m 表示。

```
设原溶液 m 克、糖 0.5m 克，每次加水 x 克
0.5m ÷ (m + x) = 40% → 0.5m = 0.4m + 0.4x → x = 0.25m
m + 2x = 60 → m + 0.5m = 60 → m = 40
糖 = 40 × 50% = 20 克
```

**答案：B**

**例11**（2022湖北选调）将一满容器浓度为 24% 的溶液放置太阳下暴晒一段时间，经过一段时间蒸发水分后溶液浓度变为 36% 且无沉淀。然后再用浓度为 12% 的溶液将容器加满。请问容器内溶液浓度变为多少？

A. 24%
B. 28%
C. 30%
D. 32%

**解析**：

**破题**："满容器 → 蒸发 → 再加满"是关键：加满所用的体积 = 蒸发掉的体积。

```
设容器容积 V，溶质 = 0.24V
蒸发后溶液 = 0.24V ÷ 36% = 2V/3 → 蒸发了 V/3
用 12% 溶液补 V/3：补入溶质 = 0.12 × V/3 = 0.04V
最终浓度 = (0.24V + 0.04V) ÷ V = 28%
```

**答案：B**

**例12**（2023全国事业单位联考）某模拟海洋养殖场有一批海鱼，其池塘具有一定的盐度，且不大于该品种鱼的最适盐度 3.5%。已知每天太阳蒸发掉相同的水量，若不采取任何措施则在第三天结束时，池塘盐度将首次达到该品种鱼可承受的最大盐度限值 5%。为了维持初始盐度不变，每天补充等体积的淡水，问每天可能补充的水量体积最少是原溶液体积的（ ）。

A. 5%
B. 10%
C. 15%
D. 20%

**解析**：

**破题**："维持初始盐度不变"→ 每天补的水正好等于当天蒸发量，答案就是"日蒸发量 ÷ 原体积"。

设原体积 V、原盐度 s、每天蒸发 w：

```
第三天结束：sV ÷ (V - 3w) = 5%
又 s ≤ 3.5% → 0.05(V - 3w) ÷ V ≤ 0.035
0.05(1 - 3r) ≤ 0.035（r = w/V）→ 1 - 3r ≤ 0.7 → r ≥ 0.1
```

故最少补充原体积的 **10%**。

> **⚠易错**：这里用"初始盐度 ≤ 3.5%"卡下界，不能用等号直接取 3.5% 后倒推成 15% 之类的数——盐度可以更低，但每天蒸发量由"第三天到 5%"锁定。

**答案：B**

## 五、反复操作

溶液浓度 n%，倒出比例 a，水加满；再倒出比例 b，水加满；再倒出比例 c，水加满。最后浓度为：

```
最终浓度 = n% × (1 - a) × (1 - b) × (1 - c)
```

> **★重点**："倒出多少比例，浓度就剩多少比例"——每次操作只乘一个 `(1 - 倒出比例)`，与容器原有溶液量无关。

> **⚠易错**：若倒出的是"固定克数"而非"固定比例"，必须先换算成比例（倒出克数 ÷ 当时溶液总量），不能直接用克数。

**例13**（2024联考）现有一容器，装有 100 克浓度为 75% 的盐水，从中倒出 40 克盐水后，再加入 40 克纯净水，如此反复三次。问此时盐水的浓度是：

A. 16.20%
B. 9%
C. 1.62%
D. 0.90%

**解析**：

**破题**：倒 40 克、加 40 克 → 溶液总量始终 100 克，每次浓度乘 (1 - 40/100)。

```
75% × 0.6 × 0.6 × 0.6 = 75% × 0.216 = 16.2%
```

**答案：A**

**例14**（2018江西）从一瓶浓度为 52% 的酒精溶液中倒出 专，加满纯净水，再倒出 亏，又加满纯净水，此时酒精溶液的浓度是多少？

A. 5.8%
B. 23.1%
C. 17.3%
D. 31.5%

**解析**：

**破题**：两次"倒出—加满"→ 浓度连乘两次。**两次倒出的比例在 OCR 中识别为"专""亏"，已丢失**。

按选项反推：只有 `52% × (1 - 2/3)² = 52% ÷ 9 ≈ 5.8%` 落在选项中，故两次倒出比例应为 **2/3**。

```
52% × (1 - 2/3) × (1 - 2/3) = 52% × 1/3 × 1/3 ≈ 5.8%
```

（原文倒出比例 OCR 不清，建议核对 PDF 第 22 页。）

**答案：A**

**例15**（2024四川）现有浓度为 70% 的盐水 100 克。从中倒出 40 克，再加入 40 克浓度为 20% 的盐水，如此操作共 5 次后，问盐水的浓度在以下哪个范围内？

A. 低于23%
B. 在23%到25%之间
C. 在25%到27%之间
D. 高于27%

**解析**：

**破题**：这次"补进来的是 20% 盐水而不是水"，不能直接连乘，要写成递推。

设第 n 次操作后浓度为 pₙ（溶液始终 100 克，故浓度即溶质克数 ÷ 100）：

```
pₙ₊₁ = pₙ × (60/100) + 20% × (40/100) = 0.6pₙ + 8%
不动点：p = 0.6p + 8% → p = 20%
∴ pₙ - 20% = 0.6ⁿ × (70% - 20%) = 0.6ⁿ × 50%
n = 5：0.6⁵ = 0.07776 → 3.888% → p₅ = 23.888%
```

浓度约 23.9%，落在 23%—25% 之间。

**答案：B**

## 六、本章梳理

| 模块 | 内容 | 方法 |
| --- | --- | --- |
| 溶液公式 | 浓度 = 溶质 ÷ 溶液；溶质 = 溶液 × 浓度 | 公式法、线段法（距离与量成反比） |
| 两类混合 | 两种浓度溶液相混 | 溶质守恒列一个方程；等量混合浓度居中 |
| 三者混合 A+B+C | 三种浓度混合 | **两两混合**逐步降维 |
| 等量变化（稀释） | 溶液 n%，加水变 m%，再加等量水 | 列表 / 赋值溶质（取浓度公倍数）/ 求加水量 |
| 等量变化（蒸发） | 溶液 n%，蒸发变 m%，再蒸发等量水 | 同上，溶质不变 |
| 反复操作 | 倒出比例 a、b、c，每次水加满 | `n% × (1-a) × (1-b) × (1-c)` |

> **★重点**：三类模型的"统一视角"——**溶质守恒**。混合看总量，蒸发稀释看溶质不动，反复操作看比例的连乘。

## 七、专项拔高练习十四

**练习1**（2024广东事业单位）杯中有 280ml 的水，加入浓度为 60% 的酒精溶液后，杯中溶液的酒精浓度为 18%，则加入的酒精溶液为（ ）ml。

A. 90
B. 120
C. 150

**解析**：

**破题**：水 + 酒精溶液 → 一次混合，溶质守恒。

```
设加入 x 毫升：0.6x ÷ (280 + x) = 18%
0.6x = 50.4 + 0.18x → 0.42x = 50.4 → x = 120
```

**答案：B**

**练习2**（2021联考）现有一杯浓度为 20% 的糖水 200 克，加入 6 克糖，再加入 24 克水后，此时的糖水与原来相比：

A. 不如原来甜
B. 比原来甜
C. 一样甜
D. 无法确定

**解析**：

**破题**：同时加糖加水 → 直接算新浓度对比。

```
原糖 = 200 × 20% = 40
新浓度 = (40 + 6) ÷ (200 + 6 + 24) = 46 ÷ 230 = 20%
```

浓度不变 → 一样甜。

**答案：C**

**练习3**（2020新疆）甲烧杯装有浓度为 6% 的酒精 200 克，乙烧杯装有浓度为 10.5% 的酒精 100 克。现向两个烧杯各加入 x 克水后，两个烧杯中酒精浓度相同。问 x 的值为：

A. 350
B. 400
C. 550
D. 600

**解析**：

**破题**：加同样的水后浓度相等 → 溶质比 = 溶液比。

```
12 ÷ (200 + x) = 10.5 ÷ (100 + x)
12(100 + x) = 10.5(200 + x) → 1200 + 12x = 2100 + 10.5x → 1.5x = 900 → x = 600
```

**答案：D**

**练习4**（2018联考）现有一种浓度为 15% 的盐水 30 千克，如果用 50 千克浓度更高的盐水和它混合，混合后的盐水浓度将大于 20%，而小于 35%。据此可知，后加入的盐水的浓度（假设浓度为 x）范围是：

A. 23%＜x≤47%
B. 15%＜x＜35%
C. 15%＜x≤23%
D. 23%＜x＜50%

**解析**：

**破题**：混合后浓度落在区间 → 对两端的"上限/下限"各列一个不等式。

```
总溶质 = 30 × 15% + 50x = 4.5 + 50x，总溶液 = 80
> 20%：4.5 + 50x > 16 → x > 23%
< 35%：4.5 + 50x < 28 → x < 47%
```

故 `23% < x < 47%`。

> **⚠易错**：边界 47% 处浓度恰为 35%，不满足"小于 35%"，故区间两端都是**开区间**。按 OCR 文字 A 为"≤47%"、D 为"<50%"，两者都不严格等于计算结果 —— 疑 D 选项的 50% 系 OCR 误识（原文应为 47%），建议核对 PDF 第 29 页。按计算结果应选 **D**（若 D 原为 23%＜x＜47%）。

**答案：D**（选项数值待核）

**练习5**（2023上海事业单位）在 1000 克盐水中加入 80 克盐，浓度比原来提高了约 6.67%，则原来盐水的浓度（ ）。

A. 3.33%
B. 10%
C. 16.67%
D. 20%

**解析**：

**破题**："提高 6.67%"是**百分点**差，不是倍数增长。

设原溶质 x 克：

```
(x + 80) ÷ 1080 - x ÷ 1000 = 1/15
两边乘 10800：10(x + 80) - 10.8x = 720
10x + 800 - 10.8x = 720 → 0.8x = 80 → x = 100
原浓度 = 100 ÷ 1000 = 10%
```

**答案：B**

**练习6**（2023深圳事业单位）李某有两片菜田。一号菜田里的菜刚种不久，所需的肥料浓度较低，用含有效成分 50% 的 1 升肥料原液加 4 升水调配而得。一号菜田施完肥后，剩下的肥料再加入 0.5 升肥料原液，就可以得到二号菜田所需的含有效成分 20% 的肥料。那么一号菜田施完肥后剩下肥料（ ）升。

A. 0.5
B. 1.0
C. 1.5
D. 2.0

**解析**：

**破题**：配好的肥料浓度固定（10%），再掺 0.5 升原液稀释到 20% 反向求剩余量。

```
一号田肥料浓度 = 0.5 ÷ 5 = 10%
设剩余 L 升： (0.1L + 0.5 × 0.5) ÷ (L + 0.5) = 20%
0.1L + 0.25 = 0.2L + 0.1 → 0.15 = 0.1L → L = 1.5
```

**答案：C**

**练习7**（2020江苏）使用浓度为 60% 的硫酸溶液 50 克和浓度为 90% 的硫酸溶液若干克，配制浓度为 66% 的硫酸溶液 100 克，需要加水的质量是：

A. 10克
B. 12克
C. 15克
D. 18克

**解析**：

**破题**：总量 100 克 → 水 = 100 - 两种溶液质量。

```
目标溶质 = 100 × 66% = 66
设 90% 溶液 y 克：50 × 60% + 90%y = 66 → 30 + 0.9y = 66 → y = 40
加水 = 100 - 50 - 40 = 10 克
```

**答案：A**

**练习8**（2019重庆法检）有两个容器 A 和 B，容器中原有不等量的水，分别放入葡萄糖后，容器 A 葡萄糖液体质量 270 克，浓度 10%，容器 B 葡萄糖液体质量 150 克，浓度 12%。若往两个容器分别倒入等量的水，使葡萄糖浓度相同，那么需要多少克水？

A. 30
B. 50
C. 79
D. 90

**解析**：

**破题**：加等量水后浓度相同 → 溶质比 = 溶液比。

```
27 ÷ (270 + y) = 18 ÷ (150 + y)
27(150 + y) = 18(270 + y) → 4050 + 27y = 4860 + 18y → 9y = 810 → y = 90
```

**答案：D**

**练习9**（2019江苏）现有浓度为 12% 和 24% 的盐水各若干克，将其混合后加入 50 克水，配制成浓度为 18% 的盐水 600 克，则原 12% 和 24% 的盐水质量之比是：

A. 6:5
B. 1:1
C. 5:6
D. 4:7

**解析**：

**破题**：先还原"加水前的混合液"，再用溶质守恒。

```
加水前溶液 = 600 - 50 = 550 克，溶质 = 600 × 18% = 108
设 12% 的 a 克、24% 的 b 克：a + b = 550；0.12a + 0.24b = 108
0.12a + 0.24(550 - a) = 108 → 132 - 0.12a = 108 → a = 200，b = 350
a : b = 200 : 350 = 4 : 7
```

**答案：D**

**练习10**（2023河北事业单位）两个杯子中分别装有浓度为 40% 与 10% 糖水，倒在一起后混合，糖水的浓度为 30%。若再加入 300 克 20% 的糖水，则浓度变为 25%。原有浓度为 40% 的糖水多少克？（ ）

A. 400
B. 300
C. 200
D. 100

**解析**：

**破题**：先由"40% 与 10% 混成 30%"得质量比，再由第二次混合定具体质量。

```
线段法：40% 与 10% 混成 30% → 质量比 = (30 - 10) : (40 - 30) = 20 : 10 = 2 : 1
设 40% 的 2k 克、10% 的 k 克，混合后溶质 = 0.3 × 3k = 0.9k
再加 300 克 20%：(0.9k + 60) ÷ (3k + 300) = 25%
0.9k + 60 = 0.75k + 75 → 0.15k = 15 → k = 100
40% 糖水 = 2k = 200 克
```

**答案：C**

**练习11**（2017天津）一份溶液，加入一定量的水后，浓度降到 3%，再加入同样多的水后，浓度降为 2%，该溶液未加水时浓度是：

A. 6%
B. 4%
C. 5%
D. 4.5%

**解析**：

**破题**：两次等量加水 → 赋值溶质，倒推出原溶液量。

```
赋溶质 = 6（3 与 2 的公倍数）
第一次后溶液 = 6 ÷ 3% = 200，第二次后 = 6 ÷ 2% = 300 → 每次加水 100
原溶液 = 200 - 100 = 100 → 原浓度 = 6 ÷ 100 = 6%
```

**答案：A**

**练习12**（2019辽宁）现有装有相等重量纯水的红白蓝三个桶和装有不知浓度与重量的酒精溶液的黑桶，将红桶中水全部倒入黑桶，此时酒精浓度变为 22.5%；再将白桶的水全部倒入黑桶，此时酒精浓度变为 18%；再将蓝桶的水全部倒入黑桶，此时酒精浓度变为：

A. 13.5%
B. 15.0%
C. 15.5%
D. 16.0%

**解析**：

**破题**：每次倒入等重的水 → 溶质不变，溶液按等差增加，浓度与溶液成反比。

设黑桶原溶液 m、每桶水重 w：

```
22.5% × (m + w) = 18% × (m + 2w)（溶质相等）
22.5m + 22.5w = 18m + 36w → 4.5m = 13.5w → m = 3w
溶质 = 22.5% × 4w = 0.9w
第三次：浓度 = 0.9w ÷ (m + 3w) = 0.9w ÷ 6w = 15%
```

**答案：B**

**练习13**（2019上海）一碗芝麻粉，第一次吃了半碗，然后用水加满搅匀；第二次喝了 号 碗，用水加满搅匀；第三次喝了 言 碗，用水加满搅匀；最后一次全吃完。则最后一次吃下的芝麻糊中芝麻粉含量是（ ）。

（原文选项 OCR 仅余"D.=8"字样，其余选项缺失；第二、三次喝掉的碗数被识别为"号""言"，已丢失。）

**解析**：

**破题**：反复"喝掉一部分—加满水"→ 用连乘公式，每次乘 (1 - 喝掉比例)。

```
设第一次后剩 1/2，第二次喝 1/b 碗、第三次喝 1/c 碗
最后碗中芝麻粉 = 1/2 × (1 - 1/b) × (1 - 1/c)
```

**具体数值因 OCR 缺失无法确定，建议核对 PDF 第 38 页。**

> **★重点**：本题型的通法只有一条——**每次喝掉的比例，就是当次芝麻粉的损耗比例**，三次连乘即得最终含量；分母相同的选项往往是干扰项（越喝越少，结果必然小于 1/2）。
