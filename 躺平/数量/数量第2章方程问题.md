## 一、普通方程：一个未知数（x）

### 做题步骤

1. 设未知数
2. 找等量关系
3. 约分

> **★重点**：设未知数技巧：
> ① **设小不设大**：甲是乙的两倍 → 设乙为 x，甲为 2x；
> ② **出现比例设份数**：甲:乙 = 3:5 → 设甲 3x、乙 5x；
> ③ **设中间量**：甲:乙 = 3:1，乙:丙 = 2:3 → 统一乙为 3 份，设甲 6x、乙 3x、丙 2x（取最小公倍份数）。

### 例题

**例1**（2025广东）某服务大厅设有若干个服务窗口，其中1个是快捷服务窗口，某日服务窗口的平均业务量为29单，其中快捷服务窗口的业务量为41单，其余窗口的平均业务量为28单，则服务大厅共有（）个窗口。
A. 13
B. 14
C. 15
D. 16

**破题**：A 与非 A 思想——快捷窗口 1 个与其余窗口分开表示，总量 = 单量守恒列方程。

**解析**：设共 x 个窗口，总业务量 = `29x` = 快捷 41 + 其余 `28(x - 1)`。
`29x = 41 + 28x - 28` → `x = 13`。

**答案：A**

**例2**（2025天津）某连锁餐厅甲、乙、丙三个店面2024年销售额总计为1000万元，利润总计为120万元。其中，甲店面的销售额是利润的10倍，是丙店面销售额的 2/3，乙店面的利润比甲店面多10万元且比丙店面少10万元。问乙店面的销售额是利润的多少倍？
A. 6
B. 6.25
C. 7
D. 7.2

> 注：题干"是丙店面销售额的"后的分数在 OCR 稿中缺失，已按 2025 天津真题（PDF 第 6 页）及选项内部一致性核实为 2/3。

**破题**：甲利润是核心中间量（甲销售额 = 10×甲利润）→ 设甲利润 x，三个利润都用 x 表示。

**解析**：设甲利润 x 万元，则乙 = x + 10，丙 = x + 20。
`x + (x + 10) + (x + 20) = 120` → `3x = 90` → `x = 30`。
甲利润 30、乙利润 40、丙利润 50。
甲销售额 = `30 × 10 = 300` 万元；丙销售额 = `300 ÷ (2/3) = 450` 万元。
乙销售额 = `1000 - 300 - 450 = 250` 万元。
乙销售额 ÷ 乙利润 = `250 ÷ 40 = 6.25` 倍。

**答案：B**

**例3**（2025联考）物流公司有两种载重分别为1.5吨和2吨的货车，甲乙两名调度员均调动10辆车满载运货。若甲乙调动的两种车的数量比相反，全部货物运完后，乙运的货物比甲运的货物多1吨，则乙运的货物重量为：
A. 16吨
B. 17吨
C. 18吨
D. 19吨

**破题**："数量比相反"→ 甲若 1.5 吨车 x 辆，乙则 1.5 吨车 (10 - x) 辆；各列运量、作差。

**解析**：甲运量 = `1.5x + 2(10 - x) = 20 - 0.5x`；乙运量 = `1.5(10 - x) + 2x = 15 + 0.5x`。
乙 - 甲 = `x - 5 = 1` → `x = 6`。
乙运量 = `15 + 0.5 × 6 = 18` 吨。

**答案：C**

**例4**（2025联考）某产品甲、乙两个经销商第一季度销售总额为200万元。第二季度，甲、乙的销售额比第一季度分别高20%、25%，且甲的销售额比乙高44万元。问上半年甲的销售额比乙高多少万元？
A. 72
B. 76
C. 80
D. 84

**破题**：上半年差 = 一季度差 + 二季度差（44 已知）→ 只需求一季度差，设甲一季度 x。

**解析**：设甲一季度 x 万元，乙一季度 `200 - x` 万元。
二季度：`1.2x - 1.25(200 - x) = 44` → `1.2x - 250 + 1.25x = 44` → `2.45x = 294` → `x = 120`。
一季度甲 120、乙 80，一季度差 40。
上半年差 = `40 + 44 = 84` 万元。

**答案：D**

## 二、普通方程：多个未知数（设 x、y、z）

1. 存在多个未知数，设 x、y、z；
2. **抓住问题消元求解**（没有必要把 x、y、z 都求出来）。

**例5**（2024山东）某科技创新项目有6人投资，共筹资110万元。投资额度有10万元、20万元和30万元三种。已知投资10万元的比投资20万元的多2人，问投资30万元的有多少人？
A. 2
B. 3
C. 4
D. 5

**破题**：以"投资 20 万的人数 x"为中间量，其余两类人都用 x 表示。

**解析**：设投 20 万的 x 人，投 10 万的 (x + 2) 人，投 30 万的 `6 - 2x - 2 = 4 - 2x` 人。
`10(x + 2) + 20x + 30(4 - 2x) = 110` → `10x + 20 + 20x + 120 - 60x = 110` → `-30x = -30` → `x = 1`。
投 30 万元的 = `4 - 2 = 2` 人。
（验证：10 万 3 人共 30 万 + 20 万 1 人 + 30 万 2 人共 60 万 = 110 万 ✓）

**答案：A**

**例6**（2023联考）浮雕银杯是我国古代常见的一种盛酒容器，有大银杯和小银杯之分。已知5个大银杯加1个小银杯，可以盛酒3斛（斛，是古代的一种容量单位），5个小银杯加1个大银杯，可以盛酒2斛，则1斛酒至多可以倒满小银杯的数量为：
A. 2个
B. 3个
C. 4个
D. 5个

**破题**：二元一次方程组，先消元求小银杯容量。

**解析**：设大银杯容量 a、小银杯容量 b（斛）。
`5a + b = 3`，`a + 5b = 2`。两式相减：`4a - 4b = 1` → `a = b + 0.25`。
代入第一式：`5(b + 0.25) + b = 3` → `6b = 1.75` → `b = 7/24` 斛。
1 斛可倒满小银杯 `1 ÷ 7/24 = 24/7 ≈ 3.4` 个 → 至多倒满 **3** 个。

**答案：B**

## 三、不定方程

> **★重点**：不定方程 `ax + by = M`（普通不定方程）：奇偶、倍数、尾数、代入；
> 多个未知数的不定方程 `ax + by + cz = M`：倍数特性、代入。

### 奇偶特性

**引例1** `3x + 4y = 25`，x = ？（x、y 均为正整数）
A. 2　B. 3　C. 4　D. 5

**解析**：4y 为偶数，25 为奇数 → 3x 必为奇数 → x 为奇数，排除 A、C；代入 B：x = 3 时 `3 × 3 = 9`，`y = (25 - 9) ÷ 4 = 4` ✓。**答案：B**

### 倍数特性

> **★重点**：`ax + by = M`，当 a 或 b 与 M 有公因子时，考虑倍数特性。

**引例2** `7x + 3y = 60`，y 最大为多少？（x、y 均为正整数且不为 0）
A. 12　B. 13　C. 16　D. 18

**解析**：3 与 60 有公因子 3 → 7x 能被 3 整除 → x 是 3 的倍数。x 最小取 3：`3y = 60 - 21 = 39` → `y = 13`。**答案：B**

### 尾数

> **★重点**：`ax + by = M`，当 a 或 b 尾数是 0 时，考虑尾数。

**引例3** `37x + 20y = 271`，x = ？（x、y 均为正整数）
A. 1　B. 3　C. 2　D. 4

**解析**：20y 尾数为 0，271 尾数为 1 → 37x 尾数为 1 → x = 3（37 × 3 = 111，y = 8 ✓）。**答案：B**

### 例题

**例7**（2025联考）甲乙两部门组织户外团建，共设A、B、C三项活动。甲部门每人三项活动均参加1次，乙部门每人任选2项不同活动各参加1次。已知A、B、C三项活动分别有18人、16人、15人参加，问甲部门成员至多有多少人？
A. 11
B. 12
C. 13
D. 14

**破题**：按"人次"列式：甲每人贡献 3 人次、乙每人贡献 2 人次，总人次 = 18 + 16 + 15 = 49，用奇偶性排除后代入。

**解析**：设甲 x 人、乙 y 人：`3x + 2y = 49`。2y 为偶数、49 为奇数 → 3x 为奇数 → x 为奇数，排除 B、D。
代入 C：x = 13 → `2y = 10` → y = 5，此时乙部门在 A、B、C 项的人次分别为 `18-13=5`、`16-13=3`、`15-13=2`，均非负且合计 10 = 2y ✓，符合。x 至多为 13。

**答案：C**

**例8**（2025联考）甲和乙两个科研单位共有99名工作人员。其中甲单位研究人员占本单位工作人员总数的75%，乙单位研究人员占本单位工作人员总数的88%。问甲单位的非研究人员比乙单位的非研究人员：
A. 少不到5人
B. 少5人以上
C. 多不到5人
D. 多5人以上

**破题**：75% = 3/4 → 甲人数是 4 的倍数；88% = 22/25 → 乙人数是 25 的倍数；`4k + 25m = 99` 用尾数定 m。

**解析**：设甲 4k 人、乙 25m 人：`4k + 25m = 99`。25m 尾数为 5 或 0，99 尾数为 9 → 4k 尾数为 4 → m 为奇数。
m = 1：4k = 74，不能被 4 整除 ✗；m = 3：4k = 24 → k = 6 ✓。
甲非研究人员 = k = 6 人，乙非研究人员 = `25m × 12% = 75 × 0.12 = 9` 人。
`6 - 9 = -3`，甲比乙少 3 人 → 少不到 5 人。

**答案：A**

**例9**（2020四川）某人花400元购买了若干盒樱桃。已知甲、乙、丙三个品种的樱桃单价分别为28元/盒、32元/盒和33元/盒，问他最多购买了多少盒丙品种的樱桃？
A. 3
B. 4
C. 5
D. 6

> 注：OCR 稿中 D 选项残缺（"2."），D 选项数值按 2020 四川真题（PDF 第 20 页）核实为 6。

**破题**：`28x + 32y + 33z = 400`，28、32、400 都是 4 的倍数 → 33z 必是 4 的倍数 → z 是 4 的倍数，先定 z 再验证。

**解析**：z = 8：`33 × 8 = 264`，剩 `400 - 264 = 136 = 28x + 32y` → `7x + 8y = 34`，无正整数解（8y ≡ 34 ≡ 6 (mod 7) → y ≡ 6 (mod 7)，y = 6 时 8y = 48 > 34 ✗）。
z = 4：`33 × 4 = 132`，剩 268 → `7x + 8y = 67`，`8y ≡ 4 (mod 7)` → y ≡ 4 (mod 7) → y = 4，`x = (67 - 32) ÷ 7 = 5` ✓。
最多买 4 盒丙品种。

**答案：B**

**例10**（2025浙江）篮球比赛中，三分线内，投中一次得2分，三分线外，投中一次得3分；若被犯规，则获得罚球机会，投中一次得1分。某场比赛，小张2分球命中率为62.5%，3分球命中率力44.4%，最终得分25分。已知小张罚球次数为7次，那么他的罚球命中率在以下哪个范围？
A. 30%-40%
B. 40%-50%
C. 50%-60%
D. 60%-70%

> 注：题干"命中率力"为 OCR 误字，应为"命中率为"。

**破题**：62.5% = 5/8、44.4% ≈ 4/9 → 命中数与出手数成比例，设 2 分命中 5x、3 分命中 4y，列得分方程。

**解析**：2 分命中 5x 次（出手 8x 次）得 `10x` 分；3 分命中 4y 次（出手 9y 次）得 `12y` 分；罚球命中 z 次。
`10x + 12y + z = 25`。2 分、3 分球都有命中（x、y ≥ 1）：x = 1、y = 1 → `z = 3`。
罚球命中率 = `3 ÷ 7 ≈ 42.9%`，在 40%-50% 之间。

**答案：B**

## 四、不定方程组

```
a₁x + b₁y + c₁z = M
a₂x + b₂y + c₂z = N
```

> **★重点**：
> 第一类（整数型，主流）：未知数一定是整数 → 先消元转化为不定方程，再按不定方程求解。备注：只有整数型才可以用不定方程特性（奇偶、倍数、尾数、代入）解题。
> 第二类：未知数可以是小数（单价和时间）→ ①凑系数（高中考法，不好想）；②**赋零法**：赋其中 1 个未知数为零，快速算出其他未知数。赋谁为零：大的数、不好算的数。

### 例题（整数型）

**例11**（2024联考）商店销售甲、乙、丙、丁四种商品，每件分别盈利15元、9元、4元和1元。某日销售这四种商品共40件，共盈利201元。四种商品每种至少销售1件，且甲、丁商品销量相同。问当天丙商品的销量为多少件？
A. 21
B. 27
C. 29
D. 31

**破题**：甲 = 丁，设甲丁各 x 件，两个方程消 x 转化为不定方程。

**解析**：设甲、丁各 x 件，乙 y 件，丙 z 件：
`2x + y + z = 40`；`15x + 9y + 4z + x = 201` → `16x + 9y + 4z = 201`。
第一式 × 8：`16x + 8y + 8z = 320`，用第二式减去它：`y - 4z = -119` → `4z = y + 119`。
y ≥ 1 且 `y + 119` 是 4 的倍数 → y ≡ 1 (mod 4) → y 最小取 1，此时 `z = 30`、`x = (40 - 1 - 30)/2 = 4.5` 非整数 ✗；
y = 5 → `z = 31`，`x = (40 - 5 - 31)/2 = 2` ✓。
（验证：盈利 `15×2 + 9×5 + 4×31 + 1×2 = 30 + 45 + 124 + 2 = 201` ✓）

**答案：D**

**例12**（2025天津）某旅行团有游客15人，租用6辆车外出旅行，每辆车乘坐游客最多4人。已知每辆车至少乘坐1名游客，问乘坐2名游客的车辆至多有几辆？
A. 1
B. 2
C. 3
D. 4

**破题**：问"至多"→ 从大往小代入；剩余车辆每车 1~4 人能装下即可。

**解析**：设 2 人车 k 辆，其余 `6 - k` 辆装 `15 - 2k` 人，需 `6 - k ≤ 15 - 2k ≤ 4(6 - k)`。
右不等式：`15 - 2k ≤ 24 - 4k` → `2k ≤ 9` → k ≤ 4。
验证 k = 4：其余 2 辆装 7 人，每辆 ≤ 4 人（4 + 3）✓。至多 4 辆。

**答案：D**

### 例题（小数型·赋零法）

**例13**（2025四川）某企业采购甲、乙和丙三种不同配置的电脑，已知甲、乙、丙各1台共2.3万元，2台甲加1台乙的总价比1台丙的单价高2.2万元。该企业最终决定采购1台甲、3台乙和7台丙，问采购总费用为多少万元？
A. 6.6
B. 7.1
C. 7.6
D. 8.1

**破题**：两个方程三个未知数，结果与单个未知数无关 → 赋零法，赋系数大的（甲）为 0。

**解析**：设甲 a、乙 b、丙 c（万元）：`a + b + c = 2.3`；`2a + b - c = 2.2`。
赋 a = 0：`b + c = 2.3`，`b - c = 2.2` → `b = 2.25`，`c = 0.05`。
采购总费用 = `a + 3b + 7c = 0 + 6.75 + 0.35 = 7.1` 万元。

**答案：B**

**例14**（2023湖北事业单位）顾客安女士在水果店里购买了1箱苹果、3盒草莓和5盒蓝莓，共花费260元。顾客何先生在同一水果店以同样的单价购买了1箱苹果、4盒草莓和7盒蓝莓，共花费320元。那么购买1箱苹果、1盒草莓和1盒蓝莓需花费（）元。
A. 140
B. 150
C. 160
D. 170

**破题**：两个方程三个未知数，问 `a + b + c` → 赋零法，赋蓝莓为 0。

**解析**：设苹果 a、草莓 b、蓝莓 c：`a + 3b + 5c = 260`；`a + 4b + 7c = 320`。
赋 c = 0：`a + 3b = 260`，`a + 4b = 320` → `b = 60`，`a = 80`。
`a + b + c = 80 + 60 + 0 = 140` 元。

**答案：A**

**例15**（2021黑龙江边境）幼儿园需采购春联、窗花、小狗玩偶三种新年用品，已知大班采购春联7幅，窗花12对、小狗玩偶5个，共花费200元，中班采购春联9幅、窗花19对、小狗玩偶5个，共花费224元。问小班采购春联10幅，窗花10对，小狗玩偶10个需花费多少元？
A. 170
B. 176
C. 340
D. 352

**破题**：两式相减先锁定春联、窗花的单价组合，再回代求玩偶单价。

**解析**：设春联 x 元/幅、窗花 y 元/对、玩偶 z 元/个：
`7x + 12y + 5z = 200`；`9x + 19y + 5z = 224`。
相减：`2x + 7y = 24`。取 y = 2 → `x = 5`；回代：`35 + 24 + 5z = 200` → `z = 28.2`。
小班费用 = `10 × 5 + 10 × 2 + 10 × 28.2 = 50 + 20 + 282 = 352` 元。

**答案：D**

## 专项拔高练习二

**练习1**（2025浙江）农学院学生采集了甲、乙两个品种的水稻样本各若干份，其中36份为有效样本。已知乙品种采集样本30份，那么甲品种的有效样本比乙品种的无效样本：
A. 多6份
B. 多12份
C. 少6份
D. 少12份

**破题**：甲有效 + 乙有效 = 36，乙无效 = 30 - 乙有效 → 作差整体消元。

**解析**：设甲有效 x 份、乙有效 y 份，则 `x + y = 36`，乙无效 = `30 - y` 份。
甲有效 - 乙无效 = `x - (30 - y) = x + y - 30 = 36 - 30 = 6` → 多 6 份。

**答案：A**

**练习2**（2023北京）张、王、李三人总共有120本书，张、王的书分别是李的2倍和5倍，则王有多少本书？
A. 65
B. 70
C. 75
D. 80

**破题**："李"是中间量，设李 x 本。

**解析**：张 2x、王 5x、李 x → `8x = 120` → `x = 15`，王 = `5 × 15 = 75` 本。

**答案：C**

**练习3**（2023广东）甲、乙两个仓库共存有340吨粮食。如果甲仓库存放的粮食是乙仓库的2倍多10吨，则甲仓库存有粮食（）吨。
A. 110
B. 120
C. 230
D. 240

**破题**：设小的（乙）为 x。

**解析**：甲 = `2x + 10`，`x + 2x + 10 = 340` → `3x = 330` → `x = 110`，甲 = `230` 吨。

**答案：C**

**练习4**（2020江苏B）某社区组织了一次助学捐款活动，在场的老王、老李和老张均积极捐款。若老王捐款的是老李捐款的 3/5、老张捐款的 3/11，且老张比老王多捐192元，则他们的捐款总额是：
A. 418元
B. 456元
C. 494元
D. 532元

> 注：题干两个分数在 OCR 稿中缺失，已结合课程笔记与选项（PDF 第 33 页）核实为 3/5、3/11。

**破题**：王 = (3/5)李 = (3/11)张 → 三人比 3 : 5 : 11，设份数求解。

**解析**：设王 3x、李 5x、张 11x。
张 - 王 = `8x = 192` → `x = 24`。
总额 = `3x + 5x + 11x = 19x = 456` 元。
（验证：王 72、李 120、张 264，264 - 72 = 192 ✓）

**答案：B**

**练习5**（2025联考）某单位优化办事流程，每个窗口总服务时间不变，但个人服务和企业服务的单次用时分别下降了50%和20%。原来每个窗口每天可以服务80名个人和30家企业，现在每个窗口可以服务54名个人和42家企业。问现在每次企业服务的用时是个人服务的多少倍（服务衔接时间忽略不计）？
A. 不到11倍
B. 11~13倍之间
C. 13~15倍之间
D. 超过15倍

**破题**：一天总服务时间不变 → 原来用时之和 = 现在用时之和，设原来单次用时列方程。

**解析**：设原来个人单次用时 t₁、企业单次用时 t₂（每天按 1 个单位时间）：
`80t₁ + 30t₂ = 1`；现在：`54 × 0.5t₁ + 42 × 0.8t₂ = 1` → `27t₁ + 33.6t₂ = 1`。
第一式 × 27/80：`27t₁ + 10.125t₂ = 0.3375`；两式相减：`23.475t₂ = 0.6625` → `t₂ ≈ 0.02822`，`t₁ = (1 - 30 × 0.02822)/80 ≈ 0.001917`。
现在企业/个人单次用时之比 = `0.8t₂ ÷ 0.5t₁ = 1.6 × 0.02822 ÷ 0.001917 ≈ 23.6` 倍 → 超过 15 倍。

**答案：D**

**练习6**（2024联考）某包装车间包装甲、乙两种规格的袋装杂粮，甲、乙两袋杂粮的重量之比为5:2，如果从甲袋中称出2公斤放入乙袋后，甲、乙两袋杂粮的重量之比变为4:3。问甲袋杂粮原来重量为：
A. 8公斤
B. 10公斤
C. 12公斤
D. 15公斤

**破题**：设份数：甲 5x、乙 2x，移动后作比列方程。

**解析**：`(5x - 2) : (2x + 2) = 4 : 3` → `3(5x - 2) = 4(2x + 2)` → `15x - 6 = 8x + 8` → `7x = 14` → `x = 2`。
甲原来 = `5 × 2 = 10` 公斤。

**答案：B**

**练习7**（2024广东）某企业在展销会上销售甲、乙两种产品。已知甲产品的库存比乙产品多100件，展销会结束后，甲产品全部售完，乙产品售出库存的60%，两种产品共售出1260件，则甲、乙两种产品原有总库存（）件。
A. 1450
B. 1500
C. 1550
D. 1600

**破题**：设乙库存 x，甲 = x + 100，售出量列方程。

**解析**：`(x + 100) + 0.6x = 1260` → `1.6x = 1160` → `x = 725`。
总库存 = `2x + 100 = 1550` 件。

**答案：C**

**练习8**（2020广东）某部门正在准备会议材料，共有153份相同的文件，需要装到大小两种文件袋里送至会场，大的每个能装24份文件，小的每个能装15份文件。如果要使每个文件袋都正好装满，则需要大文件袋（）个。
A. 2
B. 3
C. 5
D. 7

**破题**：`24大 + 15小 = 153`，两边除以 3 化简，用尾数/整除定大袋数。

**解析**：化简：`8大 + 5小 = 51`。5小 尾数只能是 0 或 5，51 尾数为 1 → 8大 尾数为 1 或 6。
大 = 2：`8 × 2 = 16`，小 = `35 ÷ 5 = 7` ✓。大袋 2 个。

**答案：A**

**练习9**（2022江苏）某企业年终评选了30名优秀员工，分三个等级，分别按每人10万元、5万元、1万元给与奖励。若共发放奖金89万元，则获得1万元奖金的员工有：
A. 14人
B. 19人
C. 20人
D. 21人.

**破题**：`10a + 5b + c = 89`，`a + b + c = 30` → 两式消 c 得不定方程，用余数求解。

**解析**：`10a + 5b + c = 89`，`c = 30 - a - b` 代入：`9a + 4b = 59`。
`4b ≡ 59 ≡ 5 (mod 9)` → `b ≡ 8 (mod 9)` → b = 8，`a = (59 - 32) ÷ 9 = 3`，`c = 30 - 3 - 8 = 19` 人。

**答案：B**

**练习10**（2018上海）现有甲、乙、丙三种货物，若购买甲1件、乙3件、丙7件共需200元；若购买甲2件、乙5件、丙11件共需350元。则购买甲、乙、丙各1件共需多少元？
A. 50
B. 100
C. 150
D. 200

**破题**：三元两式问组合价 → 赋零法，赋丙为 0。

**解析**：设甲 a、乙 b、丙 c：`a + 3b + 7c = 200`；`2a + 5b + 11c = 350`。
赋 c = 0：`a + 3b = 200`，`2a + 5b = 350` → `a = 50`，`b = 50`。
`a + b + c = 100` 元。

**答案：B**

## 小结

| 类型 | 方法要点 |
| --- | --- |
| 普通方程 | 设小不设大、出现比例设份数、设中间量；找等量关系 |
| 普通方程组 | 存在多个未知数设 xyz；抓住问题、消元求解 |
| 不定方程 `ax + by = M` | 奇偶、倍数、尾数、代入 |
| 不定方程 `ax + by + cz = M` | 倍数特性、代入 |
| 不定方程组（整数型） | 消元转化为不定方程求解 |
| 不定方程组（小数型） | 凑系数、赋零法（赋大的、不好算的数为零） |
