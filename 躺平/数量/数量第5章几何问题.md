## 1. 几何公式

### 长度相关公式

```
正方形周长：C正方形 = 4a
长方形周长：C长方形 = 2(a + b)
圆形周长：  C圆 = 2πr
弧长 = n°/360° × 2πr
```

> **★重点**：弧长公式的 `n°` 是圆心角，分子分母都带度数，别把 360° 写成 180°。

### 面积相关公式

```
S正方形 = a²
S长方形 = ab
S菱形 = 对角线乘积 ÷ 2
S平行四边形 = ah
S三角形 = 1/2 · ah
S梯形 = 1/2 · (a + b)h
S圆 = πr²
S扇形 = n°/360° · πr²
多边形内角和 = (n - 1) × 180°
```

| 图形 | 面积公式 | 关键量 |
| --- | --- | --- |
| 正方形 | `a²` | 边长 a |
| 长方形 | `ab` | 长 a、宽 b |
| 菱形 | `对角线乘积 ÷ 2` | 两条对角线 |
| 平行四边形 | `ah` | 底 a、高 h |
| 三角形 | `1/2 · ah` | 底 a、高 h |
| 梯形 | `1/2 · (a + b)h` | 上底 a、下底 b、高 h |
| 圆 | `πr²` | 半径 r |
| 扇形 | `n°/360° · πr²` | 圆心角 n° |

> **⚠易错**：多边形内角和是 `(n - 1) × 180°`（原文写法），常见教材写作 `(n - 2) × 180°`，做题时以题给条件和图形为准，别混用。

### 表面积相关公式

```
S正方体 = 6a²
S长方体 = 2ab + 2bc + 2ac
S球 = 4πr²
S圆柱 = 2πr² + 2πrh
```

> **★重点**：圆柱表面积 = 两个底面积 + 侧面积，`2πr² + 2πrh`；只求"外表面"时要判断底面是否算入。

### 体积相关公式

```
V正方体 = a³
V长方体 = abc
V柱体 = Sh
V锥体 = 1/3 · Sh
V球 = 4/3 · πr³
长方体体对角线 = √(a² + b² + c²)
```

常用近似值：

```
√2 ≈ 1.414    √3 ≈ 1.732    √5 ≈ 2.236
```

> **★重点**：`V锥 = 1/3 Sh` 的 1/3 是最高频失分点；球体积 4/3 与表面积 4 常被互换，记"体积带 1/3、表面积不带"。

## 2. 三角形

本节五条主线：

1. 直角三角形
2. 正六边形
3. 坐标构造
4. 三角形同底或者同高（长方形）
5. 相似三角形

### （1）普通三角形

```
两边之和 > 第三边
两边之差 < 第三边
```

特殊三角形：直角三角形、等边三角形。

### （2）勾股定理相关

常考点：`a² + b² = c²`、特殊角三角形三边关系。

**1. 特殊勾股数**

```
(3, 4, 5)   (6, 8, 10)   (5, 12, 13)   (7, 24, 25)
```

**2. 边长的放缩**：勾股数同比例放大缩小仍是勾股数，如 `(3,4,5) × 2 = (6,8,10)`。

> **★重点**：几何问题中出现**平方加和**的条件，直接想勾股定理（`a² + b² = c²`）。

**3. 特殊角三角形三边关系**

```
30°-60°-90°：三边比 1 : √3 : 2
45°-45°-90°：三边比 1 : 1 : √2
```

- 30°-60°-90°：短直角边是斜边的**一半**；长直角边是短直角边的 **√3 倍**。
- 45°-45°-90°：两直角边**相等**；斜边是直角边的 **√2 倍**。

### （3）等边三角形

```
边长：a
高：  (√3/2)a
面积：S = (√3/4)a²
```

### （4）正六边形

正六边形由 **6 个等边三角形**构成，特性是对称性强。

> **★重点**：正六边形边长 a 时，最长对角线 = 2a，隔点连成的大正三角形边长 = √3a。

### （5）圆中的直角

- 不在同一直线上的三个点确定一个圆；
- **圆的直径所对的角是直角（90°）**。

> **★重点**：圆上最远的两个点构成直径；出现切线，先找 90°。

### 例题

**例1**（2025联考）高速公路某路段转向处靠近居民楼，为减少噪声需设置隔音板（如下图所示），安装隔音板范围为公路转向处的一段圆曲线（即从点 A 至点 B 圆弧），测控人员在过点 A、B 的两条切线的交点 C 处，测得从 A 到 B 转角 α 为 60°，若此圆曲线的半径 OA = 1km，则这段隔音板的安装长度为：

（原题含图形，建议核对 PDF 第 9 页）

A. π/4 km

B. π/2 km

C. 2π/3 km

D. 3π/4 km

**解析**：

**破题**：两条切线夹角 60° → 圆心角与切线夹角互补，先求圆心角再用弧长公式。

- 两条切线夹角 α = 60°，四边形 OACB 中 ∠AOB = 180° - 60° = 120°；
- 半径 r = OA = 1；
- 弧长 = `120°/360° × 2π × 1 = 2π/3`。

答案：**C**。

> **⚠易错**：弧长公式里的角是**圆心角 120°**，不是切线夹角 60°；直接用 60° 会错选 π/3 类选项。

**例2**（2025国考）一个长方体零件最大面的面积是最小面的 3 倍，次大面的面积是最大、最小面面积平均值的 9/16。问该零件最小面的长是其宽的多少倍？

A. 7/3

B. 7/6

C. 8/3

D. 4/3

**解析**：

**破题**：长方体三个面两两相乘 → 设长宽高 a ≥ b ≥ c，把三个面用 ab、ac、bc 表示，直接代条件。

设长、宽、高分别为 a、b、c，且 a ≥ b ≥ c，则三个面面积为 `ab`（最大）、`ac`（次大）、`bc`（最小）。

- 最大 = 3 × 最小：`ab = 3bc` → `a = 3c`；
- 平均值为 `(ab + bc)/2 = (3bc + bc)/2 = 2bc`；
- 次大：`ac = 9/16 × 2bc = 9bc/8` → `a = 9b/8`，即 `b = 8a/9`；
- 最小面是 bc，其长宽比 `b/c`：由 `a = 3c` 与 `b = 8a/9 = 8c/3` 得 `b/c = 8/3`。

答案：**C**。

> **★重点**：长方体三面面积的乘积关系 `(ab)(ac)(bc) = (abc)²`，已知两个面的比例就能锁第三个面的比例。

**例3**（2025联考）某三层高的露天平台每层可视作圆柱体（如下图所示）。已知每层高 5 米，下层直径 100 米，中层直径 80 米，上层直径 68 米，现要对平台的外表面进行清洁维护，共需要维护多少平方米？

（原题含图形，建议核对 PDF 第 11 页）

A. 3740π

B. 5256π

C. 6240π

D. 6496π

**解析**：

**破题**：外表面 = 三段圆柱侧面 + 三级露出的环面（顶层整圆 + 两级圆环）。

半径分别为 50、40、34 米。

```
侧面积 = π × 5 × (100 + 80 + 68) = 1240π
顶面圆 = π × 34² = 1156π
中层环 = π(40² - 34²) = π(1600 - 1156) = 444π
下层环 = π(50² - 40²) = π(2500 - 1600) = 900π
合计   = 1240π + 1156π + 444π + 900π = 3740π
```

答案：**A**。

> **⚠易错**：环面用**半径平方差**，不能写成"直径差 × π"；顶层是一个完整圆而非圆环。

**例4**（2025上海）公园打算修建一个横截面为月牙形（如图所示）的柱体水池养观赏鱼，其中大圆的半径为 4 米，小圆内部为休息区，其半径为 2 米，水池深 2 米，等到水池修建好，需要注入大约（ ）立方米的水。

（原题含图形，建议核对 PDF 第 12 页）

A. 57

B. 64

C. 76

D. 88

**解析**：

**破题**：月牙形 = 大圆减小圆（两圆内切），先求截面积再乘深度。

```
截面积 = π × 4² - π × 2² = 16π - 4π = 12π
体积   = 12π × 2 = 24π ≈ 24 × 3.14 = 75.4（立方米）
```

答案：**C**（约 76）。

> **★重点**：柱体体积 = 底面积 × 高，月牙、环形这类"面积差"截面先算差再乘高。

**例5**（2025浙江）一块直角梯形空地 ABCD 如右图所示，其中 AD = AC = 2AB。现准备在图中三角形区域 ABC 建设特色生态园，并在图中与两条边相切的圆形区域建设特色花坛。已知 D 点到圆上任一点最短距离为 AB 长度的一半，那么特色生态园与特色花坛的面积比值在以下哪个范围？

（原题含图形，建议核对 PDF 第 21 页；圆的相切边与梯形摆放方式 OCR 无法还原）

A. 小于1

B. 1-1.5

C. 1.5-2

D. 大于2

**解析**：

**破题**：出现"点到圆的最短距离"，意味着**圆心、切点、D 三点共线**，即 `D 到圆心距离 = r + AB/2`。

- 设 AB = a，则 AC = AD = 2a；
- △ABC 中 AB ⊥ BC（直角梯形），由 `AC² = AB² + BC²` 得 `BC = √(4a² - a²) = √3a`；
- 故 `S△ABC = 1/2 × a × √3a = (√3/2)a²`；
- 设花坛半径 r，由 D 到圆最短距离为 a/2 得 `DO = r + a/2`，与相切条件联立可解出 r，再算 `πr²`。

> **⚠易错**：本题关键是把"最短距离"翻译成"圆心距 = 半径 + 最短距离"，这是切线类问题的通用翻译，不要试图直接量图。

（圆的具体半径依赖图中相切的两条边，OCR 后图形缺失，最终比值请对照 PDF 第 21 页图示核算。）

**例6**（2025上海）在一个宁静的村庄里有三座古老的瞭望塔，分别位于村庄的 A、B、C 处，且由三条笔直的公路连接，这三条公路恰好构成一个以 AC 为底边的等腰三角形。村民们发现，塔 C 到塔 A、B 的距离之比恰为 2:√5，且塔 C 到公路 AB 的最短距离为 4 公里，那么塔 B、C 之间的距离为（ ）公里。

A. 2

B. 5

C. 2√5

D. 5√5

**解析**：

**破题**：以 AC 为底的等腰三角形 → 腰是 AB = BC；再用"面积 = 1/2 × 底 × 高"两次列式。

设 CA = 2k，CB = √5k，则 AB = BC = √5k，C 到 AB 的高 h = 4。

设垂足到 A 的距离为 x：

```
CA² - x² = h²        →  4k² - x² = 16
CB² - (AB - x)² = h² →  5k² - (√5k - x)² = 16
```

两式相减：`5k² - (5k² - 2√5kx + x²) = 4k² - x²` → `2√5kx = 4k²` → `x = 2k/√5`。

代回第一式：

```
4k² - 4k²/5 = 16  →  16k²/5 = 16  →  k² = 5  →  k = √5
BC = √5 × √5 = 5
```

答案：**B**。

> **★重点**：等腰三角形给"高"和"两边比"，用两次勾股（或面积法）比用余弦定理快得多。

**例7**（2024江苏）如图所示，ABCDEF 是一个边长为 2 的正六边形，圆 O 是 △ACE 的内切圆，则圆 O 的面积是（ ）。

（原题含图形，建议核对 PDF 第 23 页）

A. π

B. 2π

C. 5π/4

D. 3π/2

**解析**：

**破题**：正六边形隔点相连得到正三角形，边长放大 √3 倍；内切圆半径 = 正三角形边长 × √3/6。

- 正六边形边长 2，△ACE 边长 = `2 × √3 = 2√3`；
- 内切圆半径：`r = (√3/6) × 2√3 = 1`；
- 面积 `S = πr² = π`。

答案：**A**。

> **★重点**：正六边形 → 隔点连成的大正三角形边长为 `√3a`；等边三角形内切圆半径 `r = (√3/6)a`、外接圆半径 `R = (√3/3)a`。

### （3）坐标构造

**例8**（2025山东事业单位）某巡逻船在休渔期开展常规海上检查，在海域 m 点发现其东南方向的 n 点有一艘渔船正匀速向正北方向行驶，巡逻船在 m 点立即沿东偏南 30 度方向按照与渔船相同的速度行驶 4 海里后相遇，m 与 n 之间的距离多少海里？

A. 2√2

B. 2√3

C. 4√2

D. 4√3

**解析**：

**破题**：同速同时间 → 两船路程相等，都是 4 海里；把相遇点设为原点建坐标，用坐标算两点距离。

设相遇点为 P(0, 0)：

- 渔船向正北行驶 4 海里，故 n 在 P 的正南 4 海里：`n(0, -4)`；
- 巡逻船沿东偏南 30° 行驶 4 海里到 P，故 m 在 P 的西偏北 30° 方向 4 海里：

```
m = (-4cos30°, 4sin30°) = (-2√3, 2)
mn = √[(2√3)² + (2 + 4)²] = √(12 + 36) = √48 = 4√3
```

答案：**D**。

> **★重点**：方向角题一律**建系**：以东为 x 轴、以北为 y 轴，"东偏南 30°"就是 `(cos30°, -sin30°)`。

**例9**（2024广东）甲、乙、丙三艘船在海上航行。某一时刻，甲观测到乙位于它的北偏西 30° 方向，甲、乙相距 6 千米；甲观测到丙位于它的正西方向，甲、丙相距 6 千米，则乙与丙之间的距离为（ ）千米。

A. 3

B. 4

C. 5

D. 6

**解析**：

**破题**：两条边都是 6，先求夹角，再判三角形形状。

- 丙在甲正西，乙在北偏西 30°（即西偏北 60°），两方向夹角 = 60°；
- 甲乙 = 甲丙 = 6，夹角 60° → **等边三角形**；
- 乙丙 = 6。

答案：**D**。

> **★重点**：两边相等 + 夹角 60° 直接判等边，不用余弦定理。

### （4）三角形同底或者同高（长方形）

考法：多个面积。

方法：**底相同，面积之比等于高之比**（同理，高相同则面积之比等于底之比）。

**例10**（2025四川）一块正方形花圃如下图所示。现将其划分为 4 个矩形，分别种植 A、B、C、D 四种作物。已知 B、C 的种植面积比为 14:9，B、C 的种植面积之和比 A 的种植面积大 2/21，则 D 的种植面积是 A 的：

（原题含图形，建议核对 PDF 第 28 页）

A. 1/3

B. 2/5

C. 2/7

D. 3/11

**解析**：

**破题**：四个矩形拼成正方形 → 对角两块面积的乘积相等（`B × C = A × D`），设一份为 x 即可。

设 B = 14x、C = 9x，则 B + C = 23x。

- 由 `B + C = A × (1 + 2/21) = (23/21)A` 得 `A = 21x`；
- 正方形内对角两块满足 `A × D = B × C`：`21x × D = 14x × 9x` → `D = 6x`；
- `D/A = 6x/21x = 2/7`。

答案：**C**。

> **★重点**：矩形被两条直线分成四块时，**对角两块面积之积相等**，这是本类题的核心结论。

**例11**（2025国考）某厂区如图所示，其中 ABCD 为矩形，ABEF 为直角梯形，AB 与 DE 相交于 G 点，其中阴影区域 ADGF 为涉密区域。已知 AD、AF、AB 长度分别为 240 米、150 米、100 米，问涉密区域的面积为多少万平方米？

（原题含图形，建议核对 PDF 第 29 页；G 点位置需按图读取）

A. 1.2

B. 1.3

C. 1.4

D. 1.5

**解析**：

**破题**：阴影是不规则四边形 → **割补法**，用矩形面积减去三角形面积。

- 矩形 ABCD 面积：`AD × AB = 240 × 100 = 24000`（平方米）；
- 阴影 ADGF = 矩形 ABCD − △BCG（或按图中实际割补关系），其中 G 是 AB 与 DE 的交点，需由梯形 ABEF 的 AF = 150 米确定 G 的位置；
- 得到面积后换算：`1 万平方米 = 10000 平方米`，故结果落在 1.2~1.5 万平方米之间。

> **⚠易错**：单位是**万平方米**，算出平方米后必须除以 10000；割补时看清阴影边界是折线 ADGF 还是三角形。

（G 点坐标依赖图中梯形的摆放，OCR 图形缺失，具体数值请核对 PDF 第 29 页。）

**例12**（2025浙江）一块四边形田地 ABCD 如下图所示，已知 △AOD、△AOB 和 △COD 的面积分别为 9 平方千米、15 平方千米和 12 平方千米，CD 长 8 千米。问 B 点到 CD 的距离为多少千米？

（原题含图形，建议核对 PDF 第 30 页）

A. 6

B. 7

C. 8

D. 9

**解析**：

**破题**：四边形对角线分出的四个三角形，**同高看底**：△AOD 与 △AOB 同高（顶点都是 A），面积比就是 OD:OB。

- `S△AOD : S△AOB = OD : OB = 9 : 15 = 3 : 5`；
- △COD 与 △BOC 同高（顶点都是 C），同样有 `S△COD : S△BOC = OD : OB = 3 : 5`；
- 故 `S△BOC = 12 × 5/3 = 20`；
- `S△BCD = S△BOC + S△COD = 20 + 12 = 32`；
- 由 `S△BCD = 1/2 × CD × h`：`32 = 1/2 × 8 × h` → `h = 8`。

答案：**C**。

> **★重点**：对角线四块面积满足 `S△AOD × S△BOC = S△AOB × S△COD`，可用来快速验算。

### （5）相似三角形

- 两个角相等，三角形相似；
- 对应边成比例。

**例13**（2024全国事业单位联考）一条东西向的河流宽 50 米，如下图所示。甲划船从北岸的 A 点出发，直线航行 130 米后到达南岸的 B 点，然后向左转向 90 度继续直线行驶，到达河流北岸的 C 点。问 A、C 两点的距离在以下哪个范围内？

（原题含图形，建议核对 PDF 第 32 页）

A. 不到150米

B. 150~160米之间

C. 160~170米之间

D. 超过170米

**解析**：

**破题**：两次航行垂直 → △ABC 是直角三角形（∠ABC = 90°），AC 为斜边；先由 AB 与河宽求夹角的余弦。

- 河宽 50，AB = 130，故 AB 的水平分量 `= √(130² - 50²) = √14400 = 120`；
- 设 AB 与河岸夹角 θ，则 `cosθ = 120/130`；
- 在 Rt△ABC 中 `AC = AB / cosθ = 130 ÷ (120/130) = 16900/120 ≈ 140.8`（米）。

答案：**A**（不到 150 米）。

> **⚠易错**：AC 是**斜边**，比 AB = 130 长；别把 AC 当成 B 到 C 的水平投影（那是 99.2 米）。

## 3. 最短路径

考查方式：求 AB 两点到直线距离之和最短。

解题原理：**两点之间，线段最短**。

解题技巧：

- 两点异侧，直接连线；
- 两点同侧，**镜面对称后连线**。

**例14**（2024国考）甲、乙两个联络站相距 10 千米。一条道路与甲、乙联络站连线相平行，且与两联络站连线的垂直距离为 12 千米。现需紧邻该道路建一个工作站，问工作站距离甲、乙联络站距离之和最小为多少千米？

A. 20

B. 22

C. 24

D. 26

**解析**：

**破题**：两点在道路同侧 → 作对称点，把"两段之和"拉成一条直线。

- 甲、乙同侧且到道路等距 12，把甲对称到道路另一侧得甲′，`甲甲′ = 24`；
- 最小距离和 = 甲′乙 = `√(10² + 24²) = √676 = 26`。

答案：**D**。

> **★重点**：对称后两点连线与道路的交点就是工作站位置；"距离和最小 = 对称点连线长"。

## 4. 几何最值

### 几何最值理论（一）——立体图形（"垃圾袋/饺子皮"原理）

```
表面积一定，越接近球，体积越大
体积一定，越接近球，表面积越小
```

> **★重点**：表面积一定求最大体积 → 往"球"上靠；体积一定求最小表面积 → 也往"球"上靠。

### 几何最值理论（二）——平面图形（"耳机/剪纸"原理）

```
周长一定，越接近圆，面积越大
面积一定，越接近圆，周长越小
```

特殊矩形：

```
四边形周长一定时，正方形面积最大
四边形面积一定时，正方形周长最小
```

**例15**（2024联考）某公园绿化管理部门采购了 100 片围栏，每片长 1 米且不可弯折。现拆分拟围成 5 块周长相等且互不相邻的矩形花卉区域。若不考虑拼接间隙，那么这 5 块区域的最大与最小面积最多可相差多少平方米？

A. 10

B. 12

C. 16

D. 25

**解析**：

**破题**：5 块周长相等 → 每块用 20 片，周长 20 米；"每片 1 米不可弯折"意味着边长必须是整数米。

- 每块半周长 = 10 米，设长 a、宽 10 - a，面积 `S = a(10 - a)`；
- 面积最大：a = 5，`S = 25`；
- 面积最小：a 只能取整数，a = 1 时 `S = 1 × 9 = 9`；
- 差值 = `25 - 9 = 16`（平方米）。

答案：**C**。

> **⚠易错**：若忽略"每片 1 米不可弯折"，会认为面积可趋近 0、差值趋近 25 而错选 D；**整数边长约束**正是本题的坑。

## 5. 同比例放缩

若将一个图形尺度变为原来的 N 倍，则：

```
1. 对应角度不变
2. 周长变为原来的 N 倍，增长了 N - 1 倍
3. 面积变为原来的 N² 倍，增长了 N² - 1 倍
4. 体积变为原来的 N³ 倍，增长了 N³ - 1 倍
```

> **★重点**：**长度比 N → 面积比 N² → 体积比 N³**。题干给"高度一半""边长 1/3"时，体积比是它的立方。

**例16**（2025联考）一个空的倒置的圆锥形容器，倒入 1 瓶固定容量的水后，水的高度恰好为容器高度的一半。若要使容器盛满水，则需要再倒入水的瓶数为：

A. 5瓶

B. 7瓶

C. 8瓶

D. 10瓶

**解析**：

**破题**：倒置圆锥中水面与容器相似，高度比 1/2 → 体积比 (1/2)³。

- 水体积 : 容器容积 = `(1/2)³ = 1/8`；
- 1 瓶 = 1/8 容器，盛满还需 7/8 → **7 瓶**。

答案：**B**。

> **⚠易错**：别按面积比 1/4 算成 3 瓶；圆锥是三维图形，用立方。

**例17**（2025联考）妈妈将一个圆锥形冰淇淋（如下图所示，顶面是半径为 3 厘米的平面）将距离顶面三分之一高的位置平行切开，下面那块给小安，上面那块给小凡，那么小安吃的冰淇淋份量是小凡的多少倍？

（原题含图形，建议核对 PDF 第 41 页）

A. 8/27

B. 19/27

C. 19/8

D. 8/19

**解析**：

**破题**：平行于底面切开 → 上面是小圆锥，与原圆锥相似，体积比 = 高度比的立方。

| 部分 | 体积占整体 | 说明 |
| --- | --- | --- |
| 上面（小凡） | 8/27 | 高为整体的 2/3，`(2/3)³ = 8/27` |
| 下面（小安） | 19/27 | `1 - 8/27` |

```
小安 : 小凡 = 19/27 : 8/27 = 19 : 8
```

答案：**C**。

> **⚠易错**：题干"距离顶面三分之一高"若按字面理解，上锥高为 1/3，体积比应为 1/27，与四个选项均不匹配；按选项与图形，切面应取在**距顶面 2/3 高（距底面 1/3 高）**处。此处 OCR 与题干表述存疑，请核对 PDF 第 41 页原图。

## 6. 几何最优构造（手工操作题）

**例18**（2025江苏）某单位在边长为 200 米的正方形广场上组织一场招聘会，计划安排若干名工作人员提供咨询服务，每名工作人员入场后将分别随机站在一个位置上，其服务半径不超过 50√2 米。若要确保咨询服务全覆盖，则至少需要安排工作人员：

A. 4名

B. 5名

C. 6名

D. 7名

**解析**：

**破题**："位置随机、确保全覆盖" → 按最坏情况把广场**等分成小块**，每块的外接圆半径不超过服务半径。

- 把 200 × 200 的正方形四等分，每块 100 × 100；
- 每块外接圆半径 = 对角线一半 = `(100√2)/2 = 50√2`，恰好等于服务半径；
- 工作人员站在每块中心即可全覆盖，4 块 → **4 名**。

答案：**A**。

> **★重点**：覆盖问题的标准解法是"分割 + 外接圆"；判断标准是「小区域外接圆半径 ≤ 服务半径」，而不是面积相除。

**例19**（2025四川）某工匠计划在 700 × 115 厘米的钢板上裁剪若干大小为 70 × 40 厘米的钢片，且在裁剪时，每块钢片之间还应保留至少 5 厘米的间隔。问最多能裁剪出多少块？

A. 23

B. 24

C. 25

D. 26

**解析**：

**破题**：先看 115 厘米这个"窄边"能排几行：`70 + 5 + 40 = 115`，正好一行横放、一行竖放。

**方案**：把 115 分成 40 + 5 + 70 两行。

- 40 厘米高的那一行：钢片按 70 × 40 摆，横向 `n × 70 + (n-1) × 5 ≤ 700` → `75n ≤ 705` → n = 9（占宽 670）；
- 70 厘米高的那一行：钢片旋转成 40 × 70，横向 `n × 40 + (n-1) × 5 ≤ 700` → `45n ≤ 705` → n = 15（占宽 670）；
- 合计 `9 + 15 = 24` 块。

**为什么到不了 25**：任一竖直方向的组合只有两种可能——`40 + 5 + 40 = 85` 或 `70 + 5 + 40 = 115`，即最多两行；含 70 高钢片的那一行只能放 40 宽的块（15 块），40 高的那一行只能放 70 宽的块（9 块），两行上限相加即 24。

答案：**B**。

> **★重点**：切割排布题先算"一行能放几个、能放几行"，再看两个方向**混合摆**能否刚好填满窄边（本题 `70 + 5 + 40 = 115` 是关键巧合）。

## 梳理

### 几何公式

周长、面积、表面积、体积四类，公式必须背熟：

| 类别 | 核心公式 |
| --- | --- |
| 周长 | `C正方形 = 4a`、`C长方形 = 2(a+b)`、`C圆 = 2πr`、`弧长 = n°/360° · 2πr` |
| 面积 | `a²`、`ab`、`对角线积÷2`、`ah`、`1/2ah`、`1/2(a+b)h`、`πr²`、`n°/360°·πr²` |
| 表面积 | `6a²`、`2ab+2bc+2ac`、`4πr²`、`2πr²+2πrh` |
| 体积 | `a³`、`abc`、`Sh`、`1/3Sh`、`4/3πr³` |

### 三角形

- **普通三角形**：两边之和大于第三边，两边之差小于第三边；
- **直角三角形**：
  - 特殊勾股数 `(3,4,5)`、`(6,8,10)`、`(5,12,13)`、`(7,24,25)`；
  - 边长的放缩；出现平方加和条件，直接想 `a² + b² = c²`；
  - 30°-60°-90°：短直角边是斜边的一半，长直角边是短直角边的 √3 倍；
  - 45°-45°-90°：两直角边相等，斜边是直角边的 √2 倍；
- **等边三角形**：边长 a，高 `(√3/2)a`，面积 `(√3/4)a²`；
- **正六边形**：由 6 个等边三角形构成；
- **圆中的直角**：不在同一直线的三个点确定一个圆；直径所对的角是 90°；圆上最远的两个点构成直径；
- **同底或同高**：考法是多个面积，底相同则面积之比等于高之比；
- **相似三角形**：对应边成比例。

### 最短路径

求 AB 两点到直线距离之和最短 → **镜面对称后连线**（异侧直接连）。

### 几何最值

| 条件 | 结论 | 记忆名 |
| --- | --- | --- |
| 表面积一定 | 越接近球，体积越大 | 垃圾袋原理 |
| 体积一定 | 越接近球，表面积越小 | 饺子皮原理 |
| 周长一定 | 越接近圆，面积越大 | 耳机原理 |
| 面积一定 | 越接近圆，周长越小 | 剪纸原理 |

### 同比例放缩

```
周长：N 倍（增长 N - 1 倍）
面积：N² 倍（增长 N² - 1 倍）
体积：N³ 倍（增长 N³ - 1 倍）
```

### 几何最优构造（手工操作题）

分割覆盖、切割排布，先算单行/单列，再看能否混合摆满。

## 专项拔高练习五

**练习1**（2025联考）某农科所将一块上底长为 20 米的直角梯形状实验田划分为 4 个完全相同的区域（如下图所示），种上 4 个不同品种的玉米，产量分别为 110、115、125 和 130 千克。那么，该实验田玉米的平均产量为多少千克/平方米？

（原题含图形，建议核对 PDF 第 47 页；梯形下底与高需按图读取）

A. 0.6

B. 0.8

C. 1

D. 1.25

**解析**：

**破题**：求"平均产量/平方米"= 总产量 ÷ 总面积；总产量可直接加，总面积要靠图形。

- 总产量 = `110 + 115 + 125 + 130 = 480`（千克）；
- 4 个区域完全相同，说明梯形被等分，面积需按图中下底与高计算：`S = 1/2 × (上底 + 下底) × 高`；
- 若按图读得下底 40 米、高 20 米，则 `S = 1/2 × (20 + 40) × 20 = 600`，平均 = `480 ÷ 600 = 0.8`。

> **⚠易错**：选项给的是"千克/平方米"，不是总产量；除法方向别反。

（图中尺寸 OCR 不可见，下底与高请核对 PDF 第 47 页，答案按 600 平方米对应 B。）

**练习2**（2025联考）某黄金首饰店的回收活动规则为：按当日金价的 75% 回收，回收后若置换店里的黄金首饰则不收取任何额外费用，若要将一个底面直径和高均为 6cm 的圆锥形实心黄金首饰回收，并置换为球形实心黄金首饰，将该圆锥形首饰分割成体积相等的两个部分，其截面半径与该球形首饰的直径相等（如下图所示）。那么圆锥形首饰可置换该款球形首饰的数量为：

（原题含图形，建议核对 PDF 第 48 页）

A. 4个

B. 6个

C. 8个

D. 9个

**解析**：

**破题**：截面把圆锥**体积二等分** → 上锥体积为一半，用 `(1/2)^(1/3)` 求半径，再算球体积比。

- 圆锥 r = 3、h = 6：`V锥 = 1/3 × π × 9 × 6 = 18π`；
- 上半部分体积为 9π，与整个圆锥相似，体积比 1/2 → 半径比 `(1/2)^(1/3) ≈ 0.7937`，截面半径 `≈ 3 × 0.7937 ≈ 2.38`；
- 截面半径 = 球的直径 → 球半径 `≈ 1.19`；
- `V球 = 4/3 × π × 1.19³ ≈ 2.25π`；
- 数量 = `18π ÷ 2.25π = 8`。

> **★重点**：体积二等分 ≠ 高度二等分，半径比是 `(1/2)^(1/3)`；本题用"8 个球"反推也可（选项 8 与体积比 8:1 吻合）。

**练习4**（2025全国事业单位）有长为 150mm，直径分别为 90mm 和 120mm 的两根铜柱，以此为原料最多可以熔铸直径为 100mm 的铜球多少个？（球体积 = 4/3 πr³）（ ）

**练习5**（2024联考）A、D 两地设有通信基站（如下图所示），发射信号范围分别是以 A、D 为圆心，AE 和 DB 为半径的圆形区域，小林从 B 地出发，沿与 DB 垂直的 BA 方向匀速行进，步行速度为 4 千米/小时，那么步行约多少分钟后小林的手机能够重新接收到信号？（√5 ≈ 2.23）

**练习6**（2024天津事业单位）平面做一个边长为 3 的正方形，再以这个正方形的对角线为边做第二个正方形，再以第二个正方形的对角线为边做第三个正方形，以此类推，第 11 个正方形的面积为（ ）。

A. 2048

B. 3072

C. 8192

D. 9216

**解析**：

**破题**：每步以对角线为边长 → 边长乘 √2，面积乘 2，是等比数列。

- 第 1 个面积 `S₁ = 3² = 9`；
- 每次面积 ×2：`Sₙ = 9 × 2^(n-1)`；
- `S₁₁ = 9 × 2^10 = 9 × 1024 = 9216`。

答案：**D**。

> **★重点**：`45°、45°、90°` 等腰直角三角形斜边是直角边的 √2 倍，所以"以对角线为边"面积翻倍。

**练习7**（2022联考）兔子和乌龟举行一场跑步比赛，终点位于起点正北方 500 米处。兔子和乌龟同时出发，均保持匀速奔跑，且兔子的速度是乌龟的 5 倍。兔子先向正东方跑了一会后发现自己跑错了方向，马上直奔终点，速度不变，结果兔子和乌龟同时到达终点。那么兔子发现跑错方向时已经跑了多少米？

A. 600

B. 1200

C. 2400

D. 3000

**解析**：

**破题**：同时到达 → 兔子总路程是乌龟的 5 倍；"先正东再直奔终点"构成直角三角形。

设兔子向东跑了 x 米，龟速 v、兔速 5v，龟全程 500 米：

```
乌龟用时 = 500/v
兔子路程 = x + √(x² + 500²)
兔子用时 = [x + √(x² + 500²)]/(5v)
```

同时到达：

```
x + √(x² + 500²) = 2500
√(x² + 250000) = 2500 - x
x² + 250000 = 6250000 - 5000x + x²
5000x = 6000000  →  x = 1200
```

答案：**B**。

> **★重点**：折线路径题先画直角三角形，把"斜边 + 直角边"整体当一个方程解，平方时注意保留 `x²` 相消。

**练习8**（2020国考）部队前哨站的雷达监测范围为 100 千米。某日前哨站侦测到正东偏北 30° 100 千米处，一架可疑无人机正匀速向正西方向飞行。前哨站通知正南方向 150 千米处的部队立即向正北方向发射无人机拦截，匀速飞行一段时间后，正好在某点与可疑无人机相遇。问我方无人机速度是可疑无人机的多少倍？

A. (2/3)√5

B. (4/3)√3

C. √3 + 1

D. 3(√3 - 1)

**解析**：

**破题**：两条航线互相垂直（正西 vs 正北）→ 建系，先定相遇点坐标，再比路程（同时间 → 速度比 = 路程比）。

以雷达站为原点，东为 x 轴、北为 y 轴：

- 可疑机初始位置：`(100cos30°, 100sin30°) = (50√3, 50)`，向正西飞；
- 我方从 `(0, -150)` 向正北飞，始终在 x = 0 上；
- 相遇点必在 y 轴上：可疑机从 `x = 50√3` 飞到 `x = 0`，路程 `50√3`；我方从 `y = -150` 升到 `y = 50`，路程 `200`；
- 速度比 = `200 ÷ 50√3 = 4/√3 = (4/3)√3`。

答案：**B**。

> **⚠易错**：相遇点 y 坐标是可疑机的 50，我方总路程是 `150 + 50 = 200`，只算 150 会得到 3/√3 = √3（无此选项）。

**练习9**（2025天津）某矩形农场 ABCD 如图所示，矩形区域 ADEF 为生产区，矩形区域 BCEF 为休闲区。现连接 BD 将两区域打通，与 EF 相交于 O 点。已知 AF 和 FE 的长度分别为 600 米和 400 米，问 COD 围成的三角形阴影区域面积为多少万平方米？

（原题含图形，建议核对 PDF 第 55 页）

A. 12

B. 15

C. 16

D. 18

**解析**：

**破题**：矩形被一条水平线分成两块，对角线 BD 与 EF 交于 O → 用相似三角形定位 O，再算 △COD。

- AF = 600 是上半块的竖直高度，FE = 400 是矩形总宽；
- BD 与 EF 的交点 O 到 D 的竖直距离为 600（与 AF 相等，由相似 `△BOF ∽ △BDC` 得出 O 恰在 EF 上且 `OD` 竖直高 600）；
- △COD 以 CD（= 400）为底，高即 O 到 CD 的水平距离，面积为 `1/2 × 400 × 600 = 120000` 平方米 = **12 万平方米**。

答案：**A**。

> **⚠易错**：单位换算 `1 万平方米 = 10000 平方米`；阴影是三角形不是梯形，别再乘 1/2 之外的系数。

**练习10**（2023联考）为推动产业园和产业集聚区加快转型，某地计划在三角形 ABC 区域内建设新能源产业园区（如下图所示），三角形 DEF 是中央工厂区，已知 BD : DE : EC = 1 : 2 : 3，F 为 AE 的中点，则新能源产业园区总面积是中央工厂区面积的：

（原题含图形，建议核对 PDF 第 56 页）

A. 7倍

B. 6倍

C. 5倍

D. 4倍

**解析**：

**破题**：B、D、E、C 共线 → 以 A 为顶点，**同高看底**，面积比等于底边比。

- `BD : DE : EC = 1 : 2 : 3`，BC 共 6 份；
- `S△ADE = (2/6)S△ABC = 1/3 S`；
- F 为 AE 中点，△DEF 与 △ADE 同底 DE、高也相同（顶点都在 AE 上，F 是 AE 中点 → 高为 A 到 DE 的一半）：

```
S△DEF = 1/2 × S△ADE = 1/6 S
S△ABC : S△DEF = 6 : 1
```

答案：**B**。

> **★重点**：共线分点面积的"底边比"直接用；顶点在中点会把面积再减半。

**练习11**（2025江苏）借景是古典园林建筑常用的构景手段之一，已知某景区中轴线（在同一水平面）上有两座相距 200 米的建筑物，其中一座建筑物为平顶，高度为 23.7 米；另一座建筑物为顶尖，高度为 133.7 米，其中顶尖的部分高度为 22 米。若身高为 1.7 米的小王从中轴线上某处看向平顶建筑物时，发现恰好能够看到尖顶建筑物的整个尖顶部分（如图所示）。则小王所站位置和平顶建筑物的直线距离为（ ）。

（原题含图形，建议核对 PDF 第 57 页）

A. 30米

B. 40米

C. 50米

D. 60米

**解析**：

**破题**：视线"刚好看到整个尖顶"→ 视线过平顶顶端，且落在尖顶部分的**底端**，两次相似三角形。

- 尖顶部分底端高度：`133.7 - 22 = 111.7` 米；
- 设小王到平顶建筑距离 x，两楼相距 200；
- 视线从 1.7 米高出发，过平顶顶端（23.7 米），到达尖顶部分底端（111.7 米）：

```
(23.7 - 1.7)/x = (111.7 - 1.7)/(x + 200)
22/x = 110/(x + 200)
22x + 4400 = 110x  →  88x = 4400  →  x = 50
```

答案：**C**。

> **★重点**：视线高度要**先减去身高 1.7**；"看到整个尖顶"是指视线擦过尖顶底端。

**练习12**（2019四川下）如图，沙漏计时器由上下两个大小相同、相互连通且底面互相平行的圆锥组成，下面的圆锥内装有细沙，计时开始时，将沙漏倒置，已知上面圆锥中细沙全部流下恰好需要 1 小时，则细沙高度下降一半所需的时间是：

（原题含图形，建议核对 PDF 第 58 页）

A. 30分钟

B. 45分钟

C. 47.5分钟

D. 52.5分钟

**解析**：

**破题**：沙漏中"剩余的沙"始终是一个与整锥相似的小圆锥，高度一半 → 剩余体积 1/8。

- 高度降为一半时，剩余沙体积 `= (1/2)³ = 1/8`；
- 已流下 `7/8`，按流量均匀：`7/8 × 60 = 52.5` 分钟。

答案：**D**。

> **⚠易错**：问"高度下降一半"耗掉的是 7/8 而不是 1/2；这与"流完一半体积"是两个不同的量。

**练习13**（2023联考）某餐馆承诺 25 分钟内上齐一桌菜，若超时则未上的菜品免单。每张餐桌上都有一个装满后正好 25 分钟漏完的圆锥形沙漏（如下图所示）。某位顾客在等待的过程中发现沙漏内上方沙子的高度为原先的一半，此时还差一道菜未上，则再过多久还未上菜，这位顾客将享受免单服务？

（原题含图形，建议核对 PDF 第 59 页）

A. 不到3分钟

B. 3-4分钟之间

C. 4-5分钟之间

D. 超过6分钟

**解析**：

**破题**：与练习12 同构——上方沙子高度减半 → 剩余 1/8，已漏 7/8。

- 已用时间 `25 × 7/8 = 21.875` 分钟；
- 剩余 `25 - 21.875 = 3.125` 分钟，落在 3~4 分钟之间。

> **★重点**：`25 × 1/8 = 3.125` 也可直接算"剩余时间"，比先算已用更快。

**练习14**（2024联考）气象学中，24 小时内降落在某面积上的雨水深度叫做日降雨量（不考虑渗漏、蒸发、流失等损耗，单位：mm），将日降雨量记为 w，其等级划分如下：小雨（0.1 ≤ w < 10），中雨（10 ≤ w < 25），大雨（25 ≤ w < 50），暴雨（50 ≤ w < 100）。某地某日用一个圆锥形容器接了 24 小时的雨水（如下图所示），则该地日降雨量等级是：

（原题含图形，建议核对 PDF 第 60 页；图中标注 300mm、400mm、200mm）

A. 暴雨

B. 大雨

C. 中雨

D. 小雨

**解析**：

**破题**：日降雨量 = 接到的水体积 ÷ 容器口面积；容器内水面是相似圆锥，先算体积比。

- 容器口直径 300mm → 口面积 `π × 150²`，容器总高 400mm，水深 200mm；
- 水体积 : 容器容积 = `(200/400)³ = 1/8`；
- 水体积 `= 1/8 × 1/3 × π × 150² × 400`；
- 降雨量 `= 水体积 ÷ (π × 150²) = 1/8 × 1/3 × 400 ≈ 16.7`（mm）；
- `10 ≤ 16.7 < 25` → **中雨**。

答案：**C**。

> **★重点**：降雨量是"体积 ÷ 口面积"，本质是**把水铺平的高度**；`1/3` 与 `1/8` 相乘时别漏掉锥体的 1/3。
