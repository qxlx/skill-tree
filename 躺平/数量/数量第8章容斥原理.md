## 1. 两集合

### （1）两集合公式

```
A + B - A∩B = 总 - 都不
```

> **★重点**：公式的本质是"加两次、减一次重复"；`总` 是全集，`都不` 是两个集合都不满足的人数。

### （2）两集合公式变形

识别：**都比都不**（都 - 都不）。

```
A + B - 总 = A∩B - 都不
```

> **★重点**：题干给"两个都……比两个都不……多/少几人"时，用变形公式，一步出结果，不必求全集。

**例1**（2022广东）某单位计划从全部 80 名员工中挑选专项工作组成员，要求该组成员须同时有基层经历和计算机等级证书。已知，单位内有 40 人有基层经历，有 46 人有计算机等级证书，既没有基层经历又未获得计算机等级证书的有 10 人。那么能够进入工作组的员工有（ ）人。

A. 16

B. 40

C. 46

D. 54

**解析**：

**破题**：求"两者都有"= 标准两集合，直接套 `A + B - A∩B = 总 - 都不`。

```
40 + 46 - A∩B = 80 - 10
86 - A∩B = 70
A∩B = 16
```

答案：**A**。

> **⚠易错**：`总 - 都不` 才是"至少满足一个"的人数（70），别拿 80 直接减。

**例2**（2023浙江）某班级对 70 多名学生进行数学和英语科目摸底测验，有 12% 的学生两个科目均不及格。已知有 2/3 的学生英语及格，数学及格的学生比英语多 10 人，那两科均及格的学生有多少人？

A. 31

B. 37

C. 41

D. 44

**解析**：

**破题**：百分数 + 分数 → 先由整除性锁定总人数（12% 与 2/3 都要是整数人）。

- 总人数是 25 的倍数（12% 为整数）且是 3 的倍数（2/3 为整数），又是"70 多" → **N = 75**；
- 英语及格 `75 × 2/3 = 50`，数学及格 `50 + 10 = 60`；
- 都不及格 `75 × 12% = 9`，至少一科及格 `75 - 9 = 66`；
- 两科都及格：`50 + 60 - 66 = 44`。

答案：**D**。

> **★重点**：题目给百分数/分数却问具体人数时，第一步永远是用**整除性**定总数，这是隐藏条件。

**例3**（2025国考）某研发小组员工中，60% 的人参与了 A 项目，45% 的人参与了 B 项目，两个项目都参与的人比两个项目都不参与的多 2 人。问该研发小组有多少人？

A. 100

B. 50

C. 40

D. 20

**解析**：

**破题**：出现"都比都不多 2 人"→ 直接用变形公式 `A + B - 总 = A∩B - 都不`。

设总人数 N，两个都参与 x，都不参与 y，则 `x - y = 2`：

```
0.6N + 0.45N - N = x - y
0.05N = 2
N = 40
```

答案：**C**。

> **★重点**：变形公式把"总人数"和"差值"直接连起来，左边只与比例有关，右边就是题干给的差。

## 2. 三集合

### （1）三集合标准型

**题型识别**：出现 `A∩B`、`A∩C`、`B∩C`（分别给出两两交集）。

```
A + B + C - A∩B - A∩C - B∩C + A∩B∩C = 总 - 都不
```

> **★重点**：三个都满足的部分被加了 3 次、减了 3 次，所以要**加回 1 次**——最后是 `+ A∩B∩C`，符号千万别写成减。

**例4**（2020新疆）某单位共有 240 名员工，其中订阅 A 期刊的有 125 人，订阅 B 期刊的有 126 人，订阅 C 期刊的有 135 人，订阅 A、B 期刊的有 57 人，订阅 A、C 期刊的有 73 人，订阅 3 种期刊的有 31 人，此外，还有 17 人没有订阅这三种期刊中的任何一种。问订阅 B、C 期刊的有多少人？

A. 57

B. 64

C. 69

D. 78

**解析**：

**破题**：给了两两交集和三者交集 → 标准型，把未知的 `B∩C` 当未知数代入。

```
125 + 126 + 135 - 57 - 73 - B∩C + 31 = 240 - 17
386 - 57 - 73 + 31 - B∩C = 223
287 - B∩C = 223
B∩C = 64
```

答案：**B**。

> **⚠易错**：`总 - 都不 = 240 - 17 = 223`，别用 240；三个单项相加时漏项会整体偏移。

### （2）三集合非标准型

**前提：出现"满足两个条件"**（注：满足两个条件 = **只**满足两个条件）。

```
A + B + C - 满足两项 - 满足三项 × 2 = 总 - 都不
```

> **★重点**：非标准型里"满足两项"是**恰好两项**，所以要按 2 倍去减三项；标准型的 `A∩B` 是"至少两项"，两者不能混。

**三集合标准型和非标准型的区分**：

| 类型 | 判定标志 | 公式 |
| --- | --- | --- |
| ①标准型 | 分别给出两两集合的交集（既 A 又 B、既 A 又 C、既 B 又 C） | `A+B+C-A∩B-A∩C-B∩C+A∩B∩C = 总-都不` |
| ②非标准型 | 给出"只满足两种"（满足两种） | `A+B+C-满足两项-满足三项×2 = 总-都不` |

> **★重点**：看到"既 A 又 B"就是**至少两项**（标准型）；看到"只参加两科"就是**恰好两项**（非标准型）。一个"只"字决定公式。

**例5**（2019河北）某班参加学科竞赛人数 40 人，其中参加数学竞赛的有 22 人，参加物理竞赛的有 27 人，参加化学竞赛的有 25 人，只参加两科竞赛的有 24 人，参加三科竞赛的有多少人？

A. 2

B. 3

C. 5

D. 7

**解析**：

**破题**："只参加两科"= 恰好两项 → 非标准型公式。

设三科都参加 y 人：

```
22 + 27 + 25 - 24 - 2y = 40
74 - 24 - 2y = 40
2y = 10  →  y = 5
```

答案：**C**。

> **⚠易错**：`满足三项 × 2` 的 2 不能漏，否则会算成 y = 10。

### （3）三集合非标准型变形

**特征**：至少满足两个条件 = 满足两个条件 + 满足三个条件。

```
A + B + C - 满足两项 - 满足三项 × 2 = 总 - 都不
A + B + C - 满足两项 - 满足三项 - 满足三项 = 总 - 都不
A + B + C - (满足两项 + 满足三项) - 满足三项 = 总 - 都不
A + B + C - (至少满足两项) - 满足三项 = 总 - 都不
```

> **★重点**：题干给的是"至少参观两种"时，括号里整体替换成"至少两项"，再减一次"三项"，等价于原来的 2 倍。

**例6**（2022北京）单位组织职工前往甲、乙、丙三个爱国主义教育基地学习，要求每名职工至少去 1 个基地。已知有 48 人去了甲基地，有 42 人未去乙基地，去丙基地的人中，去 1 个、2 个、3 个基地的人数比为 3:2:1。如仅去 2 个基地和去 3 个基地的职工分别有 x 人和 y 人，则 x 和 y 的关系为：

A. x = 4y + 6

B. x = 4y - 6

C. x = 3y + 6

D. x = 3y - 6

**解析**：

**破题**：去丙的人按"去几个基地"分三档，比例 3:2:1 → 设三档为 3y、2y、y；再用"甲 48、未去乙 42"两式作差。

记各区域：仅甲 a、仅乙 b、仅丙 c、仅甲乙 d、仅甲丙 e、仅乙丙 f、三个都去 g。

- 去丙的人中：只去丙 c = 3y，去丙且另一个 e + f = 2y，三个都去 g = y；
- 未去乙的 42 人 = 只去甲 a + 只去丙 c + （甲丙）e + （乙丙）f，即 `a + 3y + 2y = 42`；
- 去甲的 48 人 = `a + d + e + y = 48`。

两式作差：

```
48 - 42 = d + e - 4y
d + e = 6 + 4y
```

而 `x = d + e + f`，其中去丙的两档满足 `e + f = 2y`；按图中"去两个基地"只发生在甲、丙之间（`f = 0`）整理：

```
x = d + e = 6 + 4y
```

答案：**A**。

> **⚠易错**：这类题不要硬背结论，标准做法是**画图设 7 个区域**，再用"去甲 48、未去乙 42"造两个等式作差。各区域的归属需按图确认，建议核对 PDF 第 20 页。

**例7**（2025江苏）某单位组织 45 名员工参观第十五届中国国际航空航天博览会。其中，21 人参观了新一代隐身战斗机歼-35A，22 人参观了嫦娥六号取回的月背月壤样品，19 人参观了大型无人机战舰"虎鲸"。所有员工中，这三种展览都未参观的有 5 人，至少参观两种的有 12 人，则这三种展览都参观的有（ ）。

A. 7人

B. 8人

C. 9人

D. 10人

**解析**：

**破题**："至少参观两种"是非标准型变形中的括号整体，直接套 `A+B+C-(至少两项)-三项 = 总-都不`。

```
21 + 22 + 19 - 12 - y = 45 - 5
62 - 12 - y = 40
y = 10
```

答案：**D**。

> **★重点**：公式可以记成"三个单项和 − 至少两项 − 三项 = 总 − 都不"，比记两个版本更省心。

## 3. 画图法

**容斥原理的方法选择**：

1. **公式法**：题目中所给所求都是公式中的一部分（清晰明了，快准狠）；
2. **画图法**：题目中所给所求公式里没有，或者公式法不好用（往往出现"只满足一个条件"）。特征：只参加 A；参加 A 但不参加 B；或者缺少代公式必要的数据。

**画图法三步走**：

1. 第一步，画圈圈；
2. 第二步，标数字（**从里到外，注意去重**）；
3. 第三步，列算式。

> **★重点**："只参加 A"这类表述公式里没有对应项，必须画图；标数一定从最里层（三者交集）开始往外填。

**例8**（2024江苏）某基层工会共有 180 名会员，举行甲、乙两项工会活动，60% 的会员参加甲活动，50% 的会员参加乙活动，若只参加甲活动的会员有 80 人，则只参加乙活动的会员有（ ）

A. 10人

B. 28人

C. 62人

D. 90人

**解析**：

**破题**：出现"只参加甲"，用画图法：先求交集，再用"参加乙 - 交集"。

```
参加甲 = 180 × 60% = 108
参加乙 = 180 × 50% = 90
两者都参加 = 108 - 80 = 28
只参加乙 = 90 - 28 = 62
```

答案：**C**。

> **★重点**：`只参加甲 = 参加甲 - 两者都参加`，是画图法最常用的一步换算。

**例9**（2025国考）某单位 65 名职工中，拥有甲、乙、丙三项认证中至少一项的职工正好占 80%，没有甲认证的职工与有乙认证的职工人数一样多，仅有丙认证的职工有 3 人，三项认证都有的职工有 6 人，问有多少人仅拥有甲、乙两项认证？

A. 10

B. 13

C. 16

D. 19

**解析**：

**破题**：条件散、公式套不上 → 画图设 7 个区域，用"没有甲 = 有乙"和"至少一项 52 人"两式相减。

设：仅甲 a、仅乙 b、仅丙 3、仅甲乙 d、仅甲丙 e、仅乙丙 f、三项 g = 6。

```
至少一项：a + b + 3 + d + e + f + 6 = 65 × 80% = 52
        → a + b + d + e + f = 43        …①
没有甲的人数 = 65 - (a + d + e + 6) = 有乙的人数 (b + d + f + 6)
        → a + b + 2d + e + f = 53        …②
```

② − ①：

```
d = 10
```

答案：**A**。

> **★重点**："没有甲 = 有乙"翻译成区域表达式后，与"至少一项"作差，恰好把 6 个未知量消到只剩 d。

## 4. 容斥原理结合不定方程（最值）

问法：求最值。

方法：**此消彼长**。

> **★重点**：总量固定时，一部分变多，另一部分必然变少；求"某部分最少"就把其余部分推到最大。

**例10**（2023广东）某单位共有员工 200 人，其中订阅杂志的人数比只订阅报纸的人数多 88%。则报纸和杂志均未订阅的员工有（ ）人。

A. 36

B. 56

C. 76

D. 96

**解析**：

**破题**：只报纸 = x，杂志 = 1.88x；未知量要靠"人数为整数"来定，再用总数扣减。

```
设只订阅报纸 x 人，订阅杂志 1.88x 人
总人数 = 只报纸 + 只杂志 + 两者都订 + 都不订
       = x + (1.88x - 两者都订) + 两者都订 + 都不订
       = 2.88x + 都不订 = 200
```

`2.88x` 必须是整数且 ≤ 200，x 取 50（`1.88 × 50 = 94` 为整数）：

```
都不订 = 200 - 144 = 56
```

答案：**B**。

> **★重点**：`2.88 = 72/25`，所以 x 必须是 25 的倍数，这是"此消彼长"之外的第二个约束（整数性）。

**例11**（2021四川）为实现产业振兴，农科院对某县的所有自然村进行了调研，结果发现，适合种植 A 作物的自然村占 4/13。适合种植 B 作物的自然村有 25 个，同时适合种植两种作物的自然村占总数的 1/14，则在该县，不适合种植两种作物的自然村至少有多少个？

A. 57

B. 67

C. 114

D. 134

**解析**：

**破题**：两个分数 → 总数是 13 与 14 的公倍数；"不适合种植两种作物"= 两种都不能种（`总 - A∪B`）。

总数 N 是 182 的倍数，取最小 N = 182：

```
A = 182 × 4/13 = 56
B = 25
A∩B = 182 × 1/14 = 13
A∪B = 56 + 25 - 13 = 68
两种都不适合 = 182 - 68 = 114
```

答案：**C**。

> **⚠易错**："不适合种植两种作物"容易误读成"不能同时种两种"（= 182-13 = 169，无此选项）；本题按"两种作物都不适合"理解。

## 5. 容斥原理和周期结合

**题型特点**：编号 1~1000，选编号为 3 的倍数参加开幕式、7 的倍数参加闭幕式。

**方法**：

1. 求 `A`、`B`、`A∩B`（倍数个数用除法取整）；
2. 套容斥原理公式。

> **★重点**：n 以内 a 的倍数有 `⌊n/a⌋` 个；`A∩B` 的个数 = 最小公倍数的倍数个数。

**例12**（2018山东选调）某高校举办春季运动会，共有 1000 名学生报名参加竞赛项目。为从运动员中选拔人员参加开幕式和闭幕式队列，现把所有运动员从 1 到 1000 进行编号，选出编号为 3 的倍数的运动员参加开幕式队列，而编号为 7 的倍数的运动员参加闭幕式队列。问：既不参加开幕式队列也不参加闭幕式队列的运动员有多少人？

A. 428

B. 475

C. 525

D. 572

**解析**：

**破题**：倍数问题 → 先算三个量，再套两集合公式。

```
3 的倍数：⌊1000/3⌋ = 333
7 的倍数：⌊1000/7⌋ = 142
21 的倍数：⌊1000/21⌋ = 47
至少参加一个 = 333 + 142 - 47 = 428
都不参加 = 1000 - 428 = 572
```

答案：**D**。

> **⚠易错**：题目问"都不参加"，要先算并集 428 再减；直接选 428 就掉坑。

**例13**（2019江苏）某公司年终联欢，准备了 52 张编号分别为 1 至 52 的奖券用于抽奖。如果编号是 2、3 的倍数的奖券可分别兑换 2 份、3 份奖品，编号同时是 2 和 3 的倍数的奖券只可兑换 3 份奖品，其他编号的奖券只可兑换 1 份奖品，则所有奖券可兑换的奖品总数是：

A. 99份

B. 100份

C. 102份

D. 104份

**解析**：

**破题**：不是简单容斥，而是**按类别分别计数**——关键是 6 的倍数"只换 3 份"，不能叠加。

```
2 的倍数（不含 6 的倍数）：⌊52/2⌋ - ⌊52/6⌋ = 26 - 8 = 18 张 → 18 × 2 = 36
3 的倍数（不含 6 的倍数）：⌊52/3⌋ - 8 = 17 - 8 = 9 张  → 9 × 3 = 27
6 的倍数：8 张 → 8 × 3 = 24
其余：52 - 18 - 9 - 8 = 17 张 → 17 × 1 = 17
合计：36 + 27 + 24 + 17 = 104
```

答案：**D**。

> **★重点**：先剔除交集再分类，比"2 倍 + 3 倍 - 交集"更不容易错；"只可兑换 3 份"意味着**取大不叠加**。

## 梳理

### 两集合

- 公式：`A + B - A∩B = 总 - 都不`；
- 变形：`A + B - 总 = A∩B - 都不`（识别："都比都不"）。

### 三集合

| 类型 | 识别 | 公式 |
| --- | --- | --- |
| 标准型 | 出现 `A∩B`、`A∩C`、`B∩C` | `A+B+C-A∩B-A∩C-B∩C+A∩B∩C = 总-都不` |
| 非标准型 | 出现"满足两个条件" | `A+B+C-满足两项-满足三项×2 = 总-都不` |
| 非标准型变形 | "至少参观两种" | 至少两项 = 满足两项 + 满足三项，代入后减两次三项 |

### 画图法

- 识别：只参加 A；参加 A 但不参加 B；缺少代公式必要的数据；
- 方法：第一步画圈圈 → 第二步标数字（从里到外，注意去重）→ 第三步列算式。

### 容斥原理最值

- 结合不定方程，方法：**此消彼长**；
- 常配合整数性、倍数性锁定未知量。

### 编号/倍数类

- 数字的容斥原理：编号 1~100，3 的倍数、5 的倍数……先求各倍数个数，再套公式。

## 专项拔高练习八

**练习1**（2022联考）某社区积极为某受灾地区捐款捐物，其中 30% 的人员捐赠了物品，70% 的人员捐了款，总计有 80% 的人员进行了捐赠。问该社区既捐赠物品又捐款的人员占该社区人员的比例为：

A. 15%

B. 20%

C. 21%

D. 25%

**解析**：

**破题**："总计 80% 进行了捐赠"就是并集，直接套两集合公式。

```
30% + 70% - 两者都捐 = 80%
两者都捐 = 20%
```

答案：**B**。

**练习2**（2022联考）某班期末考试结束后统计，物理、化学均不及格的人数占全班的 14%，物理及格的人数比化学及格的人数多 10 人，且化学及格的人数占全班的 60%。已知全班人数不超过 70 人，问物理及格的人中化学也及格的有多少人？

A. 25

B. 26

C. 27

D. 28

**解析**：

**破题**：14% 和 60% 都要是整数人 → 总人数必须是 50 的倍数，且 ≤70 → N = 50。

```
化学及格 = 50 × 60% = 30
物理及格 = 30 + 10 = 40
均不及格 = 50 × 14% = 7  →  至少一科及格 = 43
两科都及格 = 30 + 40 - 43 = 27
```

答案：**C**。

> **★重点**：`14% = 7/50`、`60% = 3/5`，公分母 50，配合"不超过 70"直接锁定 50 人。

**练习3**（2019江苏）市电视台向 150 位观众调查前一天晚上甲、乙两个频道的收视情况，其中 108 人看过甲频道，36 人看过乙频道，23 人既看过甲频道又看过乙频道，则受调查观众中在前一天晚上两个频道均未看过的人数是：

A. 17

B. 22

C. 29

D. 38

**解析**：

**破题**：求"都不"，公式移项即可。

```
至少看一个 = 108 + 36 - 23 = 121
都没看 = 150 - 121 = 29
```

答案：**C**。

**练习4**（2020山东选调）某一个专业共有 100 名学生，在第一次考试中有 52 人得 90 分以上（含 90 分），在第二次考试中有 42 人得 90 分以上（含 90 分）。已知这两次考试都没得 90 分以上（含 90 分）的有 34 人，那么这两次考试都得 90 分以上（含 90 分）的有多少人？（ ）

A. 14

B. 28

C. 8

D. 4

**解析**：

**破题**：标准两集合，求交集。

```
至少一次 90 分以上 = 100 - 34 = 66
两次都 90 分以上 = 52 + 42 - 66 = 28
```

答案：**B**。

**练习5**（2018联考）联欢会上，有 24 人吃冰激凌、30 人吃蛋糕、38 人吃水果，其中既吃冰激凌又吃蛋糕的有 12 人，既吃冰激凌又吃水果的有 16 人，既吃蛋糕又吃水果的有 18 人，三样都吃的则有 6 人。假设所有人都吃了东西，那么只吃一样东西的人数是多少？

A. 12

B. 18

C. 24

D. 32

**解析**：

**破题**：三集合标准型先求总人数，再用"只一样 = 总数 - 恰好两样 - 三样"。

```
总人数 = 24 + 30 + 38 - 12 - 16 - 18 + 6 = 52
恰好两样 = (12-6) + (16-6) + (18-6) = 6 + 10 + 12 = 28
只吃一样 = 52 - 28 - 6 = 18
```

答案：**B**。

> **⚠易错**：三个"既……又……"含三样都吃的人，必须逐个减 6 才是"恰好两样"。

**练习6**（2018联考）有关部门对 120 种抽样食品进行化验分析，结果显示，抗氧化剂达标的有 68 种，防腐剂达标的有 77 种，漂白剂达标的有 59 种，抗氧化剂和防腐剂都达标的有 54 种，防腐剂和漂白剂都达标的有 43 种，抗氧化剂和漂白剂都达标的有 35 种，三种食品添加剂都达标的有 30 种，那么三种食品添加剂都不达标的有多少种？

A. 14

B. 16

C. 18

D. 20

**解析**：

**破题**：给两两交集 + 三者交集 → 标准型求并集，再用总量相减。

```
至少一项 = 68 + 77 + 59 - 54 - 43 - 35 + 30 = 102
都不达标 = 120 - 102 = 18
```

答案：**C**。

> **★重点**：最后一步 `+ 30` 是加回被多减的三者交集，符号错会得 42。
