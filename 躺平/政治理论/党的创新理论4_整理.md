### 一、高质量发展常见搭配及基本概念

#### 关于"高质量发展"

- **高质量发展**是新时代我国经济社会发展的**鲜明主题**
- **高质量发展**是全面建设社会主义现代化国家的**首要任务**
- **发展**是解决我国一切问题的**基础和关键**

#### 中国特色社会主义

- 是**伟大事业**
- 是改革开放以来党的**全部理论和实践的主题**
- 是党和人民历尽千辛万苦、付出巨大代价取得的**根本成就**

#### 发展历程

1. **十一届三中全会**：开启了改革开放和社会主义现代化建设新时期
2. **十八届三中全会**：开启了新时代全面深化改革、系统整体设计推进改革新征程，开创了我国改革开放全新局面
3. **二十届三中全会**：通过《中共中央关于进一步全面深化改革、推进中国式现代化的决定》，紧扣推进中国式现代化这个主题，提出继续完善和发展中国特色社会主义制度，推进国家治理体系和治理能力现代化的总目标

#### 新发展阶段

- **社会主义初级阶段**（1956年三大改造完成）→ **新时代**（2012年十八大）→ **新发展阶段**（2017年十九大）
- **全面建成小康社会**（2020年）

#### 新发展理念

| 理念 | 注重解决的问题 |
|------|--------------|
| **创新发展** | 解决发展**动力**问题 |
| **协调发展** | 解决发展**不平衡**问题 |
| **绿色发展** | 解决**人与自然和谐共生**问题 |
| **开放发展** | 解决发展**内外联动**问题 |
| **共享发展** | 解决**社会公平正义**问题 |

#### 新发展格局

- **以国内大循环为主体，国际国内双循环相互促进**

**要点：**

1. 构建新发展格局是把握未来发展主动权的**先手棋**，不是被迫之举和权宜之计
2. 构建新发展格局是**开放的**国内国际双循环，不是**封闭的**国内单循环
3. 构建新发展格局是以**全国统一大市场**基础上的国内大循环为主体，不是各地都搞**自我小循环**
4. 要着力推动实施**扩大内需战略**同**深化供给侧结构性改革**有机结合
   - （1）坚持深化供给侧结构性改革这条**主线**，坚持把发展经济的着力点放在**实体经济**上
   - （2）要加快补上**内需**特别是**消费**短板，使内需成为拉动经济增长的**主动力**和**稳定锚**
   - （3）扩大内需需要增强**消费**对经济发展的**基础性作用**和**投资**对优化供给结构的**关键作用**

### 二、社会主义基本经济制度

社会主义基本经济制度包括**所有制**、**分配制度**、**资源配置体制机制**等方面，即：

1. **公有制为主体、多种所有制经济共同发展**
2. **按劳分配为主体、多种分配方式并存**
3. **社会主义市场经济体制**

**关系：** 所有制结构是基本经济制度的基础，决定分配方式和资源配置方式；合理有效的分配方式和资源配置方式有利于进一步完善所有制结构。

#### （一）所有制

**首提：** **党的十五大**首次明确提出，公有制为主体、多种所有制经济共同发展，是我国社会主义初级阶段的基本经济制度。

**两个毫不动摇（党的十六大首次提出）：**

- 必须**毫不动摇巩固和发展公有制经济**
- **毫不动摇鼓励、支持、引导非公有制经济发展**
- 公有制经济和非公有制经济都是社会主义市场经济的**重要组成部分**，都是我国经济社会发展的**重要基础**

**公有制经济：**

- **内容：** 国有经济和集体经济，还包括混合所有制经济中的**国有成分**和**集体成分**
- **主体地位体现：**
  1. 公有资产在社会总资产中占**优势**
  2. 国有经济控制国民经济的**命脉**，对经济发展起**主导作用**
     - （1）国有经济起主导作用，集中体现在其对国民经济的**控制力**上
     - （2）国有企业是中国特色社会主义的**重要物质基础**和**政治基础**，是我们党**执政兴国**的**重要支柱**和**依靠力量**

**【关键表述】**

1. 推动国有资本和国有企业**做强做优做大**，增强**核心功能**，提升**核心竞争力**
2. 推动国有资本向关系**国家安全**、国民经济命脉的**重要行业和关键领域**集中，向关系**国计民生**的**公共服务**、**应急能力**、**公益性领域**等集中，向**前瞻性战略性新兴产业**集中

**非公有制经济：**

- **内容：** 个体经济、私营经济、外资经济、混合所有制经济中的**非公有制成分**等
- **地位体现：** 是推进中国式现代化的**生力军**，是国家**税收**的重要来源，是就业创业的**重要领域**，是技术创新的**重要主体**，是金融发展的**重要依托**，是经济持续健康发展的重要力量

**【关键表述】**

1. 推进基础设施竞争性领域向经营主体**公平开放**，完善民营企业参与国家重大项目建设**长效机制**。支持有能力的民营企业**牵头承担**国家重大技术攻关任务，向民营企业进一步开放国家重大科研基础设施
2. 加强**事中事后监管**，规范涉民营企业行政检查
3. 加快营造**市场化、法治化、国际化**一流营商环境
4. 全面构建**亲清政商关系**
5. 健全以**公平**为核心原则的产权保护制度，加强对各种所有制经济组织和自然人产权的保护。使各种所有制经济依法**平等使用**生产要素、**公平参与**市场竞争、**同等受到**法律保护

#### （二）分配制度

**按劳分配为主体、多种分配方式并存**

**按劳分配：** 公有制是实行按劳分配的**前提条件**和**所有制基础**

**多种分配方式：**

1. **按个体劳动者劳动成果分配**：个体劳动者
2. **按生产要素分配**
   - （1）**劳动力要素**：指在私营企业和外资企业中劳动者所获得的**工资收入**
   - （2）**资本要素**：私营企业主生产经营取得的**税后利润**，债权人取得的**利息收入**、（资金）**股息分红**和**债券**、**股票交易收入**等
   - （3）**土地要素**：指出租土地、房屋取得的收入
   - （4）**知识、技术、信息要素**：指科技工作者、信息工作者提供新技术和信息资料取得的收入

**【关键表述】**

1. 健全**劳动、资本、土地、知识、技术、管理、数据**等生产要素由**市场评价贡献**、**按贡献决定报酬**的机制
2. 构建**初次分配、再分配、第三次分配**协调配套的制度体系，提高**居民收入在国民收入分配中的比重**，提高**劳动报酬在初次分配中的比重**。完善**税收、社会保障、转移支付**等再分配调节机制。支持发展**公益慈善事业**
3. 多渠道增加城乡居民**财产性收入**，形成有效增加**低收入群体收入**、稳步扩大**中等收入群体规模**、合理调节**过高收入**的制度体系

**分配制度速记表：**

| "按什么标准分配" | 依据"劳动、资本、土地、知识、技术、管理、数据"的贡献 | 公有制 → **按劳分配** | 非公有制 → **按生产要素分配/按个体劳动者劳动成果分配** | 由市场评价贡献、按贡献决定报酬的机制 |
|---|---|---|---|---|
| "分配过程如何调节" | 关注分配的阶段和主体(市场、政府、社会) | | | |
| | | **初次分配** → **市场主导** → 提高劳动报酬在初次分配中的比重 | | |
| | | **再分配** → **政府主导** → 完善税收、社会保障、转移支付等再分配调节机制 | | |
| | | **第三次分配** → **社会力量（自愿原则）** → 支持发展公益慈善事业 | | |

#### （三）资源配置体制机制

**社会主义市场经济体制**

**内涵：**

- **邓小平**是社会主义市场经济理论的奠基人
- 社会主义市场经济的内涵：
  1. 计划经济和市场经济不是划分社会制度的**标志**
  2. 计划和市场都是**经济手段**
  3. 坚持社会主义制度与市场经济的结合，是社会主义市场经济的**特色所在**、**优势所在**

**两只手的关系：**

- 构建高水平社会主义市场经济体制，关键是要处理好**政府**和**市场**的关系
- 二者是**有机统一**的，不是相互否定的，不能把二者**割裂开来**、**对立起来**
- 要用好"**看不见的手**"和"**看得见的手**"，推动**有效市场**和**有为政府**更好结合

**关键时间节点：**

- **1992年十四大**：确立了我国经济体制改革的目标是建立社会主义市场经济体制，提出要使市场在社会主义国家宏观调控下对资源配置起**基础性作用**
- **2013年十八届三中全会**：提出使市场在资源配置中起**决定性作用**，更好发挥政府作用
- **2024年二十届三中全会**：提出深化经济体制改革仍是进一步全面深化改革的**重点**（牵引），围绕处理好政府和市场的关系这个核心问题，把构建高水平社会主义市场经济体制摆在**突出位置**

**【举例理解两只手的作用】**

"**看不见的手**"：市场的作用

二十届三中提出要完善市场经济基础制度，具体举措有：完善**产权制度**，依法平等长久保护各种所有制经济产权，建立高效的知识产权综合管理体制。完善**市场信息披露制度**，构建商业秘密保护制度。对侵犯各种所有制经济产权和合法利益的行为实行**同责同罪同罚**，完善**惩罚性赔偿制度**。加强产权执法司法保护，防止和纠正利用行政、刑事手段干预经济纠纷，健全依法甄别纠正涉企冤错案件机制。完善**市场准入制度**，优化新业态新领域市场准入环境。深化注册资本认缴登记制度改革，实行依法按期认缴。健全企业破产机制，探索建立个人破产制度，推进企业注销配套改革，完善企业退出制度。健全**社会信用体系**和监管制度。

### 三、因地制宜发展新质生产力

**重要意义：** 发展新质生产力是推动高质量发展的**内在要求**和**重要着力点**

**新质生产力：**

- **特点/显著特点/主导/大文章：** **创新**
  - 新质生产力是**创新起主导作用**的先进生产力质态
  - 特点是**创新**，关键在**质优**，本质是**先进生产力**
  - 新质生产力的显著特点是**创新**，必须继续做好**创新**这篇大文章

- **核心要素：** **科技创新**能够催生新产业、新模式、新动能，是发展新质生产力的**核心要素**
  - 扎实推动**科技创新**和**产业创新**深度融合，助力发展新质生产力
  - （1）融合的基础是**增加高质量科技供给**
  - （2）融合的关键是**强化企业科技创新主体地位**。要充分发挥科技领军企业龙头作用，鼓励中小企业和民营企业科技创新，支持企业牵头或参与国家重大科技项目。推动企业主导的**产学研融通创新**
  - （3）融合的途径是**促进科技成果转化应用**。要做好科技金融这篇文章，引导金融资本**投早、投小、投长期、投硬科技**

- **催生原因：** 由**技术革命性突破**、**生产要素创新性配置**、**产业深度转型升级**而催生

- **特征：** 具有**高科技、高效能、高质量**特征

- **基本内涵：** 以**劳动者、劳动资料、劳动对象**及其**优化组合的跃升**为基本内涵

- **核心标志：** **全要素生产率大幅提升**

- **两个摆脱：**
  - **摆脱传统经济增长方式**
  - **摆脱传统生产力发展路径**

**【关键表述】**

1. 发展新质生产力**不是忽视、放弃传统产业**。建立未来产业投入增长机制，引导新兴产业健康有序发展，以**国家标准提升**引领传统产业优化升级
2. 各地要坚持从实际出发，**先立后破、因地制宜、分类指导**
3. **绿色发展**是高质量发展的**底色**，新质生产力本身就是**绿色生产力**
4. 发展新质生产力，必须进一步全面深化改革，形成与之相适应的**新型生产关系**
5. 鼓励和规范发展**天使投资、风险投资、私募股权投资**，更好发挥政府投资基金作用，发展**耐心资本**

**良性循环：** **教育 → 科技 → 人才**

畅通教育、科技、人才的良性循环。更好体现知识、技术、人才的市场价值，营造**鼓励创新、宽容失败**的良好氛围。

**促进改革：** 要深化经济体制、科技体制等改革，着力打通束缚新质生产力发展的**堵点卡点**。

### 四、建设现代化经济体系

**到2035年：** 建成现代化经济体系，形成新发展格局，基本实现**新型工业化、信息化、城镇化、农业现代化**

#### 现代化产业体系

- 立足**实体经济**这个根基，做大做强**先进制造业**，改造提升**传统产业**，培育壮大**新兴产业**，超前布局建设**未来产业**，加快构建以**先进制造业**为支撑的现代化产业体系

#### 乡村全面振兴

- **农业强国**是社会主义现代化强国的**根基**
- 全面建设社会主义现代化国家，最艰巨最繁重的任务依然在农村，最广泛最深厚的基础依然在农村
- 加快建设**供给保障强、科技装备强、经营体系强、产业韧性强、竞争能力强**的农业强国

#### 区域协调发展

- 推动**西部大开发**形成新格局，推动**东北全面振兴**取得新突破，促进**中部地区**加快崛起，鼓励**东部地区**加快推进现代化（率先发展）
- 推动**京津冀、长三角、粤港澳大湾区**等地区发挥高质量发展**动力源**作用

#### 常见搭配（三农）

1. 要把保障**粮食和重要农产品稳定安全供给**作为**头等大事**
2. 确保**国家粮食安全**作为现代农业建设的**首要任务**
3. 要坚持把**增加农民收入**作为"三农"工作的**中心任务**
4. 保障国家粮食安全的根本在**耕地**。（耕地是粮食生产的"**命根子**"）
5. **种子**是农业的"**芯片**"，要实现种业科技**自立自强**、种源**自主可控**
6. 推进以**县城**为重要载体的**新型城镇化**建设。（发挥县城连接城市、带动乡村作用）
7. 率先在**县域内**破除**城乡二元结构**。（率先在县域内实现城乡融合发展）
8. 以确保**国家粮食安全**、确保**农村人口不发生规模性返贫致贫**为底线
9. 以提升**乡村产业发展水平**、**乡村建设水平**、**乡村治理水平**为重点
10. 强化**科技和改革双轮驱动**（以改革开放和科技创新为动力）
11. 以**农业关键核心技术攻关**为引领，以产业急需为导向，加快以**种业**为重点的农业科技创新，以发展**农业新质生产力**推进农业强国建设

#### 关键表述（三农）

1. 学习运用"**千万工程**"经验
2. 稳定粮食播种面积，主攻**单产和品质提升**。（稳面积、增单产）
3. 严格**耕地总量管控**和"**以补定占**"
4. 严格落实**省级党委和政府耕地保护责任**
5. 实施**中央统筹下**的粮食产销区省际横向利益补偿
6. 综合施策推动粮食等重要农产品价格保持在**合理水平**，稳定市场供需
7. 注重激发**内生动力**，强化对有劳动能力的农村低收入人口的**开发式帮扶**
