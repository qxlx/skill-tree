# 党的创新理论9

## 第十七节 全面从严治党

### 一、新时代党面临的考验与危险

| 项目 | 内容 |
|------|------|
| 四大考验 | **执政考验**、**改革开放考验**、**市场经济考验**、**外部环境考验** |
| 四大危险 | **精神懈怠危险**、**能力不足危险**、**脱离群众危险**、**消极腐败危险** |
| 最大的危险 | **脱离群众** |

---

### 二、健全全面从严治党体系

**重要性：**

- 全面建设社会主义现代化国家、全面推进中华民族伟大复兴，关键在党，关键在全面从严治党。必须以永远在路上的执着把全面从严治党引向深入，以党的伟大**自我革命**引领伟大**社会革命**。

**五大体系：**

1. 要健全**上下贯通、执行有力**的组织体系。
2. 要健全**固本培元、凝心铸魂**的教育体系。
3. 要健全**精准发力、标本兼治**的监管体系。
4. 要健全**科学完备、有效管用**的制度体系。
5. 要健全**主体明确、要求清晰**的责任体系。

---

### 三、自我革命

**两个答案：**

- 跳出历史周期率问题，是关系党千秋伟业的一个重大问题。如何跳出历史周期率？如何实现长期执政？党始终在思索、一直在探索。毛泽东在延安的窑洞里给出了**第一个答案**，这就是"**让人民来监督政府**"。经过百年奋斗特别是党的十八大以来新的实践，党又给出了**第二个答案**，这就是**自我革命**。

**显著标志：**

- **勇于自我革命**是中国共产党区别于其他政党的**显著标志**，也是我们党**最大的优势**、**最鲜明的品格**。

**理解：**

- 社会革命与自我革命的关系：
  ①要针对伟大社会革命实践的新要求来谋划党的自我革命。
  ②用伟大社会革命发展的新成果来检验党的自我革命的实际成效。
  ③以党的自我革命引领伟大社会革命、以伟大社会革命促进党的自我革命。

---

### 四、新时代党的建设总要求

| 项目 | 内容 |
|------|------|
| 主线 | 加强党的**长期执政能力建设**、**先进性**和**纯洁性**建设 |
| 统领 | **政治建设**（摆在首位） |
| 根基 | **坚定理想信念** |
| 着力点 | 调动全党**积极性、主动性、创造性** |

**政治建设：**

- 党的政治建设是党的**根本性建设**。
- 首要任务：**保证全党服从中央，坚持党中央权威和集中统一领导**。（另一说：两个维护）

**思想建设：**

- 思想建设是党的**基础性建设**。
- 首要任务：**坚定理想信念**。

**制度建设：**

- 从严治党要靠思想教育，也要靠制度保障，靠制度是**长远之策、根本之策**。
- 要把制度建设贯穿到党的各项建设之中。
- 以党章为根本，以**民主集中制**为核心，完善党内法规制度体系。

**组织建设：**

- 严密的组织体系是党的优势所在、力量所在。
- 坚持**大抓基层**的鲜明导向。

**正风肃纪：**

- 作风问题核心是党同人民群众的**关系问题**。
- 持续深化纠治**形式主义、官僚主义、享乐主义和奢靡之风**。
- 加强党的纪律建设是一项经常性工作，要引导党员、干部把他律转化为自律。

### 五、反腐败斗争

**腐败：**

- 腐败是危害党的生命力和战斗力的**最大毒瘤**；
- 是我们党面临的**最大威胁**。

**反腐败：**

- 反腐败是**最彻底的自我革命**。

**成就：**

- 党中央以"**得罪千百人、不负十四亿**"的坚定决心，开展了史无前例的反腐败斗争，持续形成强大威慑，**不敢腐**的目标初步实现，**不能腐**的笼子越扎越紧，**不想腐**的堤坝正在构筑，反腐败斗争取得**压倒性胜利并全面巩固**。经过不懈努力，管党治党宽松软状况得到根本扭转，风清气正的党内政治生态不断形成和发展，全面从严治党取得**历史性、开创性成就**，产生**全方位、深层次影响**。

**现状：**

- 当前反腐败斗争形势仍然**严峻复杂**。腐败存量尚未清除，增量还在持续发生，铲除腐败滋生土壤和条件任务仍然艰巨繁重。

**风腐同查同治：**

- 坚持正风肃纪反腐相贯通，以"**同查**"严惩风腐交织问题，以"**同治**"铲除风腐共性根源。

### 三不腐

1. **不敢腐、不能腐、不想腐**是相互依存、相互促进的有机整体：
   - （1）"**不敢**"是**前提**，要以严格的执纪执法增强制度刚性，让党员、干部从害怕被查处的"不敢"走向敬畏党和人民、敬畏党纪国法的"不敢"；
   - （2）"**不能**"是**关键**，要科学配置权力，加强重点领域监督机制改革和制度建设，推动形成不断完备的制度体系、严格有效的监督体系；
   - （3）"**不想**"是**根本**，要靠加强理想信念教育、提高党性觉悟、涵养廉洁文化，筑牢拒腐防变的思想道德防线，夯实不忘初心、牢记使命的思想根基。
2. **一体推进不敢腐、不能腐、不想腐**，必须三者同时发力、同向发力、综合发力，把不敢腐的强大震慑效能、不能腐的刚性制度约束、不想腐的思想教育优势融于一体。
3. 在新的历史条件下，要继续在**不敢腐**上持续加压，始终保持零容忍震慑不变、高压惩治力量常在；在**不能腐**上深化拓展，前移防腐关口，深化源头治理；在**不想腐**上巩固提升，更加注重正本清源、固本培元。

## 最后的复盘

### 错误句子共性：有可以做手脚的"显眼包"

- ~~以各区域经济发展增长速度作为检验区域战略成效的评判标尺~~ → 应为"以**高质量发展**作为检验区域战略成效的评判标尺"
- ~~坚持把高速高效发展作为各级各类教育的生命线~~ → 应为"坚持把**高质量发展**作为各级各类教育的生命线"
- ~~坚持以人民为中心，这是我们的最大政治优势，是我国改革开放成功推进的根本保证~~ → 搭配有误
- ~~统一战线是党领导的统一战线，其最鲜明的特征是坚持以人民为中心~~ → 最鲜明的特征是**大团结大联合**
- ~~弘扬社会主义法治精神、传承中华优秀传统法律文化是社会主义法治建设的首要任务~~ → 搭配有误
- ~~要把文化遗产合理利用放在第一位~~ → 应为"坚持把**保护**放在第一位"
- ~~人口数量、素质、结构已成为实现中国式现代化的决定性因素~~ → 应为"**人口综合红利**仍然具有明显优势"等
- ~~要坚持以理论工作者的首创精神为引领，注重从理论创新中总结实践经验~~ → 搭配有误
- ~~各级领导干部身处实践最前沿，对实践变化感知最敏感、感受最深切，也最聪慧~~ → 搭配有误
- ~~健全生产要素由收益评价贡献、按贡献决定报酬的机制~~ → 搭配有误

### 常识性错误

1. ~~促进数字技术和实体经济深度融合，催生新产业新业态新模式替代传统产业~~ → 不是"替代"，是"融合"
2. ~~坚持把扩大内需战略同深化供给侧结构性改革有机结合起来，扩大消费，减少投资~~ → 不是"减少投资"
3. ~~优化区域开放布局，巩固中西部和东北地区开放先导地位，提高东部地区开放水平~~ → 应为"巩固**东部地区**开放先导地位"
4. ~~完善税收、社会保障、转移支付等第三次分配调节机制~~ → 第三次分配是**慈善公益**等
5. ~~中华文明是世界上绵延不断且以国家形态发展至今的四大文明之一~~ → 是"**唯一**"，不是"四大文明之一"
6. ~~中国具有百万年的人类史、一万年的文明史、五千多年的文化史~~ → 应为"一万年的**文化**史、五千多年的**文明**史"（文化史和文明史互换）
7. ~~截至2023年底，基本医疗保险覆盖10亿人，基本养老保险覆盖14亿人~~ → 数据有误
8. ~~高质量充分就业主要表现为每个公民不仅有活干，而且工作稳定、收入合理、保障可靠、职业安全等~~ → 这是**微观层面**的表现
9. ~~抓住人口增量发展蕴含的新机遇，优化人口结构和分布~~ → 我国已进入**减量发展**阶段
