# 混合增长率

> 来源：混合增长率 ｜ 资料分析专项（第九章，讲义 123—135 页，主讲：高照）

## 一、判定

**题型识别**

```
量的关系：部分 1 + 部分 2 = 整体
增长率关系：混合增长率（整体增长率介于两个部分增长率之间）
具体判定：求增长率，且量存在加和关系 → 考虑是否为混合
```

**四类常见关系**

1. **固定搭配**

```
进出口 = 进口 + 出口
全国 = 城镇 + 农村
邮电 = 邮政 + 电信
本外币 = 人民币 + 外币
```

2. **时间混合**

```
全年 = 1—11 月 + 12 月
一季度 = 1—2 月 + 3 月
累计增长率（1—n 月 = 1—(n-1) 月 + n 月）
```

3. **差值转化**

```
出口 - 进口 = 顺差   →  出口 = 进口 + 顺差
进口 - 出口 = 逆差   →  进口 = 出口 + 逆差
收入 - 支出 = 盈余   →  收入 = 支出 + 盈余
```

4. **矛盾关系**

```
总体 = A + 非 A
```

> **★重点**：**差值先转成加和**——"顺差增速"不能直接混合，必须写成 `出口 = 进口 + 顺差` 后，用"出口增速"混合出"顺差增速"。这一步是差值类题目的命门。

## 二、口诀法

### 1. 居中（整体在中间）

```
部分 1 的增长率 < 总体的增长率 < 部分 2 的增长率
```

**【例 1】**（2023 山东）2021 年，中国跨境电商交易规模达 14.2 万亿元，占我国货物进出口总额的比例为 36.3%。其中出口跨境电商交易规模 11 万亿元，同比增速 13.4%；进口跨境电商交易规模 3.2 万亿元，同比增速 14.3%。2021 年，我国跨境电商交易规模同比增长：

A. 12.8%　　B. 13.4%　　C. 13.6%　　D. 14.3%

**破题**：混合增长率（出口 + 进口 = 进出口），只需"居中 + 偏向"。

解析：

1. 居中：整体必在 13.4% 与 14.3% 之间 → 排除 A、B、D。
2. 偏向：出口 11 万亿 > 进口 3.2 万亿，整体贴近出口的 13.4%。
3. → **C.13.6%**。

> **★重点**：**只有一个选项落在两个部分增速之间时，直接选，不必算**。这是混合增长率性价比最高的一条。

### 2. 偏向（跷跷板原理）

```
混合增长率偏向基期量（一般参考现期量）大的一方
（从正中间向"胖"的一侧偏）
```

**【例 3】**（2021 新疆兵团）2018 年 H 市完成邮电业务总量 108.2 亿元。其中，邮政业务总量 40.8 亿元，同比增长 26.5%；电信业务总量 67.4 亿元，同比增长 56.7%。2018 年 H 市邮电业务总量同比增速在下列哪一个范围内？

A. 23%—41%　　B. 41%—57%　　C. 57%—71%　　D. 高于 71%

**破题**：混合增长率（邮电 = 邮政 + 电信），居中后按量偏向。

解析：

1. 居中：整体在 26.5%—56.7% 之间 → 排除 A（下界低于 26.5%）、C、D。
2. 偏向：电信 67.4 > 邮政 40.8，整体偏向上限一侧，即 41.65%（中点）—56.7% 之间。
3. → **B.41%—57%**。

> **⚠易错**：中点 = `(26.5+56.7)/2 = 41.6%`。**偏向大的一方 = 落在"中点与大部分增速"之间**，不是"落在中点与平均值之间"。方向反了就会选 A。

**【例 4】**（2025 四川）2023 年上半年，全国新注册登记机动车 1688 万辆，同比增长 1.9%。新注册登记汽车 1175 万辆，同比增长 5.8%。2023 年上半年，全国新注册登记非汽车类机动车数量比上年同期：

A. 增长了不到 2%
B. 增长了 2% 以上
C. 减少了不到 2%
D. 减少了 2% 以上

**破题**：矛盾关系（机动车 = 汽车 + 非汽车），已知整体 1.9% 与一部分 5.8%，求另一部分。

解析：

1. 判方向：整体 1.9% < 汽车 5.8% → 非汽车必然**低于** 1.9%，且很可能为负 → 排除 A、B。
2. 用线段法精算：非汽车量 `= 1688 - 1175 = 513` 万辆；基期 总 `1688/1.019 ≈ 1656.5`、汽车 `1175/1.058 ≈ 1110.6` → 非汽车基期 `≈ 545.9`。
3. `513 / 545.9 - 1 ≈ -6.0%` → **D.减少了 2% 以上**。

> **★重点**：矛盾关系题里"另一部分"的量小（513 万辆），它的增速必须**离整体更远**才能拉动整体——这就是"距离与量成反比"的直观解释。

**【例 5】**（2024 四川）2021 年 1—2 月，限额以下单位餐饮收入同比约增长了：

| --- | --- | --- |
| 社会消费品零售总额 | 69737 | 33.8 |
| 其中：除汽车以外的消费品零售额 | 63076 | 30.4 |
| 其中：限额以上单位消费品零售额 | 24375 | 43.9 |
| 其中：实物商品网上零售额 | 14412 | 30.6 |

**破题**：矛盾关系（餐饮收入 = 限额以上 + 限额以下），已知整体 68.9% 与一部分 61.8%。

1. 限额以下量：`7085 - 1459 = 5626` 亿元。

## 三、线段法

### 1. 原理推导（了解即可）

**引例**：浓度为 14% 的溶液 A 克与浓度为 22% 的溶液 B 克，混合后浓度为 17%。

```
14%·A + 22%·B = (A + B)·17%
(22% - 17%)·B = (17% - 14%)·A
→ A : B = (22% - 17%) : (17% - 14%) = 5 : 3
```

```
1、距离和量成反比
2、距离指部分与混合后的差值（也就是做差）
```

> **★重点**：**线段法口诀——① 部分写两边，整体写中间；② 距离和量成反比。** 记住这两句，浓度、比重、平均数、增长率四类混合题通吃。

### 2. 练习

**练习 1**：浓度 14% 的溶液 450 克与浓度 22% 的溶液 B 克，混合后浓度 16%。

1. 距离：左 `16-14 = 2`，右 `22-16 = 6`，距离比 `2:6 = 1:3`。
2. 量比 = 距离反比 = `3:1` → `450 : B = 3 : 1` → `B = 150` 克。

**练习 2**：浓度 14% 的溶液 500 克与浓度 22% 的溶液 300 克，混合后浓度为多少？

1. 距离比 = 量反比 = `300 : 500 = 3 : 5`，总距离 `22-14 = 8` 个百分点。
2. 混合点距左端 `8 × 3/8 = 3` → `14% + 3% = 17%`。

**练习 3**：浓度 14% 的溶液 A 克与浓度 22% 的溶液 150 克，混合后浓度 20%。

1. 距离：左 `20-14 = 6`，右 `22-20 = 2`，距离比 `6:2 = 3:1`。
2. 量比 = 反比 = `1:3` → `A : 150 = 1 : 3` → `A = 50` 克。

### 3. 线段法的适用与"量"的取法

```
距离：部分增长率与总体增长率的差值
量：部分的基期量（一般参考现期量）
```

**原理**：`增长率 = 增长量 / 基期量`，量是分母，所以混合增长率的"量"是**基期量**（与浓度题里"溶液质量"地位相同）。

**【例 10】**（2021 广东）2020 年上半年，我国农产品进出口总额达 1159.0 亿美元。农产品进口额为 807.5 亿美元，同比增长 13.2%；农产品出口额同比下降 3.8%，为 351.5 亿美元。2020 年上半年，我国农产品进出口额同比增长约：

A. 2.5%　　B. 5.0%　　C. 7.5%　　D. 10.0%

**破题**：混合增长率（进出口 = 进口 + 出口），两侧一正一负，必须用基期量做权重。

解析：

1. 基期：进口 `807.5/1.132 ≈ 713.3`，出口 `351.5/0.962 ≈ 365.4`，合计 `1078.7`。
2. `1159.0 / 1078.7 - 1 ≈ 7.4%` → **C.7.5%**。

> **★重点**：一正一负时**不能只看现期量偏向**——出口是负增长，基期反而比现期大，用现期量会高估进口的权重。

## 四、变型

### 1. 差值转化

**【例 6】**（2023 广东）2022 年，全国居民人均可支配收入 36883 元，比上年增长 5.0%。城镇居民人均可支配收入 49283 元，增长 3.9%；农村居民人均可支配收入 20133 元，增长 6.3%。2022 年，全国居民人均消费支出 24538 元，比上年增长 1.8%。城镇居民人均消费支出 30391 元，增长 0.3%；农村居民人均消费支出 16632 元，增长 4.5%。2022 年，全国居民人均收支盈余比上一年（　）。（注：收支盈余 = 收入 − 消费支出）

A. 增加了约 5%
B. 减少了约 5%
C. 增加了约 12%
D. 减少了约 12%

**破题**：差值转化——`收入 = 支出 + 盈余`，故 `盈余 = 收入 - 支出`，用"收入"作整体混合"支出"与"盈余"。

解析：

1. 盈余现期：`36883 - 24538 = 12345` 元。
2. 基期：收入 `36883/1.05 ≈ 35126.7`，支出 `24538/1.018 ≈ 24104.1` → 盈余基期 `≈ 11022.6`。
3. `12345 / 11022.6 - 1 ≈ 12.0%` → **C.增加了约 12%**。

> **★重点**：收入增速 5.0% > 支出增速 1.8%，差值（盈余）的增速必然**高于 5%**——先判方向就能排除 A、B。

**【例 7】**（2024 国考）2023 年 1—3 月我国机器人设备累计出口金额 1.9 亿美元，较上年增长 62.1%；累计进口金额 6.9 亿美元，较上年增长 55.1%。2023 年一季度，我国机器人设备进出口贸易逆差比上年同期：

A. 下降了不到 30%
B. 下降了 30% 以上
C. 上升了不到 30%
D. 上升了 30% 以上

**破题**：差值转化——`进口 - 出口 = 逆差`，即 `进口 = 出口 + 逆差`。

解析：

1. 逆差现期：`6.9 - 1.9 = 5.0` 亿美元。
2. 基期：进口 `6.9/1.551 ≈ 4.449`，出口 `1.9/1.621 ≈ 1.172` → 逆差基期 `≈ 3.277`。
3. `5.0 / 3.277 - 1 ≈ 52.6%` → **D.上升了 30% 以上**。

> **⚠易错**：逆差 = 进口 − 出口，是**进口更大**。若误按"出口 − 进口"算，会得到负值而选"下降"。

### 2. 当月增速与当月累计增速

```
当月增速 > 累计增速  →  累计增速上升（当月把均值往上拉）
当月增速 < 累计增速  →  累计增速下降
（口诀：累计不滑坡，当月就比累计多）
```

> **★重点**：**看累计增速的"拐点"就够了**——累计增速比上月**上升**，说明当月增速高于累计增速；反之下降。不必求当月值。

**【例 8】**（2025 联考）2024 年 3—11 月，全国啤酒当期产量增长率高于累计增长率的有几个？

| --- | --- | --- | --- | --- |

**破题**：时间混合——当月增速 > 累计增速 ⟺ 累计增速比上期**上升**。

解析（只看啤酒累计增速的升降）：

## 五、变型：混合倍数与"多者混合"

### 1. 混合倍数（增长倍数）

**【例 12】**（2021 北京）2016 年女性参加生育保险的人数达 8020 万人，比 2010 年增长 49%。2016 年，参加城镇职工基本医疗保险的女性 1.4 亿人，比 2011 年增长 21.5%；参加城镇居民基本医疗保险的女性 1.9 亿人，比 2011 年增长了 1.5 倍。2016 年参加城镇职工和城镇居民基本医疗保险的女性比 2011 年增长了约多少倍？

A. 0.7　　B. 1.2　　C. 1.7　　D. 2.2

**破题**：混合增长率 + 倍数转换——先混合出增长率，再换算成"多几倍"（增长率本身就是倍数）。

解析：

1. 现期合计：`1.4 + 1.9 = 3.3` 亿人。
2. 基期：职工 `1.4/1.215 ≈ 1.152`，居民 `1.9/2.5 = 0.76` → 合计 `≈ 1.912`。
3. `3.3 / 1.912 - 1 ≈ 0.726` → 增长约 0.7 倍 → **A.0.7**。

> **★重点**："增长了 1.5 倍"即增长率 150%，基期 = 现期 ÷ 2.5。"增长几倍"问的是增长率本身，不必再减 1。

**【例 13】**（2024 联考）2023 年一季度，新疆外贸进出口总值 680.7 亿元，同比增长 80.3%。其中，出口 584.7 亿元，同比增长 86.9%。2023 年一季度，新疆外贸进口值同比增长约：

A. 26%　　B. 32%　　C. 48%　　D. 56%

**破题**：矛盾关系（进出口 = 进口 + 出口），已知整体 80.3%、出口 86.9%，求进口。

解析：

1. 进口现期：`680.7 - 584.7 = 96.0` 亿元。
2. 基期：整体 `680.7/1.803 ≈ 377.6`，出口 `584.7/1.869 ≈ 312.8` → 进口基期 `≈ 64.8`。
3. `96.0 / 64.8 - 1 ≈ 48.1%` → **C.48%**。

> **★重点**：整体 80.3% < 出口 86.9% → 进口必然**低于** 80.3%；进口量小（96 亿），离整体更远 → 答案应在 40%—50% 之间，直接锁 C。

### 2. 多者混合

```
居中：最小的增长率 < 总体的增长率 < 最大的增长率
拆分成多个两两混合，优先找等量混合
```

> **⚠易错**：多者混合**计算量大，往往只考"大小居中"思维**。三个以上部分混合时，只要能定位"最小值—最大值"区间并判断偏向，就不必精确计算。

**【例 14】**（2024 全国事业单位联考）2023 年 1—4 月，F 省饮料产量比上年同期下降了：

**图　2022 年 1 月—2023 年 4 月 F 省饮料产量情况**（单位：万吨）

| 年份 | 1 月 | 2 月 | 3 月 | 4 月 | 1—4 月合计 |
| --- | --- | --- | --- | --- | --- |
| 2022 | 150.1 | 92.1 | 83.5 | 83.3 | 409.0 |
| 2023 | 117.7 | 99.8 | 93.8 | 91.8 | 403.1 |

（原图为柱状图 + 折线图，OCR 只保留可配对的 1—4 月数值；5—12 月数值月份对应错位，未列入。）

A. 不到 7%　　B. 7%—14% 之间　　C. 14%—21% 之间　　D. 21% 以上

**破题**：多者混合（1—4 月 = 1—3 月 + 4 月），也可直接总量相比。

解析：

1. 2023 年 1—4 月：`117.7 + 99.8 + 93.8 + 91.8 = 403.1` 万吨。
2. 2022 年 1—4 月：`150.1 + 92.1 + 83.5 + 83.3 = 409.0` 万吨。
3. `403.1 / 409.0 - 1 ≈ -1.4%` → 下降不到 7% → **A**。

> **★重点**：也可按混合做——1—3 月 `311.3 / 325.7 - 1 ≈ -4.4%`，4 月 `91.8/83.3 - 1 ≈ +10.2%`，混合后在 −4.4% 与 +10.2% 之间且偏向 1—3 月（311 > 92），约为 −1.5%，与直除一致。

**【例 15】**（2022 江苏）2020 年 7 月—2021 年 6 月，我国原油季度产量同比增速超过 2.5% 的季度个数是：

**表　2020 年 7 月—2021 年 6 月我国原油日均产量变动情况**

| 时间 | 2020.7 | 2020.8 | 2020.9 | 2020.10 | 2020.11 | 2020.12 | 2021.1—2 月 | 2021.3 | 2021.4 | 2021.5 | 2021.6 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 日均产量（万吨） | 53.1 | 53.7 | 53.7 | 52.9 | 53.2 | 52.5 | 54.4 | 55.1 | 54.7 | 54.9 | 55.6 |
| 同比增长（%） | 0.6 | 2.3 | 2.4 | 1.4 | 1.2 | 0.9 | 0.4 | 3.3 | 3.4 | 3.5 | 2.8 |

A. 0　　B. 1　　C. 2　　D. 3

**破题**：多者混合（月 → 季），只需判断"混合值是否超过 2.5%"。

解析：

1. 2020 年三季度（7、8、9 月）：0.6、2.3、2.4 → 混合必在 0.6—2.4 之间，**不足 2.5%** ✗
2. 2020 年四季度（10、11、12 月）：1.4、1.2、0.9 → 均低于 2.5% ✗
3. 2021 年一季度（1—2 月 0.4、3 月 3.3）：混合在 0.4—3.3 之间，但 1—2 月占两个月权重，混合约 `(0.4×2+3.3)/3 ≈ 1.4%` ✗
4. 2021 年二季度（4、5、6 月）：3.4、3.5、2.8 → 全部 > 2.5%，混合必 > 2.5% ✓
5. 共 1 个 → **B.1**。

> **★重点**：判断"季度增速是否超过阈值"，先看三个月是否**都**超、或**都**不超——同侧时不必精算；跨阈值（如 2021 年一季度）才需要加权。

## 六、警惕反例

```
混合：居中，偏向基期量大的（多数情况 99.9% 可用现期代替基期计算）
```

> **⚠易错**：当两个部分的**增长率相差很大（通常差 20 个百分点甚至更多）**时，可能出现"叛逃"——**现期量大的一方，基期量反而小**，导致偏向判断失真。
>
> **操作**：发现两个 r 相差很大，不要偷懒，直接估算基期，看偏向即可出答案。

**【例 2】**（2022 四川下）2019 年 1—2 月，我国包裹寄递量比去年同期：

**破题**：时间混合（一季度 = 1—2 月 + 3 月），已知整体（一季度）与一部分（3 月），反求另一部分（1—2 月）。

**【例 11】**（2021 山东）2019 年 12 月，A 地区社会消费品零售总额同比增速约为？

| 其中：批发和零售业 | 5754.74 | 6.1 |
| 住宿和餐饮业 | 828.11 | 11.2 |

**图　2019 年 1—11 月 A 地区社会消费品零售总额各月累计金额及累计同比增速**

| 累计区间 | 1—11 月 |
| --- | --- |

**破题**：时间混合（全年 = 1—11 月 + 12 月），已知整体 6.7%、1—11 月 6.4%，求 12 月。

解析：

1. 12 月金额：`6582.85 - 5925 = 657.85` 亿元。
2. 基期：全年 `6582.85/1.067 ≈ 6169.6`，1—11 月 `5925/1.064 ≈ 5568.6` → 12 月基期 `≈ 601.0`。

> **★重点**：整体 6.7% > 1—11 月 6.4% → 12 月必然**高于** 6.7%，且 12 月量小（658/6583 ≈ 10%），要拉动整体 0.3 个百分点，自身需高出约 3 个百分点 → 9%—10% 区间，直接锁 C。

## 本章小结

```
混合增长率
├─ 识别：求增长率，数据不全，主体可转化为加和或差值
│   ├─ 固定搭配：进出口=进口+出口、全国=城镇+农村、邮电=邮政+电信、本外币=人民币+外币
│   ├─ 时间混合：全年=1—11月+12月、一季度=1—2月+3月（累计增长率）
│   ├─ 差值转化：出口-进口=顺差、进口-出口=逆差、收入-支出=盈余
│   └─ 矛盾关系：总体 = A + 非A
├─ 三步走
│   ├─ 第一步 找关系：总体 = 部分1 + 部分2
│   ├─ 第二步 定位置：总体在中间，部分在两边（居中）
│   └─ 第三步 先口诀、后线段
│       ├─ 口诀：偏向基期量（一般参考现期）大的一方（跷跷板）
│       └─ 线段法：距离与量成反比
│           距离 = 部分增长率与总体增长率的差值
│           量   = 部分的基期量（一般参考现期）
├─ 反例：现期接近或部分增长率相差较大时，口诀法与线段法都必须用基期，不能参考现期
├─ 累计增速：当月 > 累计 → 累计上升；当月 < 累计 → 累计下降
└─ 多者混合：居中；拆成两两混合，优先找等量混合（多数只考大小居中）
```

> **★重点**：混合增长率一节的**全部结论**只有两条——**居中**（整体夹在两个部分之间）和**距离与量成反比**（量用基期）。前者定范围、后者定位置；能定范围就别算，必须定量才用线段法。
