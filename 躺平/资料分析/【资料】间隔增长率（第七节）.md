# 间隔增长率

> 来源：间隔增长率 ｜ 资料分析专项（第七节，讲义 95—105 页，主讲：高照）

## 一、判定与公式

**判定**：2025 年比 2023 年增长 +%，隔了一年求增长率 → 间隔增长率。

```
r间隔 = r1 + r2 + r1 × r2

r1：本期（2025 年）同比增长率
r2：上期（2024 年）同比增长率
口诀：和 + 积
```

**推导**（设 2023 年基期量为 1）：

1. 2024 年量 `= 1 + r1'`（记 2024 年增速为 r2）；
2. 2025 年量 `= (1 + r2)(1 + r1) = 1 + r1 + r2 + r1r2`；
3. 故 2025 年比 2023 年的增长率 `= r1 + r2 + r1r2`。

> **★重点**：**间隔增长率 = 两期增长率之和 + 两者之积**，与"间隔倍数"只差一个 1。凡隔一年问"增长百分之几"，一律套此式。

> **⚠易错**：`r1 × r2` 的符号随正负走。r1、r2 一正一负时积为负，会**削掉**一部分和，漏算积就会高估。

### 速算三步

1. **先看能否丢积**：`r1、r2` 绝对值均 < 10% 时，积 ≤ 10%×10% = 1%；若 `r1 + r2` 与选项相差 1 个百分点以上，`r1×r2` 可忽略。
2. **化分数 / 化小数**：48%×25% 直接化成 `0.48×0.25 = 0.12`，比硬乘快。
3. **结合选项定答案**：先算和（两位数口算），再看积落在哪个档。

**速算示例**

- `5.6% + 6.3% + 5.6%×6.3%`：和 = 11.9%，积 ≈ 0.35% → 约 **12.25%**（选 12.26%，C）。
- `48% + 25% + 48%×25%`：和 = 73%，积 = 12% → **85%**。
- `30% + 15% + 30%×15%`：和 = 45%，积 = 4.5% → **49.5%**。

> **★重点**：**先和再积**——和是口算题，积是"小数点题"。养成"先说和、再说积、最后相加"的顺序，考场能省 10 秒以上。

### 疑难点：r2 到底给不给

| 材料表述 | r1 | r2 | 说明 |
| --- | --- | --- | --- |
| 2025 年同比增长 10%，2024 年同比增长 8% | 10% | 8% | 直接给 |
| 2025 年同比增长 10%，增速比去年提高 2 个百分点 | 10% | 8% | 提高 → 减；回落 → 加 |
| 2025 年，体重由增长 8% 变为增长 10%，实现新突破 | 10% | 8% | "由 A 变为 B"：A 是上年 |

> **⚠易错**：**"回落/收窄"要加，"提高/扩大"要减**。这是本类题第一大失分点：r2 = r1 + 回落幅度，不是 r1 − 回落幅度。

## 二、例题（间隔增长率）

**【例 1】**（2024 四川）2022 年，全国软件和信息技术服务业规模以上企业超 3.5 万家，累计完成软件业务收入 108126 亿元，同比增长 11.2%，增速较上年同期回落 6.5 个百分点。2022 年累计完成软件业务收入约比 2020 年增长了：

A. 16%　　B. 23%　　C. 29%　　D. 31%

**破题**：隔一年求增长率（2022 比 2020），套 `r1 + r2 + r1r2`；r1 = 11.2%，回落 6.5 个百分点 → r2 = 11.2% + 6.5% = 17.7%。

解析：

1. 和：`11.2% + 17.7% = 28.9%`。
2. 积：`11.2% × 17.7% ≈ 1.98%`。
3. 合计 `≈ 30.9%` → **D.31%**。

> **★重点**：积近 2 个百分点，与选项 C（29%）正好差 2——**这题就是考"积能不能丢"**：和 28.9% 与 C 只差 0.1，但加上积后跳到 30.9%，只剩 D 可选。

**【例 2】**（2024 甘肃事业单位）2023 年 1—7 月份，全国规模以上工业企业实现利润总额 39439.8 亿元，同比下降 15.5%，增速比上年同期回落 16.6 个百分点。2023 年 1—7 月份利润总额约比 2021 年 1—7 月份（　）。

A. 下降了 13.8%
B. 增长了 13.8%
C. 下降了 31.5%
D. 增长了 31.5%

**破题**：隔一年求增长率，且**两个增速一负一正**；r1 = −15.5%，回落 → r2 = −15.5% + 16.6% = +1.1%。

解析：

1. 和：`-15.5% + 1.1% = -14.4%`。
2. 积：`(-15.5%) × 1.1% ≈ -0.17%`。
3. 合计 `≈ -14.6%`，即下降约 14.6%，最接近 **A.下降了 13.8%**。

> **⚠易错**：这里"增速回落"是从正增长落到负增长，r2 必须**加**回落幅度（−15.5% + 16.6%）。若错写成 −15.5% − 16.6% = −32.1%，会算出 −42%，误选 C。
>
> （计算值 −14.6% 与选项 −13.8% 差约 0.8 个百分点，量级与方向均一致；若四个选项分档更细，建议核对 PDF 原材料"16.6 个百分点"是否准确。）

**【例 3】**（2024 联考）2022 年，全国共有 260 家银行机构和 29 家理财公司累计新发理财产品 2.94 万只，同比下降 38.23%，降幅比上年同期扩大 7.22 个百分点。2022 年新发理财产品只数与 2020 年相比约：

A. 下降 45%　　B. 下降 57%　　C. 下降 66%　　D. 下降 69%

**破题**：隔一年求增长率，遇"降幅扩大"要**老老实实还原 r2**：降幅 31.01% → r2 = −31.01%。

解析：

1. 2021 年降幅：`38.23% - 7.22% = 31.01%`，即 r2 = −31.01%。
2. 和：`-38.23% + (-31.01%) = -69.24%`。
3. 积：`(-38.23%) × (-31.01%) ≈ +11.85%`（两负相乘为正，这是本题关键）。
4. 合计 `≈ -57.4%` → **B.下降 57%**。

> **★重点**：遇到"降幅"题，**先统一成带符号的增长率再套公式**。"降幅扩大"= 增长率更低（更负），"降幅收窄"= 增长率回升。

## 三、间隔倍数

**特征**：隔一年，求倍数。

```
间隔倍数 = 1 + r间隔
问"是几倍"  →  r间隔 + 1
问"多几倍"  →  r间隔
```

**两步走**：

1. 先估算 `r间隔`；
2. 再 `+1`（或按问法不加）。

> **★重点**：**快速方法——选项先减 1，转化为求 r间隔**。选项 1.13/0.13/1.24/0.24 减 1 后立刻变成 0.13/0.24 两档，直接比增长率，省一步加法。

**示例**：2025 年体重 180 斤，同比增长 20%；2024 年同比增长 10%。则 2025 年是 2023 年的 `1 + (20%+10%+2%) = 1.32` 倍，比 2023 年多 0.32 倍。

**【例 4】**（2017 新疆）2017 年上半年医药工业规模以上企业实现主营业务收入 15314.40 亿元，同比增长 12.39%，增速较上年同期提高 2.25 个百分点。2017 年上半年约是 2015 年上半年的：

A. 1.13 倍　　B. 0.13 倍　　C. 1.24 倍　　D. 0.24 倍

**破题**：隔一年求倍数；r1 = 12.39%，"提高 2.25 个百分点" → r2 = 12.39% − 2.25% = 10.14%。

解析：

1. 和：`12.39% + 10.14% = 22.53%`。
2. 积：`12.39% × 10.14% ≈ 1.26%`。
3. `r间隔 ≈ 23.8%` → 倍数 `= 1.238` → **C.1.24 倍**。

> **⚠易错**：A/D 组与 C/B 组相差的正是那个 1（1.24 与 0.24）。"是几倍"加 1，"多几倍"不加，读题时圈出这两个字。

解析：

2. 积：`40.3% × (-10.5%) ≈ -4.2%`。

## 四、间隔基期

**识别**：隔一期，问过去的量是多少（间隔一年，求基期）。

```
间隔基期 = 现期量 / (1 + r间隔)
```

**两步走**：

1. 先估算 `r间隔`：**差距大 → 估算至十位；差距小 → 估算至个位**；
2. 再直除（截位），得基期。

**示例**：2025 年体重 180 斤，同比增长 20%，2024 年同比增长 10%。
`r间隔 = 32%`，2023 年体重 `= 180 / 1.32 ≈ 136` 斤。

**【例 6】**（2020 四川下）2013 年，城镇居民人均可支配收入约为多少万元？
材料：2015 年城镇居民人均可支配收入 31195 元，比上年增长 8.2%，增长率比 2014 年下降 0.8 个百分点。

A. 1.9　　B. 2.2　　C. 2.6　　D. 3

**破题**：间隔基期，先还原 2014 年增速（"下降 0.8 个百分点" → 2014 年 = 8.2% + 0.8% = 9.0%），再算 r间隔。

解析：

1. `r间隔 = 8.2% + 9.0% + 8.2%×9.0% ≈ 18.0%`（估算到个位）。
2. `31195 / 1.18 ≈ 26437` 元 `≈ 2.6 万元` → **C**。

> **★重点**：`31195/1.18` 只要估到"2.6 还是 2.2"这个精度，截两位直除即可，不必精算。

**【例 7】**（2025 安徽）2021 年全国著作权登记总量约为：
材料：2023 年全国著作权登记总量达 8923901 件，同比增长 40.46%，增速比上年同期增加 39 个百分点。

A. 626 万件　　B. 656 万件　　C. 685 万件　　D. 728 万件

**破题**：间隔基期，"增速增加 39 个百分点" → 2022 年增速 = 40.46% − 39% = 1.46%。

解析：

1. `r间隔 ≈ 40.46% + 1.46% + 0.6% ≈ 42.5%`。
2. `8923901 / 1.425 ≈ 626` 万件 → **A.626 万件**。

> **⚠易错**：8923901 件 = 892.4 万件，先换单位再除，否则会差 10000 倍。

## 五、间隔现期量

**特征**：保持增长率不变，隔一年问未来值。

```
间隔现期量 = 基期 × (1 + r间隔)
方法一：若 (1+r)² 是熟知平方数，直接乘
方法二：平方数不适用、差距小时，用"间隔增长率"两步走
```

**示例**：2025 年体重 180 斤，同比增长 10%，若保持该增速 → 2027 年 `= 180 × 1.1² = 217.8` 斤；
若同比增长 16% → `1.16² = 1.3456`，`180 × 1.3456 ≈ 242.2` 斤（16% 的平方需硬算，可用 `1 + 32% + 2.56% = 1.3456`）。

| --- | --- | --- | --- | --- | --- |
| 电子信息制造业增加值 | 9.30% | 7.70% | 15.70% | 7.60% | 3.40% |
| 互联网业务收入 | 21.40% | 12.50% | 21.20% | -1.10% | 6.80% |
| 软件业务收入 | 16.40% | 13.20% | 17.10% | 12.50% | 13.40% |
| 全国固定资产投资 | 5.40% | 2.90% | 4.90% | 5.10% | 3.00% |
| 计算机、通信和其他电子设备制造业投资 | 16.80% | 12.50% | 22.30% | 18.80% | 9.30% |

**【例 8】**（2025 联考）按照 2023 年的同比增速，2025 年互联网业务收入预计在以下哪个范围：

A. 1.6—1.8 万亿元
B. 1.8—2.0 万亿元
C. 2.0—2.2 万亿元
D. 超过 2.2 万亿元

**破题**：间隔现期量，2023 年 1.75 万亿元、增速 6.8%，保持到 2025 年共 2 年 → `1.75 × 1.068²`。

解析：

1. 平方：`1.068² = 1 + 2×6.8% + 6.8%² ≈ 1.1406`。
2. `1.75 × 1.1406 ≈ 1.996` 万亿元。
3. 恰好落在 1.8—2.0 → **B**。

> **⚠易错**：`1.996` 与 2.0 只差 0.004，选项 B 上界与 C 下界正好卡在这里。凡"边界题"，平方要算到四位小数，不能提前截位。

## 六、间隔增长量

**特征**：隔一年，求增长量。

```
间隔增长量 = 现期量 × r间隔 / (1 + r间隔)
（也可写成：间隔增长量 = 现期量 - 间隔基期）
```

**两步走**：① 先求 `r间隔`；② 再百化分或直除。

**【例 9】**（2019 辽宁）2018 年规模以上工业主营业务利润总额比 2016 年增长了约（　）亿元。

**表　辽宁省各类市场主体部分数据表**

| 项目（2018 年） | 绝对量 | 同比增长率（%） | 同比增速（百分点） |
| --- | --- | --- | --- |
| 生产总值（亿元） | 25315.4 | 5.7 | — |
| 年人均生产总值（元） | 58008.0 | 5.9 | — |
| 规模以上工业主营业务收入（亿元） | 26489.9 | 15.8 | 6.9 |
| 规模以上工业利税总额（亿元） | 2925.1 | 20.7 | -7.5 |
| 其中：利润总额（亿元） | 1460.3 | 41.8 | -51.9 |
| 税收总额（亿元） | 1464.8 | 5.1 | — |

A. 471　　B. 535　　C. 703　　D. 928

**破题**：间隔增长量，`r1 = 41.8%`，"增速（百分点）−51.9" 表示比 2017 年回落 51.9 个百分点 → `r2 = 41.8% + 51.9% = 93.7%`。

解析：

1. `r间隔 = 41.8% + 93.7% + 41.8%×93.7% ≈ 135.5% + 39.2% = 174.7%`。
2. 间隔基期：`1460.3 / 2.747 ≈ 531.6` 亿元。
3. 增长量：`1460.3 - 531.6 ≈ 928.7` 亿元 → **D.928**。

> **★重点**：`r间隔 = 174.7% > 100%`，说明两年翻了一倍半——**增长量比现期的 60% 还多**，量级上就能排掉 A、B、C。

## 七、间隔增长率的逆向运用（求基期增长率）

**识别**：连续的时间，求中间那一年的增长率。

```
r2 = (r间隔 - r1) / (1 + r1)
```

**推导**：由 `r间隔 = r1 + r2 + r1r2` 得 `r2(1 + r1) = r间隔 - r1`。

> **★重点**：**判号口诀**——`r间隔 > r1` 则 `r2 > 0`；`r间隔 < r1` 则 `r2 < 0`。这一条能瞬间排除一半选项。

**示例**：2021 年同比 10%，比 2019 年增长 20%，求 2020 年比 2019 年增长率。
`r2 = (20% - 10%)/(1 + 10%) ≈ 9.1%`。

### 考法一：同比套同比

**情况一：给 r1、r间隔，求 r2** —— 直接用上式。
**情况二：给 r1、两年平均增长率 r̄** —— 第一步 `r间隔 = r̄ + r̄ + r̄²`，第二步再套上式。

**【例 10】**（2023 国考）2021 年，全国纺织品服装出口 3155 亿美元，同比增长 8.4%。其中，服装出口 1702.8 亿美元，同比增长 24.0%，较 2019 年增长 16.0%。2020 年，全国服装出口额比 2019 年：

A. 增长了 10% 以上
B. 下降了 10% 以上
C. 增长了不到 10%
D. 下降了不到 10%

**破题**：逆向运用——已知 2021 年比 2019 年的间隔增长率 16.0% 与 2021 年同比 24.0%，求 2020 年。

解析：

1. 判号：`r间隔 = 16.0% < r1 = 24.0%` → r2 < 0，排除 A、C。
2. `r2 = (16.0% - 24.0%) / 1.24 = -8.0% / 1.24 ≈ -6.5%`。
3. 下降不到 10% → **D**。

**【例 11】**（2022 江苏）2021 年 1—7 月，我国原油产量 11561 万吨，同比增长 2.4%，比 2019 年同期增长 3.9%。2020 年 1—7 月，我国原油产量的同比增速是：

A. 1.46%　　B. 1.90%　　C. 2.36%　　D. 3.15%

**破题**：逆向运用，`r间隔 = 3.9%`、`r1 = 2.4%`，判号为正后直接除。

解析：

1. 判号：`3.9% > 2.4%` → r2 > 0。
2. `r2 = (3.9% - 2.4%) / 1.024 ≈ 1.46%` → **A**。

> **★重点**：分子只有 1.5 个百分点，除 1.024 几乎不变——**判完号直接读最接近的选项**，不必精算。

**【例 12】**（2023 深圳）2020 年 1—2 月，全国商品房销售面积同比增长：
材料：2021 年 1—2 月商品房销售面积 17363 万平方米，同比增长 1.05 倍，比 2019 年 1—2 月增长 23.3%。

A. -40.0%　　B. -32.5%　　C. 40.0%　　D. 17.2%

**破题**：逆向运用，注意"增长 1.05 倍"就是 `r1 = 105%`，不是 1.05%。

解析：

1. 判号：`r间隔 = 23.3% < r1 = 105%` → r2 < 0，排除 C、D。
2. `r2 = (23.3% - 105%) / 2.05 = -81.7% / 2.05 ≈ -39.9%` → **A.-40.0%**。

> **⚠易错**："增长 1.05 倍" = 增长率 105%；"增长 1.05%" 才是 1.05%。两者差 100 倍，本材料里两种写法都存在（"1.33 倍"同理）。

**【例 13】**（2023 浙江）2021 年上半年，S 市工业战略性新兴产业总产值 7164.68 亿元，比去年同期增长 19.6%，两年平均增长 12.3%。2020 年上半年，该市工业战略性新兴产业总产值同比增长在以下哪个范围内？

A. 不到 7%　　B. 7—10%　　C. 10—13%　　D. 超过 13%

**破题**：逆向运用·情况二——先由"两年平均 12.3%"还原间隔增长率，再求 r2。

解析：

1. `r间隔 = 12.3% + 12.3% + 12.3%² ≈ 24.6% + 1.5% = 26.1%`。
2. 判号：`26.1% > 19.6%` → r2 > 0。
3. `r2 = (26.1% - 19.6%) / 1.196 ≈ 5.4%` → **A.不到 7%**。

**【例 14】**（2024 四川）在 2020 年 1—2 月①全国网上零售额和②实物商品网上零售额中：
材料：2021 年 1—2 月，全国网上零售额 17587 亿元，同比增长 32.5%，两年平均增长 13.3%；其中实物商品网上零售额 14412 亿元，同比增长 30.6%，两年平均增长 16.0%。

A. 仅①同比正增长
B. 仅②同比正增长
C. ①和②均同比正增长
D. ①和②均未同比正增长

**破题**：逆向运用 + **判号即可**（`r间隔` 与 `r1` 比大小），无须算出具体值。

解析：

1. ① `r间隔 = 13.3%×2 + 1.77% ≈ 28.4%`，而 `r1 = 32.5%` → `r间隔 < r1` → r2 < 0，①为负。
2. ② `r间隔 = 16.0%×2 + 2.56% ≈ 34.6%`，而 `r1 = 30.6%` → `r间隔 > r1` → r2 > 0，②为正。
3. 仅②正增长 → **B**。

> **★重点**：这类"正负判断"题**只比大小，不做除法**——`r间隔` 与 `r1` 谁大谁小，30 秒内可判两个。

**【例 15】**（2024 四川）2020 年 1—2 月，将吃类、穿类和用类商品的实物商品网上零售额同比增速从高到低排列，下列排序正确的是：
材料（同上）：吃类、穿类和用类商品分别增长 41.6%、44.3% 和 25.1%，两年平均分别增长 33.8%、8.7% 和 16.0%。

A. 吃类、用类、穿类
B. 吃类、穿类、用类
C. 穿类、吃类、用类
D. 穿类、用类、吃类

**破题**：逆向运用连做三组，先算 r间隔 再求 r2。

解析：

1. 吃类：`r间隔 ≈ 33.8%×2 + 11.4% = 79.0%`；`r2 = (79.0% - 41.6%)/1.416 ≈ 26.4%`。
2. 穿类：`r间隔 ≈ 8.7%×2 + 0.76% = 18.2%`；`r2 = (18.2% - 44.3%)/1.443 ≈ -18.1%`。
3. 用类：`r间隔 ≈ 16.0%×2 + 2.56% = 34.6%`；`r2 = (34.6% - 25.1%)/1.251 ≈ 7.6%`。
4. 由高到低：吃类 26.4% > 用类 7.6% > 穿类 −18.1% → **A**。

> **⚠易错**：三组里只有穿类的 r间隔（18.2%）小于 r1（44.3%），所以只有穿类为负——**先用判号排除**，再算另外两个的正值大小即可。

**【例 16】**（2024 四川）2018 年 7 月，我国摩托车销量约比上月下降了：

A. 18%　　B. 12%　　C. 6%　　D. 1%

**破题**：同比套环比——环比需要 2018 年 6 月的数据，图中不含，须由"2019 年 7 月同比、2019 年 6 月同比、2018 年 7 月环比"三者串起来（本题图中缺 2019 年 7 月，实际按 `r2 = (r间隔 - r1)/(1+r1)` 反推）。

解析（方法示范）：

1. 设 2019 年 7 月同比为 `r1`、2018 年 7 月环比为 `r间`，则 2019 年 7 月环比 `= (1+r1)(1+r间)/(1+r2019.6) - 1`。
2. 本题可变形为求 2018 年 7 月环比：`r2018.7环比 = (1+r2018.7同比)/(1+r2017.7同比) × (1+r2017.7环比) - 1`。
3. 由于图中只给了 2018.7—2019.6 的同比链，2017 年数据缺失，**本题无法仅凭 OCR 文本定值**；按图中 2018 年 7 月 117.2 万辆与前月水平的量级差，降幅落在 15%—20% 区间，对应 **A.18%**。

> **⚠易错**：本图 OCR 的月份—数值对应不可靠（12 组数值被拉成竖列），**此题请务必对照 PDF 原图核算**，以上仅为方法演示，不作为标准答案依据。

**【例 17】**（2018 国考）2016 年末全国手持船舶订单较同年 2 月末：
材料：2017 年 1—2 月，全国造船完工 936 万载重吨，同比增长 123%；承接新船订单 221 万载重吨，同比增长 133%。2 月末，手持船舶订单 9207 万载重吨，同比下降 22.6%，比 2016 年末下降 7.6%。

A. 降低 16.2%　　B. 降低 2.2%　　C. 增加 16.2%　　D. 增加 2.2%

**破题**：同比套年底（时点链）——`2017.2 → 2016.2` 为 −22.6%（间隔），`2017.2 → 2016 年末` 为 −7.6%（r1），求 `2016 年末 → 2016.2`（r2）。

解析：

1. 判号：`r间隔 = -22.6% < r1 = -7.6%` → r2 < 0，排除 C、D。
2. `r2 = (-22.6% + 7.6%) / (1 - 7.6%) = -15.0% / 0.924 ≈ -16.2%` → **A**。

> **★重点**：两个增速都是负的，"谁更低"要比绝对值——−22.6% 比 −7.6% 更低，说明 2016 年末比 2016 年 2 月末**更高**？不，是 2016 年末**低于** 2016 年 2 月末，故为负 → 降低 16.2%。

## 八、间隔多年增长率

**识别**：2025 年比 2022 年增长百分之几（隔两年以上）。

**方法一：多间隔几次**——逐年套 `r1 + r2 + r1r2`，链式相乘。
**方法二：西瓜 + 芝麻原理**——多个正增长率的乘积，主体（西瓜）由大项决定，小项（芝麻）只做微调。

```
小技巧一：间隔增长率 > 年均增长率 × 年份差
小技巧二：当各年 r > 0 时，间隔多年增长率 > r1 + r2 + … + rn
```

> **★重点**：`(1+r1)(1+r2)…(1+rn) - 1` 恒大于 `r1 + r2 + … + rn`（各项同号为正时）。所以"和"是**下限**，选项若只有一个比"和"大，直接选它。

**【例 18】**（2020 广东）2014—2019 年，我国农民工规模增加了约：

**图　2015—2019 年我国农民工规模及增速**

| 年份 | 2015 | 2016 | 2017 | 2018 | 2019 |
| --- | --- | --- | --- | --- | --- |
| 规模（万人） | 27747 | 28171 | 28652 | 28836 | 29077 |
| 同比增速（%） | 1.3 | 1.5 | 1.7 | 0.6 | 0.8 |

（2018、2019 年增速 OCR 原识为"0.8""1.6"，与"28836/28652 = 1.006""29077/28836 = 1.008"不符，已按相邻年规模反算修正为 0.6、0.8。）

A. 3.2%　　B. 4.8%　　C. 6.2%　　D. 7.8%

**破题**：间隔多年增长率——2014 年需由 2015 年反推，再用首末相除；也可用"和 + 芝麻"。

解析：

1. 2014 年：`27747 / 1.013 ≈ 27395` 万人。
2. `29077 / 27395 - 1 ≈ 6.15%` → **C.6.2%**。

> **★重点**：用"西瓜 + 芝麻"验算——五年增速之和 `= 1.3 + 1.5 + 1.7 + 0.6 + 0.8 = 5.9%`，间隔增长率必**大于**和（各年均为正），故答案 > 5.9%，只有 C 的 6.2% 符合，A、B 可直接排除。

**【例 19】**（2024 全国事业单位）按 2019 年的同比增速推算，未来国内出游人次首次达到或超过 2019 年水平的年份是：

**图　2019—2023 年国内出游人次及其增长速度**

| 年份 | 2019 | 2020 | 2021 | 2022 | 2023 |
| --- | --- | --- | --- | --- | --- |
| 出游人次（亿人次） | 60.1 | 28.8 | 32.5 | 25.3 | 48.9 |
| 比上年增长（%） | 8.4 | -52.1 | 12.8 | -22.1 | 93.3 |

A. 2024 年　　B. 2025 年　　C. 2026 年　　D. 2027 年

**破题**：间隔现期量的连续应用——以 2023 年为基期、按 8.4% 逐年复利，找首次 ≥ 60.1 的年份。

解析：

1. 2024：`48.9 × 1.084 ≈ 53.0` < 60.1
2. 2025：`53.0 × 1.084 ≈ 57.5` < 60.1
3. 2026：`57.5 × 1.084 ≈ 62.3` > 60.1 → **C.2026 年**

> **★重点**：也可用"间隔增长率"跳步——`1.084² ≈ 1.175`，`48.9 × 1.175 ≈ 57.5`（2025 年）；再乘 1.084 即 2026 年。

**【拓展·练习】** 2015 年，我国服务业投资额为 31.19 万亿元，2012—2015 年均增长 15.9%。2015 年我国服务业投资额相当于 2012 年的增长率约为：

A. 16%　　B. 56%　　C. 48%　　D. 32%

**破题**：间隔多年增长率（3 年），`(1 + 15.9%)³ - 1`，用西瓜芝麻原理估算。

解析：

1. 三年"和"：`15.9% × 3 = 47.7%`（下限）。
2. 积的补偿：`1.159³ = 1.159 × 1.343 ≈ 1.556` → 增长 `55.6%` → **B.56%**。

> **★重点**：先算"和"47.7% 排除 A、D；答案必然**大于**和，只剩 C（48%）与 B（56%），再用一次乘法即可定 B。

## 本章小结

```
间隔增长率
├─ 间隔增长率：r间 = r1 + r2 + r1×r2（和 + 积）
│   └─ 速算：|r|均<10% 且和与选项差 1 个百分点以上 → 可丢积
├─ 间隔倍数：是几倍 = r间 + 1；多几倍 = r间
│   └─ 快速法：选项先减 1，转化为求 r间
├─ 间隔基期：现期 / (1 + r间)
│   └─ 差距大估到十位，差距小估到个位，再直除
├─ 间隔现期量：基期 × (1 + r间)：能平方就平方，不能就两步走
├─ 间隔增长量：现期 × r间 / (1 + r间)
├─ 逆向运用（求基期增长率）：r2 = (r间 - r1)/(1 + r1)
│   ├─ r间 > r1 → r2 > 0；r间 < r1 → r2 < 0
│   ├─ 同比套同比：情况一给 r1、r间；情况二给 r1 与两年平均增长率
│   └─ 同比套环比、同比套年底：画两条时间链补齐缺环
└─ 间隔多年增长率（西瓜 + 芝麻）
    ├─ 间隔增长率 > 年均增长率 × 年份差
    └─ 各年 r > 0 时，r间 > r1 + r2 + … + rn（"和"是下限）
```

> **★重点**：整个第七节只有**一个公式**（`r1 + r2 + r1r2`）和**一个逆向式**（`(r间 - r1)/(1 + r1)`）。倍数 +1、基期 ÷(1+r)、增长量 ×r/(1+r)，全部由这一式派生，理解推导即可不必死记。
