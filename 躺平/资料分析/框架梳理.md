## 框架总览

```
资料分析框架
├── 基期      ── 基期量、基期差、基期倍数、基期比重
├── 现期      ── 现期量、现期倍数、现期比重
├── 增长量    ── 增长量计算、增长量比较、年均增长量
├── 增长率    ── 一般增长率、增长率比较
├── 间隔增长率 ── R = r1 + r2 + r1·r2
├── 年均增长率 ── (1+r)^n = 现期/基期
├── 乘积增长率 ── R = a + b + a·b
├── 混合增长率 ── 居中、偏向、线段法
├── 比重      ── 现期比重、基期比重、两期比重升降与差值
├── 平均数    ── 现期平均数、基期平均数、平均数增长率
├── 倍数与比例 ── 是几倍、多几倍、比重转化
├── A与非A    ── 值、增长量、增长率、比重、平均数、倍数
├── 综合分析  ── 找分析、看表述、避陷阱、易到难、敢常识
└── 其他
```

配套练习分两块：**框架自测（练习81—100）**与**模块梳理（各模块例题）**。

## 一、框架自测（练习81—100）

### 【练习81】（2021浙江）

**材料**：2017年，国内旅游市场高速增长，入出境市场平稳发展，供给侧结构性改革成效明显。国内旅游人数50.01亿人次，比上年同期增长12.8%；入出境旅游总人数2.7亿人次，增长3.7%；全年实现旅游总收入5.40万亿元，增长15.1%；全年全国旅游业对GDP的综合贡献为9.13万亿元，占GDP总量的11.04%；旅游直接就业2825万人，旅游直接和间接就业7990万人，占全国就业总人口的10.28%。

**题干**：2016年，全国国内旅游人数约为入出境旅游总人数的多少倍？

A. 17　　B. 19　　C. 21　　D. 23

**破题**：求"基期倍数"——两个量都先化基期，再相除。

**解析**：
分子 `50.01 / (1+12.8%) = 50.01 / 1.128 ≈ 44.34 亿`
分母 `2.7 / (1+3.7%) = 2.7 / 1.037 ≈ 2.60 亿`
倍数 `44.34 / 2.60 ≈ 17.0`，选 **A**。

> **⚠易错**：不能直接用 50.01 / 2.7 = 18.5 选 B——两个量的增速不同（12.8% 与 3.7%），基期倍数必须各自还原。

### 【练习82】（2020山东）

**材料**：2017年，J省实现海水养殖产量93.1万吨，同比增长3%；海洋捕捞产量53万吨，同比下降3.4%；远洋渔业产量2.9万吨，同比增长43.3%。2017年，J省海工装备产值同比增长6.9%。全省沿海地区风电装机容量达到589.7万千瓦，同比增长16.6%；海上风电装机容量达到162.5万千瓦，同比增长46.3%。2017年，全省完成海水淡化产量1.31万吨，同比增长7.4%。

**题干**：2016年J省海水养殖产量约为海洋捕捞产量的：

A. 0.6倍　　B. 0.8倍　　C. 1.6倍　　D. 1.8倍

**破题**：基期倍数，一升一降，分子变大、分母变小。

**解析**：
`93.1 / 1.03 ≈ 90.4`；`53 / (1-3.4%) = 53 / 0.966 ≈ 54.9`
`90.4 / 54.9 ≈ 1.65`，选 **C**。

> **⚠易错**：负增长率做分母要用 `1-3.4%`，误写成 `1+3.4%` 会得 1.53，仍落在 C，但方法错了；若再截位粗放易跳到 1.8（D）。

A. x > 99.5%
B. 88.9% < x < 99.5%
C. 83.8% < x < 88.9%

### 【练习87】（2019国考）

**材料**：图1为2017年3月~2018年2月全国进口药品数量及同比增速，图2为同期全国进口药品金额及同比增速（均为柱状+折线组合图）。

**题干**：2017年第三季度，全国平均每吨进口药品单价约为多少万美元？

A. 2　　B. 19　　C. 8　　D. 96

**破题**：平均数 = 金额 / 数量，取7、8、9三个月合计；注意"亿美元 / 万吨"的量级换算（1亿美元/1万吨 = 1万美元/吨）。

**解析**：
单价（万美元/吨）= 三季度金额（亿美元）÷ 三季度数量（万吨）。
即 `(7月+8月+9月金额) / (7月+8月+9月数量)`，两图形单位恰好抵消为"万美元/吨"，无需再乘除1万。

> **⚠易错**：图表数值 OCR 严重错乱（柱高与折线标签混排），本题**未能可靠还原具体数值**，仅保留解题路径与量级判断（答案量级在个位到十位之间，D 的 96 明显偏大）。建议核对 PDF 第 8 页原图。

### 【练习89】（2025山东事业单位）

**材料**：2024年前三季度，全省固定资产投资同比增长3.9%。分产业看，第一产业投资同比增长15.6%，第二产业投资同比增长15.6%，第三产业投资同比下降3.4%。分领域看，制造业投资同比增长15.0%，高新技术产业投资同比增长20.5%，房地产开发投资同比下降12.2%。2024年前三季度，全省规模以上工业增加值同比增长8.2%。分三大门类看，采矿业增加值同比增长8.2%、制造业同比增长8.7%，电力、热力、燃气及水的生产和供应业同比增长3.5%。分经济类型看，国有控股企业增加值同比增长4.3%，股份制企业同比增长8.9%，外商及港澳台商投资企业同比增长4.4%，私营企业同比增长8.6%。分行业看，装备制造业增加值同比增长8.8%，增速快于全部规模以上工业0.6个百分点。

2024年1—10月，全省规模以上工业增加值同比增长8.3%，较前三季度提高0.1个百分点。其中，10月份同比增长8.7%，较上月提高0.9个百分点。全省规模以上高技术制造业增加值同比增长11.6%，较前三季度提高1.1个百分点，高于上年同期4.8个百分点。全省规模以上装备制造业增加值同比增长9.0%，高于全部规模以上工业0.7个百分点。

**题干**：2023年1—10月全省规模以上工业增加值是2023年前三季度的多少倍？

A. 1.25　　B. 1.05　　C. 1.15　　D. 0.95

**破题**：时间跨度之比 → 1—10月 = 前三季度 + 10月，倍数 ≈ 1 + 10月占比；用 2024 年增速还原 2023 年水平。

**解析**：
`2023年1—10月 = 2024年1—10月 / 1.083`
`2023年前三季度 = 2024年前三季度 / 1.082`
两式相除：倍数 `= (2024年1—10月 / 2024年前三季度) × (1.082/1.083) ≈ 2024年1—10月 / 2024年前三季度`

按"单月约占1—10月的 1/10"估算，`1—10月 / 前三季度 ≈ 10/9 ≈ 1.11`，最接近 **C（1.15）**。

> **⚠易错**：题目问的是**2023年**的倍数，不是增速之比；但两年增速仅差 0.1 个百分点，`1.082/1.083 ≈ 1`，可直接忽略，用 2024 年的量比代替，误差在选项间距之内。

### 【练习90】（2021江苏）

**材料**：2019年，全国居民人均可支配收入30733元，比2000年增长4.4倍。全国居民人均消费支出21559元，比2012年增长78.9%，年均增长8.7%。其中，城镇居民人均消费支出28063元，比2012年增长64.0%；农村居民人均消费支出13328元，比2012年增长99.9%。

**题干**：2019年城镇居民人口占总人口的比重约为：

A. 52.7%　　B. 53.8%　　C. 54.1%　　D. 55.9%

**破题**：加权平均反推权重——"全国人均 = 城镇人均×城镇人口占比 + 农村人均×农村人口占比"。

**解析**：
设城镇人口占比 p：
`28063p + 13328(1-p) = 21559`
`p = (21559-13328) / (28063-13328) = 8231 / 14735 ≈ 55.9%`，选 **D**。

> **★重点**：人均量指标的"混合"用**人口**加权；比重指标（如覆盖率、占比）的混合用**总体量**加权——分母不同，别记混。

### 【练习91】（2019国考）

**材料**：2017年，A省完成高铁客运量17872万人次，旅客周转量474.64亿人公里，同比分别增长20.3%和18.1%。高铁客运量和旅客周转量分别占铁路旅客运输总量的62.7%和54.3%，比重比上年分别提高4.3个和3.9个百分点。

**题干**：2016年，A省高铁客运量约是普铁（除高铁外的铁路）客运量的多少倍？

A. 1.4　　B. 1.7　　C. 0.8　　D. 1.1

**破题**：基期量 + 基期比重 → "高铁/普铁" = 高铁占比 ÷ 非A占比。

**解析**：
2016年高铁占比 `62.7% - 4.3% = 58.4%`，则2016年普铁占比 `1 - 58.4% = 41.6%`。
倍数 `= 58.4% / 41.6% ≈ 1.40`，选 **A**。

### 【练习93】（2017国考）

**材料**：截至2014年末，我国共有博物馆3658个，占文物机构总数的43.5%。全国文物机构拥有文物藏品4063.58万件，比上年末增加222.77万件。其中，博物馆文物藏品2929.97万件，文物商店文物藏品770.00万件。文物藏品中，一级文物9.82万件，二级文物68.82万件，三级文物340.51万件。

## 二、模块梳理

### （一）基期

```
基期量 = 现期量 / (1 + r)
基期差 = A/(1+a) - B/(1+b)
基期倍数 = [A/(1+a)] ÷ [B/(1+b)]
基期比重 = 部分现期 × (1+整体增速) / (整体现期 × (1+部分增速))
```

> **★重点**：求基期，**看到"增长"除、看到"下降"也除**；分母永远是 `1+增长率`（负增长时代入负数）。

### （二）现期

```
现期量 = 基期量 × (1 + r)
现期量 = 基期量 + 增长量
按增速推算未来：现期 × (1+r)^n
```

> **★重点**：题干出现"按……增速推算""若保持……不变"，一律是现期量正推，用乘法；「首次达到/超过」型用不等式试算。

#### 【例6】（2024全国事业单位）

**材料**：

图 2019~2023年国内出游人次及其增长速度

| 年份 | 出游人次（亿人次） | 比上年增长（%） |
| --- | --- | --- |
| 2019 | 60.1 | 8.4 |
| 2020 | 28.8 | -52.1 |
| 2021 | 32.5 | 12.8 |
| 2022 | 25.3 | -22.1 |
| 2023 | 48.9 | 93.3 |

**题干**：按2019年的同比增速推算，未来国内出游人次首次达到或超过2019年水平的年份是：

A. 2024年　　B. 2025年　　C. 2026年　　D. 2027年

**解析**：
`48.9 × (1+8.4%)^n ≥ 60.1` → `1.084^n ≥ 1.229`
n=1：52.99；n=2：57.44；n=3：62.27 ≥ 60.1。
故 2023 年后第 3 年即 **2026年**，选 **C**。

> **★重点**：正推起点必须用**最新年份**（2023），不能从 2019 年往后推；"首次"意味着取满足条件的最小 n。

### （三）增长量

```
增长量 = 现期量 - 基期量
增长量 = 基期量 × r = 现期量 × r/(1+r)
年均增长量 = (末期 - 初期) / 年数差
```

> **★重点**：给"现期+增长率"求增长量，用 `现期×r/(1+r)`（百化分最快）；`r ≈ 1/n` 时增长量 ≈ `现期/(n+1)`。

### （四）增长率

```
增长率 r = (现期 - 基期) / 基期 = 增长量 / 基期 = 现期/基期 - 1
```

> **★重点**：比较增长率大小，用 `现期/基期` 比较即可（减1不影响大小关系）；分数比较用"直除首位"或"分子分母同向变化"。

### （五）间隔增长率

```
间隔增长率 R = r1 + r2 + r1 × r2
反推其中一期：r2 = (1+R)/(1+r1) - 1
```

> **★重点**：`r1、r2` 都小于 10% 时，`r1×r2` 可忽略（<1个百分点）；但两者都大时必须算乘积项，否则答案会偏小一档。

#### 【例1】（2024四川）

**材料**：2022年，全国软件和信息技术服务业规模以上企业超3.5万家，累计完成软件业务收入108126亿元，同比增长11.2%，增速较上年同期回落6.5个百分点。

**题干**：2022年，全国软件和信息技术服务业规模以上企业累计完成软件业务收入约比2020年增长了：

A. 16%　　B. 23%　　C. 29%　　D. 31%

**破题**：求2020→2022的间隔增长率，已知2022年增速与"回落6.5个百分点"。

**解析**：
2021年增速 `= 11.2% + 6.5% = 17.7%`
`R = 11.2% + 17.7% + 11.2%×17.7% = 28.9% + 1.98% ≈ 30.9%`，选 **D**。

> **⚠易错**："回落6.5个百分点"是**加法**还原上年增速；乘积项 1.98% 不能丢，丢了就掉到 29%（C）。

#### 【例6】（2020四川下）

**材料**：2015年国民经济和社会发展统计公报显示，全年全国居民人均可支配收入21966元，比上年增长8.9%，增长率下降1.2个百分点。按常住地分，2015年城镇居民人均可支配收入31195元，比上年增长8.2%，增长率比2014年下降0.8个百分点；农村居民人均可支配收入11422元，比上年增长8.9%，增长率比2014年下降2.3个百分点。

**题干**：2013年，城镇居民人均可支配收入约为多少万元？

A. 1.9　　B. 2.2　　C. 2.6　　D. 3

**破题**：连续两期基期还原，不是间隔增长率公式——要**连除两次**。

**解析**：
2014年增速 `= 8.2% + 0.8% = 9.0%`
2014年 `= 31195/1.082 ≈ 28831 元`
2013年 `= 28831/1.09 ≈ 26450 元 ≈ 2.6 万元`，选 **C**。

> **★重点**：问"某年具体值"用**连除**；问"两年合计增长百分之几"才用**间隔增长率公式**。两者不可混用。

**材料**：2021年上半年，S市工业战略性新兴产业总产值7164.68亿元，比去年同期增长19.6%，两年平均增长12.3%。其中，新能源汽车、新能源和高端装备产值同比分别增长2.5倍、32.1%和24.5%。

**解析**：
两年平均 12.3% → 间隔增长率 `R = 1.123² - 1 ≈ 26.1%`
`r(2020) = 1.261/1.196 - 1 ≈ 5.4%`，不到 7%，选 **A**。

> **★重点**："两年平均增长率"是**几何平均**，还原间隔增长率必须 `(1+r)²-1`，不能 `2r`（用 24.6% 会得 4.2%，虽同选A但方法错）。

### （六）年均增长率

```
(1 + r)^n = 末期量 / 初期量      （n = 年份差）
年均增长量 = (末期 - 初期) / n
```

> **★重点**：比较年均增速大小 → 只需比 `末期/初期`（n 相同时）；n 不同则需开方，可用"平方/立方试算"。

#### 【例3】（2022北京）

**材料**：

| 材料 | 2014 | 2015 | 2016 | 2017 | 2018 | 2019 | 2020 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 金属耐磨材料 | 359 | 363 | 366 | 386 | 401 | 416 | — |
| 陶瓷耐磨材料 | 30 | 25 | 24 | 25 | 26 | 24 | — |
| 树脂耐磨材料 | 50 | 46 | 48 | 51 | 49 | 47 | 48 |

（金属、陶瓷两行末列数值与表头年份的对应在 OCR 中略有错位，首末年份 2014、2020 的取值不受影响）

**题干**：将①金属耐磨材料、②陶瓷耐磨材料和③树脂耐磨材料按2014—2020年消费量年均增速（以2014年为基础）从高到低排列，以下正确的是：

**解析**：
① 金属：359 → 416，上升（倍数 > 1）
② 陶瓷：30 → 24，下降（倍数 0.8，年均约 -3.7%）

### （七）乘积增长率

```
若 C = A × B，则 Rc = Ra + Rb + Ra × Rb
```

> **★重点**：识别标志——"总量 = 单价×数量""收入 = 人数×人均""比重×总量"等**乘积关系**；本质与间隔增长率同式，只是两个因子是不同指标。

#### 【例3】（2022联考）

| --- | --- | --- | --- | --- | --- |

| 2016 | 12363.4 | 5021.8 | 4741.3 | 272.1 | 2328.2 |
| 2017 | 13432.4 | 5498.4 | 5027.8 | 303.0 | 2603.2 |

### （八）混合增长率

```
整体增速介于部分增速之间，且偏向"基期量大"的一方
线段法：量之比 = 增速差的反比（距离与基期量成反比）
```

> **★重点**：判断"某月增速高于累计增速" ⟺ 累计增速比上月上升；判断"比重升降"亦可用同一思路（部分增速 vs 整体增速）。

#### 【例6】（2023广东）

**材料**：2022年，全国居民人均可支配收入36883元，比上年增长（以下如无特别说明，均为同比名义增长）5.0%。分城乡看，城镇居民人均可支配收入49283元，增长3.9%；农村居民人均可支配收入20133元，增长6.3%。

2022年，全国居民人均消费支出24538元，比上年增长1.8%。分城乡看，城镇居民人均消费支出30391元，增长0.3%；农村居民人均消费支出16632元，增长4.5%。

**题干**：2022年，全国居民人均收支盈余比上一年（）。（注：收支盈余 = 收入 - 消费支出）

A. 增加了约5%　　B. 减少了约5%　　C. 增加了约12%　　D. 减少了约12%

**破题**：盈余 = 收入 - 支出，两端都要化基期再做差，不能直接用两个增速。

**解析**：
2022年盈余 `= 36883 - 24538 = 12345 元`
2021年盈余 `= 36883/1.05 - 24538/1.018 ≈ 35127 - 24104 = 11023 元`
增速 `= 12345/11023 - 1 ≈ +12.0%`，选 **C**。

> **⚠易错**：收入增5%、支出增1.8%，两者**相差不大但基数悬殊**（36883 vs 24538），盈余增速会被放大到12%，远高于两者之差。用"5%-1.8%=3.2%"会完全跑偏。

### （九）比重

```
比重 = 部分 / 整体
基期比重 = (部分现期/(1+a)) ÷ (整体现期/(1+b))
两期比重差 = 现期比重 × (a - b)/(1 + a)
升降判定：a > b → 比重上升；a < b → 比重下降
```

> **★重点**：两期比重比较**只看增速**（a 与 b 谁大），不必算具体值；求具体差值才用公式，且差值绝对值通常很小（多以"百分点"计）。

#### 【例6】（2025四川）

**材料**：2023年上半年，全国新注册登记机动车1688万辆，同比增长1.9%。新注册登记汽车1175万辆，同比增长5.8%。其中，新注册登记载客汽车1034万辆，同比增长5.6%；新注册登记载货汽车133万辆，同比增长8.1%。新注册登记新能源汽车313万辆，同比增长41.6%。

2023年6月末，全国机动车保有量4.26亿辆，同比增长4.9%。其中，汽车3.28亿辆，同比增长5.8%；新能源汽车1620万辆，同比增长61.8%。新能源汽车中，纯电动汽车保有量1259万辆，同比增长55.4%；2023年6月末，全国机动车驾驶人为5.13亿人，同比增长4.3%。其中，汽车驾驶人4.75亿人，同比增长4.6%。2023年上半年，全国新领证驾驶人1191万人，同比增长8.0%。

**题干**：2023年6月末，新能源汽车保有量占汽车保有量的比重，比当年上半年新注册登记新能源汽车数量占新注册登记汽车数量的比重约低多少个百分点？

A. 12　　B. 17　　C. 22　　D. 27

**破题**：两个都是"现期比重"，直接各算再相减（不是两期比重差）。

**解析**：
保有量比重 `= 1620/32800 ≈ 4.94%`
新注册比重 `= 313/1175 ≈ 26.64%`
差 `≈ 26.64% - 4.94% = 21.7 个百分点`，选 **C**。

> **★重点**：看清是"存量比重 vs 增量比重"的横向比较，还是"同一比重跨期"的纵向比较——本题是前者，用不到 a、b 公式。
> **⚠易错**：汽车保有量 3.28 亿辆 = 32800 万辆，与新能源 1620 万辆**单位必须统一**，否则差 1 万倍。

### （十）平均数

```
平均数 = 总量 / 份数
基期平均数 = (总量/(1+a)) ÷ (份数/(1+b))
平均数增长率 = (1+a)/(1+b) - 1
```

> **★重点**：平均数增长率只看"总量增速 a"与"份数增速 b"：a > b 则平均数上升。求具体值时才用公式。

#### 【例5】（2019上海）

**材料**：

2007—2016年我国城市天然气供气情况（柱状+折线组合图）：柱为"城市天然气供气总量"（亿立方米），线为"城市天然气用气人口"（万人）。2016年供气总量 1171.72 亿立方米、用气人口 30855.57 万人。

**题干**：2016年我国城市天然气用气人口中，平均每人每月使用天然气约（）立方米。

A. 32　　B. 65　　C. 167　　D. 380

**破题**：平均数 + 时间摊薄，`人均月用量 = 年供气总量 / 用气人口 / 12`。

**解析**：
`1171.72 亿 m³ = 1.17172×10¹¹ m³`，`30855.57 万人 = 3.085557×10⁸ 人`
人均年用量 `= 1.17172×10¹¹ / 3.085557×10⁸ ≈ 379.7 m³`
人均月用量 `= 379.7/12 ≈ 31.6 m³`，选 **A**。

> **★重点**：`亿/万 = 万倍`，即 `1171.72亿 ÷ 30855.57万 ≈ 379.7`——量级换算一次到位，不必写全科学计数法。
> **⚠易错**：题目问"每人**每月**"，漏除12会得 380，正好是 D 项陷阱。

**材料**：

| 月份 | 产量（万吨） | 同比增速（%） |
| --- | --- | --- |
| 1—2月 | 15035 | 29.8 |
| 3月 | 8640 | 3.7 |
| 4月 | 7510 | 8.0 |
| 5月 | 7760 | 0.7 |
| 6月 | 8516 | -4.8 |
| 7月 | 8571 | -2.9 |
| 8月 | 8633 | 1.8 |
| 9月 | 8437 | 1.3 |
| 10月 | 8645 | -0.9 |

**题干**：2023年，平均每个月铁矿石产量约为：

A. 7600万吨以下　　B. 7600万—8000万吨　　C. 8000万—8400万吨　　D. 8400万吨以上

#### 【例18】（2024国考）

**材料**：

2015~2022年我国马铃薯播种面积及产量（柱线组合图）

| 年份 | 2015 | 2016 | 2017 | 2018 | 2019 | 2020 | 2021 | 2022 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 播种面积（万公顷） | 479 | 480 | 486 | 476 | 467 | 466 | 461 | 456 |
| 产量（万吨） | 1770 | 1798 | 1778 | 1798 | 1831 | 1852 | 1699 | 1654 |

**题干**：2018—2022年，我国马铃薯单位面积产量同比增长的年份有几个？

A. 2　　B. 3　　C. 4　　D. 5

**破题**：单位面积产量 = 产量/面积；同比上升 ⟺ `产量增速 > 面积增速`，或直接比两期单产。

**解析**：
逐年单产（吨/公顷，即产量万吨除以面积万公顷）：
2018 `1798/476 ≈ 3.777`
2019 `1831/467 ≈ 3.921`（↑）
2020 `1852/466 ≈ 3.974`（↑）
2021 `1699/461 ≈ 3.685`（↓）
2022 `1654/456 ≈ 3.627`（↓）

2018—2022年间同比上升的有 2019、2020，共 2 个，选 **A**。

> **★重点**：可用"分子增速 vs 分母增速"快速判：2019年产量 +1.8% 而面积 -1.9%，必升；2021年产量 -8.3% 而面积仅 -1.1%，必降。不必逐一精算。

#### 【例19】（2025上海）

**材料**：根据相关数据报告显示，2024年春节档电影总票房达80.16亿元，同比增长18.5%。总观影人次1.63亿，同比增长26.4%。票房、观影人次及场次三项关键数据均创下我国影史新高。

**题干**：2024年春节档的平均票价比2023年春节档的平均票价：

A. 降低了约3元　　B. 降低了约1元　　C. 上涨了约1元　　D. 上涨了约3元

**破题**：平均票价 = 票房/人次，平均数增长率 `(1+a)/(1+b)-1`，a=18.5%（票房），b=26.4%（人次）。

**解析**：
`a < b` → 均价下降。
2024年均价 `= 80.16/1.63 ≈ 49.2 元`
2023年均价 `= (80.16/1.185)/(1.63/1.264) ≈ 67.64/1.289 ≈ 52.5 元`
差 `≈ -3.3 元`，即降低约3元，选 **A**。

> **★重点**：`a=18.5% < b=26.4%` 已能定性（降），再比幅度：`(1.185/1.264-1) ≈ -6.3%`，`52.5×6.3% ≈ 3.3` → 降3元左右，"约3元"而非"约1元"。

#### 【例21】（2025联考）

**材料**：图1为2024年1~11月全国烤烟当期出口额情况，图2为同期全国烤烟当期出口量情况（均为柱状+折线组合图）。

**题干**：2024年11月全国烤烟当期出口均价（出口均价 = 出口额/出口量）的同比增速大约是：

A. 不到20%　　B. 20%—30%　　C. 30%—40%　　D. 超过40%

**破题**：均价 = 出口额/出口量 → 平均数增长率 `(1+a)/(1+b) - 1`，a 为出口额增速、b 为出口量增速。

**解析**：
步骤：① 读11月出口额同比增速 a、出口量同比增速 b；② `均价增速 = (1+a)/(1+b)-1`；③ 对档。

> **⚠易错**：均价增速**不是** a - b，两者都是百分数时须用除式。若 a、b 均为负，`a-b` 与 `(1+a)/(1+b)-1` 方向可能相反。
>
> 图形数值 OCR 错乱（柱高与折线标签混排，11月数据未能可靠归位），建议核对 PDF 第 62 页原图。

### （十一）倍数与比例

```
A 是 B 的 n 倍：n = A/B
A 比 B 多 n 倍：n = A/B - 1
比重 ↔ 倍数转化：A占总体 50% ⟺ A=非A；66.7% ⟺ A=2×非A；75% ⟺ A=3×非A
```

> **★重点**："是几倍"与"多几倍"差 1，是本模块最高频的失分点；选项里往往同时出现 n 和 n-1。

#### 【例6】（2025联考）

**材料**：2023年，我国东部地区11个省（区、市）纸及纸板产量为8843万吨，占全国纸及纸板产量比例为68.2%，同比增长5.44%；中部地区8个省占比为19.2%，同比增长2.51%；西部地区12个省（区、市）占比为12.6%，同比增长1.43%。我国有18个省（区、市）纸及纸板产量超过100万吨，产量合计12597万吨，占全国纸及纸板总产量的97.16%。

**题干**：2023年我国东部地区纸及纸板产量与中部地区相比约多：

A. 4倍以上　　B. 3—4倍　　C. 2—3倍　　D. 1—2倍

**破题**：同一整体下，产量之比 = 占比之比，无需先求全国总量。

**解析**：
`东部/中部 = 68.2%/19.2% ≈ 3.55`（是3.55倍）
"多"的倍数 `= 3.55 - 1 = 2.55`，落在 2—3 倍，选 **C**。

> **⚠易错**：题干是"**多**几倍"，必须减1。不减则 3.55 落在 B（3—4倍）——这就是设 B 项的原因。

#### 【例13】（2025上海）

**材料**：

图1 2011~2022年中国音乐著作权协会会员人数及许可收入金额（柱线组合图，柱为"许可收入（万元）"，线为"会员数（人）"）。

**题干**：2022年，中国音乐著作权协会平均每名会员的许可收入约是2011年的（）倍。

A. 0.9　　B. 2.5　　C. 3.0　　D. 3.5

**破题**：平均数之比 =（2022年收入/2022年会员）÷（2011年收入/2011年会员），四个数都要读准。

**解析**：
步骤：① 读2011年、2022年的许可收入与会员数；② 分别求"人均许可收入"；③ 相除。

> **⚠易错**：这是"平均数再相除"，不是"收入倍数"也不是"会员倍数"。图中柱（万元）与线（人）量级差很大，OCR 提取的数值系列（8889、10992、11226、13737…及 6523、6903、7301、7700…）无法确定年份归属，**本题未可靠还原**，建议核对 PDF 第 65 页原图。

#### 【例17】（2024联考）

**材料**：

2013~2022年全国亿元以上食品、饮料及烟酒市场成交情况　单位：亿元

| 时间 | 总计 | 食品饮料市场 | 茶叶市场 | 烟酒市场 | 其他市场 |
| --- | --- | --- | --- | --- | --- |
| 2013年 | 1675 | 753 | 244 | 74 | 604 |
| 2014年 | 1314 | 399 | 247 | 76 | 592 |
| 2015年 | 1283 | 359 | 269 | 73 | 582 |
| 2016年 | 1345 | 343 | 279 | 110 | 613 |
| 2017年 | 1207 | 309 | 255 | 105 | 538 |
| 2018年 | 1200 | 275 | 297 | 107 | 521 |
| 2019年 | 1152 | 208 | 308 | 105 | 531 |
| 2020年 | 1057 | 208 | 292 | 49 | 508 |
| 2021年 | 1133 | 230 | 346 | 50 | 507 |
| 2022年 | 1098 | 228 | 354 | 45 | 470 |

（校验：各年"食品饮料+茶叶+烟酒+其他 = 总计"均成立，表结构可靠）

**题干**：2016—2018年，全国亿元以上茶叶市场成交总额占食品、饮料及烟酒市场成交总额的比重为：

A. 不到15%　　B. 15%—20%　　C. 20%—25%　　D. 超过25%

**破题**：多年比重 = 各年分子求和 ÷ 各年分母求和（**先加总再相除**，不是各年比重取平均）。

**解析**：
茶叶 2016—2018：`279+255+297 = 831`
总计 2016—2018：`1345+1207+1200 = 3752`
比重 `= 831/3752 ≈ 22.1%`，落在 20%—25%，选 **C**。

> **⚠易错**：不能求三年比重的算术平均（`20.7%+21.1%+24.8%` 平均≈22.2%，恰好接近），但分母逐年变化时必须"先合后除"才是正确定义。

#### 【例22】（2024国考）

**材料**：2022年12月，全国规模以上工业企业的工业机器人完成产量4万套，服务机器人完成产量49.1万套。2022年1—12月全国规模以上工业企业的工业机器人累计完成产量44.3万套，服务机器人累计完成产量645.8万套。

**题干**：2022年12月，全国规模以上工业企业的①工业机器人完成产量和②服务机器人完成产量：

A. 均高于1—11月的月均水平
B. 均低于1—11月的月均水平
C. 仅①高于1—11月的月均水平
D. 仅②高于1—11月的月均水平

**破题**：`12月 vs (1—12月累计 - 12月)/11`。

**解析**：
① 工业机器人：1—11月 `44.3-4 = 40.3`，月均 `40.3/11 ≈ 3.66` 万套；12月 4 万套 > 3.66，**高于**。
② 服务机器人：1—11月 `645.8-49.1 = 596.7`，月均 `596.7/11 ≈ 54.2` 万套；12月 49.1 万套 < 54.2，**低于**。

仅①高于，选 **C**。

> **★重点**：等价判断式——`12月×12 > 全年累计` 则高于月均。① `4×12=48 < 44.3`? 不成立，故用减法更稳；判断量级时可用"12月×11 >（累计-12月）"。

#### 【例23】（2023广东）

**材料**：2022年，全国居民人均可支配收入36883元，比上年增长（以下如无特别说明，均为同比名义增长）5.0%。分城乡看，城镇居民人均可支配收入49283元，增长3.9%；农村居民人均可支配收入20133元，增长6.3%。

**题干**：2022年，我国城镇居民与农村居民人数之比最接近：

A. 2:3　　B. 3:2　　C. 3:4　　D. 4:3

**破题**：人均量加权反推人数结构；权重用**基期**人数（近似等于现期）。

**解析**：
`49283p + 20133(1-p) = 36883` → `p = (36883-20133)/(49283-20133) = 16750/29150 ≈ 0.575`
城镇:农村 `≈ 0.575 : 0.425 ≈ 1.35 ≈ 4:3`，选 **D**。

> **★重点**：权重应取"基期人数"，本题两年人数结构变化极小，可直接用现期人均值近似；若严格用2021年数据（47432、18939）反推，p≈0.568，结果同样是 4:3。

### （十二）A与非A

```
总体 = A + 非A
总体的增长量 = A的增长量 + 非A的增长量
总体的增长率 = 混合增长率（居中、偏向、线段法）
A占总体比重 + 非A占总体比重 = 100%
```

> **★重点**：识别标志——"非……""规模以下""除……以外""其他""限额以下"。看见这些词，先想"总数 - 已知部分"。

#### 【例4】（2024山东）

**材料**：2022年，风电、光伏年发电量首次突破1万亿千瓦时，达到1.19万亿千瓦时，较2021年增加2073亿千瓦时，同比增长21%，占全社会用电量的13.8%，同比提高2个百分点，接近全国城乡居民用电量。2022年，可再生能源发电量达到2.72万亿千瓦时，占全社会用电量的比重为31.6%，较2021年提高1.7个百分点，可再生能源在保障能源供应方面发挥的作用越来越明显。

**题干**：2021年，除风电、光伏发电外的可再生能源发电量及其占全社会用电量的比重约为：

A. 1.36万亿千瓦时，18.1%
B. 1.36万亿千瓦时，14.2%
C. 1.51万亿千瓦时，18.1%
D. 1.51万亿千瓦时，14.2%

**破题**：A与非A ——"除风光外的可再生" = 可再生 - 风光；占比 = 31.6%-13.8% 的基期值，两者都先化2021年。

**解析**：
2021年风光发电量 `= 1.19 - 0.2073 = 0.9827 万亿千瓦时`，占比 `= 13.8% - 2% = 11.8%`
→ 2021年全社会用电量 `= 0.9827/11.8% ≈ 8.328 万亿千瓦时`
2021年可再生占比 `= 31.6% - 1.7% = 29.9%`，除风光占比 `= 29.9% - 11.8% = 18.1%`
除风光发电量 `= 8.328 × 18.1% ≈ 1.51 万亿千瓦时`

选 **C**。

> **★重点**：先用"占比 + 用量"互推总盘子（`0.9827÷11.8%`），再乘目标占比——比分别还原分子分母快得多。
> **⚠易错**：`29.9%-11.8%=18.1%` 是**百分点相减**，两个占比的基期都是同一年（2021），可以直接减；不可用现期 31.6%-13.8%=17.8%。

#### 【例7】（2024广东事业单位）

**材料**：

| 年份 | 海水养殖（万吨） | 海洋捕捞（万吨） | 海水产品合计（万吨） |
| --- | --- | --- | --- |
| 2018 | 316.73 | 139.83 | 456.56 |
| 2019 | 329.13 | 126.36 | 455.49 |

（原图图例顺序为"海洋捕捞 / 海水养殖"，但按数值走势——养殖逐年上升、捕捞逐年下降——已按实际对应归位；合计列为两值相加）

**题干**：2018年—2021年，广东省海水养殖产量占海水产品产量比重最高的是（）。

A. 2018年　　B. 2019年　　C. 2020年　　D. 2021年

**破题**：比重 = 养殖/(养殖+捕捞)；分子逐年增、分母基本持平 → 比重单调上升，最高年份即最末年。
