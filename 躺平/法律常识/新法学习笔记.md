## 一、公务员法

### 不得录用为公务员的情形 ⭐
1. 因犯罪**受过刑事处罚**的；
2. **被开除中国共产党党籍**的；
3. **被开除公职**的；
4. 被依法列为**失信联合惩戒对象**的；
5. 有法律规定不得录用的其他情形。

### 奖励
- 种类（由低到高）⭐：**嘉奖、记三等功、记二等功、记一等功、授予称号**。
- 对受奖励的公务员或集体予以表彰，对个人给予**一次性奖金或其他待遇**。

### 处分 ⭐⭐

| 要点 | 内容 |
| --- | --- |
| 种类（6 种） | **警告、记过、记大过、降级、撤职、开除** |
| 晋升限制 | 受处分期间**不得晋升职务、职级和级别**；其中受**记过、记大过、降级、撤职**的，**不得晋升工资档次** |
| 处分期间 ⭐ | 警告 **6 个月**；记过 **12 个月**；记大过 **18 个月**；降级、撤职 **24 个月** |
| 撤职 | 受撤职处分的，按照规定**降低级别** |
| 解除 | 受**开除以外**处分，期间有悔改表现且无再违纪违法行为 → 处分期满**自动解除** |
| 解除效果 | 解除后晋升不再受影响；**但解除降级、撤职处分不视为恢复原级别、原职务、原职级** ⭐ |

### 复核与申诉 ⭐（记数字）
- 对涉及本人的人事处理不服：**知道之日起 30 日内**向**原处理机关申请复核**；
- 对复核结果不服：**接到复核决定之日起 15 日内**，向**同级公务员主管部门**或**上一级机关**申诉；
- 也可**不经复核**，自知道之日起 **30 日内直接申诉**。

## 二、公职人员政务处分法

- 处分种类与期间与公务员法一致：**警告 6 个月、记过 12 个月、记大过 18 个月、降级/撤职 24 个月**（6 种：警告、记过、记大过、降级、撤职、开除）⭐。
- **复审复核** ⭐：
  - 对**监察机关**作出的政务处分不服 → 向**作出决定的监察机关申请复审**；仍不服 → 向**上一级监察机关申请复核**；
  - 监察机关发现处分确有错误 → 及时纠正或责令下级纠正；
  - **复审、复核期间，不停止原政务处分决定的执行** ⭐；
  - **不因提出复审、复核而被加重政务处分** ⭐。

## 三、监察法（新修订亮点）⭐⭐

### 1. 增设"再派出"制度
- 各级监委可向本级党的机关、国家机关、政协机关、法律法规授权或委托管理公共事务的组织单位及辖区内特定区域、国企、事业单位**派驻或派出**监察机构、监察专员。
- **再派出**三类（均须**经国家监察委员会批准**）⭐：
  1. 国家监委派驻**垂直管理或双重领导以上级为主**的单位、国企的监察机构 → 可向**下一级单位**再派出（例：国家监委派驻海关总署 → 可向青岛海关再派出）；
  2. 国家监委派驻监察机构 → 可向驻在单位**管理领导班子的普通高等学校**再派出（例：派驻教育部 → 可向北京大学再派出）；
  3. 国家监委派驻国务院国资委的监察机构 → 可向驻在单位管理领导班子的**国有企业**再派出（例：可向国家电网再派出）。

### 2. 新增三项监察强制措施 ⭐⭐（重点：时限）

| 措施 | 适用 | 时限 |
| --- | --- | --- |
| **强制到案** | 涉嫌**严重职务违法或职务犯罪**的被调查人 | 持续不超过 **12 小时**；需采取**管护或留置**的，不超过 **24 小时**；**不得以连续强制到案变相拘禁** |
| **责令候查** | 不符合留置条件，或符合留置条件但**患严重疾病生活不能自理 / 怀孕或正在哺乳自己婴儿的妇女 / 生活不能自理者的唯一扶养人**；留置期满不需继续留置；案件特殊情况更适宜候查 | **最长不得超过 12 个月** |
| **管护** | 未留置人员（**自动投案**、**谈话函询询问中交代**、**讯问中主动交代重大职务犯罪**）存在**逃跑、自杀**等重大安全风险 | 采取后**立即送留置场所，至迟不超过 24 小时**；**7 日内**作出留置或解除决定，特殊情况可**延长 1–3 日** |

- 三项措施均须经**监察机关主要负责人批准**。
- **责令候查人员义务**：未经批准**不得离开所居住的市/县辖区**；住址、工作单位、联系方式变动 **24 小时内报告**；接到通知及时到案；**不得干扰证人作证**；**不得串供或伪造、隐匿、毁灭证据**；违反情节严重的**可以依法留置**。

### 3. 留置 ⭐⭐⭐（原有核心考点）

| 项目 | 内容 |
| --- | --- |
| 适用情形 | 涉嫌**贪污贿赂、失职渎职**等严重职务违法/犯罪，已掌握部分违法犯罪事实及证据，仍有重要问题需进一步调查，且：①案情**重大复杂**；②可能**逃跑、自杀**；③可能**串供或伪造、隐匿、毁灭证据**；④可能**有其他妨碍调查行为** |
| 涉案人员 | 对涉嫌**行贿犯罪或共同职务犯罪**的涉案人员也可留置 ⭐ |
| 决定主体 | 由监察机关**领导人员集体研究决定** ⭐ |
| 批准/备案 | **设区的市级以下**监委留置 → 报**上一级监委批准**；**省级**监委留置 → 报**国家监委备案** ⭐ |
| 执行配合 | 可提请**公安机关配合** |
| 期限 ⭐⭐ | **不超过 3 个月**；特殊情况**可延长一次，不超过 3 个月**；省级以下延长须报**上一级监委批准**。**可能判处 10 年以上有期徒刑**的，延长期限届满仍不能调查终结 → 经**国家监委批准或决定可再延长 2 个月**；省级以上监委发现**不同种重大职务犯罪**（或影响罪名认定、量刑档次的同种重大犯罪）→ 经国家监委批准或决定，**自发现之日起重新计算**留置时间，**重新计算以一次为限** |
| 解除 | 发现留置不当或无需继续 → **及时解除或变更为责令候查** |

### 4. 强化自身建设
- **特约监察员**：从各方面代表中聘请，对监察机关及其工作人员履职情况实行监督。
- **禁闭措施** ⭐：监察人员涉嫌严重职务违法/犯罪，经依法审批可禁闭，**期限不得超过 7 日**；调查发现符合管护或留置条件的可转为**管护或留置**。

「考」2022 国考（哪一处分**不恰当**）：依《政务处分法》，被**单处罚金**（丙，盗窃罪）——受刑事处罚被判处管束刑以上？规则：故意犯罪被判处刑罚的一般应**开除**；而**过失犯罪**被判处缓刑等可撤职以下。逐项分析：A 故意伤害罪（故意犯罪）被判有期徒刑缓刑 → 应当**开除**而非撤职，**处分畸轻、不恰当**；B 交通肇事属**过失**犯罪情节轻微不起诉 → 撤职可；C 盗窃**单处罚金** → 按"被单处罚金的，予以撤职以上（含开除）"?，实务判例给撤职可以（课件真题答案 A）；D 免予刑事处罚 → 撤职恰当。→ 选 **A**

## 四、能源法（2025.1.1 施行）⭐

| 板块 | 要点 |
| --- | --- |
| **总则** | 国家建立**能源消耗总量和强度双控 → 碳排放总量和强度双控**全面转型新机制 ⭐；建立**主体多元、统一开放、竞争有序、监管有效**的能源市场体系 |
| **能源规划** | 体系：全国**综合**能源规划、全国**分领域**能源规划、**区域**能源规划、**省级**能源规划。全国综合规划由**国务院能源主管部门会同有关部门**编制；跨省区域规划可由国务院能源主管部门会同有关部门**和有关省级政府**编制；调整须**报原批准机关同意** |
| **开发利用** ⭐ | ①**优先开发利用可再生能源**，合理开发和清洁高效利用化石能源，提高**非化石能源**消费比重；②制定可再生能源消费**最低比重目标**；③统筹水电开发与生态保护，**严格控制开发建设小型水电站**；④风能太阳能：**集中式与分布式并举**，合理有序开发**海上风电**，积极发展**光热发电**；⑤鼓励**生物质能**，促进**海洋能**规模化，因地制宜发展**地热能**；⑥**积极安全有序发展核电**；⑦发挥**煤炭**在能源供应体系中的**基础保障和系统调节**作用；⑧油气**陆上与海上并重**，鼓励**非常规油气**（致密油气、页岩油、页岩气、煤层气）；⑨重点支持**革命老区、民族地区、边疆地区、欠发达地区**农村能源；⑩农村临时能源短缺 → **优先保障农村生活用能和农业生产用能** |
| **市场体系** | **自然垄断环节独立运营**和**竞争性环节市场化**改革；能源价格主要由资源状况、成本、供求、可持续发展决定；政府定价/指导价以**中央和地方定价目录**为依据 |
| **储备应急** ⭐ | 原则：**政府主导、社会共建、多元互补**；**政府储备 + 企业储备**相结合，**实物储备 + 产能储备、矿产地储备**相统筹；政府储备=中央+地方；企业储备=**社会责任储备**+其他生产经营库存；应急体制：**统一领导、分级负责、协调联动** |
| **科技创新** | 以**国家战略科技力量为引领、企业为主体、市场为导向、产学研深度融合** |
| **监督管理** | 被检查单位应配合，不得拒绝阻碍；对知悉的国家秘密、商业秘密、个人隐私、个人信息负**保密义务**；**能源输送管网接入使用争议** → 可由**省级以上能源主管部门协调**，协调不成可起诉，也**可直接起诉** |

## 五、学位法（2025.1.1 施行）⭐⭐

| 板块 | 要点 |
| --- | --- |
| **学位制度** | 学位分**学士、硕士、博士**；包括**学术学位、专业学位**等类型。学术学位突出**学术研究能力**，专业学位突出**专业实践能力** ⭐ |
| **学位评定委员会** ⭐ | 由**高级专业技术职务**的负责人、教学科研人员组成；成员**不少于 9 人的单数**；**主席由学位授予单位主要行政负责人担任** |
| **学位授予资格** ⭐⭐ | 高等学校：可申请学士、硕士、博士资格；**科学研究机构：只能申请硕士、博士**（无学士）。审批：学士 → **省级学位委员会审批，报国务院学位委员会备案**；硕士 → 省级学位委员会组织**审核**，报**国务院学位委员会审批**；博士 → **国务院教育行政部门组织审核**，报**国务院学位委员会审批** |
| **授予程序** ⭐ | ①学士：学位评定委员会组织**审查**作出决议；②硕博：答辩前学位论文/实践成果**送专家评阅**，合格才进入答辩；③**硕士答辩委员会 ≥3 人；博士 ≥5 人（其中外单位专家 ≥2 人）**；④答辩**当场宣布决议**；**投票表决，全体组成人员 2/3 以上通过**；除涉及国家秘密外**答辩公开举行** |
| **不授予/撤销学位情形** ⭐ | ①学位论文或实践成果存在**代写、剽窃、伪造**等学术不端；②**盗用、冒用他人身份顶替**取得入学资格，或以其他非法手段取得入学资格、毕业证书；③攻读期间存在依法不应授予学位的其他严重违法行为 |
| **争议解决** ⭐ | 对**学术评价结论**（专家评阅、答辩、成果认定）有异议 → 向学位授予单位申请**学术复核**，**复核决定为最终决定**；对**不受理申请、不授予或撤销学位**不服 → 向学位授予单位申请复核，**或请求有关机关依法处理**（可走行政途径） |

## 六、学前教育法（2025.6.1 施行）⭐⭐

| 板块 | 要点 |
| --- | --- |
| **总则** | 学前教育 = 对**三周岁到入小学前**儿童的保育和教育；坚持**政府主导，以政府举办为主**，大力发展**普惠性**学前教育；**国务院领导**全国学前教育工作 |
| **学前儿童** ⭐ | ①坚持**最有利于学前儿童**原则，特殊、优先保护；②入园**除必要身体健康检查外，不得组织任何形式的考试或测试** ⭐；③普惠性幼儿园应接收**能够适应幼儿园生活的残疾儿童**；④任何单位和个人不得组织学前儿童参与**违背身心发展规律或与年龄特点不符**的商业性活动、竞赛类活动 |
| **幼儿园** ⭐⭐ | ①政府扩大**普惠性资源**供给；②应设立**家长委员会**（提意见建议、监督保教与日常管理）；③**不得利用财政性经费、国有资产、集体资产或捐赠资产**举办或参与举办**营利性民办园**；④**公办园不得转制为民办园**，不得举办/参与举办营利性民办园和其他教育机构；⑤**社会资本不得通过兼并收购等方式控制公办园、非营利性民办园**；⑥**幼儿园不得直接或间接作为企业资产在境内外上市**；上市公司不得通过股票市场融资投资营利性民办园、不得通过发行股份或支付现金购买其资产 |
| **教职工** ⭐ | 聘任时应向**教育、公安等部门查询**应聘者有无**虐待、性侵害、性骚扰、拐卖、暴力伤害、吸毒、赌博**等违法犯罪记录 → 有记录或酗酒、严重违反师德师风等危害儿童身心安全情形的**不得聘任**；在岗发现 → **立即停止工作、依法解除合同**并报告县级教育行政部门，可纳入**从业禁止人员名单**；有相关情形者**不得举办幼儿园** |
| **保育教育** ⭐⭐ | ①**把保护学前儿童安全放在首位**；②发现儿童受侵害/疑似受侵害/面临危险 → 立即保护并向**公安、教育等部门报告**；③**不得采用小学化教育方式，不得教授小学阶段课程**；**小学坚持按课程标准零起点教学**；④**校外培训机构等其他任何机构不得对学前儿童开展半日制或全日制培训**，不得教授小学阶段课程 |
| **投入保障** | **政府投入为主、家庭合理负担、多渠道筹措经费**；有条件的地方**逐步推进免费学前教育** ⭐ |

## 七、科学技术普及法【修订】（2024.12.25 施行）⭐

| 亮点 | 内容 |
| --- | --- |
| 亮点 1 ⭐ | 把科普放在**与科技创新同等重要**的位置；**每年 9 月为全国科普月** |
| 亮点 2 | 发展科普事业是国家长期任务；构建**政府、社会、市场协同推进**格局；开放大学、老年大学、老年科技大学、社区学院等应提升**老年人、残疾人**信息获取、识别和应用能力 |
| 亮点 3 | 新增"**科普活动**"一章：国家部署实施**新技术领域重大科技任务**，符合保密前提下可组织必要科普；鼓励职业培训、农民技能培训、干部教育培训中**增加科普内容**；完善科普工作**评估体系**和公民科学素质**监测评估体系** |
| 亮点 4 ⭐ | **治理网络伪科普**：科普产品和服务、发布的科普信息应具有**合法性、科学性**，不得有虚假错误内容；对**传播范围广、社会危害大**的虚假信息，主管部门应**及时澄清纠正**；**网络服务提供者**发现用户传播虚假错误信息应**立即处置、防止扩散** |
| 亮点 5 | 新增"**科普人员**"专章：科技人员 and 教师应积极参与科普，**科技领军人才和团队应带头开展科普**；鼓励老年科技人员参与；支持高校、职业学校设置**科普相关学科专业**；完善**科普志愿服务制度**；健全科普人员**评价、激励**机制（符合科普特点的职称评定、绩效考核） |

## 八、文物保护法【修订】（2025.1.1 施行）⭐⭐

| 亮点 | 内容 |
| --- | --- |
| 亮点 1 ⭐⭐ | 新增保护前置机制：地上文物"****先调查、后建设**"**（旧城改建、土地成片开发须先进行不可移动文物调查，**未经调查任何单位不得开工建设**）；地下文物"**先考古、后出让**"（土地出让或划拨前，由**省级文物行政部门**组织考古调查、勘探；可能存在地下文物的区域由省级文物行政部门**划定并动态调整**） |
| 亮点 2 ⭐ | 文物分类：**不可移动文物**（古文化遗址、古墓葬、古建筑、石窟寺、古石刻、古壁画、近现代重要史迹和代表性建筑）与**可移动文物**。不可移动文物分为**文物保护单位**和**未定级不可移动文物**；文物保护单位分为**全国重点、省级、设区的市级、县级**。未定级不可移动文物由**县级政府文物行政部门登记**，报本级政府和上一级文物行政部门**备案**，并向社会公布。原址保护措施按文保单位级别报相应文物部门**批准**，未定级的报**县级文物行政部门**批准，未经批准不得开工；未定级文物迁移异地保护或拆除 → 报**省级文物行政部门批准** |
| 亮点 3 ⭐ | 新增**地下文物埋藏区**和**水下文物保护区**制度：由**省级政府**划定、制定保护措施并公告施行；**涉及两个以上省份**或**涉及中国领海以外由中国管辖的其他海域**的 → 由**国务院文物行政部门**划定并制定措施，**报国务院核定公布** |
| 亮点 4 ⭐⭐ | **流失海外中国文物追索**：国家加强国际合作，国务院文物行政部门会同有关部门对因**被盗、非法出境**等流失境外的文物开展追索；对非法流入中国境内的外国文物，根据条约、协定、协议或对等原则开展返还合作；**国家对于流失境外的文物保留收回的权利，且该权利不受时效限制** |

## 九、粮食安全保障法（2024.6.1 施行）⭐

| 板块 | 要点 |
| --- | --- |
| **耕地保护** ⭐ | 建立**耕地保护补偿制度**、实行**占用耕地补偿制度**；**严格控制耕地转为林地、草地、园地等其他农用地**；**禁止违规占用耕地绿化造林、挖湖造景**；禁止在国家批准退耕还林还草计划外擅自扩大退耕范围；耕地**应当主要用于粮食和棉、油、糖、蔬菜等农产品及饲草饲料生产**；发现违反种植用途管控 → 村委会、农村集体经济组织应**及时向乡镇政府或县级农业农村主管部门报告** |
| **粮食生产** ⭐ | **省级以上政府建立种子储备制度**（灾害时生产需要及余缺调剂）；**主产区、主销区、产销平衡区都要保面积、保产量**：主产区不断提高**综合生产能力**，主销区稳定和提高**自给率**，产销平衡区确保**基本自给**；健全**主产区利益补偿机制**，完善对主产区和**产粮大县**的财政转移支付 |
| **粮食储备** ⭐⭐ | 政府粮食储备分**中央储备和地方储备**，用途：**调节供求、稳定市场、应对突发事件**；承储企业实行**储备与商业性经营业务分开**；**承储中央储备和省级储备的企业应当剥离商业性经营业务** ⭐；**专仓储存、专人保管、专账记载**，不得虚报瞒报数量、质量、品种；县级以上政府应将粮食储备情况列为**年度国有资产报告内容**，向**本级人大常委会**报告 |
| **粮食流通** | 不得侵占、损毁、擅自拆除或迁移**政府投资建设**的粮食流通基础设施，不得擅自改变用途；收购储存加工销售经营者及饲料、工业用粮企业应建立**粮食经营台账**并报送数据；国家建立**粮食风险基金制度**（用于支持储备、稳定市场等） |
| **粮食加工** ⭐ | 重点支持在**粮食生产功能区和重要农产品生产保护区**发展加工业；不得掺杂使假、以次充好；**优先保障口粮加工**，饲料用粮、工业用粮加工**应当服从口粮保障** |
| **粮食应急** | 体制：**统一领导、分级负责、属地管理为主**；建立**粮食市场异常波动报告制度**；完善**政策性农业保险**制度，鼓励商业性保险 |
| **粮食节约** | **禁止故意毁坏在耕地上种植的粮食作物青苗** ⭐；公民个人和家庭树立文明、健康、理性、绿色消费理念 |
| **监督管理** ⭐ | **任何单位和个人不得编造、散布虚假的粮食安全信息**；建立**粮食质量安全追溯体系**；**省级党政对本行政区域耕地保护和粮食安全负总责，其主要负责人是第一责任人**；建立**粮食生产经营者信用记录** |

## 十、农村集体经济组织法（2025.5.1 施行）⭐⭐

| 板块 | 要点 |
| --- | --- |
| **种类及地位** | 包括**乡镇级、村级、组级**农村集体经济组织；依法登记取得**特别法人**资格 ⭐ |
| **成员确认** ⭐ | 因成员**生育**而增加的人员 → **应当**确认为成员；因**结婚、收养、政策性移民**而增加的人员 → **一般应当**确认为成员 |
| **成员身份丧失** ⭐⭐ | ①死亡；②**丧失中华人民共和国国籍**；③已取得其他农村集体经济组织成员身份；④**已经成为公务员**（**聘任制公务员除外**）；⑤法律法规和章程规定的其他情形 |
| **不因以下原因丧失** ⭐⭐ | **就学、服役、务工、经商、离婚、丧偶、服刑** |
| **争议解决** ⭐ | 成员身份异议或内部管理、运行、收益分配纠纷 → 可请求**乡镇政府、街道办事处或县级农业农村主管部门调解**；不愿调解或调解不成 → 向**农村土地承包仲裁机构申请仲裁**，或**直接向法院起诉** |
| **妇女权益保护** ⭐ | 确认成员身份时侵害妇女合法权益**导致社会公共利益受损**的 → **检察机关可以发出检察建议或依法提起公益诉讼** |

## 十一、关税法（2024.12.1 施行）⭐

| 板块 | 要点 |
| --- | --- |
| **适用范围** | 对准许进出口的货物、进境物品由**海关**依法征收关税 |
| **纳税人** ⭐ | 进口货物的**收货人**、出口货物的**发货人**、进境物品的**携带人或收件人** |
| **扣缴义务人** ⭐ | 从事**跨境电子商务零售进口**的**电子商务平台经营者、物流企业和报关企业**，以及法律规定负有代扣代缴、代收代缴义务的单位和个人 |
| **免征关税** ⭐⭐ | ①国务院规定的**免征额度内的一票货物**；②**无商业价值的广告品和货样**；③进出境运输工具装载的**途中必需的燃料、物料和饮食用品**；④**在海关放行前损毁或者灭失**的货物、进境物品；⑤**外国政府、国际组织无偿赠送**的物资；⑥我国缔结或参加的国际条约协定规定免征的；⑦其他依法免征的 |
| **减征关税** | ①**在海关放行前遭受损坏**的货物、进境物品（注意与免征"损毁或灭失"区分）；②条约协定规定减征的；③其他依法减征的 |
| **专项优惠** | **国务院**可根据国家利益、对外交往、经济社会发展、科技创新需要或突发事件等制定关税专项优惠政策，**报全国人大常委会备案** ⭐ |
| **特殊情形** ⭐ | 因**品质、规格原因或不可抗力**：出口货物自出口之日起**1 年内原状复运进境** → 不征进口关税；进口货物自进口之日起 **1 年内原状复运出境** → 不征出口关税。因残损、短少、品质不良或规格不符，由发货人、承运人或保险公司**免费补偿或更换的相同货物**，进出口时不征关税；被免费更换的原货物不退运的，海关对原进出口货物**重新征收关税**；纳税人应在合同约定请求赔偿期限内且**不超过原进出口放行之日起 3 年内**申报办理 |
| **征收管理** ⭐ | 可实施**货物放行与税额确定相分离**模式；可**选择海关**办理申报纳税；允许**汇总缴纳税款**；**多缴税款申请退税期限由 1 年延长为 3 年** ⭐；维持反倾销、反补贴、保障措施和报复性关税，并新增：对**不履行与我国条约协定中最惠国待遇条款或关税优惠条款**的国家和地区，可按**对等原则**采取相应措施 |

## 十二、增值税法（2026.1.1 施行）⭐⭐

### 1. 应税交易
**境内**发生应税交易的判断 ⭐：
1. 销售**货物** → 货物**起运地或所在地**在境内；
2. 销售或租赁**不动产**、转让**自然资源使用权** → 不动产、自然资源**所在地**在境内；
3. 销售**金融商品** → 在境内**发行**，或**销售方**为境内单位和个人；
4. 销售**服务、无形资产**（除上两项外）→ 在**境内消费**，或**销售方**为境内单位和个人。

**视同应税交易**（需缴增值税）⭐：①单位和个体工商户将**自产或委托加工**的货物用于**集体福利或个人消费**；②单位和个体工商户**无偿转让货物**；③单位和个人**无偿转让无形资产、不动产或金融商品**。

**不属于应税交易、不征增值税** ⭐⭐：①**员工为受雇单位或雇主提供取得工资、薪金的服务**；②收取**行政事业性收费、政府性基金**；③依照法律规定**被征收、征用而取得补偿**；④取得**存款利息收入**。

### 2. 税率 ⭐⭐⭐
- **四档税率：13%、9%、6%、0**（0 税率：①纳税人**出口货物**，国务院另有规定除外；②境内单位和个人**跨境销售国务院规定范围内的服务、无形资产**）。
- **简易计税方法：征收率 3%**。
- 兼营（发生**两项以上**应税交易涉及不同税率/征收率）→ **应当分别核算**；**未分别核算的，从高适用税率** ⭐。
- 混合销售（发生**一项**应税交易涉及两个以上税率/征收率）→ **按应税交易的主要业务**适用税率、征收率 ⭐。

### 3. 税收优惠
- **小规模纳税人**：销售额**未达起征点免征**；**达到起征点的全额**计算缴纳 ⭐。
- **免征增值税项目** ⭐⭐（高频多选/单选）：
  1. **农业生产者销售的自产农产品**；农业机耕、排灌、病虫害防治、植物保护、农牧保险及相关技术培训业务，家禽、牲畜、水生动物的**配种和疾病防治**；
  2. **医疗机构提供的医疗服务**；
  3. **古旧图书**；**自然人销售的自己使用过的物品**；
  4. 直接用于**科学研究、科学试验和教学的进口仪器、设备**；
  5. **外国政府、国际组织无偿援助**的进口物资和设备；
  6. 由**残疾人的组织直接进口供残疾人专用**的物品；**残疾人个人提供的服务**；
  7. **托儿所、幼儿园、养老机构、残疾人服务机构**提供的**育养服务**；**婚姻介绍**服务；**殡葬**服务；
  8. **学校提供的学历教育服务**；**学生勤工俭学**提供的服务；
  9. **纪念馆、博物馆、文化馆、文物保护单位管理机构、美术馆、展览馆、书画院、图书馆举办文化活动的门票收入**；宗教场所举办文化、宗教活动的**门票收入**。
- 免税项目具体标准由**国务院**规定。
- **兼营优惠项目应单独核算销售额；未单独核算的，不得享受优惠** ⭐。
