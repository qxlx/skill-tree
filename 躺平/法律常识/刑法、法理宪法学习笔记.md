# 第一部分 刑法

## 一、刑法的适用范围

### （一）空间效力 ⭐⭐（四大管辖原则）

| 原则 | 规则 | 记忆要点 |
| --- | --- | --- |
| **属地管辖** | 在**我国领域内**犯罪，除法律特别规定外适用我国刑法 | 领域 = ①**固有领域**：领土、领水、领空、**我国驻外使领馆**；②**流动领域**：**悬挂我国国旗的船舶、航空器** ⭐。**享有外交特权和豁免权的外国人** → 通过**外交途径**解决 |
| **属人管辖** | 我国公民**在我国领域外**犯本法之罪，适用本法 | 但按本法规定**最高刑为 3 年以下有期徒刑**的，**可以不予追究** |
| **保护管辖** | **外国人**在我国领域外对我国国家或公民犯罪 | 按本法**最低刑为 3 年以上有期徒刑**的可以适用；**但按犯罪地法律不受处罚的除外** ⭐ |
| **普遍管辖** | 我国缔结或参加的国际条约所规定的罪行 | 在承担条约义务范围内行使管辖权 |

> 注意：**国际列车不属于流动领域**（仅船舶、航空器）；犯罪地或结果地之一在我国境内即视为领域内犯罪（遍在说）。

### （二）时间效力 —— **从旧兼从轻** ⭐
- 原则**从旧**（适用行为时的法律）；
- 适用**新法**的条件：①**未决案件**；②**新法规定更轻**。

## 二、自然人犯罪

### （一）刑事责任年龄 ⭐⭐⭐（必背四档）

| 年龄 | 责任 |
| --- | --- |
| **＜12** | **一律不负**刑事责任 |
| **12 ≤ X ＜14** | 犯**故意杀人、故意伤害罪**，致人死亡或以**特别残忍手段**致人重伤造成**严重残疾**，**情节恶劣**，经**最高人民检察院核准追诉**的，应当负刑事责任 ⭐ |
| **14 ≤ X ＜16** | 只对 **8 种严重犯罪**负责：**故意杀人、故意伤害致人重伤或者死亡、抢劫、强奸、贩卖毒品、放火、爆炸、投放危险物质** ⭐⭐ |
| **≥16** | 犯罪应当负刑事责任 |

### （二）刑事责任能力 ⭐

| 类型 | 规则 |
| --- | --- |
| **无刑事责任能力**（"全疯"） | 精神病人在**不能辨认或者不能控制**自己行为时造成危害结果，经法定程序鉴定确认的，**不负**刑事责任；责令家属或监护人严加看管和医疗，必要时**政府强制医疗** |
| **限制刑事责任能力**（"半疯"） | 尚未完全丧失辨认或控制能力的精神病人犯罪 → **应当负**刑事责任，但**可以从轻或者减轻**处罚 |
| **完全刑事责任能力** | 达法定年龄且精神正常能辨认控制自己行为 |
| 其他规定 ⭐ | ①**间歇性精神病人**精神正常时犯罪 → **应当负**刑事责任；②**醉酒的人**犯罪 → **应当负**刑事责任；③**又聋又哑的人或者盲人**犯罪 → **可以**从轻、减轻**或者免除**处罚 |

## 三、正当防卫 —— 五个构成条件 ⭐⭐

| 条件 | 要点 |
| --- | --- |
| **防卫起因** | 存在**不法侵害**，且具有社会危害性和**侵害紧迫性** |
| **防卫对象** | **只能是不法侵害人本身**；对第三者防卫不构成正当防卫 ⭐ |
| **防卫意图** | 为保护国家、公共利益、本人或他人的人身、财产等**合法权利** |
| **防卫时间** | 不法侵害**正在进行**；未开始=**事前防卫**，已结束=**事后防卫** ⭐ |
| **防卫限度** | **明显超过必要限度造成重大损害**的（防卫过当），应当负刑事责任，但是**应当减轻或者免除**处罚 |

## 四、重要罪名 ⭐⭐

### 财产犯罪

| 罪名 | 构成要点 |
| --- | --- |
| **抢劫罪** | 以**暴力、胁迫或者其他方法**抢劫公私财物。**转化型抢劫** ⭐：犯**盗窃、诈骗、抢夺罪**，为**窝藏赃物、抗拒抓捕或者毁灭罪证**而**当场**使用暴力或以暴力相威胁的 → 按抢劫罪定罪 |
| **抢夺罪** | 抢夺公私财物数额较大，或多次抢夺。**携带凶器抢夺的 → 按抢劫罪定罪**（拟制抢劫）⭐ |
| **盗窃罪** | 数额较大，或**多次盗窃、入户盗窃、携带凶器盗窃、扒窃** ⭐（后四种不要求数额） |
| **诈骗罪** | 以**非法占有为目的**，**虚构事实或隐瞒真相**，骗取数额较大公私财物 |

### 贪污贿赂犯罪（主体均为**国家工作人员**，利用**职务上的便利**）

| 罪名 | 构成要点 |
| --- | --- |
| **贪污罪** | **侵吞、窃取、骗取**或以其他手段**非法占有公共财物** |
| **受贿罪** | **索取**他人财物，或**非法收受**他人财物**为他人谋取利益** ⭐（索贿不要求"为他人谋取利益"） |
| **挪用公款罪** | 挪用公款归个人使用：①进行**非法活动**；②数额较大进行**营利活动**；③数额较大**超过 3 个月未还** ⭐。**挪用救灾、抢险、防汛、优抚、扶贫、移民、救济款物**归个人使用的 → **从重处罚** ⭐ |

### 新设/常见罪名

| 罪名 | 构成要点 |
| --- | --- |
| **负有照护职责人员性侵罪** | 对**已满 14 不满 16 周岁未成年女性**负有**监护、收养、看护、教育、医疗**等特殊职责的人员，与其发生性关系 → 3 年以下；情节恶劣 3–10 年。**奸淫不满 14 周岁幼女的，以强奸论，从重处罚** ⭐ |
| **高空抛物罪** | 从建筑物或其他高空抛掷物品，**情节严重** → 1 年以下有期徒刑、拘役或管制，并处或单处罚金；**同时构成其他犯罪的，依照处罚较重的规定定罪** ⭐ |
| **妨害安全驾驶罪** | 对**行驶中**的公共交通工具驾驶人员**使用暴力或抢控驾驶操纵装置**，干扰正常行驶、危及公共安全 → 1 年以下；**驾驶人员擅离职守与他人互殴或殴打他人**的同样处罚；竞合择重 |
| **帮助信息网络犯罪活动罪**（"帮信罪"）⭐ | **明知**他人利用信息网络实施犯罪，为其提供**互联网接入、服务器托管、网络存储、通讯传输等技术支持**，或提供**广告推广、支付结算**等帮助，**情节严重** |

「考」2024 国考（我国刑法**不具有**管辖权）：A 下毒行为地在我国机场（属地）；B 我国公民境外绑架（属人，绑架最高刑 3 年以上应追究）；C **国际列车**上外国人对外国人犯罪——国际列车不属我国流动领域，不属我国管辖 → **选 C**；D 我国境内电话教唆，行为地部分在我国（属地）。

「考」2023 国考（电信诈骗，选错误）：A 非法使用"伪基站"应以**扰乱无线电通讯管理秩序罪/破坏计算机信息系统罪**等论处，而非"非法侵入计算机信息系统罪" → **选 A**。B 最高可判无期，对；C 可向有过错的运营商索赔，对；D 招募者按共同犯罪论处，对。

# 第二部分 法理（法的渊源・法律谚语）

## 一、法的渊源 ⭐⭐⭐（制定机关 + 批准/备案程序是核心考点）

### 正式渊源一览

| 渊源 | 制定机关 | 注意内容 |
| --- | --- | --- |
| **宪法** | **全国人大**（一届一次会议创立） | 具有**最高法律效力**。修改：由**全人常或 1/5 以上全人大代表提议**，由**全国人大以全体代表的 2/3 以上多数**通过 ⭐ |
| **法律·基本法律** | **全国人大**（可授权全人常制定） | 修改主体：全人大；**闭会期间全人常可部分补充或修改，但不得同基本原则相抵触** ⭐ |
| **法律·非基本法律** | **全国人大常委会** | 修改主体：全人常 |
| **行政法规** | **国务院** | 国家**行政机关体系中最高的规范性文件** ⭐ |
| **监察法规** | **国家监察委员会** | 公布后 **30 日内报全人常备案** |
| **地方性法规** | **省级**人大、人常；**设区的市级**人大、人常 | 设区的市级**仅限 4 方面**：**城乡建设与管理、生态文明建设、历史文化保护、基层治理**，须**报省级人常批准后施行** ⭐⭐ |
| **自治法规** | 民族自治地方（自治区、自治州、自治县）**人大** | **自治区**的自治条例、单行条例 → 报**全人常批准**后生效；**自治州、自治县** → 报**省级人常批准**后生效 ⭐ |
| **规章·部门规章** | 国务院各部、委员会、**中国人民银行、审计署**和具有行政管理职能的**直属机构** | — |
| **规章·地方政府规章** | 省级和**设区的市、自治州**人民政府 | 设区的市、自治州限于上述**4 方面**事项 |
| **经济特区法规** | 特区所在地省、市人大及其常委会（依全国人大授权） | 在经济特区范围内实施 |
| **浦东新区法规** | 上海市人大及其常委会（依全人常授权） | 在浦东新区实施 |
| **海南自由贸易港法规** | 海南省人大及其常委会 | 在海南自贸港范围内实施 |
| **国际条约和国际惯例** | — | 条约=我国作为国际法主体缔结的双边多边协议；惯例=国际裁决机构判例确认的规则+共同遵守的不成文习惯 |

「考」2025 国考（立法权，选正确）：A **限制人身自由**的强制措施（强制隔离戒毒）与**冻结存款汇款**只能由**法律**设定？——冻结存款属行政强制措施，其设定权属法律，**限制人身自由的强制措施只能由法律设定**，A 表述符合立法法，**选 A**；B 全国人大不可授权国务院"制定法律"（只能授权制定**行政法规**），错；C 法律解释权**专属全国人大常委会**，错；D 行政法规由**国务院**制定发布，错。

「考」2024 国考（立法法，选错误）：**B 县级人大常委无权制定地方性法规**（限于省级和设区的市级）→ 选 **B**。A 国家监委可向全人常提出法律案，对；C 设区的市人常可设基层立法联系点，对；D 草案说明应包括重大分歧意见协调处理情况，对。

## 二、法律谚语 ⭐（常考出处与思想对应）

| 谚语 | 出处 | 内涵 |
| --- | --- | --- |
| **法不阿贵，绳不挠曲** | 《韩非子·有度》 | 法律不迎合权贵 → **法律面前人人平等** |
| 法者，天下之程式也，万事之仪表也 | 《管子·明法解》 | 法律的**普遍性和公平性** |
| **奉法者强则国强，奉法者弱则国弱** | 《韩非子·有度》 | **法律执行力**的重要性 |
| **刑称罪则治，不称罪则乱** | 《商君书》 | **罪刑相适应**原则 |
| 刑过不辟大臣，赏善不遗匹夫 | 《韩非子》 | 惩罚不避权贵，奖赏不漏平民 → 平等 |
| 不教而诛，则刑繁而邪不胜；教而不诛，则奸民不惩 | 《荀子·富国》 | **教化与惩戒结合** |
| **徒善不足以为政，徒法不能以自行** | 《孟子·离娄上》 | **道德与法律相辅相成** |
| 天下从事者，不可以无法仪；无法仪而其事能成者，无有也 | 《墨子·法仪》 | 治国需依赖**法律规范** |
| 法令行则国治，法令弛则国乱 | 《潜夫论》（王符） | 法律**严格执行**则国安 |
| 法者，天下之度量，而人主之准绳也 | 《淮南子·主术训》 | 法律是**衡量是非的标准** |
| **立善法于天下，则天下治；立善法于一国，则一国治** | 王安石《周公》 | **良法**是治国基础 |
| 禁胜于身，则令行于民；上不行法则民不从彼 | 《管子·法法》 | **统治者自身守法**法令才能推行 |
| 不以私害法，则治 | 《商君书·修权》 | 不因私利损害法律 |
| **宥过无大，刑故无小** | 《尚书·大禹谟》 | **过失**犯罪可宽恕，**故意**犯罪必严惩 |
| 法令明具，而用之至密，举天下惟法之知 | 苏轼《策别第八》 | 条文**明确**、执行**严密** |
| **天下之事，不难于立法，而难于法之必行** | 张居正 | **立法易、执行难** |
| 唯奉三尺之律，以绳四海之人 | 《贞观政要》 | 以统一法律约束所有人（**普遍性**） |

「考」2018 国考（法谚解读正确）：A "法无授权不可为"针对的是**公权力**而非公民，错；B "枪炮作响法无声"→ 战乱时常态法律秩序荡然无存，**正确**；C "法律必须被信仰"强调**法治信仰/内心拥护**，非"法律与道德相辅相成"，错；D "法不阿贵"强调**平等适用**，与"初衷好不好"无关，错。→ 选 **B**

# 第三部分 宪法

## 一、国家制度 ⭐⭐

| 项目 | 内容 |
| --- | --- |
| **国体** | **人民民主专政** |
| **政体** | **人民代表大会制度**。人大代表当选条件 ⭐：**直接选举（县、乡）**= 选区**全体选民过半数投票** + 获得**过半数选票**；**间接选举（市以上）**= 全体代表**过半数**同意 |
| **根本制度** | **社会主义制度** |
| **根本政治制度** | **人民代表大会制度** |
| **基本政治制度** | 民族区域自治制度、多党合作与政治协商制度、基层群众自治制度 |
| **国家结构形式** | **单一制** |
| **经济制度** | **公有制为主体、多种所有制经济共同发展**；**按劳分配为主体、多种分配方式并存**；社会主义市场经济体制。**公共财产神圣不可侵犯**；**公民合法的私有财产不受侵犯**，国家保护私有财产权和继承权；为**公共利益**需要可依法**征收或征用并给予补偿** ⭐ |

## 二、公民的基本权利 ⭐⭐

### 1. 平等权
公民在**法律面前一律平等**。

### 2. 政治权利和自由
- **选举权与被选举权**：**年满 18 周岁**公民，不分民族、种族、性别、职业、家庭出身、宗教信仰、教育程度、财产状况、居住期限，都有选举权和被选举权；**依照法律被剥夺政治权利的人除外** ⭐。
- **政治自由**：**言论（首要、基础）**、出版、集会、结社、游行、示威 ⭐。

### 3. 宗教信仰自由
- 不得**强制**公民信仰或不信仰宗教，不得**歧视**；
- 国家保护**正常的宗教活动**；不得利用宗教破坏社会秩序、损害公民身体健康、妨碍国家教育制度；
- **宗教团体和宗教事务不受外国势力的支配** ⭐。

### 4. 人身自由权 ⭐⭐

| 权利 | 关键规则 |
| --- | --- |
| **人身自由** | 任何公民，**非经人民检察院批准或者决定或者人民法院决定，并由公安机关执行，不受逮捕** ⭐；禁止非法拘禁、非法剥夺限制人身自由，**禁止非法搜查公民身体** |
| **人格尊严** | 不受侵犯；禁止用任何方法**侮辱、诽谤和诬告陷害** |
| **住宅不受侵犯** | 禁止**非法搜查或者非法侵入**公民住宅 |
| **通信自由和通信秘密** | 除因**国家安全或者追查刑事犯罪的需要**，由**公安机关或者检察机关**依照法律规定的程序对通信进行检查外，任何组织或个人不得以任何理由侵犯 ⭐（注意：**法院无权检查通信**） |

### 5. 诉愿权（监督权）
- 对任何国家机关和工作人员有**批评和建议**权；对违法失职行为有**申诉、控告、检举**权（不得捏造歪曲事实诬告陷害）；
- 有关机关必须查清事实负责处理，**任何人不得压制和打击报复**；
- 因国家机关和工作人员侵犯权利受损失的，有**依法取得赔偿**的权利。

### 6. 社会经济与文化权利

| 权利 | 要点 |
| --- | --- |
| **劳动** | **既是权利又是义务** ⭐ |
| **受教育** | **既是权利又是义务** ⭐ |
| **休息权** | 主体是**劳动者**（非全体公民）；国家发展休息休养设施，规定工作时间和休假制度 |
| **物质帮助权** ⭐ | 公民在**年老、疾病或者丧失劳动能力**的情况下，有从国家和社会获得物质帮助的权利（**宪法未规定自然灾害情形**可得物质帮助，注意区分） |
| **文化权利与自由** | 科学研究、文学艺术创作和其他文化活动的自由 |
| **财产权** | 合法的私有财产不受侵犯；可依法征收征用**并给予补偿** |

## 三、中央国家机关 ⭐⭐⭐

### 全国人民代表大会
- **性质**：**最高国家权力机关**。
- 组成：省、自治区、直辖市、特别行政区和**军队**选出的代表；各少数民族应有适当名额。
- 任期：**每届 5 年**（代表可连选连任）；**每年举行一次会议，由全国人大常委会召集**。
- 职权：
  - **立法权**：**修改宪法**、监督宪法实施；**制定和修改基本法律**（注意：宪法的"制定"是 1954 年一届一次会议完成的历史行为，现行常表述为修改权）。
  - **人事任免权（选举）** ⭐：**"一常一委两高三主席"** —— 全国人大常委会全体成员、国家监察委员会主任、最高人民法院院长、最高人民检察院检察长、国家主席副主席、中央军委主席。
  - **决定权**：**批准省、自治区和直辖市的建置** ⭐；决定特别行政区的设立及其制度；审查批准国民经济和社会发展计划、国家预算及执行报告；改变和撤销全人常不适当的决定。
  - 提名+决定：**国家主席提名决定总理**、**总理提名决定其他（副总理、国务委员、各部长等）**、**中央军委主席提名决定其他**。

> 行政区划口诀 ⭐：**"乡找省、村找县、县级以上国务院、全国人大批省建"**（乡级建置由省批准；村级由县批准；县级以上区域的划分与州、县、自治县、市的建置由国务院批准；省、自治区、直辖市的**建置**由全国人大批准，其**区域划分**由国务院批准）。

### 全国人大常委会
- **性质**：全国人大的**常设机关**，闭会期间行使国家最高权力。
- 组成：委员长、副委员长、秘书长、委员；每届 5 年；**委员长、副委员长连续任职不得超过两届** ⭐；组成人员**不得担任**国家行政机关、监察机关、审判机关、检察机关职务 ⭐。
- 职权：
  - **立法权**：**解释宪法和法律** ⭐；闭会期间对全人大制定的法律**部分补充和修改**，不得抵触基本原则。
  - 决定权：闭会期间审查批准计划、预算的**部分调整方案**；**撤销**国务院同宪法法律相抵触的行政法规、决定、命令；**撤销**省级权力机关同宪法法律行政法规相抵触的地方性法规和决议；决定驻外全权代表任免；决定同外国缔结条约和重要协定的**批准和废除**；规定军人外交人员衔级制度；规定和决定授予国家勋章荣誉称号；**决定特赦** ⭐；闭会期间决定战争状态的宣布；决定**全国总动员或局部动员**；决定**全国或者个别省、自治区、直辖市进入紧急状态** ⭐；监督国务院、中央军委、国家监委、最高法、最高检工作。
  - 人事：总理提名决定部长等、军委主席提名决定其他、最高法院长提名任免副院长等、检察长提名任免副检察长等、监察委主任提名任免副主任委员。

### 国家主席
- **国家元首**。根据全国人大及其常委会的决定行使职权（公布法律、任免、授予勋章、发布特赦令、宣布进入紧急状态、宣布战争状态、发布动员令）；代表国家进行国事活动，接受外国使节。

### 国务院
- **性质**：最高国家权力机关的**执行机关**，**最高国家行政机关**。
- 组成：总理、副总理、国务委员、各部部长、各委员会主任、审计长、秘书长；每届 5 年；**总理、副总理、国务委员连续任职不得超过两届** ⭐。
- 职权：根据宪法和法律**制定行政法规**、发布决定命令；编制执行计划预算；管理对外事务、缔结条约协定；**改变或撤销**各部委不适当的命令指示和**规章**；**改变或撤销**地方各级行政机关不适当的决定和命令；**批准省、自治区、直辖市的区域划分，批准自治州、县、自治县、市的建置和区域划分** ⭐；决定**省、自治区、直辖市范围内部分地区**进入紧急状态 ⭐；领导和管理经济、城乡建设、生态文明、教育科技文卫体、民政公安司法、国防建设、民族事务、华侨权益等。

### 中央军事委员会
- **领导全国武装力量**的最高军事领导机关。注意：**中华人民共和国的武装力量属于人民** ⭐。

### 人民法院 / 人民检察院
- 法院：**审判机关**，独立行使审判权，不受行政机关、社会团体和个人干涉。
- 检察院：**国家法律监督机关**。

### 监察委员会
- **国家监察机关**。三大职责 ⭐：
  1. **监督** —— 对象是**所有行使公权力的公职人员**；
  2. **调查** —— 可依法**留置**；
  3. **处置** —— 违法公职人员→**政务处分**；失职领导人→**问责**；涉嫌犯罪→**移送人民检察院**。

## 四、历次宪法修正案重点 ⭐⭐⭐（现行 1982 年宪法，共 5 次修正：1988、1993、1999、2004、2018）

### 1988 年（2 条）
- 私营经济是**公有制经济的补充**，实行引导、监督、管理；
- **允许转让土地使用权** ⭐（所有权仍不得转让）。

### 1993 年 —— 口诀：**"国家正市五年"**
- 我国正处于**社会主义初级阶段**，坚持**改革开放**，建设**富强、民主、文明**的国家；
- 确立**多党合作和政治协商制度**；
- "**国营经济**"改为"**国有经济**"；
- 农村：**家庭联产承包为主的责任制**；
- 国家实行**社会主义市场经济**，加强经济立法、完善宏观调控；
- **县级人大任期 3 年改 5 年** ⭐。

### 1999 年 —— 口诀：**"长分治，非安全"**
- 我国将**长期处于**社会主义初级阶段，**邓小平理论**入宪；
- **依法治国**，建设社会主义法治国家 ⭐；
- 确立**公有制为主体、多种所有制共同发展**的基本经济制度和**按劳分配为主体、多种分配方式并存**的分配制度；
- 农村：**家庭承包经营为基础、统分结合的双层经营体制**；
- **非公有制经济是社会主义市场经济的重要组成部分**，保护个体、私营经济合法权利；
- "**反革命活动**"改为"**危害国家安全的犯罪**" ⭐。

### 2004 年 —— 口诀：**"我们都是建设者，三个代表下，有人权、买社保、唱国歌；鼓励支持引导 + 合法财产受保护，征收征用要给钱"**
- "**三个代表**"入宪；推动物质文明、政治文明、精神文明协调发展；
- 爱国统一战线增加"**社会主义事业的建设者**" ⭐；
- 土地、公民私有财产均可**征收或征用并给予补偿**；
- **公民合法的私有财产不受侵犯**，保护私有财产权和继承权 ⭐（真题确认：该条为 2004 年，非 1993 年）；
- **建立健全同经济发展水平相适应的社会保障制度**；
- **国家尊重和保障人权** ⭐（真题确认：2004 年，非 1999 年）；
- 全国人大增加**特别行政区**选出的代表；
- "**戒严**"改为"**紧急状态**"；
- 国家主席**代表国家进行国事活动，接受外国使节**；
- **乡级人大任期 3 年改 5 年** ⭐；
- **增加国歌**（《义勇军进行曲》）⭐。

### 2018 年
- **科学发展观、习近平新时代中国特色社会主义思想**入宪；推动"五个文明"协调发展，实现**中华民族伟大复兴**；
- 爱国统一战线增加"**致力于中华民族伟大复兴的爱国者**"；
- 坚持和平发展道路、互利共赢开放战略，**推动构建人类命运共同体**；
- **中国共产党领导是中国特色社会主义最本质的特征** ⭐；
- 国家机构增加"**监察机关**"，由人大产生、对它负责、受它监督；
- 国家倡导**社会主义核心价值观**；
- 增加**宪法宣誓制度** ⭐；
- **取消国家主席连续任职限制** ⭐；
- 规定**监察委员会**的组成、任期及职权。

「考」2022 国考（宪法条款与修正案对应）：A 私有财产不受侵犯 → 应为 2004，错；B 双层经营体制 → 应为 1999，错；C 尊重和保障人权 → 应为 2004，错；D **中国共产党领导是最本质特征 → 2018**，正确 → 选 **D**
