## 一、行政许可

### 概念与设定 ⭐⭐

| 项目 | 内容 |
| --- | --- |
| 概念 | 行政机关根据行政相对方的**申请**，经**审查**依法**赋予其从事某种活动的法律资格或者实施某种行为的法律权利**的**具体行政行为** |
| **经常性**行政许可的设定 ⭐ | **法律**（全国人大及其常委会）、**行政法规**（国务院）、**地方性法规**（有权地方人大及其常委会） |
| **临时性**行政许可的设定 ⭐ | **国务院决定**；**省、自治区、直辖市人民政府规章**（注意：设区的市规章**无权**设定） |

> 课件示例图：支付宝（中国）网络技术有限公司的《支付业务许可证》（央行发证）——许可即"赋权/赋资格"的典型。

### 实施程序 ⭐⭐
流程：**申请 → 受理 → 审查 → 决定**
期限（记数字）：
1. 能**当场**决定的当场决定；不能当场的 → 自受理之日起 **20 日内**作出决定；20 日内不能作出的，经**本行政机关负责人批准**可**延长 10 日**，并告知理由（法律、法规另有规定除外）；
2. **统一办理、联合办理、集中办理**的：办理时间不超过 **45 日**；不能办结的经**本级政府负责人批准**可**延长 15 日**，告知理由。

### 听证程序 ⭐
1. 举行听证的 **7 日前**通知申请人、利害关系人时间地点，必要时公告；
2. 听证**公开举行**；
3. **案外人主持**；
4. 当事人**申辩、质证**；
5. **听证笔录的案卷排他原则**（决定只能基于听证笔录作出）⭐。

### 监督检查：撤销 / 撤回 / 吊销 / 注销 ⭐⭐⭐（易混四兄弟）

| 方式 | 适用情形 | 记忆 |
| --- | --- | --- |
| **撤销** | **违法取得**（如欺骗、贿赂或审批违法） | 出生就错了 |
| **撤回** | **合法取得**，但①许可所依据的法律、法规、规章**修改或废止**；②准予许可所依据的**客观情况发生重大变化** | 情势变了 |
| **吊销** | 合法取得、**违法使用**（是一种**行政处罚**） | 拿到后干坏事 |
| **注销** | **程序性**收尾（如许可有效期届满未延续、主体终止等） | 办手续 |

## 二、行政处罚 ⭐⭐⭐（本章最重）

### 1. 处罚种类（按性质记）

| 类型 | 种类 |
| --- | --- |
| 申诫罚 | **警告** |
| 声誉罚 | **通报批评** |
| 财产罚 | **罚款、没收违法所得、没收非法财物** |
| 资格罚 | **暂扣许可证件、降低资质等级、吊销许可证件** |
| 行为罚 | **限制开展生产经营活动、责令停产停业、责令关闭、限制从业** |
| 自由罚 | **行政拘留**（最重，只能由**法律**设定） |
| 兜底 | 法律、行政法规规定的其他处罚 |

### 2. 设定权限 ⭐⭐⭐（谁最多能设什么）

| 依据 | 可设定的处罚 |
| --- | --- |
| **法律** | **各种**处罚（限制人身自由的处罚**只能**由法律设定） |
| **行政法规** | 除**限制人身自由**外 |
| **地方性法规** | 除**限制人身自由、吊销营业执照**外 |
| **部门规章** | **警告、通报批评、罚款**；罚款限额由**国务院**规定 |
| **地方政府规章** | **警告、通报批评、罚款**；罚款限额由**省级人大常委会**规定 |

### 3. 管辖
- 由**违法行为发生地**的**县级以上**地方人民政府具有行政处罚权的行政机关管辖（法律、行政法规另有规定除外）。
- 省、自治区、直辖市可决定将基层管理迫切需要的县级部门处罚权**交由能够有效承接的乡镇政府、街道办事处**行使，并**定期组织评估** ⭐（处罚权下沉）。

### 4. 不予处罚的情节 ⭐⭐
1. **不满 14 周岁**的人有违法行为 → 不予处罚，责令**监护人加以管教**；
2. **精神病人**在不能辨认或不能控制自己行为时有违法行为 → 不予处罚，责令监护人严加看管和治疗；
3. **违法行为轻微并及时纠正，没有造成危害后果** → 不予处罚；
4. **初次违法且危害后果轻微并及时改正** → **可以**不予处罚 ⭐（"首违不罚"）；
5. 当事人**有证据足以证明没有主观过错** → 不予处罚（法律、行政法规另有规定除外）⭐；
6. **超过追责时效** → 不再处罚（法律另有规定除外）。

### 5. 追责时效与一事不再罚 ⭐⭐⭐
- 追责时效：违法行为**2 年内未被发现**不再处罚；**涉及公民生命健康安全、金融安全且有危害后果**的 → 延长至 **5 年**（法律另有规定除外）。
- **一事不再罚**：对同一个违法行为，**不得给予两次以上罚款**；同一行为违反多个法律规范均应罚款的 → **按罚款数额高的规定处罚** ⭐。

### 6. 决定程序

| 程序 | 要点 |
| --- | --- |
| **普通程序** ⭐ | 立案 → 调查取证 → 告知听取（陈述申辩）→ 特定事项**法制审核** → **自立案之日起 90 日内**作出决定 → 送达（当场交付当事人；当事人不在场的 **7 日内**送达） |
| **简易程序** ⭐⭐ | 适用条件（目）：①**违法事实确凿并有法定依据**；②对**公民处 200 元以下**、对**法人或其他组织处 3000 元以下**罚款**或者警告**。特点：**当场决定、当场送达** |

### 7. 听证程序 ⭐⭐

**应当告知有权申请听证的情形**：①**较大数额罚款**；②**没收较大数额违法所得、没收较大价值非法财物**；③**降低资质等级、吊销许可证件**；④**责令停产停业、责令关闭、限制从业**；⑤其他较重的行政处罚；⑥法律、法规、规章规定的其他情形。

**听证会程序**：
1. 当事人要求听证的 → 行政机关**告知后 5 日内**提出；行政机关应在**听证的 7 日前**通知时间地点；
2. **公开举行**（涉国家秘密、商业秘密、个人隐私除外）；
3. **案外人主持**；
4. 当事人可亲自参加，也可**委托 1–2 人代理**；
5. 无正当理由拒不出席或未经许可中途退出 → **视为放弃听证权利，终止听证** ⭐；
6. 申辩、质证；
7. 听证笔录适用**案卷排他原则**。

### 8. 执行程序 ⭐⭐

| 制度 | 内容 |
| --- | --- |
| **罚缴分离** | 作出罚款决定的机关与收缴罚款的机构**分离**（到指定银行/电子支付缴纳） |
| **当场收缴**（例外） | ①简易程序当场处罚：**依法给予 100 元以下罚款**或**不当场收缴事后难以执行**的；②简易程序或普通程序，在**边远、水上、交通不便地区**向银行或电子支付缴纳确有困难，**经当事人提出**，可当场收缴 |

> 注意区分三个数字：简易程序门槛（公民 **200** / 组织 **3000**）≠ 当场收缴门槛（**100**）。

## 三、行政强制 ⭐⭐⭐（措施 vs 执行是必考区分）

### 1. 行政强制措施（**暂时性**控制，事中）
- 概念：为**制止违法行为、防止证据损毁、避免危害发生、控制危险扩大**等，依法对公民**人身自由实施暂时性限制**，或对财物**实施暂时性控制**。
- 种类：①**限制公民人身自由**（约束至酒醒、强制戒毒、强制隔离）；②**查封**场所、设施或者财物；③**扣押**财物；④**冻结存款、汇款**；⑤其他。

### 2. 行政强制执行（**实现义务**，事后）
- 概念：使用强制措施**实现行政法义务**的国家执行制度。
- 种类：①**加处罚款或滞纳金** ⭐：到期不缴罚款的，**每日按罚款数额的 3%** 加处，**加处罚款数额不得超出罚款数额**（"罚不过本金"）；②**划拨**存款、汇款；③**拍卖**或依法处理查封扣押的场所设施或财物；④**排除妨碍、恢复原状**；⑤**代履行**；⑥其他。

> 速记：查封扣押冻结（还没定论，先控制）= 措施；划拨拍卖代履行（义务已定，强制实现）= 执行。

## 四、行政复议 ⭐⭐⭐

### 1. 概念与重要制度
- 概念：公民、法人或其他组织认为行政行为侵犯其合法权益，向复议机关申请，复议机关受理、审理行政行为**合法性 + 适当性**（比行政诉讼多审"适当性"⭐）。
- **一级复议制度** ⭐：经复议机关**一次审理**作出决定后，即使不服也**不得再次申请复议**，只能**向法院起诉**（法律规定复议决定为最终裁决的除外）。
- **调解制度**：复议**可以调解**（与行政诉讼"不适用调解"形成对比⭐），须遵循**合法、自愿**原则，不得损害国家利益、社会公共利益和他人合法权益，不得违反法律法规强制性规定。

### 2. 复议范围 ⭐⭐（可申请复议的事项，重点记）
行政处罚不服；**行政强制措施、行政强制执行**决定不服；**行政许可**拒绝、逾期不答复或其他决定不服；**确认自然资源所有权或使用权**的决定不服；**征收征用决定及其补偿决定**不服；**赔偿决定或不予赔偿决定**不服；**不予受理工伤认定申请的决定或工伤认定结论**不服；侵犯**经营自主权、农村土地承包经营权/土地经营权**；**滥用行政权力排除或限制竞争**；违法**集资、摊派费用**；申请履行保护**人身权利、财产权利、受教育权利**法定职责被拒绝/未依法履行/不予答复；申请**抚恤金、社会保险待遇、最低生活保障**未依法给付；政府**特许经营协议、土地房屋征收补偿协议**等行政协议纠纷；**政府信息公开**侵权；其他行政行为侵权。

### 3. 排除事项 ⭐⭐⭐（不能复议的"四不"）
1. **国家行为**：国防、外交等；
2. **抽象行政行为**：行政法规、规章或具有普遍约束力的决定、命令等规范性文件（**不能单独复议**）；
3. **内部行政行为**：行政机关对工作人员的**奖惩、任免**等决定 ⭐（如公务员降职 → 只能申诉，不能复议）；
4. **行政调解行为**：行政机关对民事纠纷作出的调解。

> 抽象规则不服怎么办 ⭐：**具体行政行为不服可以直接告；抽象行政行为不服只能附带审查一部分**（不能单独就"红头文件"起诉/复议，但可在对具体行为申请复议时**附带**审查该规范性文件——规章除外）。
> 课件案例：①县政府出台"行人闯红灯罚 10 元"规定，小明认为规定违法 → 不能单独就该规定复议/起诉；②小明因闯红灯被罚 10 元，认为处罚依据违法 → 可在复议/诉讼处罚决定时**一并提出**对该规定的附带审查申请。

### 4. 复议机关 ⭐⭐⭐（口诀："找爹"）

**思维导图（课件原图整理）——找复议机关（找爹）**：

```
找复议机关（找爹）
├─ 政府
│   ├─ 乡、县、市政府 → 上一级政府
│   └─ 省级政府 → 找自己
├─ 政府部门
│   ├─ 公安局、卫生局、教育局、市场监督管理局等 → 本级政府
│   ├─ 海关、金融、外汇、税务、国家安全机关（垂直领导）→ 上一级主管部门
│   ├─ 司法局 → 本级政府 或 上一级主管部门（二选一）
│   └─ 国务院部门 → 找自己
└─ 派出所 → 县级政府
```

法条化表述：
- **县级以上地方各级政府统一行使行政复议职责**，管辖：①对**本级政府工作部门**行为不服；②对**下一级政府**行为不服；③对**本级政府依法设立的派出机关**行为不服；④对本级政府或其工作部门管理的**法律法规规章授权组织**行为不服。
- 省级政府同时管辖**对本机关**行为不服的案件（找自己）。
- **国务院部门**：对本部门行为、本部门设立的派出机构以派出机构名义的行为、本部门管理的授权组织的行为 → 由**该部门自己**管辖（对复议决定不服可诉讼，或向国务院申请**最终裁决**）。
- **垂直领导机关**（海关、金融、外汇管理、税务、国家安全机关）→ **上一级主管部门**。
- 地方**司法行政部门**（履行复议机构职责）→ **本级政府或上一级司法行政部门**。
- 部门设立的**派出机构**（如派出所）以自己名义行为 → **本级政府**管辖；其中直辖市、设区的市政府部门按行政区划设立的派出机构 → 也可由**所在地政府**管辖。

### 5. 复议申请与复议前置 ⭐⭐⭐
- 申请期限：自**知道或应当知道**行政行为之日起 **60 日内**（法律规定超过 60 日的除外）。
- **复议前置**（必须先复议、不服才能起诉的 5 种情形）⭐⭐：
  1. 对**当场作出**的行政处罚决定不服；
  2. 对行政机关作出的**侵犯其已经依法取得的自然资源所有权或使用权**的决定不服；
  3. 认为行政机关**未履行法定职责**（不作为）；
  4. 申请**政府信息公开**，行政机关**不予公开**；
  5. 法律、行政法规规定应当先复议的其他情形。

### 6. 听证制度 ⭐
1. 审理**重大、疑难、复杂**案件 → **应当**组织听证；机构认为有必要或申请人请求 → **可以**组织；
2. 听证组成：**1 名主持人 + 2 名以上听证员 + 1 名记录员**；
3. 举行听证的 **5 日前**书面通知时间地点和拟听证事项；
4. 申请人无正当理由拒不参加 → **视为放弃听证权利**；
5. **被申请人的负责人应当参加听证**，不能参加的应说明理由并委托相应工作人员 ⭐；
6. 经过听证的案件，复议机关应**根据听证笔录**和审查认定的事实证据作出决定。

### 7. 简易程序 ⭐
事实清楚、权利义务关系明确、争议不大的下列案件可适用：
1. 被申请复议的行为是**当场作出**；
2. 被申请的行政行为是**警告或者通报批评**；
3. 案件涉及款额 **3000 元以下**；
4. 属于**政府信息公开**案件。
除上述外，**当事人各方同意**适用的，也可以适用。

## 五、行政诉讼 ⭐⭐⭐

### 1. 概念
公民、法人或其他组织认为**行政主体**的行政行为侵犯其合法权益，向法院起诉，由法院**对被诉行政行为进行审理并裁判**。

### 2. 级别管辖 ⭐⭐

| 法院 | 管辖一审案件 |
| --- | --- |
| **基层法院** | **原则**上管辖一审行政诉讼 |
| **中级法院** | ①对**国务院部门**或者**县级以上地方人民政府**所作行政行为提起诉讼的案件 ⭐；②**海关**处理的案件；③本辖区内**重大、复杂**案件；④其他法律规定由中院管辖的 |
| **高级法院** | 辖区内重大、复杂案件 |
| **最高法院** | 全国范围内重大、复杂案件 |

### 3. 地域管辖 ⭐⭐⭐

| 规则 | 内容 |
| --- | --- |
| 一般规定 | **原告就被告**——由**最初作出行政行为的行政机关所在地**法院管辖 |
| 经复议案件 | **最初作出行为的机关所在地** 或 **复议机关所在地**法院均可（选择）⭐ |
| 涉及**不动产** | 由**不动产所在地**法院管辖（专属）⭐ |
| 对**限制人身自由**的行政强制措施不服 | 由**被告所在地或原告所在地**法院管辖；原告所在地包括**户籍地、经常居住地、被限制人身自由地** ⭐⭐ |
| 选择管辖 | 两个以上法院都有管辖权 → 原告可**选择其一**；向两个以上起诉的 → 由**最先立案**的法院管辖 |

> 课件案例（限制人身自由）：甲户籍新泰市、经常居住地顺义区，在朝阳区醉酒裸奔，被朝阳区公安分局在海淀区约束至酒醒 → 可选管辖法院：被告（朝阳区公安分局）所在地**朝阳区** + 原告所在地**新泰市（户籍）、顺义区（经常居住地）、海淀区（被限制人身自由地）**。
>
> 课件案例（复议后被告与管辖）：县公安局罚款 100 元，经县政府复议——①**复议维持**：县公安局和县政府为**共同被告**（"双被告"⭐），管辖可选最初机关或复议机关所在地法院；②**复议改变**：**复议机关（县政府）**为被告；③**复议不作为**（逾期不答复）：告原行为 → 县公安局为被告；告复议不作为 → 县政府为被告。

### 4. 举证责任与起诉期限 ⭐⭐⭐
- **被告对作出的行政行为负举证责任**，应提供作出该行为的**证据和所依据的规范性文件**；诉讼中**被告及其诉讼代理人不得自行向原告、第三人和证人收集证据** ⭐。
- 起诉期限：
  - **直接起诉**：自知道或应当知道作出行政行为之日起 **6 个月内**（法律另有规定除外）；
  - **复议后起诉**：不服复议决定 → 收到复议决定书之日起 **15 日内**起诉。

> 数字对比记忆：复议申请 **60 日** → 复议后起诉 **15 日**；直接起诉 **6 个月**；民事诉讼时效 **3 年**。

### 5. 审理原则 ⭐⭐

| 制度 | 内容 |
| --- | --- |
| **公开审判** | 公开审理，涉**国家秘密、个人隐私**和法律另有规定的除外；涉**商业秘密**的案件，**当事人申请**不公开审理的，可以不公开 ⭐ |
| **回避制度** | 适用于**书记员、翻译人员、鉴定人、勘验人** |
| **诉讼不停止执行** | 起诉期间不停止被诉行政行为的执行 |
| **不适用调解** ⭐ | 行政诉讼**原则上不适用调解**（行政赔偿、补偿及行政机关行使自由裁量权的案件可以调解）——与**行政复议可以调解**对比记忆 |

## 真题演练

「考」2025 国考（**不在**复议范围内）：A 吊销许可证（行政处罚）可复议；B 许可申请因材料不全被拒绝可复议；C **公务员降职属内部人事处理，只能申诉，不能复议** → 选 **C**；D 不予受理工伤认定可复议。

「考」2025 国考（交警当场罚款 200 元、记 9 分）：A **错**——对**当场作出的行政处罚**不服属于**复议前置**情形，不能直接起诉 ⭐；B 错——交警大队行为，复议机关应为**该县公安局或本级政府**方向（按新复议法由**县级以上地方人民政府**统一管辖，即该县人民政府），不是县公安局自己；C 错——当场作出 + 款额 3000 元以下，**可以**适用简易程序；D **对**——行政复议**可以调解** → 选 **D**。
