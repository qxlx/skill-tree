## 一、民法总则

### （一）民法概述
- **概念**：民法是调整**平等主体**的自然人、法人和非法人组织之间的**人身关系和财产关系**的法律规范的总和。

### 民法的基本原则 ⭐

| 原则 | 内容 |
| --- | --- |
| 民事权益受法律保护 | 人身权利、财产权利及其他合法权益受法律保护，**任何组织或个人不得侵犯** |
| 平等原则 | 民事主体在民事活动中的**法律地位一律平等** |
| 自愿原则 | 按照**自己的意思**设立、变更和终止民事法律关系 |
| 公平原则 | **合理确定**各方的权利和义务 |
| 诚信原则 | 秉持诚实，**恪守承诺** |
| 守法与公序良俗原则 | 不得违反法律，**不得违背公序良俗** |
| 绿色原则 | 应有利于**节约资源、保护生态环境** |

### （二）自然人

#### 1. 民事权利能力
- **从出生时起到死亡时止**，具有民事权利能力。
- **涉及遗产继承、接受赠与等胎儿利益保护的，胎儿视为具有民事权利能力**；但胎儿娩出时为死体的，其民事权利能力**自始不存在**。⭐
- 自然人的民事权利能力**一律平等**。

> 课件举例：丙车祸去世时妻子丁怀孕，问丙遗产如何分配？（考点：胎儿视为具有权利能力，应保留继承份额）

#### 2. 民事行为能力 ⭐⭐（必背表格）

| 类型 | 判断标准 | 能否独立实施民事法律行为 |
| --- | --- | --- |
| **完全行为能力人** | 年龄 **≥18**；或 **≥16 且以自己的劳动收入为主要生活来源**，并且可以辨认自己行为 | **可以**独立实施 |
| **限制行为能力人** | **8 ≤ 年龄 ＜18**；或**不能完全**辨认自己行为 | 可独立实施**纯获利益**的或**与其年龄、智力相适应**的行为；超越范围的由法定代理人代理或经其**同意、追认** |
| **无行为能力人** | 年龄 **＜8**；或**不能**辨认自己行为 | 由**法定代理人代理**实施 |

> 课件举例：超哥 7 岁受赠口琴（纯获利，有效）、9 岁受赠钢琴（有效）、12 岁赠村花 2 万元戒指（超出年龄智力，需法定代理人追认）、13 岁写遗嘱（**遗嘱无效**，遗嘱须完全/限制行为能力且有相应能力，无行为能力人所立遗嘱无效）。

### （三）诉讼时效

#### 1. 概述
- 概念：权利人在法定时效期间内**不行使权利**，期间届满时，**债务人获得诉讼时效抗辩权**。
- **一般诉讼时效期间：3 年** ⭐。起算点：自权利人**知道或者应当知道**权利受到损害**以及义务人**之日起计算。
- 例外起算 ⭐：
  1. 无/限制民事行为能力人**对其法定代理人**的请求权 → 自**法定代理终止**之日起算；
  2. **未成年人遭受性侵害**的损害赔偿请求权 → 自受害人**年满 18 周岁**之日起算；
  3. 同一债务**分期履行** → 自**最后一期**履行期限届满之日起算。

> 案例 1：2020-1-31 到期借款 20 万一直未还、从未主张 → 时效 2023-1-31 届满，超哥起诉时璐璐可提时效抗辩。
> 案例 2：冰哥持续发帖骂超哥（侵权行为持续状态）→ 时效尚未起算/可主张停止侵害。

#### 2. 诉讼时效的中止与中断 ⭐⭐

| | 中止 | 中断 |
| --- | --- | --- |
| 规定 | 时效**最后 6 个月内**出现法定事由不能行使请求权 → **暂停**计算，原因消除之日起**满 6 个月**届满 | 时效进行中因**权利人行使权利** → 已进行期间**全部归零**，**重新计算** |
| 事由 | ①**不可抗力**；②无/限制行为能力人无法定代理人或法定代理人死亡、丧失行为能力、丧失代理权；③继承开始后**未确定继承人或遗产管理人**；④权利人被义务人或他人控制；⑤其他障碍 | ①权利人**向义务人提出履行请求**；②义务人**同意履行义务**；③权利人**提起诉讼或申请仲裁**；④与起诉、仲裁同等效力的其他情形 |

记忆：**中止=客观障碍"暂停键"（最后6个月内才生效）；中断=主观主张权利"重置键"**。

> 案例（中止）：2023-1-1 超哥刚要出门讨债被冰哥绑架至 2023-6-1（处于时效最后 6 个月内 + 权利人被控制）→ 时效中止，自获救起再满 6 个月（2023-12-1）时效届满。
> 案例（中断）：2021-7-1 发微信催款、2021-12-31 璐璐表示一定还钱、2022-7-1 起诉——每次均中断，时效重新起算，起诉在时效内。

#### 3. 不适用诉讼时效的情形 ⭐⭐⭐
1. 请求**停止侵害、排除妨碍、消除危险**；
2. **不动产物权和登记的动产物权**的权利人请求**返还财产**；
3. 请求支付**抚养费、赡养费或者扶养费**；
4. 依法不适用的其他请求权。
- **人民法院不得主动适用**诉讼时效的规定。
- 时效的期间、计算方法及中止中断事由**由法律规定，当事人约定无效**；**预先放弃**时效利益无效。

「考」2024 国考：①拆除妨碍通行的围墙（排除妨碍）②修复可能致儿童坠落的下水道（消除危险）③要求占用名下房屋者搬离（不动产登记物权返还财产）均不适用时效；④专利使用费适用。→ 选 **D.①②③**

「考」2022 事业单位联考（选错误）：A"满十六周岁便可以独立实施民事法律行为"——**错误**，须 16 周岁以上且以自己劳动收入为主要生活来源。→ 选 **A**

## 二、物权

### （一）概念和类型 ⭐
- **物权**：权利人依法对特定的物享有**直接支配和排他**的权利。

| 类型 | 含义 | 举例 |
| --- | --- | --- |
| **所有权** | 对自己的财产占有、使用、收益、处分 | **最充分、最完整的物权** |
| **用益物权** | 对**他人所有**的不动产或动产，占有、使用、收益 | 建设用地使用权、宅基地使用权、土地承包经营权、地役权、**居住权** |
| **担保物权** | 以支配交换价值、确保债权实现为目的 | **抵押权、质权、留置权** |

### （二）物权的公示 ⭐⭐
- **不动产**：设立、变更、转让和消灭，**经依法登记发生效力**；未经登记不发生效力（法律另有规定除外）。
- **动产**：设立和转让，**自交付时发生效力**（法律另有规定除外）。

> 案例 1：甲"一房二卖"——乙签约付款但未过户，丙后签约且**已过户** → **房屋归丙**（登记生效）；乙只能向甲主张违约责任。
> 案例 2：法院判决房子归乙，**判决于 5 月 1 日生效时乙即取得所有权**（法律文书导致物权变动，自文书生效时发生效力，无需登记）；5 月 5 日过户只是处分前提。

### （三）所有权
- 所有权人对自己的不动产或动产依法享有**占有、使用、收益和处分**的权利。
- **专属于国家所有**的财产 ⭐：**矿藏、水流、海域、无居民海岛、城市的土地、无线电频谱资源、国防资产**。

### 善意取得 ⭐⭐⭐

| 项目 | 内容 |
| --- | --- |
| 概念 | **无权处分人**转让标的物给**善意第三人**时，第三人一般可取得所有权，原权利人不得请求返还 |
| 构成要件 | ①出让人**无权处分**；②受让人受让时**善意**；③以**合理价格**转让；④应登记的**已登记**、不需登记的**已交付**（公示完成） |
| 效力 | 原所有权人有权向**无处分权人**请求损害赔偿 |
| **不适用** | **盗赃物、遗失物、埋藏物**一般不适用善意取得 ⭐ |

> 案例：①甲托乙保管手机，乙市价卖给不知情丙并交付 → **丙善意取得**；②甲手机**遗失**被乙捡到卖给丙 → **遗失物不适用**，甲可追回。

### 拾得遗失物
- 权利人**有权追回**遗失物。
- 拾得人应当**返还权利人**，及时通知领取或送交公安等部门；部门不知道的应发布招领公告。
- **自发布招领公告之日起 1 年内无人认领的，归国家所有**。⭐

### （四）居住权 ⭐
- 概念：按合同约定对**他人住宅**享有**占有、使用**的**用益物权**，满足生活居住需要。
- 设立：①**书面形式**合同（也可遗嘱设立）；②**无偿设立**（另有约定除外）；③**自登记时设立** ⭐。
- 变更消灭：**不得转让、继承**；设立的住宅**不得出租**（另有约定除外）；期限届满或**居住权人死亡**消灭，应办注销登记。

### （五）担保物权 ⭐⭐

| 权利 | 对象 | 成立条件 |
| --- | --- | --- |
| **抵押权** | 不动产 | 有效合同 **+ 登记** |
| | 动产 | 有效合同 |
| **质权** | 动产 | 有效合同 **+ 交付** |
| **留置权** | 动产 | 合法占有 + 债权已届清偿期 + 同一法律关系 |

「考」2025 国考（所有权取得，选正确）：A 拾得遗失物未取得所有权，错；B 自行车系卖家**借来**（无权处分），乙以市价善意受让并交付 → **善意取得，正确**；C 继承取得物权自继承开始时生效，无需登记，错；D 承包取得的是土地承包经营权（用益物权），所有权归集体，错。→ 选 **B**

## 三、合同

### （一）概述
- 合同是**平等主体**之间设立、变更、终止民事权利义务关系的**协议**。
- **婚姻、收养、监护等身份关系协议**，适用身份关系法律规定；无规定的可参照适用合同编。
- 形式：**书面、口头和其他形式**。

### （二）合同的成立 ⭐

| 概念 | 要点 |
| --- | --- |
| **要约** | **希望与他人订立合同**的意思表示：①内容明确具体；②表明要约人受约束 |
| **要约邀请** | 希望他人向自己发出要约：拍卖公告、招标公告、招股说明书、债券募集办法、基金招募说明书、商业广告和宣传、寄送的价目表等；**商业广告内容符合要约条件的，构成要约** |
| **承诺** | 受要约人**同意要约**的意思表示：①期限内发出；②内容与要约一致；③**承诺生效时合同成立** |

### （三）合同的担保 ⭐⭐

| 方式 | 规则 |
| --- | --- |
| **违约金** | 约定违约时支付一定数额或损失赔偿计算方法 |
| **定金** | 给付定金方不履行 → **无权请求返还**；接受定金方不履行 → **双倍返还**（定金罚则） |
| 关系 | **定金罚则与违约金不可同时适用**，既约定定金又约定违约金的，**择一适用** ⭐ |

### （四）合同的解除
- **约定解除**：协商一致可解除；可约定解除事由。
- **法定解除** ⭐：①**不可抗力**致使不能实现合同目的；②履行期届满前一方**明确表示或以行为表明不履行主要债务**；③一方**迟延履行主要债务，经催告后合理期限内仍未履行**；④迟延履行或其他违约行为**致使不能实现合同目的**；⑤法律规定的其他情形。
- 以持续履行的债务为内容的**不定期合同**，可**随时解除**，但应在合理期限前通知对方。

### （五）违约责任
承担方式：**实际履行、采取补救措施（修理重作更换）、赔偿损失、支付违约金、继续履行**。

> 情势变更（课件补充）⭐：合同基础条件发生订约时**无法预见、不属于商业风险**的重大变化，继续履行明显不公平的 → 先重新协商；协商不成可**请求法院或仲裁机构变更或解除**。

「考」2025 国考（甲主张最可能被支持）：A 现场拍卖**落槌时合同成立**——正确；B 仅表达合作意向的备忘录不构成预约合同；C 格式条款仅勾选提示，未尽到显著提示义务；D 合同可撤销≠以已登记为由主张有效。→ 选 **A**

「考」2018 事业单位联考：房贷政策收紧致无法贷款 → 属**情势变更**（非不可抗力），乙可请求法院**变更或解除合同** → 选 **A**。

## 四、人格权 ⭐

| 权利 | 核心要点 |
| --- | --- |
| **生命权** | 生命安全和**生命尊严**受法律保护 |
| **身体权** | **身体完整和行动自由**；侵权方式：破坏完整性/完满性、侵害活动自由。**器官捐献**：**完全民事行为能力人**可依法自主决定**无偿**捐献，须**书面形式**（可立遗嘱）；生前未表示不同意的，死后由**配偶、成年子女、父母共同决定**；**禁止买卖**人体细胞、组织、器官、遗体（买卖无效） |
| **健康权** | 身心健康受保护；致生理/心理机能不能正常发挥即构成侵害 |
| **姓名权/名称权** | 自然人：决定、使用、变更、许可他人使用姓名（不得违背公序良俗）；法人、非法人组织：名称权还可**转让**。禁止**干涉、盗用、假冒** |
| **肖像权** | 制作、使用、公开、许可使用自己肖像；侵权：**丑化、污损**或以**信息技术手段伪造**（如AI换脸）；未经同意不得制作、使用、公开。**对自然人声音的保护，参照适用肖像权规定** ⭐ |
| **名誉权** | 禁止以**侮辱、诽谤**侵害；名誉=品德、声望、才能、信用等的**社会评价**（一般评价） |
| **荣誉权** | 不得非法**剥夺荣誉称号**，不得诋毁、贬损荣誉（荣誉=机关按程序作出的**正式积极评价**） |
| **隐私权** | 禁止以**刺探、侵扰、泄露、公开**侵害；隐私=私人生活安宁 + 不愿为他人知晓的**私密空间、私密活动、私密信息** |
| **个人信息** | 受法律保护：姓名、出生日期、身份证件号码、生物识别信息、住址、电话号码、电子邮箱、健康信息、行踪信息等 |

「考」2025 江苏省考：张某在业主群讨债并在公告栏、电梯间张贴判决书 → 讨债本身不侵权，但公开判决书中的私密信息 → **侵犯隐私权**，选 **C**。

「考」2016 山东省考：影楼未经同意将个人写真印在宣传册（营利用途，不属于合理使用情形）→ **侵犯肖像权**，选 **D**。（寻亲广告、学校宣传获奖、报社刊登公务活动均符合合理使用）

「考」2020 事业单位联考（不属于侵犯隐私权）：B 孙某**模仿**上司神态语气拍视频——未公开他人私密信息，不侵犯隐私权（可能涉肖像/名誉但非隐私）。→ 选 **B**

## 五、婚姻家庭

### （一）结婚条件及效力 ⭐

| 项目 | 内容 |
| --- | --- |
| 结婚条件 | ①法定婚龄：**男 ≥22，女 ≥20**；②不得重婚；③不得有禁止结婚的亲属关系 |
| **无效婚姻** | ①重婚；②有禁止结婚的亲属关系；③未到法定婚龄 |
| **可撤销婚姻** | ①**因胁迫**结婚；②一方**患有重大疾病婚前未如实告知** ⭐ |

### （二）夫妻财产制度 ⭐⭐⭐

| 夫妻共同财产 | 夫妻一方个人财产 |
| --- | --- |
| ①工资、奖金、劳务报酬 | ①**一方的婚前财产**（含婚后产生的**孳息和自然增值**） |
| ②生产、经营、投资的收益 | ②一方因**人身损害获得的赔偿或补偿** |
| ③**知识产权的收益**（婚内实际取得或已明确可取得的财产性收益） | ③遗嘱或赠与合同中**确定只归一方**的财产 |
| ④继承或受赠的财产（遗嘱/赠与合同确定只归一方的除外） | ④**一方专用的生活用品** |
| ⑤其他应归共同所有的财产 | ⑤**军人的伤亡保险金、伤残补助金、医药生活补助费** |

补充规定（民法典婚姻家庭编司法解释要点）：
- **同居析产**：各自所得归各自；共同出资购置或共同生产经营收益，以出资比例为基础，综合考虑共同生活、有无共同子女、贡献大小分割。
- **婚前/婚内约定赠与房屋未过户**：离婚诉讼时法院可综合婚姻存续时间、共同生活及孕育子女情况、离婚过错、贡献、房屋市价等判决归属并确定补偿。
- **直播打赏**：一方擅自用共同财产打赏**明显超出家庭一般消费水平** → 另一方可请求**婚内分割共同财产**，或离婚时请求对打赏方**少分或不分** ⭐。
- **父母婚后出资购房**：一方父母**全额出资**且无明确约定只赠自己子女的，离婚分割时可判归出资人子女一方并酌情补偿；**部分出资/双方出资**的，以出资来源及比例为基础综合判决归属并合理补偿。
- **彩礼返还** ⭐：
  - 应当返还：**未缔结婚姻**（未登记或未共同生活）、**借婚姻索取财物**；
  - 酌情返还：未登记但已共同生活；已登记但共同生活时间短；婚前给付导致给付人**生活困难**；
  - 不予返还：**已登记结婚且长期共同生活**。

### （三）离婚

#### 1. 协议离婚 ⭐
条件：①自愿离婚意思表示；②对子女抚养、财产、债务处理协商一致；③**亲自**到婚姻登记机关申请。
**冷静期 30 日**：自收到申请之日起 30 日内任何一方可撤回；**期满后 30 日内**双方应亲自申请发离婚证，未申请的**视为撤回**。

#### 2. 诉讼离婚 ⭐⭐
法院应**先调解**；感情确已破裂、调解无效的应准予离婚。法定情形：
1. **重婚或与他人同居**；2. **实施家庭暴力**或虐待、遗弃家庭成员；3. 有**赌博、吸毒**等恶习屡教不改；4. 因感情不和**分居满 2 年**；5. 其他导致感情破裂情形。
- 一方**被宣告失踪**，另一方起诉 → 应准予离婚。
- **判决不准离婚后又分居满 1 年**，再次起诉 → 应准予离婚。

#### 3. 离婚补偿与离婚赔偿 ⭐

| 离婚补偿 | 离婚赔偿（无过错方请求损害赔偿） |
| --- | --- |
| 一方因**抚育子女、照料老年人、协助另一方工作**等负担较多义务，离婚时有权请求补偿 | ①重婚；②与他人同居；③实施家庭暴力；④虐待、遗弃家庭成员；⑤**有其他重大过错** |

「考」2025 公务员联考（新疆卷）：A 妻子自行流产不构成侵犯生育权赔偿；B 已登记且未共同生活？——"一天也没回家住过"实际未共同生活，可主张返还彩礼，法院支持；C 婚内转让专利收入属共同财产；D 已约定归女儿个人所有。→ 选 **B**

| 顺序 | 继承人范围 |
| --- | --- |

## 七、侵权责任 ⭐⭐（归责原则是核心考点）

### 1. 非法使被监护人脱离监护
- 监护人可请求为恢复监护状态支出的合理费用等财产损失赔偿；致亲属关系严重损害的认定为**严重精神损害**；被监护人脱离监护期间死亡的，可同时主张人身损害与监护关系侵害损失。

### 2. 监护人责任 —— **无过错责任**
- 原则上由监护人承担；**有财产的**无/限制行为能力人造成损害，**先从本人财产支付**，不足部分由监护人赔偿（应保留必要生活费和义务教育费用）。
- 夫妻离婚后未成年子女侵权：离异双方**共同承担**，不以未共同生活为由减责；内部份额可协议，协议不成按履行监护职责情况确定。
- **未与子女形成抚养教育关系的继父/继母不承担**，由生父母承担。
- 受托履行监护职责的人：监护人承担全部责任；**受托人在过错范围内与监护人共同承担**，总赔偿不超出应受偿损失。

### 3. 无/限制民事行为能力人在教育机构受损 ⭐⭐⭐
- 归责原则：**无民事行为能力人（不满 8 周岁）→ 过错推定**；**限制民事行为能力人 → 一般过错**。
- 责任主体：学校、幼儿园或其他教育机构。
- **第三人**致害：第三人担责；教育机构未尽管理职责的承担**补充责任**，**补充后可向第三人追偿**。

### 4. 用工责任 —— **无过错**
- **单位用工**（劳动关系）：对外由**用人单位**担责；对内可向**有故意或重大过失**的工作人员**追偿**。
- **劳务派遣**：实际用工单位承担无过错责任；派遣单位**有过错的承担相应责任**。

### 5. 安保义务人责任 —— **一般过错**
- 主体：商场、娱乐场所、宾馆、银行、车站等**公共场所管理人或群众性活动组织者**（不以有交易关系为必要）。
- 第三人侵权：第三人担责；安保义务人有过错的在过错范围内承担**补充责任**，**承担后可向第三人追偿**。

### 6. 产品责任 —— **无过错**
- 被侵权人**可以向生产者或销售者任一方**请求赔偿（不真正连带）。
- 缺陷由生产者造成 → 销售者赔偿后**可向生产者追偿**；因销售者过错使产品有缺陷 → 生产者赔偿后**可向销售者追偿**。

### 7. 饲养动物损害责任 ⭐⭐

| 动物类型 | 归责原则 | 责任主体 | 免责事由 |
| --- | --- | --- | --- |
| 一般动物 | **无过错** | 饲养人或管理人 | **烈性犬：无免责事由**；无安全措施的动物：仅受害人**故意（减轻）**；有安全措施的动物：受害人**故意（免责）**、**重大过失（减轻）** |
| **动物园** | **过错推定** | 动物园 | 受害人故意、重大过失 |

### 8. 高空抛物责任 ⭐⭐
- **能确定侵权人**：侵权人担责（**过错推定**）。
- **不能确定侵权人**：除能证明自己不是侵权人的外，由**可能加害的建筑物使用人给予补偿**（**公平责任**），补偿后有权向侵权人追偿。
- **物业**：未采取必要安全保障措施的，承担未履行安保义务的侵权责任（**一般过错**）。

### 9. 环境污染和生态破坏责任 —— **无过错 + 举证责任倒置、因果关系推定** ⭐
- 生态环境损害赔偿范围：服务功能丧失损失、永久性损害损失、调查评估费、清除修复费、防止损害扩大的合理费用。
- **故意**污染环境、破坏生态造成严重后果的 → **惩罚性赔偿**。

### 10. 机动车侵权责任 ⭐⭐

| 情形 | 规则 |
| --- | --- |
| 机动车 vs 非机动车、行人 | 机动车一方**无过错责任**。免责/减责：①对方有过错按程度**减轻**；②机动车方**无过错的承担不超过 10%**；③损失系对方**故意碰撞（碰瓷）**造成 → **不承担**赔偿责任 |
| 机动车之间 | **过错责任**，按各自过错比例分担 |
| **好意搭乘** | 非营运机动车无偿搭乘人受损，属本方责任的**应当减轻**其赔偿责任，但机动车使用人有**故意或重大过失**的除外 |

「考」2024 江苏省考：甲无证驾驶，乙无偿搭顺风车，甲急刹致乙受伤。甲无证存在重大过失？——甲因接打电话急刹（一般过失），可适用好意同乘**减轻**责任？关键：甲**未取得驾驶证**仍上路，属重大过错风险 → 标准答案 **B（甲应当承担侵权责任）**，好意搭乘前提是合法驾驶，且"应当减轻"非"免除"；A 错在"不承担"，C 错在甲无证不满足减责保护初衷，D 无据。

「考」2023 山东省考（化工厂排污）：A 错（无过错责任，达标也担责）；B 错（一般时效 3 年）；C 错（环境污染由**排污者就法律规定的免责事由及因果关系不存在承担举证责任**——举证倒置）；D **对**（不可抗力是免责事由）。→ 选 **D**

「考」2022 山东省考：A 错（张某作为监护人仍担责，受托人肖某按过错共同承担）；B **对**（产品责任可直接向销售者索赔）；C 对（有安全措施的动物因受害人故意挑逗可免责）——按课件要点 B、C 均有依据，真题答案为 **B**。D 错（蔡某能证明自己不是侵权人 → **不补偿**）。→ 选 **B**
