### 各朝代详解

#### 夏朝

**中国古代第一个国家政权**（公天下代替家天下）；出现青铜器。河南洛阳**二里头**文化遗址为夏朝中晚期都城遗址。

- **禹死启继**
- **鸣条之战**（商汤灭夏桀）

天下九州  冀、豫、雍、徐、青、扬、梁、兖、荆

方便记忆：鲫鱼用须，清扬两眼睛



#### 商朝

**甲骨文成熟**；青铜铸造技艺成熟，产生了**后母戊鼎**、**四羊方尊**、**人面纹铜鼎**等杰出青铜器；**职业商人和贝币**出现；**牧野之战**，商纣王军队临阵倒戈。

- **商汤**（亳州）
- **盘庚迁都**（殷）
- **武丁中兴**（殷）
- **牧野之战**（武王伐纣）

#### 西周（长）

实行**井田制**、**宗法制**、**礼乐制**；**周幽王烽火戏诸侯**。

- **周武王**（镐）
- **营造洛邑**
- **周厉王**（国人暴动）
- **周幽王**（烽火戏诸侯）

#### 东周 — 春秋

**春秋五霸**（**齐桓公**、宋襄公、**晋文公**、秦穆公、**楚庄王**）；**铁农具和牛耕**出现；**老子创立道家**，**孔子创立儒家学派**；鲁国"初税亩"承认土地私有；《春秋》关于**哈雷彗星**最早记录。

另一种说法是齐桓公、晋文公、楚庄王、吴王阖闾、越王勾践，出自《荀子》。

#### 东周 — 战国

**战国七雄**（齐、楚、燕、韩、赵、魏、秦）；**百家争鸣**；**商鞅变法**；**长平之战**，秦国坑杀40余万赵军；**司南**出现；《甘石星经》；**扁鹊四诊疗法**。

#### 秦朝

施行**三公九卿制**，地方施行**郡县制**；**统一文字**（小篆）、**货币**、**度量衡**（度计量长短，量计算容积，衡测量轻重）、**车轨**；修筑**长城**；北击**匈奴**（蒙恬）；**焚书坑儒**。

- **统一**
  - 政治：皇权VS相权 / 中央VS地方
  - 军事：击匈奴 / 修长城
  - 经济：度量衡、车轨
  - 文化：文字、焚书坑儒

#### 楚汉相争

**大泽乡起义** → **秦朝灭亡** → **楚汉相争** → **乌江自刎**

#### 西汉

汉初盛行黄老"**无为而治**"，开创**文景之治**；**汉武帝罢黜百家、独尊儒术**（董仲舒），设立乐府，收集民间诗歌；**卫青、霍去病、李广抗击匈奴**；**盐铁专卖**；**张骞出使西域**，开辟**丝绸之路**（从长安经河西走廊、今新疆地区，通往中亚、西亚，直到欧洲）；葡萄、石榴、苜蓿、胡豆、胡麻、胡瓜、胡桃、大蒜等传入内陆；第一部较完整的历书《太初历》；最早农书《氾胜之书》；设立**西域都护府**，新疆归中央管辖；出现**造纸术**；**佛教传入**。

- 刘邦称帝
- **文景之治**
- **汉武盛世**
  - 军事：击匈奴
  - 文化：独尊儒术
  - 人、钱、马
- **王莽篡汉**

#### 东汉

定都**洛阳**；**光武中兴**；**蔡伦改进造纸术**；**道教产生**；**张衡对月食做出了最早科学解释**；**官渡之战**；**赤壁之战**。

- **光武中兴**   刘秀（洛阳）
- **黄巾起义**
- **官渡之战**（统一北方）
- **赤壁之战**（三分天下）

#### 三国两晋南北朝

**建安文学**；**王羲之天下第一行书《兰亭序》**；**北魏孝文帝改革**；**玄学盛行**。

- 魏、蜀、吴
- 魏（曹）
- **杨坚**（隋朝）

#### 隋朝

**隋文帝开皇之治**；隋朝开创**科举制**，开凿**京杭大运河**；**三省六部制**。

- **开皇之治**（杨坚）
- **二世而亡**（杨广）

#### 唐朝

**李渊**次子**李世民**发动**玄武门之变**，登基为**唐太宗**；抗击**突厥**（李靖、薛仁贵）；**文成公主入藏**；**武则天**增设武举、殿试；**安史之乱**；**火药产生**；**唐三彩**盛行；**玄奘西行**撰《大唐西域记》；**鉴真东渡**；出现最早雕版印刷作品《金刚经》。

- **唐高祖**（李渊）
- **玄武门之变**
- **贞观之治**
- **贞观遗风**
- **开元盛世**
- **安史之乱**
- **黄巢起义**

#### 北宋

**陈桥兵变**，**黄袍加身**；**澶渊之盟**；出现最早纸币"**交子**"；**毕昇发明活字印刷术**；**水运仪象台**；**王安石变法**；**司马光编《资治通鉴》**；打破坊市制度，**早市、夜市**出现。

- **陈桥兵变**
  - **黄袍加身**
  - **杯酒释兵权**
  - **赵匡胤**（宋太祖）

- **澶渊之盟**
- **靖康之耻**

#### 南宋

理学集大成者**朱熹**；**陆九渊**；**棉纺织业兴起**，棉布逐渐代替了麻布，成为主要衣被原料。

- **赵构**
  - **迁都临安**

- **绍兴和议**
- **文天祥抗元**
- **崖山海战**（陆秀夫）

#### 元朝

**行省制**是中国省制的开端；设**宣政院**管理全国佛教事务和西藏地区的行政事务，**西藏成为元朝正式的行政区**；设**澎湖巡检司**，负责管辖澎湖和台湾；《授时历》年周期与现行公历同，但早于现行公历300年问世；第一部由政府颁布的指导农业生产的技术理论书籍《农桑辑要》。

#### 明朝

废丞相，设三司；最大一部类书《永乐大典》；**明成祖（朱棣）**派**郑和七下西洋**；**明世宗（嘉靖）**派**戚继光抗倭**；**郑成功打败荷兰殖民者，收复台湾**；地理学巨著《徐霞客游记》；引进**玉米、番薯、西红柿、花生、辣椒、土豆、木瓜、烟草**等农作物。

- **朱元璋**
  - **建都应天**

- **靖难之役**
- 郑和下西洋
- **李自成攻陷北京 崇祯煤山上吊**
- **郑成功收复台湾**

#### 清朝

在西藏设置**驻藏大臣**；设置**伊犁将军**管辖新疆地区。**康熙**派**施琅**率兵攻取台湾，次年正式设**台湾府**，隶属福建省。

- **顺治**（入关进京）
- **康熙**（平三藩）→ 收台湾
- **雍正** → 驻藏大臣
- **乾隆** → 伊犁将军

### 朝代更替填空

**【填空题】**

- 夏朝 → _________ → 周朝（西周、东周：______ → 战国）
- 秦朝 → _________ → _________
- 三国（魏、蜀、吴）→ 西晋 → 东晋 → 南北朝
- 隋朝 → _________ → 五代十国
- 宋朝（______、南宋）→ _________ → 明朝 → 清朝

**【答案】**

- 夏朝 → **商朝** → 周朝（西周、东周：**春秋** → 战国）
- 秦朝 → **西汉** → **东汉**
- 三国（魏、蜀、吴）→ 西晋 → 东晋 → 南北朝
- 隋朝 → **唐朝** → 五代十国
- 宋朝（**北宋**、南宋）→ **元朝** → 明朝 → 清朝
